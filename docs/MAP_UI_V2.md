## 1. 版式总览

```
┌─────────────────────────────────────────────┬──────────────────┐
│ HUD（常驻）                                  │                  │
├─────────────────────────────────────────────┤  #mm-dock 右上   │
│                                             │  ┌────────────┐  │

├─────────────────────────────────────────────┤                  │

```

- **停靠容器 `#mm-dock`**：固定右上，`width: clamp(300px, 29vw, 420px)`、`height: clamp(260px, 52vh, 480px)`。
  1280×720 下实测 **371×374**（高 ≥260 ✓）。面板 `#minimap` 宽高 100% 填满父容器（`fillsDock=true`）。
- 三段布局 `[标题带 | 总图按钮] + [地图区] + [行程列表]`：标题带 22px、行程列表 `min-height:76px;
  max-height:42%`（超高内部滚动 `#mm-log-rows`，不撑破面板），**地图区吃掉全部剩余空间**。
- 地图区按容器像素 1:1 渲染（无 viewBox 缩放）：格子 `W/14 × H/rows`，生态底整面铺满 → **空白 0%**。
  - 常驻态（战斗等）实测：格子 **25.4×11.1px**、节点直径 **Ø9.2px**、图标字号 **11px**（DOM 计算值，
    由 `NewMap.debug.metrics()` 输出）。
  - 地图选择态（居中 `#mm-dock.centered`，min(620px,94vw)×min(76vh,620px)）实测：格子 **43×26.6px**、
    节点 **Ø22.4px**、字号 **20px**。
  - 窗口范围 = 焦点带 + 下一带（16 行）；点行程行可把窗口挪到任意已访问格所在带。

## 2. 总图（点「总图」打开）

- **真实比例渲染**：SVG 自然尺寸 376×1552px（14×64 格，格距 24px），容器 `#fm-svg` 高 min(70vh,780px)
  → 内容 1552 > 视口 503，**纵向滚动出现**。
- **三种滚动方式全可用**（实测 scrollTop 轨迹，截图 02→03）：
  | 方式 | 实测 |
  |---|---|
  | 滚轮 | 0 → 1049（一滚到底，原生滚动） |
  | 拖拽（指针按住内容拖） | 600 → 420（Δ=180px，与拖距一致；拖后 click 被 `data-dragged` 拦截，不误入格子） |
  | 滚动条 | → 900（原生 webkit 滚动条，样式已配色） |
- **缩放 0.6×–2×**：`− / + / 1:1` 按钮与 Ctrl+滚轮（以光标为锚）两条路，`fmSetZoom` 钳制 [0.6, 2]，
  缩放后仍可滚动：0.6× → SVG 225.6×931.2px（截图 04）；2× → 752×3104px（截图 05）。
- **D1–D8 深度线标签**：右缘 D 标签 + 虚线分带线；**当前所在带**标签红色加亮 + 整带淡色高亮罩。
- **关闭三法**：× 按钮 / Esc / 点背景层——三路实测均关闭（`#fullmap-layer.show` 移除）。
- 总图开着时走过格子会热刷新（迷雾随 visited 重算），滚动位置保留。

## 3. 行程列表（小图下方，新增）

每**已访问**格子一行，字段固定 `图标 | 格名 | 类型 | 收获 | 一行描述`，**最新在最上面**（`unshift`）。
无记录时显示灰字「还没走过任何格子」。超高时 `#mm-log-rows` 内部滚动。**点击某行 → 小图上对应格子
高亮**（`.fm-node.hl` 红圈，且窗口自动挪到该格所在带；再点一次取消）。

- **格名**：每生态 3 个地名池（管廊苔毯 / 冰帘回廊 / 冻井站台 / 震台旧驿…），按节点 id 哈希确定性取用，不耗 RNG。
- **收获**来自进格→到达的状态差分（金币/零件 Δ、生命 Δ、新牌按对象身份 diff）+ `grantRelic` 钩子取遗物名，
  自动覆盖战斗/事件/商店/营火全部来源。
- **描述**来自事件选项 `result_text` / `campfireResult` 文案 / 战斗结果（`击退 敌A、敌B`）/ 商店固定句。
- 实测 5 已访问格 → 5 行倒序（截图 01）：
  `✉ 管廊苔毯 遭遇 金币+30` → `⌂ 冰帘回廊 休整 得卡「一击·固」` → `⚔ 冻井站台 敌袭 金币+40·得卡「…」`
  → `✉ 冰帘回廊 遭遇 遗物「相石粉末」` → `❖ 锚地花田 起点`，每行带事件原文描述。
- 日志钩子以包装全局函数实现（`grantRelic / finishCombatFlow / chooseEventOption / campfireResult`），
  不改这些函数内部逻辑。
