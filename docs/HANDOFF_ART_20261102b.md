## 二、这一下午定下的两条新规则（最重要）

### 规则 VIII：不许写现实物种名

**用户观察**：提示词写现实里有的形象（蜘蛛、蜥蜴、鱼），模型直接调现实参考照着画；
换成没有现实对应物的形态描述，它才会自己造，效果好得多。

写法：不写「蜘蛛」，写「扁而宽、八条关节长腿向两侧张开、背覆短绒毛的节肢捕食者」。
要写清四件事：**几条腿或几个体节 / 体表什么质地 / 器官长在哪一侧 / 有没有壳**。

**两个坑（都踩过）**：
1. **不能字符串替换** —— 会造出「细长无足…的水生体身覆鳞、有鳍的水生体钩一样的爪」这种病句。必须整段重写。
2. **尾部会残留** —— 重写主体段后，光照段里「鳗鱼的下缘」这类还在。重写时要同步把「X的」改成「它的」。
   ★ 批量改时注意：正则只匹配到「鳗鱼」的后半个字会留残渣（出现「鳗它的」），要按长词优先匹配。

### 卡牌材质约束（防「一张纸」）

**症状**：卡名抽象（协议/评估/库存）时，模型退回最省事的「一张纸」；「运料车」这种词又直接触发现实物（画出一辆卡车）。

**约束**：
1. 主体只能是地底工业遗物：金属、骨、管线、玻璃、陶瓷、橡胶
2. 禁止纸张、单据、书本、现代电子产品、车辆、塑料瓶、机器人手臂
3. 抽象卡名要实物化：协议→刻满凹槽的金属铭牌；评估→带刻度的黄铜量规；库存→封了蜡的金属罐；
   运料→带铁轮的低矮钢制推斗
4. 主体占满画面中部约三分之二，四周不要大片空黑
