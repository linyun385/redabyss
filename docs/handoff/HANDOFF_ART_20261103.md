## 一、规则 XI：加一条排他约束，把万相从 3D 渲染拉回版画

### 怎么发现的

GLM 通宵做了 461 张质检，用户人工复核时打回 77 条，其中 **43 条理由写的是「质感不对」**。
先查提示词层面有没有差异：

| 检查项 | 打回组 | 采用组 |
|---|---|---|
| 含「占满画面中部」 | 64% | 76% |
| 含「是画面的主体」 | 52% | 72% |
| 含「石版画 / 细密排线」 | 100% | 100% |

**没有任何提示词层面的差异**。同批措辞、同样尾部，还是一半过一半不过。

### 真正的差异在图像上

对照 `trem_0001`（打回）与 `trem_0002`（采用）：

- 打回那张：金属高光、圆柱平滑明暗、景深虚化 → **像 3D 产品图**
- 采用那张：硬边轮廓、可见排线、非物理的纯红大色块 → **像版画**

结论：**「金属 / 光滑材质 + 强红光」会触发万相的写实渲染路径**，尾部那句
「整幅画用石版画的方式绘制：细密排线，深墨轮廓」压不住它。

### A/B 验证（10 张，91 秒，10/10 成功）

同一提示词出两版，只差一句约束：

- v2 原提示词：管子仍有白色高光、管身渐变，半写实
- v1 加约束：整张变版画，管身全是排线、红色平涂、地面碎石也用排线

**用户判定：「V1 是我要的」** → 约束进正式提示词。

### 约束句（已在 `data/zh_prompts_full.json` 里，461/461 条）

> 整幅画只用墨黑与血红两种色块，中间没有灰阶过渡；所有表面都是哑光的，
> 没有高光，没有反光，没有金属亮斑；形体只靠硬边轮廓和排线分开，不靠明暗塑形。

要点：万相不认负面词，所以所有限制都写成「是什么」。
备份：`zh_prompts_full.json.bak11`。工具：`tools/_apply_extra.py`（幂等，跑重复安全）。

### 遗留判断

加约束后**红色会偏亮一档**（灰阶被压掉，红的纯度反而上来）。
用户在 A/B 时看过，接受当前亮度；如果之后要更暗，加一句「红色压制到暗褐」即可。

## 二、挑选台（`tools/pick_studio.py`，端口 8770）

### 为什么要重写

旧 `art_studio.py` 读的是 `_manifest` 的 607 条**废弃清单**（`face_eco_*`、`card_zh2_*`），
缩略图路径全 404，提示词也是旧的。修补不如重来。

### 三态状态机（用户 2026-11-03 定）

| 用户操作 | 状态 | 显示 |
|---|---|---|
| 打回某一张 | 那张从卡片消失 | 仍留在「待定」 |
| 采用一张 | 整张卡片退出待定，其余候选一并收起 | 「已选」 |
| 打回后只剩一张没选 | 移出待定 | 「待重生成」 |

判定代码：

```python
alive = [v for v in versions if v not in rejected]
if chosen is not None:            state = 'done'
elif not alive:                   state = 'regen'    # 全打回
elif len(versions) >= 2 and len(alive) <= 1: state = 'regen'   # 多选一，剩最后一张没选
else:                             state = 'open'
```

**踩过的坑**：第一版写成 `len(alive) <= 1 → regen`，把「只有 v0 一张、备选还没生成」
的 263 条误判成待重生成。只有「本来有多张、被否到最后一张」才算。

### 接口

- `GET /` 页面；`GET /api/items` 461 条（含 `state` / `alive` / `chosen` / `rejected`）
- `GET /img/<id>/<版本>` 出图（v0 = 现用图，v1+ = `art/versions/<id>_vN.webp`）
- `POST /api/pick` 采用或打回（打回必须带理由）
- `GET /api/export_regen` → 写 `data/queue_regen.json`（待重生成队列）
