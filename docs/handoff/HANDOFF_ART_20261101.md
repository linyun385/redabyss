## 一、今天定下来的方向（已被用户认可，不要再改）

1. **具象优先**：怪物要像怪物、工具像工具、事件有场面；只有 BOSS/结局允许抽象。
2. **红渊化 = 异化语言 A/C 为主、B 点缀**
   - A 材料替代（盐晶、锈铁鳞、铜鳍、玻璃珠眼、骨白珊瑚…）
   - C 工艺寄生（铜线缝合、维修牌、刻编号、接管、锁链…）
   - B 器官错位（环形多眼、第二具小骨架、两张嘴…）少量使用
3. **两条核心世界规则（最高优先级）**
   - **倒吊**：红光自地核向上 → 生物/植物的取食与生长器官长在身体最下方；生物多倒挂天花板、攀附顶面
   - **红光自下而上**：光源在画面下方；越往深处红越浓（D1 几无红 → D8 近乎单色红）
4. **风格 = 铜版/石版印刷**，不是素描：`antique lithograph print on aged yellowed paper, paper grain, fine stipple, deep ink contours, muted ochre + soot, single vermilion accent`
5. **背景必须写死**（教训）：只说"红光从下往上"会让模型自行补出地平线/建筑/道具。生物类要写 `the stone ceiling / rock wall fills the whole background`，负面词禁 `landscape, horizon, sky, building, room interior, table, pot, vase`。

## 三、当前跑到哪

- **用户判定（23:13）：09、10 都不过；08 完全过关，作为基准样本**
  - 09 失败原因：太写实，像现实世界的蜘蛛；两张都有"地表感"（岩壁像山坡、有天光）
  - 08 成功原因：垂挂伞囊（无法对应地球物种）+ 地面红光染红下半部 + 无地平线/天空 + 铁罐等器物陪衬
  - **基准图：`art/_review/08_垂挂苔毯_v2.png`**；规则写进 `ART_PROMPT_SPEC.md` §一之三
- v6（21:20）结论存档：A3 偏写实不通过、B3 变成绒毛钟乳不通过
  - `art/_samples_v6/A3_inverted_spider.png`：岩壁背景锁住了、倒挂成立、红光偏朱、纸面颗粒在。
    仍有两处：①顶面读起来像"斜坡"而不是天花板，倒吊感靠腿撑；②嘴部/螯肢退化成一团黑。
  - `art/_samples_v6/B3_hanging_moss.png`：变成一团绒毛状钟乳，**没有生态结构**（丢了"群落"）。
  - 评审副本：`art/_review/09_倒挂跳蛛_v3.png`、`10_垂挂苔毯_v3.png`
- 定论：**岩壁背景 + 单主体 + 底光**这套组合对"有明确解剖结构的对象"有效（跳蛛）；
  对"没有固定形状的群体"（苔毯/菌落）失效 —— 这类需要改写成"具象的个体形态"再画
  （例：不是"一片苔毯"，而是"一株垂下来的苔，带伞状孢囊与根须"）。这条写进规范：
  **非动物类也必须给一个"可数的主体"**，不许用"一片/一丛/一层"这种集合名词。
- 用户评审副本：`art/_review/01..08`，新的按 `09_`/`10_` 续号

## 五、性能现实（别再纠结）

- 本机 RTX 4060 Laptop 8GB：512×752 / 20–24 步 **约 3–16 分钟/张**（波动大，与显存溢出/笔记本供电有关）
- 640×936 不可用（解码换页，190–737 秒）
- fp16 VAE **会输出全黑图**（已实测），必须用 fp32 VAE 或 fp16-fix VAE
- 一晚上（8 小时）现实产出 **30–60 张**，280 族需要多晚分批
