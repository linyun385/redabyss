## 0. 问题与结论

现状：开局牌库 = 引擎基础 10 张（一击×5 + 缩起×4 + 职业签名牌）+ **startRun 随机抽 6 张池牌**
（总 16 张，强弱不可控——可能开局就抽到 0 费抽牌链、全体伤害等滚雪球件）。

审计后：随机 6 张废除，改为**固定补位 2 张**（经强度分审计挑选），总 **12 张**（R4 达标）。
四职业 300 局胜率对照全部在 ±5pp 内（最大降幅 -3.0pp）。

## 1. 强度分（tools/card_power.js）

```
power = (单体伤害 + 格挡×0.8 + 抽牌×3 + 能量×4 + 全体伤害×1.6 + 附加效果估值)
        / 费用当量          # 费用当量 = 0 费按 0.5 计，其余 max(1, 费用)
```

附加效果估值表（脚本头注释同款，可调）：heal×1.0 / strength×2.5·点 / dexterity×2.0·点 /
regenerate×0.8·点·回合 / burn×1.0·点·回合 / poison×1.5 / thorns×1.5 / weak、frail×1.5 /
retain×1.0 / resonance_gain×0.5（双刃机制保守）/ gaze_reduce×2.0 / **gaze_gain×-2.0（代价为负）** /
resonance_drain、exhaust、delete_random×-3.0（负）；cost_type ≠ none（血/记忆/锁/标记）整体 ×0.9。

分位（`tools/card_power.json`，按职业卡池）：

| 职业 | 卡池 | P50 | P75 | P90 |
|---|---|---|---|---|
| diver | 83 | 6.4 | **9** | 10.8 |
| tremor | 83 | 6 | **9** | 10.5 |
| anmin | 50 | 6.12 | **8** | 12 |
| cangmin | 50 | 6.5 | **9** | 10 |

## 2. 审计规则逐条（R1–R4）

| 规则 | 结果 | 说明 |
|---|---|---|
| R1 初始牌 power ≤ 卡池 P75 | ✓ 四职业 | 最大 power：diver 9 / tremor 7 / anmin 8 / cangmin 9（均 = P75 或更低） |
| R2 黑名单 0 张 | ✓ | 0 费且抽≥2：0；无代价全体伤害≥10：0；无限连组件：卡池中不存在此类特殊码（`retain` 保留≠抽回，逐一核对） |
| R3 ≥1 防御/应对牌 | ✓ | 缩起×4（或苍民 缩进岩洞×3+火母的注视×2） |
| R4 10–12 张、机制≥3 | ✓ | 每职业 12 张；机制 = 攻/防/抽/特殊 4 种 |
| 基础 10 张（引擎） | ✓ 全过 | 一击(7)、缩起(4)、职业签名牌(6)：power 远低于 P75，签名牌 0 费抽 1 不在黑名单（黑名单=0 费抽≥2） |

### R5：被拦下的牌不删除，仍可获得

随机开局废除后，**没有任何牌从卡池删除**——奖励池（`weightedCards`，rarity ≠ special 全量参与）与
前哨杂货（`buildShopStock` 同源）照旧。审计拦下的代表性强牌及其获得路径：

| 牌 | power | 职业 | 仍可获得 |
|---|---|---|---|
| 星髓矿业·深部震源 dive_0046 | 18 | diver | ✓ 卡牌奖励（rare 权重 1）+ 前哨杂货（150–200 金） |
| 母亲的祷文 cng_0012 | 18 | cangmin | ✓ 同上 |
| 观红（对影） trem_0078 | 15.2 | tremor | ✓ 同上 |
| 动用储备 anm_0037 | 14.4 | anmin | ✓ 同上 |

「改名」条款未触发：本实现没有把任何牌排除出卡池（只是不再随机塞进初始牌库），故无需改名移植；
若未来需要显式排除某牌出奖励池，按 R5 应以新名字建变体卡入商店，并在本表登记。
