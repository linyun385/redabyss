## 硬指标（脚本算的数字）

### 指标 1：8 层背景两两可区分（28 对 ΔE76 的最小值，≥5 及格）

| 主题 | 最小 ΔE | 结论 |
|---|---|---|
| off | 7.4 | ✓ |
| **A** | **1.4** | **✗ 作废**：78% 纸底把 8 层压成 `#b6b0a5`→`#bfa59a`，层色信息丢失。数学上纸底占比必须 ≤~32% 才能保住 min ΔE≥5（7.4×(1−w)≥5），那已经不是"纸底"了——全纸底与暗色层色本质冲突 |
| B | 7.4 | ✓（层色不动） |
| C | 7.4 | ✓（层色不动） |

### 指标 2：正文对比度（WCAG，≥4.5 及格 / 次要 ≥3）

| 主题 | 正文最差值（8 层里最差） | 次要最差值 | 结论 |
|---|---|---|---|
| off | 8.55（D8 `#ffc9bd` vs `#64101a`） | **2.07**（`#7a6f6a` vs D5 `#1a0b0e`） | 正文 ✓；次要 **2.07 < 3** 是现状就存在的旧问题（深层的次要文字偏暗），三个方案都不恶化它 |
| A | 6.43 ✓ | 2.95（差 0.05 不及格） | 随 A 一起作废 |
| B | 8.55（页面同 off）；卡面/日志正文 **10.21**（墨 vs 纸） | 卡面次要 **4.68** ✓ | ✓ |
| C | 同 B | 同 B | ✓ |

### 指标 3：卡牌图案区与卡底边界（ΔE76，边界可见）

off：2.7（靠 1px 分隔线辅助）→ **A/B/C：5.6**（纸面图案区对比更大，边界比现状更清晰）✓

### 指标 4：白 → 暗 → 红 递进（L* 亮度 + Lab a* 红绿轴）

- off/B/C：最亮 D1（L*=27.9）/ 最暗 **D5**（L*=4.4）/ 最红 D8（a*=36.9）——递进成立。
- **发现一处既有不一致**：HANDOFF_D2 注释写「D4 空洞海最黑」，但代码里 D5 `#1a0b0e` 比 D4 `#0d1013` 更暗（L* 4.4 vs 7.4）——注释与数值不符，按 T44 边界只记录不改。
- A：次序不变但被压扁（L* 72.0→67.9，a* 7.7）——与指标 1 失败同源。

### 指标 5：布局不回退

- 三检查器全绿（pack_check 5 预期警告 / test_engine / check_web 0 警告）。
- A 主题下 10 张手牌：无整页滚动条、结束回合按钮 bottom=888 在 900 视口内（实测）。

## 结论

- **A 全纸底：作废**（指标 1 失败 + 指标 2 次要差 0.05）。保留其截图作为证据。
- **B 暗底贴纸：保留**，全部硬指标通过；改动面最小（卡/日志/速查页纸底）。
- **C 层色+纸纹：保留**，全部硬指标通过；纹理与暗角画在 body 背景层（内容之下，不压任何文字）。
- 三个方案**默认 off**，由用户拍板后只改默认值。

## 边界声明

- 色差与对比度全部是**脚本算的**（ΔE76 与 WCAG 公式，纯 python，数字见上），目测只用于截图初筛。
- 层色可区分性按公式覆盖**全部 8 层**；截图只拍了 D1（地图/战斗/奖励）三个场景——D2–D8 只有公式数字，没有逐层截图。
- B/C 卡面次要文字 4.68 达标；但深层页面级 `--dim` 2.07 的旧问题三个方案都没解决（B/C 只改卡/日志/速查页，页面其余仍用旧 --dim）。
- 本任务**只用占位符号**做的验证（T42 未生图）：未来 art 图接入图案区后，图案区底色会被图片覆盖，指标 3 需要用真图再校一次。
- color-mix 使用 Chromium 111+ 特性（现代 Chrome/Edge 均可）；A 的混合色用同公式离线复算。
