# CARD_AUDIT — 卡池结构诊断（T47）

> 全部数字出自 `node tools/card_audit.js`（落盘 `tools/card_audit.json`），样本断言：diver=80 / tremor=80 / anmin=50 / cangmin=50，共 260 张。
> 「应有量」= 独立性零假设下的期望（行合计×列合计/总数，公式在脚本头注释）；残差 |O−E| ≥ max(3, 2√E) 记为热区/空洞。
> 折算系数（脚本头注释同步）：伤害/格挡/回复 1.0、抽牌 2.5、凝视 2.0、共振 0.5、力量/敏捷 4.0、再生 1.5、灼烧/中毒 1.2×回数、消耗折价 0.8。**系数是设计假设**，由此产生的结论标「平衡问题（只列不改）」。
> 本任务未改任何卡牌数据。

## 一、结构问题（空洞 / 重复）

### 1. 下潜者水脉近乎不存在
- 位置：diver / water / 全费用
- 证据：water=4/80（5%），对比 light=24、mineral=23；独立性模型下 light/1/attack 期望 13.2 实 2（残差 −11.2），是全池最大的空洞格。
- 影响：水脉连携、水脉门槛、以水为主题的遗物（净配给线）在下潜者卡组里无法成线；「偏重：光脉/矿脉」的口号成立，但水脉的空洞连杂凑牌都凑不出。
- 建议：补 4–6 张 diver 水脉卡（主题现成：贸易局的配给、冷凝水、苦水），费用 1 费为主。

### 2. 黯民 2 费真空
- 位置：anmin / 费用
- 证据：2 费=1 张（50 张里），3+ 费=0。对照 diver 2 费 19 张。
- 影响：黯民没有中期能量出口——能量上限一旦被遗物/协议抬高，多出的能量无处可花；回收流的中后期节奏塌陷。
- 建议：补 4–6 张 2–3 费黯民大件（工程线重型协议、拆解台大件），稀有度 uncommon/rare。

### 3. 苍民 3 费真空
- 位置：cangmin / 费用
- 证据：3+ 费=0，梦牌费用上限 2。梦体 60 血的长战没有高费兑现手段。
- 影响：入梦流的后期深度不足——长梦没有梦牌可升级。
- 建议：补 2–3 张 3 费稀有梦牌（三神各一张，与 T23 的三神线对齐）。

### 4. 下潜者光脉攻击空洞
- 位置：diver / light / 1 费 / attack
- 证据：实 2，期望 13.2，残差 −11.2（全池最大负残差）；light/1/power 同样残差 −10.2。
- 影响：「光导者」的幻想（持灯者的攻击手段）在卡池里不存在——光脉在下潜者手里几乎全是技能和遗物联动件。
- 建议：补 3–4 张光脉攻击（聚能枪家族已在，扩展它而不是新开家族）。

### 5. 「0 费抽 1」家族同质化（最大重复组）
- 位置：全职业 / 0 费 / 抽 1
- 证据：完全同效果指纹 45 组；最大一组 **12 张**（光导透镜（残）、矿票、震语：听骨、守夜人的表…），第二组 10 张、第三组 8 张。同名卡 0 组——名字全是原创，机制高度折叠。
- 影响：260 张的名义池子里，仅「抽 1」一个机制就占了 ≥30 张。选卡界面的新鲜度虚高：三选一里出现两张同指纹牌的概率显著（尤其 0 费池）。
- 建议：给该家族至少 4 张换出复合效果（抽 1+弃 1、抽 1+共振 1、抽 1+凝视 −1），按各职业叙事改写；不要求清零同质——低成本过牌本来就是构筑黏合剂。

### 6. 震语者能力牌（power）空洞
- 位置：tremor / type=power
- 证据：power=4/80（5%），对照 diver 10 张。rare=17 张却集中在 attack/skill。
- 影响：能力牌是全游戏最稀缺的资源格，震语者的「势」幻想基本没有卡面支撑。
- 建议：补 2–3 张震语者 power（历法/石碑主题现成）。

### 7. 黯民攻击牌密度偏低 + 矿脉攻击缺口
- 位置：anmin / type=attack 与 mineral/1/attack
- 证据：attack=11/50（22%，全职业最低）；mineral/1/attack 残差 −11.9。
- 影响：黯民是「料脉」职业但矿脉攻击几乎不存在——改造流（手牌永久 +2 伤）找不到好的矿脉攻击载体。
- 建议：补 2–3 张矿脉攻击（扳手/例检主题现成）。

### 8. 主脉集中度需要设计确认（可能是身份，不是病）
- 位置：tremor / tremor 脉；cangmin / light 脉
- 证据：震语者 tremor=32/80（40%）、苍民 light=20/50（40%）——主脉占四成。
- 影响：主脉是职业身份的强化，但 40% 意味着「跨脉事件」在这两个职业上几乎必亏（脉覆盖不足）。
- 建议：不是补牌问题，是设计确认问题——若确认主脉集中是身份，则把跨脉事件（T46 的 requires.vein_min 类）在这两个职业上标白名单。

## 二、平衡问题（只列不改——T38 已界定范围）

### 9. 墟盐（dive_0018，diver，1 费）
- 证据：每费密度 12.0，同类中位 5.8（2.07×）。格挡 9 + 再生 2 折算 12 分/1 费。
- 备注：再生按 1.5/点折算，若按"再生只在长战兑现"打折，密度降到 ~10.5，仍是同类最高。

### 10. 菌婪者组织样本（anm_0039，1 费）
- 证据：密度 20.4（中位 10，2.04×）。效果含特殊分支（协议联动），折算可能高估。

### 11. 深部震源（dive_0046，2 费）
- 证据：密度 18.0（中位 8.8）。**折算盲区**：36 伤害计入，但「消耗共振 15」的成本没有折价项（系数表无共振成本负值）——它的真实密度应扣 15×0.5=7.5，扣后 10.5 落回正常带。此条同时是「系数假设的局限」的实例。

### 12. 震频器家族被判「废卡嫌疑」同样是系数盲区
- 证据：震频器（微型）密度 0.5 vs 中位 5.8——因为共振只按 0.5/点折算。共振流构筑里 0 费共振+1 的实测价值远高于此（T38 的 sim 数据里共振流是 diver 有效流派）。
- 结论：这两个方向的嫌疑都**只记录**，真实裁定需要 sim 的胜率相关性（T38 方法），不是折算系数能定的。

## 三、边界声明

- 独立性模型假设「脉分布与费用分布无关」——主脉集中的职业会天然产生大量空洞残差，报告已把最极端的 D2–D7 主脉类空洞与「真空层」（water=4、2 费=1）分开列。
- 折算系数全部是假设（头注释写明），没有来自对局的拟合；超模/废卡嫌疑是「与同类中位数的倍数关系」，不是强度结论。
- 0 费牌以 1 费为分母，系统性低估 0 费价值——震频器家族的「废卡」判定受此影响最大。
- 完全同效果指纹不含 upgrade 变体（升级件单独计），矿票（回收藏）与其原版算同组——按机制折叠计数。
- 本次为纯诊断：cards/*.json 与 web 内联均未改动（pack_check 复跑全绿为证）。
