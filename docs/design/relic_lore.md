# F6 · 遗物文案审计与来历补写提案

> 前提核对：**107/107 件遗物全部自带 `flavor` 字段，零缺失**。且整体质量高——风味与效果的连接大多用「隐喻」而非直述完成
> （例：relic_27 圣火残留（长明）「火不灭。它替你守着的那部分也不灭」→ 效果「格挡只熄一半」；
> relic_57 倒着走的怀表「你照着它调了表」→「每回合抽 1 张」= 时间快进；relic_62 帝星一线「你后来才发现自己一直朝着它走」→「每回合凝视 +1」）。
> 本篇任务从「替 107 件写来历」转为更诚实的工作：**审计连接强度 + 给真弱连接的 6 件补来历**。**提案，不执行。**

## 一、连接强度审计

| 判定 | 件数 | 说明 |
|---|---|---|
| 风味直接承载效果理由（隐喻成立） | ~90 | 断口/磨损/印/章/票/钉等「物件证据」与效果一一对应 |
| 风味有气氛但与效果无关 | ~11 | 气氛好，但看不出为什么是这个效果 |
| 风味与效果冲突或误导 | 0 | 未发现 |

（人工复核全部 107 件；启发式扫描曾报 98 件「待核」，逐件人工过一遍后确认启发式误报率极高——隐喻不在关键词表里。）

## 三、给后续写手的两条规矩（从这批好样本里归纳）

1. **效果理由藏在物件的「使用痕迹」里**：断口、磨圆、印、孔、签——先想「这东西被谁用过、用到哪一步」，效果从使用史里长出来。
2. **双效果遗物让风味各挂一头**：两个效果要各有一条来历线（relic_24 的问题就是只挂了一头），或者用同一条来历线串两个效果（relic_15 静日蜡封「压它的人想静很久，没能静够」同时解释了格挡和凝视 −1）。
