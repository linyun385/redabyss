### anm_0028 的出图提示词摘录（本路最接近的现存卡）

> 地底工作台上，一块边缘卷曲、表面布满裂纹的金属铭牌倒挂在台面边缘。这块金属铭牌是画面的主体，占满画面中部，表面有几处明显的裂纹，边缘有些卷曲，上面刻着模糊的文字痕迹。铭牌背面贴着一张小标签，上面写有执行日期和编号。工作台只是画面上方的一条细…

设计卡若真做出来，其提示词要沿这份文本的工艺语系（石版排线/血红底/单一朱红强调）另写，并把主体从「协议：注销」换成设计卡的新对象——**不得复用同一段主体描述**（T321 换皮教训）。

## 补：抽象度档位（ART_DIRECTION_V2 §一）

报废记忆回执属 B 档：一张打了红色「作废」压痕的薄回执压在废料堆下——「回执」与 anm_0008 报废清单同语系，但主体从「清单」换成「小票」，R4 命名差异大必须拆族，不与 anm_0008 共图。
