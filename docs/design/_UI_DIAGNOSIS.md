# UI 诊断（2026-11-06 · 基于实截三屏）

截图工具：`tools/_ui_capture.js`（CDP 直连，可重跑）
输出：`docs/design/ui_shots/01_home.png` `02_map.png` `03_battle.png`

---

## 一句话结论

不是配色丑，是**没有设计系统**。五个病根，按伤害排序：

---

## 病根一：两套色板在同一个画面里打架（最重）

现在同时存在两套：

| 套 | 颜色 | 出现在哪 |
|---|---|---|
| 暗 | `#0a0a0c` 黑、`#16181c` 灰蓝、`#7a2d24` 暗红 | 背景、HUD、卡牌红边 |
| 纸 | `#e9e2cf` 米白 | 战斗日志板、地图板、卡面 |

**问题不是两种颜色同时存在，是它们各占一半面积，谁也不服谁。**

- 战斗：米色板 1080×350，占画面中央最大一块，里面只有"第 1 回合"几个字
- 地图：米色板 980×470，占了下半屏

米色本来是"纸"——用来承载卡面和文字。现在它变成了**大块填充色**。
结果就是：一个暗色 roguelike 里嵌了两块米色纸板，像网页里的 article 区块。

---

## 病根二：面积按"填满"分配，不是按"内容需要"

- **战斗**：中央 350px 高的米色板，内容是空的。真正有信息的东西（敌人卡 230px 宽、手牌）挤在上下边缘
- **地图**：上半 400px 完全空（只有标题和一行提示），下半 470px 塞满地图网格
- **首页**：四张立绘 195×270，居中，上下各留 240px 空白

三次都是同一个模式：**先定一个框，再把东西塞进去**。
正确做法反过来：**先算内容需要多大，再让容器贴着内容长**。

---

## 病根三：四套边框，没有一套是统一的

同一屏战斗里能数出四种框：

| 元素 | 边框 |
|---|---|
| 手牌 | 2px 暗红实线 + 圆角 |
| 敌人卡 | 1px 极细红线 |
| 战斗日志板 | 无边框（米色直接切出来） |
| 「打开总图」按钮 | **纯白底黑字**，全项目唯一一个亮色块 |

那个白按钮在地图界面上是视觉上最刺眼的一个点。它不属于这个游戏。

**而核心卡有金框规范**（768 画布 / 660 图 / 54 边 / 金渐变 `#8a6420 → #f6e29e → #483210`），
这个规范现在只活在卡里，UI 上一处金都没有。

金色是这个游戏唯一"贵"的颜色。它应该出现在所有"这是重要的东西"的地方：
核心卡、传说遗物、Boss 血条、通关结算。现在它被关在卡里了。

---

## 病根四：字号和字距是随手定的

- 标题「第 1 深度带 地表死寂区」：红色 + 大字距，像网页 h2 加了 `letter-spacing`
- 副标题：灰色小字，紧贴标题下方，间距不匀
- 图例：一行塞 9 组，约 10px，挤到看不清
- 手牌上的说明文字：被卡牌重叠挡住，"你把手上" 截断
- HUD：7 项数据挤一行，约 11px

没有任何字号阶梯。所有文字看起来都"差不多大"，除了标题。

---

## 病根五：图和界面的语言不一致

卡面美术是：哑光、排线、无高光、硬边轮廓、机械造物。
界面是：圆角、均匀间距、居中、`border-radius: 6px`。

**卡是"从渊里捞出来的东西"，界面是"一个后台管理页"。**

首页尤其明显：四张立绘是这套美术，装它们的框是网页卡片的框 —— 上下还有黑边
（图片比例和容器不匹配，`contain` 露底）。

---

## 附带发现（不是设计问题，是 bug 级）

1. 战斗界面左右各有约 100px 竖条露出 body 背景 —— 主容器宽度不是 100%
2. 地图网格右边缘和底边缘被容器切断，D1/D2 标签贴边
3. 首页四张立绘上下有黑边（比例不匹配）
4. 手牌重叠后文字被遮挡，最左一张几乎只看得到一角

---

## 修法（三档，代价不同）

### A｜统一色板 + 统一边框（不重排）
- 把米色从"填充"降级为"承载"：只出现在卡面、文字块，不出现在大面板
- 建立边框阶梯：金（重要/核心）、暗红（可交互）、灰（装饰）、无（内容区）
- 白按钮换成暗红或金
- 统一字号阶梯（4~5 档）
- **代价**：改 CSS 约 400 行，不动布局。效果：从"网页"变成"有风格"，但结构问题还在

### B｜重排关键屏的信息架构
在 A 的基础上：
- 战斗：日志从中央大板改成右侧窄栏或底部单行滚动条；敌人区上移占满上半；手牌区横向铺开不再重叠遮挡
- 地图：行程栏从"左上一块"改成"右侧竖条"；地图网格铺满剩余空间并留安全边距
- 首页：四张立绘等比统一，去掉黑边，卡片用金框（和核心卡同一套规范）
- **代价**：改布局 + CSS，约 800~1000 行，要动 HTML 结构。效果：像一款游戏

### C｜B + 重画 UI 素材
边框、图标、分隔线全部重画成和卡面同一套工艺（排线、硬边、哑光）。
**代价**：需要图像生成，周期以天计。

---

## 我的建议

先做 **B**，但按屏推：

1. **战斗屏**（问题最重、玩家待最久）→ 改完给你看对比
2. 如果方向对 → 地图屏、首页
3. 最后回头统一 A 的色板/边框/字号规范，收口

C 先不动。等 B 稳定了，再看哪几个边框值得重画。
