# L4–L8 敌人：更亮、更红、更少眼睛

> 2026-11-06 夜班 · 方向池 2。派单：`tasks/INBOX/08_overnight_1106.md` 方向 2。
> 数据来源：`web/index.html` 的 `RAW.enemies`（只读核对）。与 `L1_L3_rework.md` 同一套重做原则（贴顶不贴地 / 威胁从上来 / 光从下往上照），本批加一条主线：
> **越深，红光越强——敌人跟着变：更亮（被红光照透）、更红（腹面先红）、更少眼睛（眼睛是地表的器官，越深越不需要）。**
> 本文件是设计文档，没改任何数据。Boss（光蛭母/震喉/穹顶之影/墟蛹）**全部不动**，见执行注记。

---

## 一、L4–L8 的现状诊断（只列要点，方法同方向 1）

1. **红光已有雏形但没成体系**：d4 起名字带「光/红/辐射」，但外形描写仍是水中/地面生态（水面上方、池里、干泥壳），「红」多出现在 flavor 里、没出现在身体上。
2. **垂直意象零星自发的**：d7_02 光柱蛇蜥「还悬在原来的位置」、d7_06 穹顶之影「倒挂的发光网」——说明这层的作者已经在往天花板走了，本批把这条路走完。
3. **眼睛的递进已经在发生**：d4_05 盲眼、d7 无面、d8 空壳——但散乱、无刻度。本批把它定成显式递进线。

## 二、眼睛刻度（本批的递进主线，写在每只的 flavor/外形里）

| 层 | 眼睛 | 红光 |
|---|---|---|
| L4 | 还有眼，但开始不看 | 红光第一次照亮一切；生物的**腹面**发红 |
| L5 | 半数无眼，靠热定位 | 热泉的红从下面蒸上来 |
| L6 | 全部无眼，靠剂量定位 | 生物自己发红（辐射合成） |
| L7 | 无眼，也无脸 | 红光是它们的一部分（旧光者） |
| L8 | 无眼、无脸、无身体 | 它们就是红光落下的影子 |
