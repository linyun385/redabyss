# T449 · 四角色选择界面提示

> 依据：T400 §2.2 角色味道（用户定稿）+ 实际机制（初始卡组/零件/双世界，见 `first_5min.md`）。
> 提示一句 ≤30 字；简介 ≤100 字。语气：冷、短、不劝你玩。

## 下潜者 diver

- **选择提示**：公司的设备一件件发给你。先学会站住。（18 字）
- **简介**：高技术种族派下来的探险者，带全公司最齐全的装备下潜。没有花活，没有隐藏代价——它给的每件东西都写在标签上。适合第一次下来的人。（63 字）

## 震语者 tremor

- **选择提示**：牌是弹药，弃牌是定价。上限很高，下限很低。（21 字）
- **简介**：红渊原住民。他们不发誓、不记账，只听。牌库是他们的货架，弃牌堆是他们的收银台——每张牌都能吃，吃下去的都算数。打得好是天赋，打得差也是。（68 字）

## 疯先知 cangmin

- **选择提示**：每回合先选世界，再选牌。想清楚再动。（18 字）
- **简介**：魔法侧文明的最后一代，睡在两个世界之间。醒着穷、梦着疼。他的牌都不复杂，复杂的是牌与牌之间那几步——想明白的人步步为营，想不明白的人步步交学费。（72 字）

## 维护者 anmin

- **选择提示**：击杀登记入账。零件在 HUD，成长在那里点开。（23 字）
- **简介**：三号避难所的运营人员，两千年来第一次见到活人。他不变强——他把东西变强。每一具残骸都是零件，每一张废牌都是改装材料，每一次拆解都有账单。（68 字）
