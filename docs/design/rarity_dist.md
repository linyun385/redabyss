## 四、判断

- 稀有度**大体上在按强度分**：普通档以单键基准牌为主，复合效果集中在精良/稀有档。
- 但有 29 张低稀有度卡摸到了稀有档的数值线：下潜者6、震语者10、维护者7、疯先知2、通用4。其中复合键数 ≥3 的（如无门槛大 AOE、双键直伤）是真正的「稀有度给低了」候选。
- 「特殊」稀有度 14 张全是机制展示位（带 retain/共振锁定/mark 等教学效果），不是强度档——这个用法是健康的。

## 算法（复算用）

1. 桶=(角色,类型,费用)，桶内 ≥4 张才参与比较。
2. 主数值 = `audit_common.main_shape` 的主种类数值（与查重同源）。
3. 低稀强：common/uncommon 主值 ≥ 同桶 rare **同主种类**中位数（且 >0），或有效键数 ≥3。
4. 高稀平：rare 主值 ≤ 同桶 common **同主种类**中位数，且有效键数 ≤1。
5. 有效键数 = effect 里除 `target`/`hits` 外的键数（special 算 1 个）。
