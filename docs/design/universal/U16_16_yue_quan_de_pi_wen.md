# U16 · 越权的批文（u_0016）设计书

> T331 通用牌 u_0016 的逐张设计书。四段：名字来由 / 费用依据 / 效果与引擎落点 / 补哪条弱路与不该被选的条件。数值以 T341 草案为准。

## 一、名字来由

维护者世界观的核心是「批文」（anm_0036 保运行批文、anm_0015 主控授权）；越权的批文是你自己签的——签发栏是空的。「越权」点明它是全池第一张非维护者的协议入口。

## 二、费用依据

1 费。依据：激活 purge（每回合自伤 2、双方攻击 +3）。锚点：引擎里协议效果已经全部实现（[index.html:5791] 自伤段、[index.html:5825] 玩家 +3、[index.html:5734] 敌方 +3），只是没有卡能触发——它是「给已造好的引擎装钥匙」，定价 1 费 rare 是「钥匙不贵，代价在协议本身」（自伤税）。稀有度 rare 因为它是体系改写卡。

## 三、效果与引擎落点

effect: {"target": "self"}，anmin_mark: {"kind": "protocol", "protocol": "purge"}。引擎落点：**零改动**——[index.html:5726] 读 anmin_mark 判重、[index.html:5754] 激活、[engine/core.js:364] 同款。全池 0 张卡带此字段，它是「已支持但未使用」的最优 case。

## 四、它补哪条弱路

下潜者×协议流（唯一付得起自伤税的 80 血职业）；震语者×协议（可选 silence 变体）；幽灵流派的从 0 到 1。

## 五、什么情况下它不该被选

不该被选：① 疯先知（30 血 ÷ 2 自伤 = 15 回合死刑，[engine/core.js:291] 的协议每回合都扣）；② 慢速消耗流（协议是节奏加速器，慢速流用它是自裁）；③ 战斗预期 ≤2 回合时（purge 的 +3 需要至少 2 次攻击才回本自伤）。
