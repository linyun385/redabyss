# U01 · 空的手（u_0001）设计书

> T331 通用牌 u_0001 的逐张设计书。四段：名字来由 / 费用依据 / 效果与引擎落点 / 补哪条弱路与不该被选的条件。数值以 T341 草案为准。

## 一、名字来由

「空的手」来自世界观里矿工的日常动作：把不想要的东西放回岩壁的凹槽。它是全池第一张带选择弃牌的卡——起手烂牌在红渊里有了一个体面的去处，而不是干等着被 memory 代价随机撕走。

## 二、费用依据

0 费。依据：弃 1 抽 2 的净过牌是 +1 张且带选择权，与全池 66 张抽牌卡的基准「1 费抽 1」（dive_0001/anm_0003 等）相比，选择权抵掉 1 费；同类参照 StS 的 Pommel Strike 系（攻击+过滤）定价。升到 1 费会让它被 dive_0003 曜元（0 费抽 2 带消耗）直接压制，所以锁 0。

## 三、效果与引擎落点

effect: {"draw": 2, "discard": 1, "target": "self"}。引擎落点：applyCardEffect 无 discard 分支（[index.html:5807] 起），需要新增——这是它进 §三「需改引擎」名单的原因。

## 四、它补哪条弱路

疯先知×共振积累（白嫖共振转盾的手牌过滤前置）；四个职业起手烂牌的通用解；与 memory 代价流构成方差控制对（删牌是随机的，弃牌是选择的）。

## 五、什么情况下它不该被选

不该被选：① 手牌质量已经很高时（抽 2 弃 1 净收益低于任何直接抽牌）；② 场上残局需要立刻输出时（0 费不打伤害=空过节奏）；③ 牌库见底的消耗战（弃掉的牌进弃牌堆后要等洗回，等于把未来的自己透支给现在）。

| 层 | 规则 | 与本卡的关系 |
|---|---|---|
