# U02 · 守夜人的钟（u_0002）设计书

> T331 通用牌 u_0002 的逐张设计书。四段：名字来由 / 费用依据 / 效果与引擎落点 / 补哪条弱路与不该被选的条件。数值以 T341 草案为准。

## 一、名字来由

禁声日的钟在换班时敲，敲过就不许再敲——「留一半」的意象直接来自世界观（CAMPFIRE_TEXTS 的静日传统，[index.html:6662]）。它是把遗物 relic_27「圣火残留（长明）」的专利机制 democratize 成一张牌：格挡可以攒，但要交税（留一半）。

## 二、费用依据

1 费。依据：block 3 + 半保留，期望值 = 3 + 前回合剩量/2；对照 dive_0004（1 费 block 8 无保留），它的强度完全取决于你上一回合留了多少格挡——递归收益，3 点底值压到 common 档下缘。

## 三、效果与引擎落点

effect: {"block": 3, "target": "self", "special": [{"code": "keep_block_half"}]}。引擎落点：endTurn 的格挡清零段只查遗物 mod（[index.html:6042] 附近），需要给 special 加一个 case 并让清零逻辑读卡牌标记——小改。

## 四、它补哪条弱路

维护者×格挡墙（从「每回合重建」变「可累积」）；震语者×格挡的 endurance 路线；疯先知 30 血的保命底牌。

## 五、什么情况下它不该被选

不该被选：① 爆发流（每回合格挡都是刚好挡住一刀的精确计算，半保留反而诱使过盾浪费）；② 面对多段敌人时（每段都先吃满当回合格挡，保留机制收益不稳定）；③ 已持有 relic_27 时（叠满也没额外收益，卡位浪费）。
