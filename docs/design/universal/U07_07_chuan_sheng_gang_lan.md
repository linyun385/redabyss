# U07 · 传声钢缆（u_0007）设计书

> T331 通用牌 u_0007 的逐张设计书。四段：名字来由 / 费用依据 / 效果与引擎落点 / 补哪条弱路与不该被选的条件。数值以 T341 草案为准。

## 一、名字来由

抗共振司的导波索（dive_0044/0077）是把振动引走的物件；传声钢缆反过来——不是消音，是把光脉的声音传给震脉听。它的名字里没有「通用」两个字，但它做的事就是翻译。

## 二、费用依据

1 费。依据：block 5 + draw 1。全池 1 费 block+draw 的基准是 trem_0026（光导石，1 费 block 5 抽 1）——数值完全一致，差异全在双脉标签：它是第一张两个脉的牌（层规则双占、连携按首脉的降级体验见 T341 §四）。

## 三、效果与引擎落点

effect: {"block": 5, "draw": 1, "target": "self"}，veins: ["light", "tremor"]。引擎落点：零改动可用（连携降级）；完全体需改 veinChainBonus 的首脉逻辑（[engine/core.js:429]）。

## 四、它补哪条弱路

下潜者×格挡的光脉位（24 张光脉卡在断光层外全是光染）；震语者的光脉过牌；混色流的接续点。

## 五、什么情况下它不该被选

不该被选：① 纯震语者盾语循环成型时（trem_0003 等同数值本家牌更纯）；② no_light 层（双脉全占=双倍惩罚：光脉失效拦截整卡 [index.html:5817]）；③ 已经有 5 张以上抽牌的循环（draw 1 边际价值递减）。
