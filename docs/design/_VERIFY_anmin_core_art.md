## 三、提示词机制

`data/zh_prompts_anmin_core.json` ← `tools/_gen_anmin_core_prompts_v2.py`

每张 = 主体描述（各写）+ **光/空间尾部 + 画风尾部（从 anm_0001 程序切出，逐字复用）**

v2 对尾部做了**一处**修改：

- 删：「所有表面都是哑光的，没有高光，没有反光，没有金属亮斑」
- 改：「金属表面用更密的排线表现明暗和极克制的冷调反光，不要大块高光、不要镜面白斑」

原因：原句让精密金属看起来像木头，和「高科技造物」直接冲突。其余（红光自下而上、
无画框、石版画排线、只有墨黑与血红）全部保留。

★ 尾部仍写「没有画框」—— 因为金框由程序在出图后加，画面必须满幅。

## 四、金框规格（`tools/_gold_frame.py`）

```
768×768 画布，画面 660 见方居中，框宽 54px
0–4    深黑垫边
4–9    暗金内凹线
9–45   金色主带（斜向渐变 + 每 3px 一道拉丝暗线）
45–50  暗金分层线
50–53  亮金细线
53–54  黑线（与画面分隔）
四角 96px 金色角片，角片中央压一个凹点
```

金色取值：暗金 `#8a6420` → 亮金 `#f6e29e` → 深金 `#483210`，模拟高光落在框带中线。

## 五、返工记录（共 3 次）

### 0052 子代理（v1 → v2）
v1 画成**写实人形**（有头脸、短裤、脚趾）。根因：提示词含「人形替代体」「从岩壁长出来」。
v2 改为**铁链吊着的无头空壳**（肩甲 + 肋状框架 + 两条下垂手臂），去掉一切人形措辞。
★ 教训：提示词里出现「人形」，百炼会画真人。要表达替身必须写成**物件**。

### 0054 武器试验（v2 → v3）
前两版主体太小、四周大片空地，「武器插进躯体」读不出来。
v3 改为**特写构图**：武器与躯体交接处放画面正中央、两者填满画面，并显式写「几乎没有空地」。

### 0051 机械增生（v2 → v3）
v2 像一台静止设备，「增生」这个机制没出来。
v3 改为**外壳从内部被撑裂的特写**：裂口占大半个画面，成束管线从裂口朝上伸出、末端挂料边、
短管朝下滴落，崩开的铆钉散在裂口边缘。

留档：`art/_review/v1/`（v1 全部）、`art/_review/v2_noframe/`（v2 无框版）
