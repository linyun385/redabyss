## 冲突清单

### C1 · 「脉不是流派，是染色」——与新系统定位直接对立

- **位置**：`docs/design/stream/T330_STREAMS_TODAY.md` 行 59
- **原文**：「脉不是流派，是染色。五脉在四个职业都覆盖，但脉的作用只有连携加成（+1/+2）和两层环境规则（no_light/dry）——『光脉流』不存在」
- **与哪条冲突**：T400 全篇（§0「这是重构，不是加机制」、§2.1/§2.2 脉=构筑核心轴、阶段 2 脉象等级+核心卡+奖励加权全部挂在脉上）
- **性质**：写作时点是对的（当时脉确实只是染色），但 T400 定稿后这段话成了错误陈述。**旧文没有被标注「已被 T400 取代」。**

### C2 · 「267 张卡里双脉卡为 0 张」——数据已变

- **位置**：`docs/design/stream/T330_STREAMS_TODAY.md` 行 5
- **原文**：「267 张卡里双脉卡为 0 张（`veins` 数组长度 ≥2 的卡逐张核对为零），脉只做单选标签」
- **与哪条冲突**：当前卡池 219 张，双脉卡 **5 张**（u_0007 光+震、u_0008 热+震、u_0010 震+矿、u_0012 光+热、u_0013 震+矿）；且 `master/03_ENGINE.md` 已把「双脉连携改写」列为全盘成败前提——同一项目里两处说法正好相反。
- **附**：同文件行 30「凝视控制的 14 张」——当前凝视相关卡 15+ 张（gaze_cost 15 / mark 代价 7 / gaze_reduce 3，见 `vein_special_mech_cards.md`），数字过期。

### C3 · 料/素旧分类 + 全套脉分布数字过期

- **位置**：`docs/CONTENT_PLAN.md` 行 67-69、87
- **原文**：「现有脉分布：光 64 / 料 66 / 震 56 / 热 34 / 水 31 / 素 9（张）」
- **与哪条冲突**：① 分类用了旧词「料」「素」——GLOSSARY.md 与现行体系叫**矿**（料只是黯民的 Fiction 内称呼，DLC_ANMIN.md:225 自己写明「黯民按供应链文化重命名：……料（矿）」）；② 数字全过期：现行 219 张 = 光 60 / 矿 58 / 震 42 / 热 29 / 水 24 / 无脉 11（`vein_cost_curve.md`/`vein_effects_by_vein.md`）。

### C4 · 「料脉」当体系名使用

- **位置**：`docs/CARD_AUDIT.md` 行 13、49
- **原文**：「黯民是「料脉」职业」「水脉连携、水脉门槛……」
- **与哪条冲突**：GLOSSARY.md §2 把五脉唯一写法定为 光脉/水脉/热脉/震脉/矿脉。「料」按 DLC_ANMIN 自己的定义是**黯民视角的内行话**，不能当系统名用——CARD_AUDIT 在系统语境里用了 Fiction 内称呼。
- **注意**：这是术语层冲突，与 T444（术语一致性）重叠，那边会再收。

### C5 · 五脉连携流：核心卡四张不存在

- **位置**：`docs/BUILDS.md` 行 32-44、`docs/FUN_T30.md` 行 26/39/95
- **原文**：BUILDS 震语者·五脉连携流核心卡（8）含「震语：连震、五脉符、五脉符（浮位）、三震（回声）」；打法「同脉连打吃连携加成……一张回声打两遍的伤害」
- **与哪条冲突**：① 这 4 张卡在现行 219 张里**全部不存在**（失效 id 扫描实证：trem_0040/trem_0077/trem_0049 已删，连震查无此卡）；FUN_T30 自己也标注了「震语：回声（不存在）」但 BUILDS 没改；② 「五脉连携流」整条 build 建立在 veinChain 加成上——T400 阶段 2.1 要把它改造成 `veins[脉]` 等级体系，这条 build 的机制基础正在被替换。

### C6 · DLC 协议卡提案 ≠ 实装卡

- **位置**：`docs/DLC_ANMIN.md` 行 131
- **原文**：「`《协议：静默段》`——本场共振不再上涨，但每回合开始失去 1 生命；`《协议：优先级翻转》`——敌人意图全部延后一回合执行，但它们获得 +3 攻击」
