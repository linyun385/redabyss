## 二、逐条明细（真问题）

### T1 · 共鸣 vs 共振：内容层与系统层各说各话

- **GLOSSARY 裁决**（`docs/GLOSSARY.md:11`）：唯一写法=**共鸣**（含义锚点 C.resonance）；禁用「共振值／回响值」。
- **引擎运行时文案用共振**：`engine/core.js:308` 玩家在游戏里实际看到 `〔共振 10〕`；共振阈值提示、过载提示全部写「共振」。`web/index.html` 内有 6 处「共鸣」（多为注释/说明）与大量「共振」。
- **内容文档用共鸣**：`docs/content/cards_tremor.md`（50 处）、`cards_diver.md`（45）、`cards_anmin.md`（17）——卡面效果列写的全是「共鸣 +N」。
- **设计文档用共振**：T400/T410/全部脉象文档、任务书、引擎注释 1289 处。
- **后果**：玩家在卡面读到「共鸣」，打出后日志显示「共振」——同一机制两个名字在同一屏出现。
- **建议统一成**：二选一，且必须同时改 GLOSSARY 或引擎之一。按使用量（1289 vs 250）和引擎改动成本，**统一到「共振」**、GLOSSARY 改裁决更现实；按术语表权威性则反向。**这是设计者拍板项。**

### T2 · 「层」vs「深度带」：正名失守

- **GLOSSARY 裁决**（`GLOSSARY.md:18`）：唯一写法=深度带/带；禁用「层（口语可用『第 X 带』）」。
- **实际**：`docs/LAYERS.md`（整个文件名就是 LAYERS）、本夜全部产出、所有任务书、引擎 `run.depth`/`C.layer`、RAW.layers——全部用「层」。「深度带」41 处集中在 T60-T62 地图设计期文档与 web 注释。
- **建议**：要么 GLOSSARY 承认「层」为口语正名（改裁决），要么接受这是永不执行的标准。维持现状会让每个新文档都「违规」。

### T3 · 凝视 vs 注视：机制词已统一，专名例外

- 机制语境 0 处违规——全部是「凝视」。
- 「注视」23 处全是**专有名词**：初始卡 `cng_d_def 火母的注视`（`engine/core.js:120`）、卡名 `trem_0059 震台石碑（注视）`、GLOSSARY 禁用栏自引用。
- **状态**：✅ 基本合规。注意点：卡名「火母的注视/震台石碑（注视）」在字面上撞禁用词——GLOSSARY 未给专名豁免条款，建议补一条「专名内不受禁用词约束」或在 T444 结论里明确豁免，否则 text_lint 会永远误报。

### T4 · 黯民/维护者、苍民/疯先知：种族词与职业词混域

- **GLOSSARY 裁决**（`GLOSSARY.md:38-40`）：职业=下潜者/震语者/维护者/疯先知；种族=黯民/苍民（两个 DLC 种族）；「疯先知=苍民职业」。
- **混域实例**：`docs/CARD_AUDIT.md:49`「黯民是「料脉」职业」——用种族名指职业；`DLC_ANMIN.md` 通篇以「黯民」指可玩职业。
- **建议统一成**：职业语境用「维护者/疯先知」，设定语境用「黯民/苍民」。GLOSSARY 已有正确框架，是使用者不守。

### T5 · 疯先知双世界动词：入梦 / 切世 / 梦栖 三词竞争

- **建议**：GLOSSARY 补一行——机制名「切世」（动作）/「梦侧」（状态），「梦栖」降级为流派名。

## 三、复算

```python
# 术语计数脚本（同目录运行）
import glob
TERMS = ['共鸣','共振','入梦','切世','梦栖','回收件','零件','注视','凝视','属性脉','脉象',
         '黯民','维护者','苍民','疯先知','深度带','层','素卡','素品','清醒度','清醒值','回响层','二周目']
for f in glob.glob('docs/**/*.md', recursive=True) + glob.glob('engine/core.js') + glob.glob('web/index.html'):
    t = open(f, encoding='utf-8').read()
    for term in TERMS:
        if term in t: print(term, f, t.count(term))
```

计数口径：子串计数（含禁用栏自引用）；「层」因作普通语素（层级/层次）未给总数，只给「深度带」对照面。
