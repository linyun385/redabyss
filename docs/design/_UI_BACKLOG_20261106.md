### 改动过程中我自己引入又修掉的问题

- 地图容器放大到 1500×680 后**底部被裁**。原因：`#mm-body svg` 只有 `<svg width height viewBox>` 的固定像素属性，容器变宽后按宽度放大、高度溢出 `overflow:hidden`。补 `width/height:100%` 交给 `preserveAspectRatio` 处理。
- **仍未解决**：地图 SVG 的 `viewBox` 覆盖范围和实际绘制内容有偏差，底部约 20px 的节点被裁。**这个问题在原始 980×470 下也存在**，不是本轮引入。要修得看 `renderMiniMap` 里 `o.W/o.H` 的算法，留到下一轮。

## 一、地图屏 `#screen-flow` —— 最严重，P0

**实测（1600×900，scale 1.0）**

```
#screen-flow  l=0   t=39   w=1600  h=861
#flow-panel   l=180 t=63   w=1240  h=107     ← 只有 107 高！
地图卡        约 310,415 → 980×440 居中
```

问题清单：

1. **地图卡太小**：980×440 塞在 1600×900 里，上方 380px 纯空、下方 100px 纯空。地图是这一屏**唯一的玩法界面**，却只占 27% 面积。
2. **左侧「行程」栏 260px 宽，只有一条内容**（「东井站台 / 下潜的起点。红渊从这里开始替你。」），其余全空。
3. **节点「?」约 12px**，连线 1px 近乎看不见，D1→D2 的层分隔只有一条虚线。
4. **图例一行**（×敌袭 ▭头目 〰交战 ⊕补给 ⊙遭遇 ◦休整 ◆跨带BOSS ●最终BOSS ?未探明）11px 挤在左上角，读不了。
5. **两个「总图」入口**：页面上方一个「打开总图」按钮（白底黑字！），地图卡右上角又有个「总图」。
6. **「打开总图」旁边一行小字**被按钮挤到同一行，`x=650` 起，和按钮抢位。
7. **地图底色是青绿+土黄的 eco 纹理平铺**，在深蓝灰背景上显得脏，和纸色/朱红调不搭。
8. **标题「第 1 深度带 地表死寂区」**字距 4px + 大空档。

**修改方向（待定，倾向方案 B）**

- 方案 A：把地图卡放大到接近满屏（1500×700），左侧行程栏收窄到 200 或改为浮层。
- 方案 B：**去掉外面那层卡片**，地图直接铺满 `#screen-flow`，HUD 信息浮在四角。← 更符合「下潜」的沉浸感，也最能解决空白问题。
- 图例移到地图右下角，字号 13px 起。
- 「总图」只留一个入口。
- 假设这是「全屏地图」，那么 `#flow-panel` 的 1240 宽限制和居中外壳都要拆。
