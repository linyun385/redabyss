# 维护者（黯民）单页攻略

> 玩家视角单页攻略。文中**每个阿拉伯数字**都能在 `cards/anmin.json` 找到出处，逐句标在括号里，文末附核对表。

**一句话爽点**：把别人当垃圾的东西拆成零件，再拿零件把自己改成一台越打越狠的机器（0051 机械增生 / 0054 武器试验 / 0057 更新换代；本句无数值）。

## 前三回合怎么打

**第一回合**先打「机械增生」（0051，0 费、`power`、打出后本回合每打一张牌掉零件）。它本场锁死，只有一次机会，所以后面尽量接低费牌把零件滚起来（0051，`energy:0`、`cost_type:lock`）。升级后的机械增生每张牌给 2 零件，值得优先升级（0051 升级，`mech_grow.value:2`）。

**第二回合**换「重铸」转牌（0056，0 费、1 零件、抽 1、能量 +1）。它便宜且能回能量，是零件不够时最稳的润滑剂（0056，`energy:0`、`part_cost:1`、`draw:1`、`energy_gain.value:1`）。升级后抽 2 张，更划算（0056 升级，`draw:2`）。

**第三回合**等手牌堆起来再打「更新换代」（0057，1 费、抽 1、弃光手牌、每弃一张得 1 零件）。手牌越多换得越多，但抽到的那张也会被弃掉，别指望留牌（0057，`energy:1`、`draw:1`、`parts_from_discard.value:1`；「抽到的也被弃」是引擎顺序，不是卡面数值）。

## 零件：攒还是花

分界很硬：零件不到 3 别碰「武器试验」（0054，`part_cost:3`）。够 3 就换永久力量（0054，`part_cost:3`、`perm_strength.value:1`）；够 5 才考虑「有机质发电」或「子代理」（0055 / 0052，`part_cost:5`）。「悬浮体」和升级后的「有机质发电」都只要 3 零件，是中盘更划算的档位（0053，`part_cost:3`；0055 升级，`part_cost:3`）。在此之前，用「重铸」按 1 零件一笔地小口花，别一次掏空（0056，`part_cost:1`）。

## 永久力量值不值得追

值得，但只在你打算打长局时（0054，`perm_strength.value:1`）。它写回下一场、之后每一击都算，而且没有上限（机制结论，无卡面数值）。代价是本场锁死、只有一次，还要花 3 零件和 1 能量（0054，`cost_type:lock`、`part_cost:3`、`energy:1`）。同样一笔零件，拿去打「重铸」换的是抽牌和能量，是当下节奏（0056，`part_cost:1`、`draw:1`、`energy_gain.value:1`）。所以：零件紧、要过眼前这一场就先重铸；零件有余、要攒到后面几场就打武器试验（0054，`part_cost:3`；0056，`part_cost:1`）。想再狠一点就把武器试验升级，一次给 2 点永久力量（0054 升级，`perm_strength.value:2`）。
