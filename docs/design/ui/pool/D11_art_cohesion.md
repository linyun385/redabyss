# D11 · 美术协调（10 区域 × 质感和卡牌版画是不是一件事）

| # | 区域 | 质感 | 和卡牌版画协调吗 |
|---|---|---|---|
| 1 | 选人 | 暗底红框 + 职业立绘（webp） | ✅ 立绘风格与卡面图案区同源 |
| 2 | HUD | 暗底红框 + emoji 图标（♥⬢✦∿◉◈⚙☾） | ⚠ emoji 图标与卡牌的 SVG 剪影风格不同——emoji 是系统字体渲染，SVG 是自绘线条 |
| 3 | 敌人 | 暗底 + SVG 剪影（.esym） | ✅ 剪影风格统一（同色 stroke） |
| 4 | 手牌 | 暗底 + SVG 脉底纹（.art.v-XXX）+ emoji 角标 | ⚠ .cost 圆圈是 CSS border-radius 圆，与 .art SVG 底纹风格不同 |
| 5 | 卡详情 | 同手牌卡面 + 文字区 | ✅ |
| 6 | 日志 | 纯文字（12px --dim） | ✅ 无视觉冲突 |
| 7 | 地图 | 暗底面板 + SVG 格子/连线/图标 | ✅ SVG 线条风格统一 |
| 8 | 事件 | 纸片选项（T76 --opt-bg）| ⚠ 纸片质感（#e7dfcc 亮底）与暗底卡牌/暗底敌人形成反差——是 **T76 的设计决定**（暗底上亮片提高对比度） |
| 9 | 奖励 | 同手牌卡面（190×267 放大版） | ✅ |
| 10 | 全局 | 主题 C 加纸纹+暗角（repeating-linear-gradient + radial-gradient） | ✅ 纹理不覆盖内容 |

**协调判定：7/10 ✅ / 3 ⚠**。三个 ⚠ 的根因：emoji 图标（HUD .ic）与 SVG 剪影（敌人 .esym）是两套图形语言。修复方案=HUD 图标改 SVG（已有 rb-* symbol 库可复用）。P2 级——不影响功能。
