# D6 · 信息密度（10 区域 × 一屏塞了多少条）

| # | 区域 | 一屏信息条数 | 可砍 | 必须加 |
|---|---|---|---|---|
| 1 | 选人 | 1 标题 + 1 副标 + 4 卡面 = 6 | 无可砍 | 每张卡面加一行一句话提示（T449 提案） |
| 2 | HUD | 10 数值 + N 遗物 = 10+N | 「当前深度」可移到地图 | 敌人意图总伤（P03 提案） |
| 3 | 敌人 | 每敌 5 条（名/意图/血条/数值/图标）× N 敌 | 图案区可缩（信息密度低） | debuff 状态可视化（UI-006） |
| 4 | 手牌 | 每卡 6 层（cost/类型/图案/名/脉/效果）× N 卡 | .cflavor 占 3px ×2 行——战斗中可隐藏 | 能量差量提示（P06 提案） |
| 5 | 卡详情 | 卡面 + 名 + ~5 行文本 + 2 按钮 = ~9 条 | 大卡面可缩到 140px（留更多文本空间） | 升级预览（UI-007） |
| 6 | 日志 | 弹性高度 / 12px 行 | 无可砍 | 自动滚动（UI-009） |
| 7 | 地图 | 层名 + 图例 + N 节点 + N 行程 | 图例可折叠 | 无必须加 |
| 8 | 事件 | 标题 + 正文 + N 选项 | 无 | 禁用选项原因可见（UI-011） |
| 9 | 奖励 | 标题 + 3 卡 + 跳过 = 5 | 无 | 无 |
| 10 | 全局 | HUD 10 + 手牌 N×6 + 敌人 N×5 + 日志 ~20 = **60+ 条/屏** | — | 这就是 roguelike |
