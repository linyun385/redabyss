# D3 · 键盘路径（10 区域 ×「不用鼠标能不能走完」）

| # | 区域 | 无鼠标能走完吗 | 缺什么 |
|---|---|---|---|
| 1 | 选人 | ✅ Tab 选卡 → Enter 开详情 → Tab 到确认 → Enter | 无 |
| 2 | HUD | N/A（HUD 只读+零件可点击） | 零件面板无键盘入口 |
| 3 | 敌人 | ✅ 看意图（只读）；❌ 选目标（UI-003） | pending 态数字键选敌（UI-003 施工单） |
| 4 | 手牌 | ✅ 1-9 出牌 + Enter 结束 | 数字键 >9 的手牌（第 10 张）无法键盘打出 |
| 5 | 卡详情 | ✅ Esc 关 → Tab 到「打出」 → Enter | 无 |
| 6 | 日志 | N/A（只读） | 无 |
| 7 | 地图 | ✅ 方向键 + Enter/空格（T57） | 无 |
| 8 | 事件 | ✅ Tab 选选项 → Enter 确认 | 无 |
| 9 | 奖励 | ✅ Tab 选卡 → Enter 确认 / Tab 到跳过 → Enter | 无 |
| 10 | 全局 | ✅ Esc 关面板；Tab 全局导航 | 无 |

结论：**键盘-only 玩家唯一走不通的路径 = pending 态选目标（UI-003）**。其余 9 个区域全通。
