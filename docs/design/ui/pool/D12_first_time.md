# D12 · 新手第一次（10 区域 × 没看过说明的人会先做什么）

| # | 区域 | 新手会先做什么 | 会不会走错 |
|---|---|---|---|
| 1 | 选人 | 点最好看的卡面 | ✅ 每张都进详情模态，模态有「以此身份下潜」——不会直接开局 |
| 2 | HUD | 忽略 HUD（10 项看不过来）| ⚠ 生命/能量看得到，共振/凝视/清醒度被忽略——T451 已判「可接受」 |
| 3 | 敌人 | 点最左边的敌人 | ⚠ 如果目标不是第一个敌人——点错目标，牌打错人 |
| 4 | 手牌 | 拖最大的那张（最贵的）| ⚠ 能量不够 → shakeit + 不出——新手不知道为什么 |
| 5 | 卡详情 | 点卡看详情 → 按「打出」| ✅ 打出按钮 disabled 时不可按 |
| 6 | 日志 | 不看（战斗中日志是背景）| ✅ |
| 7 | 地图 | 点看起来最近的格 | ✅ 只有 pickable 格可点 |
| 8 | 事件 | 选第一个选项 | ⚠ 第一个选项不一定是最安全的（event_info 判定 39.9% 明示） |
| 9 | 奖励 | 拿最稀有/最好看的卡 | ✅ 三选一没有错误答案（都是卡） |
| 10 | 全局 | 按 Esc 想退出 → 关闭了面板 | ✅ Esc 关面板正确 |

**新手会走错的地方 3 处**：#3 点错敌人（pending 态无键盘兜底）、#4 能量不够不知道差多少（P06）、#8 事件第一个选项不一定是最好的（event_info 60% 暗示/随机）。
