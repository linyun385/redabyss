# D5 · 色盲可辨（10 区域 × 灰度想象）

| # | 区域 | 灰度后分得清吗 | 分不清的是 |
|---|---|---|---|
| 1 | 选人 | ✅ 卡面有文字标签+图片差异 | 无 |
| 2 | HUD | ⚠ 共振(--res #b05a1a)与凝视(--gaze #8b1a1a)灰度后亮度接近 | 共鸣 vs 凝视——但有文字标签 .k 辅助 |
| 3 | 敌人 | ❌ 攻意图(.i-atk 红)与防意图(.i-def 蓝)灰度后亮度差异 <5% | 攻/防意图——但有「攻/防」文字前缀 |
| 4 | 手牌 | ⚠ costly(红边)与普通(暗边)灰度后边框亮度接近 | 代价牌 vs 免费牌——但有 .cost 数字 |
| 5 | 卡详情 | ✅ .warn 红字灰度后加粗仍可见 | 无 |
| 6 | 日志 | ⚠ .blocked(红+粗+左边框)灰度后靠粗体+左边框区分 ✅ | 无 |
| 7 | 地图 | ⚠ .pick(红框脉冲)与.here(红框粗)灰度后都是「亮框」——脉冲动画是唯一区分 | 可选 vs 当前——动画区分（reduced-motion 下丢失） |
| 8 | 事件 | ✅ 色条+文字+位置三层区分 | 无 |
| 9 | 奖励 | ✅ 卡面文字即内容 | 无 |
| 10 | 全局 | ✅ 主题切换有 data-theme attribute | 无 |

结论：**色盲风险集中在 #2/#3/#4**——但都有非颜色辅助（文字标签/数字/边框）。真正的风险是 reduced-motion + 色盲同时出现时 .pick vs .here 无法区分。建议给 .pick 加一个图标（如 ▸）。
