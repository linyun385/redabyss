# D9 · 空/错状态（10 区域 × 数据为空/失败/零时显示什么）

| # | 区域 | 空/零时会怎样 | 会不会崩 |
|---|---|---|---|
| 1 | 选人 | 立绘 img 404 → alt 文本「下潜者 卡面」显示 | ❌ 不会崩（有 alt） |
| 2 | HUD | hp/energy/resonance = 0 → 数字 0 显示 ✅；relics 空 → 空行 | ❌ 不会崩 |
| 3 | 敌人 | 敌人列表空 → #enemy-area 空容器（min-height 150px 占位）| ❌ 不会崩 |
| 4 | 手牌 | 手牌 0 张 → #hand 空、#btn-end 仍可点击 ✅ | ❌ 不会崩 |
| 5 | 卡详情 | 未选中任何牌 → .hidden 隐藏 ✅ | ❌ 不会崩 |
| 6 | 日志 | 无日志 → #log 空（min-height 60px 占位） | ❌ 不会崩 |
| 7 | 地图 | region 未初始化 → renderMiniMap 第一行 `if (!st.region) return` | ❌ 不会崩（有守卫） |
| 8 | 事件 | options 空 → .opts 空容器 | ❌ 不会崩（但玩家无路可走→引擎侧不应出现） |
| 9 | 奖励 | cards 空 → #flow-cards 空 + 「跳过」按钮 | ❌ 不会崩 |
| 10 | 全局 | RAW 加载失败 → 白屏（无 try-catch 包裹顶层初始化） | ⚠ **会白屏**——但这是引擎侧问题 |

结论：**UI 层不会崩**。唯一的全局崩溃风险在引擎初始化（RAW 解析失败），不属于 UI 范畴。
