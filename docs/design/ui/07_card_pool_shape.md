## A4 结论

### 1. 最空的三个生态位

- **0费 能力**: 全池仅 0 张
- **3费 能力**: 全池仅 0 张
- **3费 技能**: 全池仅 1 张
- **0费 攻击**: 全池仅 2 张
- **3费 攻击**: 全池仅 6 张

### 2. 核心卡该占哪个生态位

核心卡 = 高费(2-3) + 独特机制 + 每职业 1-2 张。

- **3费 技能 稀有档**: 全池仅 1 张 -> 核心卡落这里最不撞车
- **3费 能力 稀有档**: 全池仅 0 张 -> 核心卡落这里最不撞车
- 3费全池 7 张（T407）；3费稀有档更少——**3费稀有档是最大空位**。
- 2费稀有攻击 9 张——如果做一张「改变玩法」的2费攻击核心，也不太撞。

### 3. 「改变玩法」的实现路径

现有 effect 键（10 个非 special）: block, damage, draw, gaze_cost, gaze_gain, heal, hits, resonance_cost, resonance_drain, resonance_gain

现有 special code（15 个）: burn, delete_random, dexterity, exhaust, frail, gaze_reduce, poison, regenerate, resonance_gain, resonance_lock, retain, rule_bypass, strength, thorns, weak

**现有键不能覆盖、需要加新键的候选**：
- 每回合首张牌翻倍 -> 需 per_turn_first 标记
- 手牌上限增减 -> 需 hand_size_mod
- 敌人意图可见+1拍 -> 需 intent_preview
- 战斗开始时从牌库检索 -> 需 tutor 机制
- 引擎 applySpecial 已有 15 个 case；新增 case = 引擎改动（不在 UI 范畴）
