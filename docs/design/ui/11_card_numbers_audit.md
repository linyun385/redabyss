## B3 · 不可解释的空洞

结合 07_card_pool_shape.md 薄位表，挑出「这个位置空着且说不通」的格子。

### 3 费稀有档（全池 7 张）

- 下潜者：4 张
- 震语者：3 张
- 维护者：0 张
- 疯先知：0 张
- shared：0 张

**说不通的理由**：3 费是能量 4 下的「大牌回合」费段（T400 §2.4 判定 3 费从鸡肋变可用），但稀有档仅 7 张——设计者可能在等核心卡填这个位。

### 0 费能力（全池 0 张）


**说不通的理由**：能力（power）是持续效果——0 费能力=白送永久 buff。全池仅 0 张说明设计者有意控制（对比：1 费能力 14 张）。不是遗漏，是平衡选择。
