## 5. 未验证项

- **未验证：`const RAW`（6401，184653 字符）内部未逐条枚举**。它是单行卡牌数据，`effect.special[].code` 是效果声明而非运行时状态写入点；本表的写入点全部取引擎区（5370–6367）与 UI 区（6404–9163）的可执行代码。若需要把「卡牌能施加哪些状态」也纳入，需单独解析该 JSON 字符串。
- **未验证：`window.ART`（3945，23442 字符）未解析**。它是美术资源路径表，与状态无关。
- **未验证：CSS 优先级与运行时渲染**。本报告只数「代码里写了什么」。例如 152 的 `.enemy .hpnum` 写了 `font-size: 12px`，若被更高优先级规则覆盖，运行时不保证生效——这类情况统一标注为「代码有、运行时不保证」。
- **未验证：任务书标注 8930 行，本地 `wc -l` 实测 9165 行 / 641927 字节**。两者差异原因未查明；本报告所有行号均以本地这份 9165 行文件为准，逐行可对照。
