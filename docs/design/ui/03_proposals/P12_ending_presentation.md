# P12 · 结算页的信息呈现

## 现状
死亡/通关结算：标题→结局文本（.ending，pre-wrap）→「这一局最值得说的事」（.memoline）→ 死因提示（.hintline）→ 统计行（战斗/击杀/事件/金币）。

## 玩家在这里会遇到什么
最想知道「怎么死的 / 打了多远 / 下次怎么办」。现在按「结局→最值得说→死因→统计」顺序——但统计行在最底部，被 .ending 的长文本推到滚动区底。

## 方案
- **A 统计提前**：把统计行（战斗/击杀/事件）移到结局文本之前——先看数字再看故事。
- **B 两栏**：左=结局文本，右=统计——需要 #flow-panel 加 flex 布局。
- **C 结局折叠**：结局文本默认折叠为标题，点击展开——先看统计，想读再展开。

## 推荐
**A**。把 statline 的 DOM 顺序移到 .ending 之前——3 行 JS（showFlowPanel 里的 appendChild 顺序调换）。
