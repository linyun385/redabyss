# P08 · 共振与凝视的临界感

## 现状
HUD 共鸣/凝视是静态数字。共振 10/20/30 阈值触发时 `body.resflash`（0.5s 屏幕边框闪红）。凝视无临界视觉。

## 玩家在这里会遇到什么
共鸣 27 时不知道「再过一回合就过载」。凝视 18 时不知道「差 2 就长审结局」。

## 方案
- **A 数字变色**：共振 ≥25 时数字变红 / 凝视 ≥15 时数字变红。阈值写在 CSS `data-attr` 选择器。
- **B 进度条**：数字下方加微型进度条（宽 40px，3 段刻度 10/20/30）。可视化「还有多远」。
- **C 闪烁预警**：共振 ≥28 时数字闪烁（比 resflash 提前 2 点预警）。

## 推荐
**A（最简）**。render() 里已有 `C.resonance` 和 `run.gaze` 的值——加一个 `data-critical` attribute，CSS 变色。约 5 行 JS + 3 行 CSS。

## 落地成本
A=8 行。B=~30 行（需要新 DOM 结构）。C=3 行（复用 atkpulse）。
