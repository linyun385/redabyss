# P09 · 卡牌详情面板的信息层级

## 现状
#card-detail 304px 宽，内含大卡面（168×236）+ 卡名 + 效果文本 + 按钮。信息从上到下：卡面→卡名→效果文本（.warn 优先）→按钮。升级预览缺失（UI-007）。

## 玩家在这里会遇到什么
想看「这张牌升级后变什么」→ 只看到「可以在营火升级」。想看「这张牌的脉标签」→ 要看小卡面上的 .cveins（字号 10px）。

## 方案
- **A 加升级预览行**：UI-007 的修法——在 #cd-lines 末尾追加 `upgradeCard()` 差量。
- **B 加脉标签行**：#cd-side 里追加脉标签行（大字号）——现在只在卡面 .cveins 里，太小。
- **C 重排信息层级**：卡名 > 效果 > 代价 > 脉 > 升级预览 > 警告——当前顺序大致正确，只是缺升级和脉太小。

## 推荐
**A + B**。A=UI-007 已写（10 行 JS）；B=3 行 JS（#cd-side 追加一行脉标签）。

## 落地成本
A+B=~15 行 JS。不改引擎。
