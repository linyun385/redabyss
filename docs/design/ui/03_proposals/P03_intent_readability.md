# P03 · 敌人意图的可读性

## 现状
意图=文字行（如「攻 8」「防 6」「增益」）+ 攻击类脉冲动画。多段攻击显示「10×3」。穿透/镜像/drain 无视觉区分（UI-002）。debuff 状态无图标（UI-006）。

## 玩家在这里会遇到什么
想算「这回合挨多少」需要：① 读每个敌人的意图文本 ② 区分穿透与普通 ③ 加总多段——三步全是文字阅读，无图形辅助。

## 方案
- **A 加伤害图标**：意图行前加 ⚔（攻）/🛡（防）/↑（buff）——视觉锚。成本=render() 加一行 + CSS 图标。
- **B 加总伤横幅**：多敌时在敌人区顶部显示「本回合总承伤预估：XX」——需要计算逻辑（引擎侧或前端 sum）。
- **C 色阶**：按攻击数值分色阶（≤5 绿 / 6-10 黄 / 11+ 红）——一眼分辨轻重。

## 推荐
**C（零改动：改 .i-atk 的 color 为三档）** + **A 的图标**（render() 加 1 行）。C 一行 CSS（用 data-attribute 选择器），A 5 行 JS。

## 落地成本
C=CSS 3 行；A=JS 5 行 + SVG 3 个 symbol。
