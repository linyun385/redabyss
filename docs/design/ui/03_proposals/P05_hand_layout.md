# P05 · 手牌 10 张的布局

## 现状
`.card` 150×210px；`layoutFan()` 间距 span=min(66, max(38, (w-170)/(n-1)))；n=10 时 span=66px（1280 下 capped）。10 张总宽 = 9×66 + 150 = 744px。#hand 高度 238px。hover 上浮 46px + scale 1.06。

## 玩家在这里会遇到什么
10 张时牌互相重叠 84px（150-66）——卡名的后 2/3 被右边卡盖住。hover 能看清，但要逐张 hover。

## 方案
- **A 等宽缩放**：10 张时 span=150（不重叠，平铺）→ 总宽 = 9×150+150 = 1500px > 1240px 溢出。需 .card 缩到 105px 宽——字号同步缩，可读性差。
- **B 扇形重叠（现状优化）**：span 从 66 缩到 52（10 张时总宽 618+150=768px），重叠 98px。hover 上浮不变。**优点=改动最小（改一个参数）；缺点=重叠更多**。
- **C 两排**：上排 5 下排 5，各 150 宽不重叠 → 总高 = 2×210+8 = 428px > #hand 238px。需扩 #hand 到 428px——压缩日志区/敌人区。

## 推荐
**B（微调参数）**。span 公式从 `min(66, max(38, …))` 改 `min(52, max(38, …))`——一行改。重叠 98px 时只露卡名前 52px（约 5-6 个字），配合 hover 上浮看全文，够用。

## 落地成本
B=1 行 JS（span 公式改一个数）。A/C 需要改 CSS + JS 布局逻辑。
