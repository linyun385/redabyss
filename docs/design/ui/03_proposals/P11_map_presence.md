# P11 · 地图的「我在哪」

## 现状
地图四种节点状态：.pick（可选，红框脉冲）、.here（当前位置，红框粗）、.near（可见未访问，半透明）、.unseen（范围外，更暗+?）。行走路线 .walked（粗线）。

## 玩家在这里会遇到什么
四种状态的视觉差异够用（T75 已做能见度三态）。但**「我从哪来」**没有可视化——.walked 线是走过就画，但不知道方向。

## 方案
- **A 箭头**：.walked 线上加方向箭头（SVG marker）——一眼看出从哪走到哪。
- **B 动画**：最近走过的线段加流动动画（stroke-dashoffset 动画）。
- **C 起点标记**：每个 visited 格加一个淡色编号（第 1 步/第 2 步……）。

## 推荐
**A**。SVG marker 5 行——`.fm-line.walked { marker-end: url(#arrow) }`。

## 落地成本
A=5 行 SVG + 2 行 CSS。
