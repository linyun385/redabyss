### 0.4 关键定义（消除歧义）

| 术语 | 定义 |
|---|---|
| 断点 | `@media` 条件里出现的**宽度类 feature**（`min-width`/`max-width`/`width` 等）阈值。本项目 **0** 个。 |
| 针对性规则 | 仅在某宽度条件成立时才生效的 CSS 规则。本项目 **0** 条。 |
| 覆盖区间 | 被至少 1 条 `@media` 宽度条件覆盖的连续宽度区间。 |
| 落空区间 | 无任何 `@media` 宽度条件覆盖的连续宽度区间。 |
| 流式自适应 | **不用** `@media`、靠 `vw`/`vh`/`min()`/`max-width`/`flex-wrap`/`auto-fill`/`overflow` 随容器缩放的机制。**不等于断点**。 |
| 结论码 | `2`=可用（自适应不溢出）、`1`=部分可用（换行/滚动兜底但非重排）、`0`=不可用（裁切/覆盖）。 |
| feature 编码 | `0`=用户偏好/设备能力类（`prefers-*`）、`1`=视口宽度类、**`2`**=视口高度类、`3`=方向/宽高比类。 |
| 兜底编码 | `0`=无兜底、`1`=`flex-wrap` 换行、`2`=`overflow-x:auto` 横向滚动、`3`=`vw`/`min()`/`max-width` 收缩或 `overflow:hidden` 裁切、`4`=`flex` 可压缩 / `auto-fill` 自适应列。 |
| 名义溢出 | 按固定 px **不收缩**铺开时超出可用内容宽的 px 数。flex 项默认 `flex-shrink:1`（`x1_sizes.md:75` 已指出 `.enemy` 未设 `flex-shrink:0`），实际渲染可能收缩 → 标「代码有、运行时不保证」。 |
