# 04_CONTENT · 内容与叙事

> 这一章解决：世界观、敌人、事件、结局的补全方案。来源：world / enemy / event / ending / death / onboard。

## 结论

八层世界观按「倒吊+红光」双弧线推演完成（D5）；36 个新敌人按引擎意图类型设计完成（D6）；16 个事件加了分支（D7）；四结局+多周目建议完成（D9）；死亡四记忆点完成（D10）；新手引导验证完成（D11）。

## 八层世界观（D5）

「倒吊+红光」双弧线：L1 直立→L2 器物倒挂→L3 悬浮无挂→L4 生物倒挂→L5 结晶倒挂会说话→L6 自发光→L7 融化坠落→L8 上下失效。红光强度弧线：无→传说→一盏灯→脉动→会说话→过载→烫手→消失。（见 D5_EIGHT_LAYERS.md）

R3-D5 补了时间维度：矿场运营→废弃→三十年自然接管→玩家到来。461 张已有卡的 flavor 碎片与时间线交叉验证通过。

## 36 个新敌人（D6）

按 8 层分布（L1×5/L2×5/L3×4/L4×4/L5×4/L6×4/L7×4/L8×6 含成对 boss），全部用引擎已实现意图类型。每个敌人是某条构筑的「考题」：thorns 流的贴地红流、AoE 例外论的同位素双生体、读盾机制的熔心残响。（见 D6_THIRTY_SIX.md）

## 事件分支（D7）

16 个代表事件 × 1-2 分支 = 24 个新分支。3 个需接线（combat_start_block / next_combat_draw / 职业条件分支）。分支的「金币等价」分析发现凝视的双向定价（长审 +5 / 背身 -1）是事件层经济的核心分歧。（见 D7_EVENT_BRANCHES.md / R2-D7）

## 结局与多周目（D9 / R2-D9）

四结局叙事序：背身（逃）→ 同行（走完）→ 回头（放下）→ 长审（融入）。多周目继承建议按结局分档（长审后凝视+3 / 背身后 gift-50% / 回头后 maxHp+10 / 同行后送通用牌）。（见 D9_ENDINGS_NG.md / R2_D9）

## 死亡设计（D10）

四个死后记忆点：死亡地点碑 / 遗言牌 / 递增墓志 / 死因分类。全部不破坏 roguelike 铁律（不做数值继承/不做复活/不做负面继承）。遗言牌是叙事继承非数值继承。（见 D10_DEATH.md / R2_D10）

## 新手引导（D11）

前 10 分钟三锚点（第 3 分钟知道 roguelike / 第 6 分钟因果成立 / 第 10 分钟构筑念头）全部由现有代码达成。增量仅 2 条 onceHint（chain/gaze_cost）。中期（10-30 分钟）原则：让玩家撞见而非教学。（见 D11_ONBOARD.md）
