# 02_STREAMS · 流派与职业

> 这一章解决：14 条弱路怎么立起来、哪条放弃。来源：T330 / T331 / T332 / patch / R2-D2。

## 结论

10 条弱路有明确补法（通用牌 + 职业牌），4 条「弱但有趣」是设计价值的核心载体，2 条不可行正式结案。通用牌的三种三卡组合原型（无脉生存包/桥梁二对一/协议点火包）在四职业的适配矩阵证明：通用牌不稀释职业差异——桥梁牌在维护者 ★★★ / 震语者 ★ 的差异是设计意图而非缺陷。（见 R2-D1 组牌策略）

## 化为体验（R2-D2）

弱路的「有趣」在战斗内的体现：维护×共振是**节奏感**（攒还是花，每回合不同）；下潜×凝视是**赌感**（敢不敢再欠一点，风险曲线递增）。两种体验不需要统一——它们是「弱但有趣」的两种表现形式。

体验风险排序：下潜×凝视的前期空转感最强（借来的凝视前 3 回合空转）→ 缓解：卡面文案暗示需要凝视来源。疯先知×协议的自伤即自杀（30÷2=15 回合）→ 缓解：卡面必须写「每回合自伤 2」。（见 R2-D2）
