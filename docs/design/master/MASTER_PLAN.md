## 七件拍板事

### 1. T335 删卡口径
A：词根变体「风味由家族代表承载」→ 删变体保代表。
B：逐卡审风味 → 全部保留。
**推荐 A**。T321 已证六成卡是换皮——逐卡审的工作量是 161 张 × 20 秒 = 54 分钟纯审读，且判断标准主观。词根规则可操作、可复算。来源：T335 §二 决定记录。

### 2. 通用牌 class 字段
A：class=shared（引擎现成路径，[index.html:6419] 的 CLASS_POOL concat）。
B：新 class=universal（需改 CLASS_POOL 加分支）。
**推荐 A**。shared 路径已存在且 share_0001 已验证。改 universal 需要动 CLASS_POOL + weightedCards + cardsOfRarity 三处。来源：T341 §一。

### 3. 灼烧叠加机制
A：覆盖→叠加（同目标 burn 值相加、回合取 max）。
B：覆盖→取最大（同目标取 burn 值最大的一组）。
**推荐 B**。叠加制容易数值失控（多张灼烧牌叠出 30+ burn），取最大制保留「换更强的烧」的策略但不会滚雪球。来源：T332 诊断 / CONFLICTS C6。

### 4. 多周目凝视初始值

B：不变（凝视每局从 0 开始）。
**推荐 A**。一行改动（newRun 的 gaze:0 → 条件判断），叙事增量大（「红渊记得你」）。来源：D9 §一。

### 5. DLC_CANGMIN.md 文件名

B：改名为 DLC_CANGMIN_CIVILIZATION.md。

### 6. 下潜者 2→3 费伤害阶梯 +3
A：接受（dive_0069 是 7×3 多段，力量配合下 >24）。

## 薄弱处

1. 平衡数字全部基于 sim.js 的 AI 策略——AI 不堆凝视、不切世界、不用零件（BALANCE_T29 §六），修完之前所有通关率数字是**测量假象**。
2. D5 世界观（倒吊+红光）和 D9 多周目建议是**新增设计**——需要用户确认是否纳入正典，不属于「诊断」范畴。
3. D2 的 19 张补牌和 D1 的 17 张通用牌之间可能存在**功能重叠**——谐振垫层（通用）和静默段·结算（维护者职业牌）的定位需要在使用中校准。
4. 事件层的 universal 分支（T333 改法一）需要改 chooseEventOption（[index.html:7429]），这是前端改动——路线图把它归入第一阶段但实际涉及 index.html 修改。
