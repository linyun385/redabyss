# 卡牌名字 AI 味审查

> 2026-11-06 夜班 · 第二轮方向 6（换角度：上一轮审 flavor，本轮审 name）。
> 样本：226 张卡的 `name`（含括号变体），脚本先扫大词分布与近似重名，再逐条人工判。
> 总评先行：**名字层比 flavor 层干净一个量级**——「永恒 / 审判 / 希望 / 命运 / 之刃 / 之心」全池 **0 命中**；「圣」仅 3 处、情绪名词直给仅 4 处。硬伤集中在 8 张卡 + 2 组系列重名 + 1 处外部联想，共 11 条。

---

## 一、判定与改写（11 条）

### A. 宗教/奇幻套件词（全池最孤立的异类，3 处「圣」全在这里）

**1. dive_0033 · 圣火武器**
- 判定：「圣」在工业公司题材里是孤峰——全池 226 名只有它和它的变体、外加一张 shared 用了宗教词根。flavor 里真正立住的意象是「火漆」（授权书上的火漆是真的火漆），名字却舍近求远去了奇幻词库。
- 改：**「火漆令」**（升格版 dive_0058 同步改「火漆令·殉爆」）。

**2. dive_0058 · 圣火武器（殉爆）**
- 判定：同上，系列随改。
- 改：**「火漆令·殉爆」**。

**3. u_0009 · 倒转圣痕**
- 判定：「圣痕」+「倒转」双重修辞；flavor 的真意象是「正面的字是警告，背面的是邀请」——一张符的两种读法。
- 改：**「两读符」**（tremor 已有「五脉符」家族，「符」字根不算外来）。

### B. 情绪名词直给（名字替玩家把感觉说完了）

**4. cng_0025 · 沉默权柄**
- 判定：「权柄」是网文权力语；flavor「不说话的东西最吓人，也最硬」——名字应该长在「不说话」上，而不是「权柄」上。
- 改：**「不说话的东西」**（本作味里最冷的一类名字：短语直接当名）。

**5. cng_0034 · 火母的怀抱**
- 判定：「怀抱」温情直给；且「火母的 X」系列已有三张，本张从名字上分不出功能（抱）。
- 改：**「抱火」**（两个字，动作即危险，把温情换成代价感）。

**6. cng_0035 · 伊格的痛苦**
- 判定：「痛苦」是情绪名词直给。同系列「伊格的方向」是好名字（方向=可执行物）。
- 改：**「伊格的疼」**（疼比痛苦具体，且和 flavor「她在梦里喊疼」同词根）。

**7. cng_0036 · 归乡**
- 判定：抽象大词 + 孤例；疯先知的梦卡命名已有成熟句式（王权梦 / 城墙梦 = X+梦）。
- 改：**「回程梦」**。

### C. 成语腔与无主语修辞

**8. u_0011 · 活水引泉**
- 判定：四字成语腔，像从俗语词典里抽的；flavor 的真意象是「泉眼出水按次序，急不算次序」。
- 改：**「泉眼的次序」**。

**9. trem_0022 · 回归墟骨**
- 判定：「回归」无主语的修辞动词；flavor 的动作是「骨头归堆，不多不少」。
- 改：**「墟骨归堆」**（归堆是本作词汇——anm_0001 已有「料料入账」式账目动词传统）。

### D. 系列内重名，从名字上分不出谁是谁

**10. cng_0003 巨神的欠条 vs cng_0021 巨神的欠账**
- 判定：两张不同卡的条款——一张是「它欠我们」，一张是「我们去讨」——名字只差一个字，读牌时必然混。
- 改：cng_0021 → **「讨债的梦」**（并入王权梦/城墙梦的梦卡句式，方向也对了：讨债发生在梦里）。

**11. cng_0039 光导 vs trem_0026 光导石**
- 判定：跨职业近似名（石/无石），且 cng 这张的功能（光蛭母放贷）完全没进名字。
- 改：cng_0039 → **「利率面议」**（flavor 原句就是「利率面议」——名字已经写好了，只差捡起来）。

### E. 外部联想（非 AI 味，但命名风险同类）

**12. cng_0044 · 三体历残卷**
- 判定：世界内「三个天体的历」成立，但「三体」在中文语境的第一联想是那部小说，玩家会以为在玩梗。
- 改（可选）：**「三历残卷」**；若维护者认为联想无害，保留原名并记录在案。

## 二、名字的 AI 味特征（6 条，与 flavor 审查的 8 条互补）

1. **宗教/奇幻套件词**：圣、痕、权柄——这类词在任何卡牌游戏里都能用，所以等于不能用。判据：把名字放进随便另一个游戏毫不出戏，就是错的（例：「圣火武器」放进任意西幻池毫无违和——这就是问题）。
2. **情绪名词直给**：痛苦、怀抱、归乡——名字是货架标签，不是抒情段；情绪应该留给 flavor 的最后一行（例：「伊格的痛苦」把 flavor 里「喊疼」的戏份全抢了）。
3. **成语腔**：四字对仗、俗语结构——成语是现成的，这个游戏的名字必须现造（例：「活水引泉」vs 同池的「泉权的丈量者」，后者是造的，前者是捡的）。
4. **无主语修辞动词**：回归、倒转、觉醒——动词需要主语，名字里没有主语的动词是氛围，不是名字（例：「回归墟骨」）。
5. **系列内无功能区分**：同一前缀下两张卡只差一个近义字（欠条/欠账），或三张卡共用「火母的 X」而 X 不指向功能——系列感不等于可分辨性。
6. **外部 IP 联想**：世界内成立的词撞上中文语境的强关联专名（「三体」）——不是错，是要记录在案让维护者拍板。

## 三、什么不算 AI 味（校准）

- **公司前缀系列**（渊光重工·工作灯 / 导光索 / 接地缆……6 张）：同一厂牌不同产品，命名纪律的正面样本。
- **Pharma 后缀变体**（曜元·缓释 / 高浓 / 夜班型）：说明书命名法，本作最好的名字家族。
- **协议：X 家族**（anmin 11 张）：编号条文式命名，职业人格的一部分。
- **括号变体**（聚能枪·超载/三管、震频器·校准）：同物异态，工业感正解。
