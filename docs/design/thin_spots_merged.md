## 一张图：洞的形状

```
费段 →  0费      1费       2费      3+费
攻击   H1 空(精/稀) L2/L4 超编  H3 单卡   M2 单卡
技能   低碳水充足   L1 超编     中等      中等
能力   H2 空       充足(挤)    H2 空     空
```

**结论一句**：卡池的洞不是随机的——**0 费与 2+ 费是两个系统性空洞，1 费是系统性超编**；脉维度上热最薄，机制维度上泄压/删牌/凝视进项三根柱子各只有一根。
