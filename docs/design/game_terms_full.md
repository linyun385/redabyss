> 词源：GLOSSARY.md（设计者权威表）+ 卡池/事件/UI 实扫（首次出现行号见 `data/audit/terms_first.txt`，web=web/index.html 行号）。

## 四、系统词（开发/设计文档用语，玩家永远不该见到）

素卡/素品、账戳（relic_77 专属，未进实装池描述？——relic_77 在池内且风味自带）、另寻一路（死路救援按钮固定文案，玩家会见到 ✅）、小图/总图、雾（可见性态）、深度带/带（被「层」击败，见 T444）。
**审计结论：除「深度带」外，开发词没有漏进玩家视野。**

## 五、总判断

1. **玩家要推的词里，只有一组推不出来：脉（五脉）**。它是核心机制词，却没有 UI 内定义——五个脉名从未被解释，连携/层规则/奖励加权全挂在玩家看不见的轴上。这是全游戏最大的名词引导缺口（与 T451 #7 同源）。
2. **世界观词的「拼图式教学」运转良好**：不需要词典，行为画像（渊民/旧光者/四神）自解释。
3. **物件词靠风味即定义**：震髓/相石/曜元的首次风味文案都顺手完成了定义——这是全池文案纪律的副产品，值得保持。
4. **零开发词泄漏**（除深度带的口径分裂）——GLOSSARY 的「唯一写法」制度在「隔离玩家」方向上是成功的，失败只在「统一开发者」（T444）。
