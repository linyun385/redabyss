# T500 · 每张卡的设计意图反推

> 方法：逐张人工判读。依据 = 效果键 + 命名 + 风味文案 + 所属角色的体系（公司/震语/协议/梦境）。
> 意图 ≠ 效果：效果说的是「它做什么」，这里猜的是「它当初想解决什么问题」。
> 每张卡带一个意图标签（固定词表），文末聚类统计由脚本数标签得出 → 可复算。
> 生成：`python data/audit/gen_t500.py`
