# I06 · 水脉为什么「60 场才成型」——答案：它不是

> **结论先行**：「水脉 60 场成型」是模拟器的 **pick_card 实现伪影**（算完分数 return shown[0]——永远拿第一张展示牌，目标脉策略从未执行）。修复后**五条脉全部 5 场成型**（H04 更正版）。水的真问题不在成型速度——在曝光多样性与味道。本篇把三层原因 + 两条补救方向写清楚。
> 全部数字为估算（模型口径见 _SIM_REPORT.md）。

## 一、事故链（三个 bug 叠出 60 场）

| 层 | bug | 效果 |
|---|---|---|
| 1 | simlib.show_three 算了 reward_weights 却用 randrange 均匀采样（I01 发现并修） | T400 权重从未生效——但这对「成型速度」反而无害（硬保证还在） |
| 2 | owned 字典用中文键 vs 卡 veins 英文键（I01 发现并修） | 主脉判定失效——硬保证也死了 |
| 3 | **simlib.pick_card 丢弃分数**（本篇发现并修） | 「优先拿目标脉」策略从未执行——每场拿的都是第一张展示牌，水脉在自己展示时被跳过 |

三层叠加：展示里偶有水牌（均匀采样下 3/68≈4.4%/槽）→ 玩家不拿它 → 持有永远 0 → 权重永远 1 → 60 场截断。**「水难成型」是三层 bug 的合成影像，不是设计事实。**

## 二、修复后的真实图景（H04 更正版）

| 脉 | 成型场数（修复后） |
|---|---|
| 光/水/热/震/矿 | **全部 5.0 场** |

为什么压平了：T400 §2.3 的**硬保证**（每次三选一 ≥1 张主脉）+ 贪心拿牌 → 每场必得 1 张目标脉 → 5 场必然成型。**在「目标脉玩家」假设下，成型速度与池密度无关**——硬保证把密度差异抹平了。

## 三、那水脉还有什么真问题？（修完 bug 后仍然成立的）

1. **曝光多样性被权重挤压**：修复后权重生效，主脉曝光占比上升——但水的可达卡只有 3 张（dive_0037/0038 + u_0011），权重 ×2.5 顶在 3 张卡上 = **同一批卡反复出现**，玩家拿到的「水脉体系」是三张卡的重复，不是体系。
2. **非保证通道没有加权**：T400 §2.3 明文「事件给牌不加权」（cardsOfRarity 纯随机）——水牌在事件通道的到达率 = 池密度 4.4%，密度小在所有非保证通道都吃亏。
3. **味道缺失**（T406 V3）：可达 3 张里 2 张（满压/水样档案）有再生搭头、1 张（u_0011）是治疗+敏捷——**没有一张的流转是主体**。就算 5 场成型，成型出来的「水体系」也撑不起 §2.1 的水判据。

## 四、两条补救方向（不指具体加卡）

1. **供给端**：把可达水牌从 3 张提到 ≥8 张（T400 补牌计划本就把水列第一优先）——目的不是缩短成型时间（硬保证已经管了），是**让 5 场成型出来的东西有内容**（三张变八张才有构筑差异），同时修复非保证通道的到达率。
2. **公式端（可选，设计者拍板）**：硬保证把成型速度压平是特性也是代价——若想要「稀脉更难成型」的表达，可以把硬保证从「≥1 张主脉」弱化为「权重 ×2.5 上限提高」——密度差异会重新进入成型速度。**这是 T400 硬保证条款的重新拍板，不是参数微调。**
