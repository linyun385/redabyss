# D5 · 八层世界观补全（按「倒吊 + 红光」推演）

> 推演规则：红渊的世界是**从上往下逐渐倒转**的——L1 的一切直立，L8 一切失效。每层给：生态（引擎 LAYERS 表 [engine/core.js:17]）、可见物、红光强度（美术主题色 [index.html:6527] 交叉）、倒吊形态、玩家会遇到什么（绑定 enemies/events 的真实 id）。

## L1 地表死寂区（协议 L0–L1 · 共振资源 1 · 模式 dormant · 规则 no_light）

| 项 | 内容 |
|---|---|
| 红光强度 | 无红光。日光的残迹从这里开始失效。（主题色 `#39434e`，[index.html:6527]） |
| 可见物 | 立着的告示牌（字朝外）、还没倒的警示灯、地表矿场的最后一份排班表、干涸的钻井口 |
| 倒吊形态 | 地表的倒吊是「没倒吊的」——地表的一切都还立在原位：立着的灯、立着的告示牌、立着的人影。倒吊从 L2 开始，L1 是「倒吊之前」的世界。玩家在这里看到的立姿物件，往后每一层都会逐渐倒过来——往下潜就是看世界慢慢倒转。 |
| 玩家会遇到什么 | 嗜热古菌（enemy_d1_01）等 D1 池全部 113 只的第一批；矿道口的碎石（event_d2_1 的前置版本）；第一次看见 cost_text 提示「代价是真的」。这层的规则教育：光脉牌会失效（no_light），通用牌不会——通用牌的价值在这里第一次显形。 |

## L2 外层冷洞（协议 L1 · 共振资源 2 · 模式 dormant · 规则 cold）

| 项 | 内容 |
|---|---|
| 红光强度 | 红光是传说。岩石只把冷传下来。（主题色 `#2a323a`，[index.html:6527]） |
| 可见物 | 倒挂工具串、钟乳石之间的人造挂钩、冷凝水珠（不滴，挂在原地）、没有字的界碑 |
| 倒吊形态 | 冷洞的第一批倒吊物出现了：钟乳石本来就是倒着长的，矿工把工具也倒挂在钟乳石之间（防潮）。倒过来看，钟乳石是「往上长的柱子」——地下的树。红光在 L2 是传说，所以这些倒吊物都靠冷凝水反光显形。 |
| 玩家会遇到什么 | 冷洞食腐鳗（enemy_d2_01）；冷洞的「首张 +1 费」让玩家学会算能量顺序；无眼鳗形的正物出场。倒吊工具串是篝火文案的实体（「你把头盔摘了」——挂在哪？挂在倒吊串上）。 |

## L3 干旱空洞区（协议 L1–L2 · 共振资源 3 · 模式 steady · 规则 dry）

| 项 | 内容 |
|---|---|
| 红光强度 | 红光第一次稳定下来。像有人在很远处留了一盏灯。（主题色 `#1c2228`，[index.html:6527]） |
| 可见物 | 悬浮粉尘带、被顶住的碎石阵、天花板上的影子（L3 特有：影子投在「天上」）、干裂的泉眼 |
| 倒吊形态 | 干旱区没有水，倒吊物换成「悬在半空而不落的」：粉尘悬浮带、被上升气流顶住的碎石。它们不挂在任何东西上——L3 的倒吊是「被托住的」。红光第一次稳定，照出这些悬浮物的影子，影子投在天花板上（地面的镜像）。 |
| 玩家会遇到什么 | 硬矿洞蛇（enemy_d3_01）；「一池不流动的水」（event_d3_2）就在这一层；水脉牌 +1 费让玩家第一次因为「带错脉」多花钱。红光稳定后玩家的瞳孔开始适应——视觉上这层比 L2 亮，心理上更暗。 |

## L4 稳定空洞海（协议 L2–L3 · 共振资源 4 · 模式 pulse · 规则 bright）

| 项 | 内容 |
|---|---|
| 红光强度 | 红光脉动。整片空洞海跟着它呼吸。（主题色 `#0d1013`，[index.html:6527]） |
| 可见物 | 垂到水面的菌幕、菌幕间的小型游动体、水面红光脉动的节律（每 6 秒一次）、被菌幕缠住的老浮标 |
| 倒吊形态 | 空洞海的倒吊是生物性的：菌幕从洞顶垂到水面，每一片都是倒挂的森林。红光脉动时菌幕整体明灭——「稳定空洞海跟着它呼吸」的实感。玩家在这里第一次意识到：倒挂的才是本地的，直立的自己才是外来者。 |
| 玩家会遇到什么 | 红腔鱼（enemy_d4_01）；红蕨空洞海是 T76 色板最冷的层（L*≈55），但红光脉动让冷暖交替；「烧过又长回来的红蕨」（event_d4_2）是本层的记忆点：烧不死的东西第一次出现。 |

## L5 热泉裂带（协议 L2–L4 · 共振资源 5 · 模式 resonant · 规则 heat_tick）

| 项 | 内容 |
|---|---|
| 红光强度 | 红光开始说话。震语者管这里叫「听得清的那一层」。（主题色 `#1a0b0e`，[index.html:6527]） |
| 可见物 | 倒挂盐晶共鸣腔、蒸汽凝结层、被烤卷的手牌边缘、震语者的刻痕（前人留下的听音记录） |
| 倒吊形态 | 热泉的倒吊物是被蒸汽顶住的凝结层：水滴挂在岩顶不落（热顶着），盐在倒挂面上结晶。震语者说这一层的红光「听得清」——倒挂的盐晶是共鸣腔，风穿过时整层裂带在说话。玩家的手牌开始被烤卷，红光开始烫。 |
| 玩家会遇到什么 | 热泉管虫（enemy_d5_01，起手 defend）；静日里响起的震语（event_d5_1，rare 发牌）；heat_tick 每 3 回合灼 2——玩家第一次感受到「环境在跟牌库抢血」。共振层抽 2 的 MODE_REACTION 在这里最实用。 |

## L6 辐射矿石区（协议 L4–L5 · 共振资源 6 · 模式 overload · 规则 rad_tick）

| 项 | 内容 |
|---|---|
| 红光强度 | 红光过了头。矿石自己会亮，亮得让人分不清方向。（主题色 `#2b0a10`，[index.html:6527]） |
| 可见物 | 自亮矿脉灯串、被射线打穿的旧装备、 miners 的防护面罩（面罩内侧的字，event_d3_1 同款）、方向失效的罗盘 |
| 倒吊形态 | 辐射矿石区的倒吊是「会自己发光的」：含辐射矿脉从洞顶垂下像倒挂的灯串，不需要红光照——它们自己就是光源。这是红光过载的形态：光不再需要来源。玩家的手牌每回合被射线打穿一个洞（rad_tick），倒吊的灯串在替这一层记账。 |
| 玩家会遇到什么 | 辐射合成菌（enemy_d6_01）；rad_tick 每回合 1 伤换 1 抽：卡库厚度第一次成为生命值；「一块有字的相石」（event_d6_1）；overload 模式敌人 +3 攻——这一层的红光替敌人干活。 |

## L7 核心高热区（协议 L5 · 共振资源 7 · 模式 locked · 规则 burn_hand）

| 项 | 内容 |
|---|---|
| 红光强度 | 红光烫手。手牌在高温里卷曲，记忆也是。（主题色 `#420a12`，[index.html:6527]） |
| 可见物 | 融态金属泪、合金冰锥、正在卷曲的手牌、前人留下的已烧空的背包、贴地流动的红 |
| 倒吊形态 | 核心高热区的倒吊是「融化的」：岩顶的热把一切悬垂物融成下坠的形态——倒挂的金属泪、倒挂的合金冰锥。burn_hand 每回合烧一张手牌：这一层的倒吊物也在烧，烧掉的变成下一层的燃料。红光烫到记忆：玩家在这里丢的不只是牌。 |
| 玩家会遇到什么 | 旧光者残影（enemy_d7_01）；burn_hand 随机烧手牌——与 D2 设计的「空的手」（弃 1 抽 2）形成正反教学：环境烧的是随机的，你的弃是选择的；「值班交接」（event_d8_4 的前置）的交接物在这里。 |

## L8 红渊核心（协议 L6 · 共振资源 8 · 模式 void · 规则 final）

| 项 | 内容 |
|---|---|
| 红光强度 | 红光消失。所有颜色都在这里失效——包括恐惧的颜色。（主题色 `#64101a`，[index.html:6527]） |
| 可见物 | 无。或者只有一样：你带下来的东西。 |
| 倒吊形态 | 核心的倒吊是「没有的」：void 层脉锁死、红光消失、倒吊物全都落下去了——或者从来没有过。玩家站在世界的最底面，头顶是空。倒吊体系在这里终结：不是倒吊完了，是「上下」这个概念失效了。长审/背身/同行三个结局都从这片空里开始。 |
| 玩家会遇到什么 | 墟蛹（enemy_d8_01，四段意图含 buff+defend+attack 10）；「核心的红光」（event_d8_3，maxhp+2/damage 6）；最终 boss 前的最后一段路。void 模式脉锁死：连携恒 0（[engine/core.js:36]）——脉构筑在这里全部失效，通用牌（无脉）成为唯一稳定的输出语言。这是 T331 设计的终局证明。 |

## 收束：倒吊体系的完整弧线

L1 直立 → L2 器物倒挂 → L3 悬浮无挂 → L4 生物倒挂 → L5 结晶倒挂+会说话 → L6 自发光（不需要挂）→ L7 融化坠落 → L8 上下失效。这条弧线的每一层都回答同一个问题：「什么东西挂在上面？」——答案从「工具」走到「没有」，正是红渊把地表世界一层层没收的过程。

红光强度弧线与之互补：无 → 传说 → 一盏灯 → 脉动 → 会说话 → 过载 → 烫手 → 消失。红光在 L8 消失不是「没了」而是「无处不在到不可见」——三个结局（长审/背身/同行 [engine/core.js:849]）都是对「无处不在」的三种回答。
