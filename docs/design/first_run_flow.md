# T507 · 第一局前 3 层完整推演

> 数据源（全部来自代码/数据，非编造）：
> - 层地图：`web/index.html` RAW.layers 的 `rows`（每行选一个节点）
> - 初始卡组：`engine/core.js` `buildStarterDeck`（10 张基础）+ `startRun` 的 `STARTER_EXTRA`（+2 张=12 张）

> - 敌人数值：`data/audit/enemy_compact.txt`（来自 RAW.enemies 等）

## 二、逐层时间线（每行选一个节点）

### 第 1 层 · 地表死寂区（4 行）

| 行 | 选项 | 大概率走法 |
|---|---|---|
| 1 | 战斗 / 战斗 | 必打一场 |
| 2 | 战斗 / 事件 | 看血量 |
| 3 | 事件 / 战斗 | 同上 |
| 4 | 战斗 | 必打 |

- 战斗 3~4 场（敌人 hp 8~13，攻击 1~3），事件 1~2 个
- 收获：金 60~160，拿牌 3~4 张（卡组 15~16），无遗物
- **体感**：教学层。一击 7 伤两三下解决一只，缩起 5 挡刚好挡住攻击 3。会在这里学会「打牌→拿牌」循环。

### 第 2 层 · 外层冷洞（4 行）

| 行 | 选项 | 说明 |
|---|---|---|
| 1 | 战斗 / 事件 | |
| 2 | **精英** / 战斗 | 精英 hp 38~46（噬骨菌群/菌膜织者），攻击 9/6，菌膜织者会**偷资源** |
| 3 | 商店 / 战斗 | 第一个商店 |
| 4 | 战斗 | 必打 |

- 战斗 3~4 场（含可选精英），事件 0~1，商店 0~1
- 收获：金累计 150~280；精英给**遗物三选一**（第一件遗物在这里）
- **⚠ 卡点 1：第 2 层精英。** 这是全游戏第一个 hp 40 档敌人。初始卡组+L1 拿牌的每回合输出约 12~18，需要 3~4 回合；每回合挨 9 点，格挡侧只有缩起×4 和少量新格挡牌（5~8 挡/张）——**净损 10~16 血**。80 血角色扛得住，76 血的维护者没问题，**30/60 血的疯先知第一次真的可能死在这里**。菌膜织者还会偷共振/凝视——维护者刚攒的共振会被没收。
- 商店时机：到店时身上 100~200 金，最便宜的回血 60——刚好买一件，买第二件要掂量。

### 第 3 层 · 干旱空洞区（4 行）

| 行 | 选项 | 说明 |
|---|---|---|
| 1 | 事件 / 战斗 | |
| 2 | 精英 / 战斗 | 精英 hp 48~52（钻孔贝群/旱螈伏兵），攻击 7~11 |
| 3 | 战斗 / 商店 | 第二个商店 |
| 4 | **精英** | **强制精英** |

- 战斗 2~3 场 + 精英 1~2 只（一只强制），事件 0~1，商店 0~1
- 收获：金累计 250~420，拿牌累计 8~11 张（卡组 20~23），遗物 1~2 件
- **⚠ 卡点 2：第 3 层末的强制精英（hp 48~68，攻击最高 11~12）。** L1 攻击 2~3 → L2 攻击 4~9 → 这里 11~12，**攻击曲线在这里跳了一档**。没有敏捷/大格挡的卡组每回合净损 3~6，精英战 4~5 回合=15~30 血。刚过完 L2 精英的角色多半已经损了 10~20 血——**这是第一局最经典的死法：L2 精英残血进 L3，被强制精英补刀**。
- 事件里「一口倒在旱地的井」「干死的通道」都在讲没水——本层没有回血事件占多数，血量只会跌不会涨。

## 四、玩家会在哪一步卡住（结论）

1. **第 2 层精英**——第一次遇到「三回合杀不死就会被磨死」的敌人；疯先知（醒 30 血）的第一次生死关。
2. **第 3 层末强制精英**——攻击力从 L1 的 2~3 跳到 11~12，是前 3 层最陡的一跳；紧跟着第 4 层就有 boss（hp 120+）。
3. **金币最紧的点在第 3 层**：如果 L2、L3 商店都逛，250~420 金在两间店里只够买 2~3 件便宜货，商店的定价（最贵 320）第一局基本只能看。

复算口径：层数/节点数来自 `RAW.layers.layers[0..2].rows`；攻击数值取自各层敌人 `intent_pattern` 最大值；金币区间 = 战斗数 × randInt(20,40) + 事件均值 40 的粗估，非模拟精确值。
