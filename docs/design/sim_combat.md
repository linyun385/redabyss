# H02 · 战斗回合数与生存模拟


> **假设**：① 玩家 DPS=%.0f（前期口径，见 combat_pace.md 双口径）；② 承伤=敌人平均单发×攻击频率×回合数（defend/buff 回合按 0 摊入，偏保守——实际会更高）；
> ③ 玩家血量 diver 80/tremor 72/anmin 76/cangmin 30（醒侧）；④ 回合数=ceil(血/DPS)。
> **局限**：不模拟格挡（承伤按裸吃算，是**上界**）；不模拟升级/遗物/层规则（dry/heat_tick 会更高）；cangmin 梦侧 60 血池未计。
> 因此「能撑几场」是**最坏情况参考**，实际存活场数应明显高于此。

## 判断

1. 期望承伤/场从 L1 的 3.3 涨到 L8 的 23.4（×7.2）——与强度曲线（T453）同向。
2. **80 血裸吃可连作战数在 L3 降到 7 场**——与 T507/T528「L3 最容易死」互证（注意这是无格挡上界，实际能撑更多，但格挡装不满时该数字就是真实压力）。
3. 疯先知（醒 30 血）裸吃口径在 L2 起只剩 5~3 场余量——**必须靠格挡/梦池活着**，这与 first_5min「他从头到尾都在血线上」一致。
