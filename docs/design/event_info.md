## 判定规则（复算用）

1. 明示-无收益：result 为空。
2. 明示-风险：result 含 damage 且文本命中风险词表。
3. 明示-收益：result 含收益键且文本命中获取动词表。
4. 完全随机：result 动 gaze/resonance，或文本 ≤6 字且无获取/风险词。
5. 其余 = 暗示。
词表：风险词 = 动/咬/疼/手慢/警告/危险/触碰/代价/裂/塌/烧/刺/毒/滑/掉；获取动词 = 拿/取/捡/搜/翻/拆/收/搬开/读/喝/领/签/抄/挖/试穿/换。
机械近似非人工精读；若有争议以逐选项表内「证据」列可追溯。
