## 三、方案 A 的实现要点（跨战斗力量）

用户 01:15 定了 A：**一局内跨战斗**，不做跨局持久化。

```
1. newRun 里加：run.strength = 0
2. 战斗开始时（C 初始化，约 L5528 附近）：buffs.strength = run.strength
3. 战斗结束时：run.strength = C.buffs.strength（写回）
4. 卡牌效果支持一个新 code，比如 {code:"perm_strength", value:1}
   → 加在 C.buffs.strength 上，战斗结束时自然写回 run
```

改动点：4 处，都在 `web/index.html`。
**风险**：`run.strength` 会让维护者的成长曲线在长局里失控（每场 +1，十场就是 +10）。需要上限或者递减。
