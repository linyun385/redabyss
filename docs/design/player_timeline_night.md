# W6 · 玩家体验时间线（夜班版 · 逐层逐节点）

> 任务书（自拟）：从点开游戏到通关，按层×节点粒度推演「会看到什么、想什么」。区别于 first_run_flow（T507，前 3 层）和 experience_map（G06，四幕粗粒度）——本篇 8 层全覆盖，每层给「心智状态 + 注意力焦点 + 可能的困惑」三维。
> 数据源：raw_all.json（层节点/敌人/事件）+ engine/core.js（初始卡组）+ sim_combat/sim_economy（节奏）。全部为推演。

## 第 1 层（约 3~5 分钟）·「学规矩」

- 会看到：12 张初始卡、5 张手牌、第一张意图列表
- 心智：好奇 → 第一次出牌 → 第一次被敌人打 → 「哦，回合制」
- 注意力：只看手牌，不看敌人意图——因为 L1 敌人太弱，不看也能赢
- 可能困惑：为什么要选角色？四个有什么区别？（选人页没有提示文本实装——见 T451）
- **节点级行走**：战斗（赢）→ 战斗（赢）→ 事件（选一个）→ 战斗（赢）→ 事件 → 战斗（赢）→ 战斗
- 结束时状态：卡组 15~16 张 / 金 60~160 / 无遗物

## 第 2 层（约 5~7 分钟）·「第一次选路」

- 会看到：第一张地图（有分支）、第一个商店、第一个精英
- 心智：自信 → 遇到精英 → 「这是什么东西」→ 第一次紧张
- 注意力：开始看敌人意图（精英的攻击 9 点不是不看就能挡的）
- 可能困惑：商店该买什么？（新手不知道删牌的价值——T534 #7）
- 精英战生死判据：菌膜织者会偷共振——维护者/震语者第一次被偷资源
- 结束时状态：卡组 17~20 张 / 金 150~280 / 遗物 0~1

## 第 3 层（约 6~8 分钟）·「第一次觉得难」

- 会看到：两层精英（一层强制）、两个商店选项
- 心智：开始规划（拿什么牌、买什么）→ 强制精英 → **可能第一次死**
- 注意力：全开——意图/格挡/共振/凝视全要看
- 可能困惑：dried 层水脉贵 1——新手不知道为什么治疗变贵了
- 死法推演：L2 精英残血进 L3 → 强制精英攻击 11-14 → 没有格挡手段就撑不住
- 结束时状态：卡组 20~23 / 金 250~420 / 遗物 1~2

## 第 4 层（约 7~9 分钟）·「构筑成型」

- 会看到：第一个 boss（光蛭母 120 血三阶段）、第一个篝火
- 心智：开始有流派意识（「我好像在打共振流」）→ boss 战的节奏感
- 注意力：构筑>战斗（开始为下一层而不是这一回合规划）
- 可能困惑：篝火是什么？能干什么？（如果升级/删牌没解释——T451）
- boss 阶段判据：三阶段偷→gift→双段压顶，每次换阶段时意图列表清零——新手不知道换了
- 结束时状态：卡组 24~27 / 金 ~450

## 第 5 层（约 7~9 分钟）·「第一次觉得热」

- 会看到：热泉环境伤害（heat_tick 每 3 回合 -2）、震喉 boss（穿透+复刻）
- 心智：疲劳感第一次出现——不是战斗难，是环境在磨你
- 注意力：分心——既要管敌人又要管环境 tick
- 可能困惑：穿透攻击无视格挡——新手第一次遇到「挡了也掉血」
- 关键事件：H02 模拟显示此层期望承伤 18.5/场——**80 血裸吃只剩 4 场余量**
- 结束时状态：卡组 27~30 / 金 ~500

## 第 6 层（约 8~10 分钟）·「最难的一层」

- 会看到：辐射环境（每回合掉血+抽牌）、金属鳞鳄王 boss（150 血纯输出不设防）
- 心智：全力应对——这一层没有余量分给任何其他事
- 注意力：全在生存
- **死亡峰**：H14 模拟 200 局中 L6 死 49 局（全曲线最高）
- 可能困惑：共振自动到 30+（layer.res=6/回合）→ 过载扣血——新手不知道共振是双刃
- 结束时状态：卡组 30~33 / 金 ~425（商店花过钱）

## 第 7 层（约 8~10 分钟）·「突然换了一种难」

- 会看到：旧光者的高频共振生物、烧手牌环境、穹顶之影 boss（56 血但攻击 30）
- 心智：困惑——「怎么 boss 血变少了反而更难？」
- 注意力：重新学——L7 的难度形态从「磨」变成「一回合定生死」
- 可能困惑：穹顶之影蓄力两拍（buff×2）之后一击 30 点——新手第一次遇到「蓄力敌人」
- 烧手牌：每回合随机烧一张手牌——卡组管理在此时变成生存问题
- 结束时状态：卡组 33~36 / 金 ~530

## 第 8 层（约 10~12 分钟）·「结局」

- 会看到：核心区场景、墟蛹 boss（200 血三阶段+穿透+弃牌堆取料）、四个结局分岔
- 心智：终局感——所有学过的机制在这里同时出场
- 注意力：全开+复盘（知道最后一层了，会尝试做最好的选择）
- 关键：凝视 ≥20 → 长审结局 / ≤5 → 背身 / 其间 → 同行——**新手不知道凝视决定结局**
- 墟蛹阶段 3 的 10×3 穿透攻击是全游戏最高单回合伤害（30 点）——需要 30+ 格挡或 30+ 生命余量
- 通关后：结局文本+「这一局最值得说的事」——然后开始第二局（二周目带死亡合同）

## 全程统计

- 总时长估算：熟练 25~30 分钟 / 新手 60~75 分钟（T533）
- 总战斗：~28 场 / 总事件：~6 次 / 总商店：~2.5 次
- **卡组成长的三个拐点**：L2 精英（第一次必须想）、L4 boss（第一次有流派）、L7（第一次换难度形态）

复算：节点数来自 RAW.layers rows；回合数来自 sim_combat；死亡层来自 sim_full_run；全部为推演。
