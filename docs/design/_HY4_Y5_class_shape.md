### 2. 黯民是不是「技能牌太多 / 攻击牌太少」？

**只答对一半。**

- 技能牌：63.0%，另外三职业合计 64.0%，**不高，还低 1.0pp**；比震语者 68.4%、苍民 68.1% 都低。所以「技能牌太多」不成立。
- 攻击牌：20.4% vs 27.3%，**确实少 6.9pp**，四职业垫底，这一半成立。
- 多出来的份额去了能力牌：16.7% vs 8.7%，**多 8.0pp**，刚好补上攻击的缺口。

准确说法：**黯民不是技能牌太多，是「攻击牌太少、能力牌太多」** —— 卡池重心在铺场（power）和 0/1 费润滑，而不是直接输出。

### 3. 加入 7 张核心卡之后，比例是变健康了还是更偏了？

**总体更偏，只有两项向中间靠拢。**

| 方向 | 指标 | 判定依据 |
|---|---|---|
| ✅ 变健康 | skill 66.0% → 63.0% | 向三职业合计 64.0% 靠拢，差距 2.0pp → 1.0pp |
| ✅ 变健康 | 平均费用 0.85 → 0.91 | 新增 7 张均值 1.29，把整体拉高，缩小与 1.06~1.23 的差距 |
| ❌ 更偏 | attack 21.3% → 20.4% | 离 27.3% 更远，差距 6.0pp → 6.9pp |
| ❌ 更偏 | power 12.8% → 16.7% | 离 8.7% 更远，差距 4.1pp → 8.0pp，几乎翻倍 |
| ❌ 更偏 | 0 费占比 17.0% → 18.5% | 新增 0051、0056 两张 0 费 |
| ➖ 新增维度 | `part_cost` 0 → 5、`no_bonus` 0 → 1 | 其他三职业没有，无法用「横向健康度」衡量；属于新机制，不计入偏向判定 |

根因：新增 7 张里 **3 张是 power（42.9%）**，而原卡池 power 只占 12.8%；attack 只补了 1 张（14.3%），低于原卡池 21.3%。所以这次落地把黯民往「能力牌铺场」又推了一步，没有补攻击短板。

**净判定：4 项更偏 / 2 项更健康 / 1 项新维度 → 更偏。**
