# F8 · 设计溯源记录（防撞参考用，只记录不评判）

> 性质声明：这是**给设计者的防撞参考**，记录「与既有游戏相似」的地方，不构成任何指控，也不构成「该改」的建议。
> 证据源：`docs/BENCHMARK_SLAY_THE_SPIRE.md`（项目自己的 StS 对标实测）+ 桌面「密教图片素材（对照风格用）」目录（风格参照物的既定事实）+ 引擎/卡池实读。

## A. 与《杀戮尖塔》（Slay the Spire）相似的结构

| # | 项 | 哪里像 | 哪里不同 |
|---|---|---|---|
| A1 | 能量-出牌-回合循环 | 能量每回合回满、出牌耗能、格挡回合末消失、结束回合敌人行动——核心动作四件套同构 | 红渊格挡「遗物可留一半」（合葬结）、敌人意图是**固定循环**（StS 是带随机的池），计算深度更高 |
| A2 | 战斗奖励三选一 | 拿牌三选一 + 稀有度加权 {普通6/精良3/稀有1} 几乎同款 | 红渊计划加「脉权重 ×(1+持有数×0.25)×擅长 1.3」（T400 §2.3）——加权维度是脉不是稀有度 |
| A3 | 商店与删牌 | 商店货架随机 + 删牌服务收费 | 红渊删牌 75 金一次（StS 按次数涨价）；商店只在 L2/L3/L6 出现，比 StS 稀疏 |
| A4 | 遗物体系 | 稀有度四档（含 boss 位）、开战/回合触发、代价型遗物（凝视+2/上限−4） | 红渊遗物走「痕迹叙事」文案；boss 遗物必给（relic_must）与 StS 的 boss 遗物选择不同 |
| A5 | 地图分支 | 节点图（战斗/事件/商店/精英/篝火/boss） | 红渊是 4 行×1~2 选的**窄分支**（StS 是宽网图）；每层只有 31 个节点的 1/3 |
| A6 | 精英/篝火/事件节点种类 | 节点类型同构（campfire 篝火存在） | 红渊篝火只在 L4+；事件密度逐层 0.5~1.0，比 StS 低 |

## B. 与《密教模拟器》（Cultist Simulator）相似的气质

> 依据：项目把密教素材目录命名为「对照风格用」——风格参照是**既定事实**，不是巧合。

| # | 项 | 哪里像 | 哪里不同 |
|---|---|---|---|
| B1 | 档案记录体文案 | 「击杀登记：料料入账」「凭证归档」「签收栏空白」——冷、短、以文书为叙事 | 密教的文书是**玩家的行动媒介**（把卡放进行动槽）；红渊的文书是**叙事语气**，玩法上仍是直接出牌 |
| B2 | 「看一眼会付代价」的资源 | 凝视（gaze）≈ 密教的「注视/知晓」意象：看得越多，世界越注意你 | 红渊凝视是纯数值门槛+风险（≥20 结局/≥10 惩罚），没有密教式的卡牌污染机制 |
| B3 | 梦境作为可进入的第二世界 | 疯先知的切世/入梦 ≈ 密教的梦入 Mansus：梦里有另一套规则和回报 | 红渊的双世界是**战斗内切换**（血池分开），不是密教那种全局行动选择层 |
| B4 | 神名与不可名之物 | 巨神/光父/火母/伊格/穹顶之影——神以天体与方位存在，不露全貌 | 红渊的神是**世界观背景板**（不参与卡牌机制），密教的神直接是玩法循环的一部分 |

## C. 与其他同类游戏的点状相似

| # | 项 | 像什么 | 哪里不同 |
|---|---|---|---|
| C1 | 战斗间改造系统（维护者零件） | 跨战斗升级卡牌 ≈ 《Griftlands》的谈判外强化 / 众多 roguelike 的 permanent upgrade | 红渊改造用**击杀掉落货币**（零件 1-2/4/10 按档）且上限受牌面插槽约束——定价铁律「零件比生命贵 2~3 倍」是自己的东西 |
| C2 | 二周目继承解锁（死亡合同·增补条款） | 通关后解锁开局卡 ≈ 尖塔解锁卡池/Hades 的契约系统 | 红渊是**单卡入组**且带叙事理由（「签过一次，第二次签得更熟练」），不是数值加成 |
| C3 | 敌人意图含「复刻玩家出牌数」（mirror） | 反应式敌人 ≈ 尖塔的「痛击回应」类机制/《杀戮尖塔 mod》 | 红渊 mirror 挂在意图循环里（base += 3×lastTurnPlayed），是数值惩罚不是复制技能 |
| C4 | 「卡牌升级」系统 | 一律有 ·新/·改/·Ⅱ 后缀 ≈ 尖塔的卡牌升级 | 红渊升级写死在卡数据 `upgrade` 字段（预定义升级），不是尖塔的营地升级选择 |
| C5 | 层规则禁用某脉（no_light） | 环境禁用 ≈ 尖塔的 curse/无敌环境效果、各种 roguelike 的 debuff 层 | 红渊的禁用**精确指向一条脉**并保留 rule_bypass 豁免位——禁用是脉象系统的一部分 |

## D. 红渊自己的东西（相似度低，列出以示区分）

| # | 项 | 为什么是自己的 |
|---|---|---|
| D1 | **脉象系统**（五脉味道/脉象等级/生态进项） | 没有直接同构物——「脉」同时承担标签、构筑轴、奖励加权、层规则交互四重角色 |
| D2 | **共振层数值自动增长 + 阈值层反应** | 共振每回合 +layer.res、10/20/30 触发层反应、30 过载——「不用也会滚」的低保设计没见过同款 |
| D3 | **凝视门槛「只查不扣」** | StS/密教都不这么做（消耗型或纯惩罚）——门槛型资源是自己的定价发明 |
| D4 | **文案禁词制度 + 语域例外裁决制** | 无同类游戏有此纪律（GLOSSARY §7 的「逐条裁决」是项目自己的机制） |
| D5 | **敌人意图固定循环（无随机）** | 全员固定循环 + 阶段归零——把可计算性推到极限的设计选择 |

## 防撞提示（一句）

结构层（A 类）的同构不可避免且无害——差异点已足够多；真正值得盯防的是**气质层**（B 类）：档案体文案+「看一眼付代价」+ 梦境双世界的组合与密教气质贴得最近，若未来做对外宣传，建议把「脉象系统/共振层反应/凝视门槛」这三件 D 类自己的东西放在门面位。
