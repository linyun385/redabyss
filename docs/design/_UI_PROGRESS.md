## 修正的错误判断

诊断初稿写的「两套色板打架」**不准确**。实际情况：

项目有 A/B/C 三套**候选**材质主题（`index.html:528` 注释写的是「默认 off = 现状」），
但 `<html data-theme="C">` 把 C 写死了。而 C 这套**只覆盖了卡牌和日志，没覆盖敌人和 HUD** ——
所以一屏里半纸半暗。不是设计冲突，是**一套主题做了一半**。
