## dive_0083 帝星毁灭者（attack · common · 10 费 · 光）

**终稿效果**：对全体敌人造成 25 点伤害，无视敌方格挡；此卡在手牌中时，你每打出一张牌，此卡能量费用 -1，最低到 0。（升级：伤害 40，其余同）

1. **触发时机**：伤害在打出时；减费是手牌内的**持续状态**——每次打出任意牌时若此卡在手牌中则减 1。减费跨回合不保留（能量每回合重算，beginTurn L5680）。
2. **目标**：全体敌人（不含子代理，`resolveTargets` 'all' 分支 L5947）。
3. **数值与上限**：伤 25（升级 40）；减费步长 1，**下限 0**（A6 拍板夹 0——负费会让能量检查 L5819 恒过、扣费 L5848 变相加能量）。一回合减费次数 = 当回合实际打出牌数，无额外上限。
4. **引擎现状**：
   - 全体伤害：支持（applyCardEffect 伤害段 L5996-6004）。
   - **无视敌方格挡：无**。dealToEnemy 对所有伤害先吸收 block（L6211-6213）；玩家侧攻击没有 pierce 类分支（pierce 目前只存在于敌方→玩家方向，L6427-6429）。需在 dealToEnemy 或伤害调用处加「无视 block」参数。
   - **手牌内动态减费：无**。cardCost（L5896-5916）只读基础费、层规则、遗物脉费。每牌打出事件的挂点先例是机械增生（置位 L6115-6120 → playCard 内 L5852 记录 / L5870-5874 结算），减费监听可走同一挂点；cardCost 需新增「手牌内此卡费用衰减」项并在卡面费用显示（L8569 附近的描述生成）同步。
5. **边界与已拍板**：A6 夹 0（本规格第 3 条已写入）。与 dive_0085 的组合为设计意图（_REVIEW 00:17），不加限制。与冷洞层（每回合第一张 +1 费，cardCost L5901-5907）叠加时：冷洞加价与减费各自独立计算，最终费 = max(0, 基础 + 层修正 - 减费)，实现时保持 cardCost 单口出账。

## dive_0084 胆大妄为（skill · rare · 0 费 · 光）

**终稿效果**：本回合你的所有手牌能量费用 -1（动态，后抽的牌也吃）；本回合你每打出一张牌，获得 1 凝视。（升级：抽一张牌，其余同）

1. **触发时机**：打出时置位（到本回合结束）；减费在 cardCost 每次计费时动态生效；凝视在每次打出其他牌时 +1。
2. **目标**：手牌全体（减费）；凝视记在 `run.gaze`。
3. **数值与上限**：减费固定 1/张；凝视 +1/张，无上限（上限=当回合打出牌数）。减费后的牌最低 0 费（同 A6 逻辑，cardCost 出账统一夹 0）。
4. **引擎现状**：
   - 全手牌临时减费：无（cardCost L5896-5916 无此项）——同 0083，需 cardCost 新增本回合全局减费项。
   - 凝视增加：effect 字段 `gaze_gain` 直接支持（L6015→addGaze L6297）；「每打出一张牌」监听复用机械增生挂点（L5852 / L5870-5874）新增一个同类 buff，beginTurn 清（L5688 有同类清零先例）。
   - 升级版抽 1：`effect.draw` 支持（L6010）。
5. **边界与已拍板**：**A7 拍板：cardCost 动态计算，不置位写入**（后抽上来的牌同样 -1）。凝视是 run 级资源不随战斗清零（addGaze L6297 直写 `run.gaze`），敌方增伤吃它（gazeMul L6394，每 10 点 +10%）——机制事实，已含在卡价里。

## dive_0085 联合科技武器（attack · common · 1 费 · 光）

**终稿效果**：触发本回合最后使用过的 3 张攻击卡的效果，按打出顺序回放；不足 3 张有几张打几张，0 张则此卡无效果；回放不再触发回放；回放的数值按各卡**打出当时**的快照。（升级：能量费用 -1，其余同）

1. **触发时机**：打出时回放。
2. **目标**：随被回放各卡的原目标（快照里一并记目标类型；单体卡回放时落点为当前默认目标，引擎 `targetIdx===undefined ? 0 : targetIdx`，applySpecial L6052）。
3. **数值与上限**：回放张数上限 3；每张的数值（伤害/灼烧 v/turns 等）取打出时快照，不吃回放时刻的力量/连携（**A8 拍板快照**）。
4. **引擎现状**：
   - 无攻击卡历史栈：引擎只有上一回合打出张数（`C.lastTurnPlayed`，L6306），不含卡身份。需在 playCard 里对 `card.type === 'attack'` 压栈（挂点同 L5852），beginTurn 清栈（L5688 附近有同类清零先例）。
   - 快照实现：入栈时记录「该卡结算后的效果描述所需的字段」（damage/hits/special 等），回放时走一个不走 cardCost、不走力量加成（str 项 L5999 需置 0）的精简结算路径。引擎已有「以任意卡为主体结算」的内部形态（`C._playingCard`，L5866）可参考。
   - 升级 -1 费：同 0083 减费通道。
5. **边界与已拍板**：**A8 拍板：有几张打几张 / 0 张空过 / 回放不触发回放 / 打出时快照**。「回放不触发回放」的实现口径：回放入栈发生在正常打出时；精简结算路径不入栈，天然无递归。与帝星毁灭者组合为设计意图（_REVIEW 00:17），不加限制。快照灼烧类回放后仍走 applySpecial 的**覆盖**语义（L6058 现行号）——多张灼烧回放只有最后一张生效，属现有引擎语义，已含在 A10 的「灼烧保持覆盖」里。

## dive_0086 殖民者的补给（power · rare · 0 费 · 水 · lock）

**终稿效果**：从弃牌堆随机取 1 张加入手牌，从抽牌堆随机取 1 张加入手牌；这两张牌本回合费用 -1。（升级：同效果 + 复制一张自身洗入牌库；复制件打完照常消耗弃置，不复制 lock 状态）

1. **触发时机**：打出时取 2 张；lock 使本场只能打出一次（applyCardCost lock 分支 L6193-6196 + canPlay 拒绝 L5834）。
2. **目标**：弃牌堆→手牌 1 张；抽牌堆→手牌 1 张。
3. **数值与上限**：各 1 张；两张临时减费 1（同 0083 减费通道，夹 0）；手牌满 10 **不取**（A9 拍板；HAND_LIMIT L5393，draw 的同类上限先例 L5793）。
4. **引擎现状**：
   - 弃牌堆/抽牌堆定向取牌：无（弃牌堆现有操作只有洗回 L5794-5800、敌方吃牌 L6408-6413；抽牌堆只有顶 pop L5802 与整堆洗）。需新增取牌函数。
   - 对特定两张牌的临时减费：无（同 0083 减费通道）。
   - **抽牌堆随机取 1：A9 拍板为随机**（随机源可用 `C.rng`，randInt L5439 / 用法先例 random_effect L6143）。**弃牌堆侧的选取方式未拍板**（A9 只写了抽牌堆）——本规格留空待补：`弃牌堆取牌方式：______（随机 / 玩家选 / 顶部）`。
   - 升级复制洗入：战斗中无复制机制；牌库写入先例在局外流程（run.deck.push，L7195）；战斗中 drawPile 是 run.deck 的拷贝（L5601），需同时插 drawPile 与 run.deck 并保证 uid 唯一（uid 先例 L6808）。
5. **边界与已拍板**：**A9 拍板**：抽牌堆随机；手牌满不抽；复制件**继承 lock 不作数——复制时必须清 `_locked`**（实现细节，A9 原话「继承 lock 不作数、必须清 `_locked`」）。取牌时过滤 `_token` 临时牌与已 `_locked` 的卡（_DECISIONS 边界声明：按过滤理解，未逐字确认——保留此标注）。

## dive_0087 粘性火焰（attack · rare · 0 费 · 热）

**终稿效果**：对目标造成 2 点灼烧；这份灼烧在本场战斗内不随回合衰减。重复施加按现有覆盖规则（后一次的数值覆盖前一次）。（升级：4 点灼烧，其余同）

1. **触发时机**：打出时施加。
2. **目标**：单体敌人（applySpecial 取 `C.enemies[targetIdx]`，L6052）。
3. **数值与上限**：灼烧 2（升级 4）；不衰减 = 不走 turns 递减；重复施加**覆盖**（A10 拍板保持现状），数值不叠加。
4. **引擎现状**：
   - 灼烧本体支持：applySpecial burn L6058；endTurn 结算伤害并 `turns--`（L6321-6324）。
   - 不衰减：现引擎 burns 无条件递减。两条实现路径：① 施加时 `turns: 99`（weak/frail 的先例 L6060-6061、anm_0055 卡池用法），零引擎改动，99 回合内等效；② 给 burn 对象加 `no_decay` 标记并在 L6323 处跳过递减。**A10 拍板「永久=本场」**，两条路径都满足本场语义；①不需要动引擎。
   - 覆盖语义：L6058 直接赋值 `{v, turns}`，保持不动。
5. **边界与已拍板**：**A10 拍板：永久=本场；灼烧保持覆盖**。`type: attack` 无伤害数值的卡面观感问题（审核报告曾列）维持原状——本规格不改类型，卡面由 T4 文案规范处理。灼烧结算走 dealToEnemy（L6321）会被敌方格挡吸收（L6211-6213）——现有语义，保留。

4. **引擎现状**：
   - 现成 `random_effect`（L6129-6143）是**硬编码 5 项池取 1**，不可配置、不可多项——需参数化（池 + 项数 + 不放回），或新增一个可参数化的 special 码；改动时**不要**改悬浮体旧码的行为（悬浮体依赖现 L6129-6143）。

5. **边界与已拍板**：**A11 拍板：不放回取 2（升级 3）；伤害单体**。按修订节·更正 1 定性：随机命中能量项是概率事件（2/5，升级 3/5），非可控循环——设计意图保留。抽牌受 HAND_LIMIT（L5793）、回血受 maxHp 封顶（L6288-6295 区间）。

## dive_0089 追逐地狱（attack · rare · 3 费 · 矿 · cost_type: mark）

**终稿效果**：打出时，弃牌堆每有 1 张牌，获得 1 点力量（本场）并回复 1 点生命；代价：凝视 +1（mark 统一定价）。（升级：去掉回血，只留力量，其余同）

1. **触发时机**：打出时一次性按当前弃牌堆张数结算（本卡打出后自身进弃牌堆，L5889，不影响本次结算基数）。
2. **目标**：自己（力量、生命）；凝视代价记 run。
3. **数值与上限**：力量 +N、回血 +N，N = 弃牌堆张数；**无稿面上限**（实际上限=牌库规模；长局后段收益大是机制事实）。mark 代价 = 凝视 +1，全池统一定价（applyCardCost mark 分支 L6189-6192），不按费用缩放。
4. **引擎现状**：
   - 弃牌堆张数可读（`C.discardPile.length`，UI 侧读数先例 L8363）。
   - **按张数缩放的动态数值 special：无**——applyBuff 只吃固定值（L6026-6048）。需新增「按弃牌堆张数缩放」的 special 码，或在打出时把 N 展开为固定值传入 applyBuff。
   - 力量进 `C.buffs.strength`（L6030），本场有效，并入伤害公式（L5999）。
   - 回血 healPlayer（L6288-6295，maxHp 封顶）。
5. **边界与已拍板**：无新增拍板项；mark 定价事实已写入第 3 条。力量收益作用于本场后续所有伤害（含多段 hits 每一段，L6001-6003）。回血与力量在同一打出动作内结算，顺序为先力量后回血或一次循环内同步——建议一次循环（每张 +1 力 +1 血）保持语义直观，**此为实现建议，最终由实现者定**。

## dive_0090 研究者（skill · rare · 3 费 · 矿 · lock）

**终稿效果**：获得再生 +5；此后本场每回合开始额外 +1 能量；本局游戏从第二层起，每到达一个新深度层，再生额外 +1（第一层不计）。（升级：抽一张牌，其余同）

1. **触发时机**：打出时获得再生与「每回合 +1 能量」状态（lock 一场一次，L6193-6196 + L5834）；深度累计在局层面持续，进新层时 +1（**A12 拍板：第一层不算，从第二层起每层 +1**）。
2. **目标**：自己。
3. **数值与上限**：再生基础 5；深度加成 = 当前层数 - 1（第二层 +1、第三层 +2……）；每回合 +1 能量（本场）。无稿面上限。
4. **引擎现状**：
   - 每回合 +1 能量：beginTurn 公式已读 `run.energyBonus`（L5680）但全文件无赋值处（_IMPL_lines 已核）——需在打出时写入/在每回合结算处加项。注意公式里 energyBonus 是 run 级（跨战斗保留），若只想要本场，须用战斗态字段（如 `C.buffs` 侧新增）或打出时置 run 级、战斗结束清——实现者二选一，规格要求语义=**本场**。
   - 再生：applyBuff regenerate → `C.buffs.regen`（L6032 / L6067），每回合开始结算（L5725）。
   - 深度累计：`run.depth` 存在（L5464 初始、L6817 起始=1、取层 L6845），无「进入新层」的卡牌钩子；跨战斗数值的现有唯一先例是 `C.runStrengthCarry`（L6080-6083，局级累加、战斗内并入 L5999）。需新增一个局级再生加成载体（同 runStrengthCarry 模式）并在战斗开始时并入。
5. **边界与已拍板**：**A12 拍板：第一层不算，从第二层起每层 +1**。即局内第 N 层战斗开始时，本卡再生 = 5 + (N-1)。lock 与每回合 +1 能量的长战收益（净赚 > 3 费）维持审核报告已录事实，不再改判。升级版抽 1 支持（L6010）。
