# D13 · 敌人命名风格指南

> 数据源：145 只敌人名（RAW 三池）+ GLOSSARY §6 已有的敌人命名三式（本项目自己的规范，先引后补）。
> GLOSSARY §6 原文：敌人命名三式——「意象+部位」（空服的壳/晒裂的软管/历壁的蛀痕）、「行为者」（守夜者/补写者/执汤者/收藏家/看守/看火者）、「系列前缀」（墟-：墟蟹/墟蛹/墟腔；硫-：硫塔菌/硫雾囊菌；震-：震鳞蜥/震鳞鲤）。同前缀=同源生物，不算重名。

## 一、实测分布（145 只，按 GLOSSARY 三式归类 + 补充两式）

| 式 | 数量 | 例子 |
|---|---|---|

## 二、从数据归纳的五条规则（新敌人照做）

1. **三段式结构优先**：`[生态/状态词] + [主体] + [部位/行为]`，长度 4~7 字为主（与卡名 4 字峰值呼应）。例：`冷洞+食腐+鳗`、`辐射+金属鳞+鳄`。
2. **行为者式带「人味反差」**：行为者名（补写者/执汤者/评估员）一定是**非人在做人的工作**——这是本游戏敌人命名的核心反差装置，新敌人用行为者式时必须维持这个反差（机器在做文职、生物在做仪式）。
3. **系列前缀绑定生态**：墟- 出现在 L2/L4/L8（墟蟹/墟蛹/墟腔/墟影/墟尘），硫- 全在 L5，震- 全在 L5/L7——**前缀=生态指示器**。新系列前缀先问「它属于哪层的地质」。
4. **等级后缀用「·」**：本体与高阶形态用 `·` 连接（震喉·空腔独奏、辐射金属鳞鳄王·蜕、墟影残片·重奏、穹顶之影·网颤）——后缀是**乐/仪式词**（独奏/蜕/重奏/网颤），不是「精英+数字」。新等级后缀从音乐/仪式词表取。
5. **维护者池的例外**：机构+编号式只属于维护者池（维护单元-7/巡逻体-3/隔离门）——其他池不要用编号式，那是黯民世界观专属的物化命名。

## 三、避免什么

1. 避免纯功能名（「近战兵」「远程怪」——零出现）。
2. 避免情绪直给（「恐怖之影」「毁灭者」——零出现；同类意象用「穹顶之影」的方位+物写法）。
3. 避免英文/数字混排（除维护者池型号 `-7`/`-3` 外零出现）。
4. 避免与卡名撞结构：敌人名不用「机构·物件」双段式（那是卡名专属），敌人用单段式。

## 四、与卡名风格指南（T414）的分工

| | 卡名 | 敌名 |
|---|---|---|
| 主体结构 | 机构·物件 / 震语：X / 协议：X / 短意象 | 三段式意象 / 行为者 / 系列前缀 |
| 反差装置 | 文书腔写非人事务 | 非人做人事 |
| 等级变体 | 括号（残/改/满压） | ·后缀（乐/仪式词） |
| 生态绑定 | 无强制 | 前缀=生态指示器 |
