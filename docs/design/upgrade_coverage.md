## 缺升级的 3 张（全部是同类）

| id | 名字 | 角色 | 稀有度 | 类型/费 |
|---|---|---|---|---|
| dive_0081 | 气闸的规程 | 下潜者 | 普通 | 技能 / 0 费 |
| dive_0082 | 按规程应答 | 下潜者 | 普通 | 攻击 / 1 费 |

**模式一眼可见**：三张全是**无脉普通卡**（T408 的无脉清单成员）——「规程/应答/不许关闭」这组零费/低费生存位没有升级形态。不是某类机制缺升级，是**无脉杂牌缺升级**；与 T408 的发现（这批卡脉标签待定）指向同一个根：它们像是后补的填充位，没走完全套制作流程（升级+脉标签都缺）。

## 复算

```python
import sys; sys.path.insert(0, 'data/audit')
from audit_common import load_cards, all_cards
n = sum(1 for _, c in all_cards(load_cards()) if c.get('upgrade'))
print(n, '/ 219')
# 无升级名单
for cls, c in all_cards(load_cards()):
    if not c.get('upgrade'):
        print(cls, c['id'], c['name'])
```
