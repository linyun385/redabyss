## 复算

```
python -c "
import json, glob, os
n = 0
for f in glob.glob('cards/*.json'):
    if os.path.basename(f).startswith('_'):
        continue
    n += sum(1 for c in json.load(open(f, encoding='utf-8')) if not c.get('veins'))
print(n)
"
```
