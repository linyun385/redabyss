## 0. 选人（点击游戏到确认下潜）

**玩家看到**：`#screen-select`（L43-59）五个职业立绘（.classface，3:4 图 + 职业名）。点任一职业 → 弹 `#class-modal`（L8700-8713）：立绘 + 一句身份叙事 + 三条 stats（如维护者「初始生命 76 / 偏重：料脉 / 照脉 / 专属：零件与协议」）+ 三条 mechs + 「以此身份下潜」按钮。五职业文案在 `CLASS_INFO`（L8672-8697）。
**困惑点**：
- 指南 §0.2 要求「每个角色选择界面写一句提示告诉玩家大概怎么玩」——`mechs` 三条已经承担了，但**没有一条讲「这一职业第一场该怎么打」**；新手拿到 12 张牌后仍不知道优先做什么。
- `CLASS_INFO` 里 stats 写「偏重：料脉 / 照脉」——用族名「黯民」的自我称呼出现在叙事里（L8693「黯民。登记在册的维护者。」），与 C3 双轨制（UI 名=职业名）**一致**，但新手同时见到「黯民」「维护者」两个词，没有解释它们是同一拨人。

## 1. 开局（确认后到第一张地图）

**玩家看到**：`startRun`（L6794-6825）：
- 初始牌库 **12 张**：通用「一击」×5（1 费 7 伤）+「缩起」×4（1 费 5 挡）+ 职业 0 费抽 1 牌 ×1（L5490-5527）+ **审计补位 2 张**（下潜者=dive_0053 备用电源 + dive_0019 锚桩，L6799；通关过一次改为只补 1 张并加「死亡合同（增补条款）」L6806-6815）。
- 初始生命：下潜者 80 / 维护者 76 / 震语者 72 / 疯先知 30（L5450-5456）。
- 金币 0、零件 0、`depth=1` → 直接进地图 `showMap`（L6886）。
- 地图每层 4 行、每行走 1 格（advanceNode L6995-7005）；层说明用 `LAYER_NOTE`（L6781-6790，一层一句，已经写好玩家向文案）。

**困惑点**：
- **第一层的层规则对新手最狠**：L1 `no_light`——光脉牌直接打不出（能量照扣，L5984-5990）。而开局 12 张里下潜者补位牌 dive_0053 备用电源是**光脉**——新手第一层就拿着一张打不出的牌，且没有任何战前提示说「这层光脉没用」（LAYER_NOTE 有写，但在地图上是否显眼未核）。
- 补位牌与基础牌的来历没有交代（「备用电源」「锚桩」怎么就在包里了）——纯体验问题，不影响功能。

## 2. 第一战（L1 第 1 行，必为战斗）

**玩家看到**：`#screen-combat` 战斗屏。敌人数：35% 单只 / 65% 双只（L9230）。每回合抽 5 张（L5394）、能量 4/回合（L5395）、手牌上限 10（L5393）。敌方头顶显示下一步意图（L7245 hint）。战斗内 onceHint 教学弹条共 6 类，且**只在前 3 场战斗出现**（`run.stats.battles < 3`，L7244/7324/8201/8222/8476）：
- 抽牌循环：「一回合抽五张。用过的牌进弃牌堆，堆里洗空了就回来。」（L7244）
- 意图：「它下一步做什么，写在它头上。」（L7245）
- 代价：「这张牌要你付代价。它拿走的是真的东西。」（L7324）
- 凝视：「红渊记住了你一点。」（L8201）
- 共振：「共振到 10 了。这一层的红光会应你一声。」（L8222）
- 能量：「能量见底了。结束回合，它会满上。」（L8476）

**困惑点**：
- **格挡不清零的规则没有提示**：玩家格挡在回合结束清零（L6335），这与多数同类游戏一致，但没有任何 hint 提；新手容易攒着格挡不用。
- 敌方格挡（黄条）与玩家格挡的表现是否区分明显——视觉问题，代码层无法判定（**未确认**：需看 `#screen-combat` 渲染与 ui.css）。
- 「过载」：共振 ≥30 每回合受层数伤害（L5738-5740）——只在触到 10 时有一条 hint（L8222），**30 的悬崖没有任何事前提示**；第 1 层 +1/回合很难触到，但这是通用机制的第一次缺失。

## 3. 战后奖励（第一战结束后）

**玩家看到**：普通战后 = **三选一卡牌**（`weightedCards(3)`，L7495）；精英战后 = 卡牌 + 遗物两步（L7482-7483）；boss 战后 = **必给遗物** + 金币（第 8 层 boss 不给，L7479-7481；金币 50~80，L7501）。维护者战后在胜利面板里多一个「拆解」入口（3 零件换随机遗物+威胁等级，L8627-8637）。

**困惑点**：
- 三选一里出现的卡来自**职业池 + 通用池**（CLASS_POOL，L6752-6757）——新手分不清「这是我的职业牌还是通用牌」，卡面没有任何归属标识（**未确认**：卡牌 UI 是否渲染 class 字段——cardDesc 生成逻辑 L8565-8602 不含归属）。
- 遗物第一次出现（精英/boss 战后或商店）没有任何解释性文案：遗物效果只有 `effect_text` 一行，玩家不知道它是被动的还是需要点击。

## 4. 事件（地图上选 event 节点）

**玩家看到**：`showEvent`（L7705-7732）：标题 + 正文 + 3 个选项按钮，按钮左侧有**脉向色条**（OPT_BAR，L6759），选项下方标注脉名；`requires.vein_min` 类门槛会把按钮禁用并写明原因（L7720-7727，但全池 0 个选项在用，见 _EVENTS_AUDIT）。选完给结果文本 + 数值行（回血/掉血/凝视/金币→零件/删牌等，chooseEventOption L7734-7764）。

**困惑点**：
- 选项的「代价」**不预告**：选「搬开碎石」之前不知道会掉 5 血——结果文本是事后的。这是叙事设计（选择了才揭示），但对新手意味着**每个选项都是赌**；首个事件若同时出现「+40 金 -5 血」与「空选项」，新手学到的第一课是「第三选项永远安全」。
- 金币与零件的关系只对维护者解释（胜利面板 toast「零件 +N」），其他职业拿金币——新手维护者看到商店只收金币时会懵（见下）。

## 5. 营火（campfire 节点）

**玩家看到**：`showCampfire`（L7017-7070）四个选项：
- **静日**：回复 50% 最大生命（L7035-7042）；
- **修整装备**：升级 1 张卡（L7043 起，走 `upgradeCard` L6655，special 默认追加/`special_mode:'replace'` 替换）；
- **听震**：删 1 张牌（L7059 起）；
- 无牌可升/可删时的兜底：给随机遗物，连遗物池都空了给 50 金（L7048-7056）。

**困惑点**：
- 营火四个选项**是否互斥只能选一个**——从代码看是选一个即 `campfireResult` → `advanceNode`，新手第一次会以为能全拿（同类游戏惯例也是选一，属预期内，但界面上没有「只能选一」的明示）。
- 升级选卡界面 `showUpgradePick` 会给预览（`RedAbyss.upgradeCard(card)` L7096）——升级效果预览是否把 special 追加语义显示对（尤其 `special_mode:'replace'`），代码上走同一函数，显示一致（**未确认**：预览 UI 是否展示特殊码明细）。

## 6. 商店（shop 节点）

**玩家看到**：`showShop`（L7168-7226）：2~3 张卡（rare 150-200 / uncommon 75-110 / common 40-60 金）+ 1 件遗物（120-320 金）+ 删牌 75 + 回复 60（L7150-7165）。买不起变灰（L7219-7225）。

**困惑点（对维护者是硬伤）**：
- **维护者在商店买不起任何东西**：扣款只走 `run.gold`（L7192），而维护者金币收入为 0（战斗金币 L6510-6511 返回 0，事件与 boss 奖励全折零件 L7742/L7502-7503）。商店面板还显示「金币 0」（L7176）。新手维护者的前 20 分钟里商店=空房间。这是 T7 已录事实的体验面后果。
- 金币与零件是两个 HUD 栏（L6901-6906 把维护者的金币栏隐藏、只留零件栏），但商店只认金币——**同一局内两种货币并存且不互通**，没有任何提示说明。

## 7. 前 20 分钟的时间线（按结构数字推算）

选人+开局 <1 分钟 → 第 1 层 2~4 场普通战（每场 2~4 分钟）+ 0~2 事件 → 第一个营火/商店在第 2 层（layers.json L2 有 shop、L4 才有 campfire）→ 打到第一个精英（L2/L3）约第 10~15 分钟 → 第一个 boss 在 L4（强制，L4 第 4 行），正常节奏在第 20~30 分钟。**即「前 20 分钟」实际覆盖 L1~L3**：这三层的教学内容是——光脉失效（L1）、冻结首牌（L2）、水脉加价（L3），三条全是**限制型**规则，玩家在学会任何一条正面机制（bright/共振反应）之前先吃三条负反馈。
