## 十一、通用牌视觉体系位置

通用牌卡面视觉规则（T334 §5）：通用牌底色从五脉色板剥离，走「无色/灰白底 + 单一朱红强调」——本图的血红底是红渊全项目统一色，保留即可（它不是脉色，是世界观色）；通用牌与 special 稀有度卡的区分靠框线与角标，不在底色上区分。因此回收图的血红底**不需要**为通用牌改色，需要新增的是「无脉通用角标」——一个全批共用的角标，14 张一次性设计完成。

```
地底洞窟的碎石堆里，一块刻有模糊文字和审判图案的古老金属铭牌半埋在碎石中，露出上半个。这块金属铭牌是画面的主体，占满画面中部，表面布满了岁月侵蚀的痕迹，边缘处有几道裂纹，底部有一圈锈迹斑斑的铁环。工作台只是画面上方一条细细的边。洞底是一整片深红的光，从下往上照。红光铺满画面下三分之一，整个洞底、岩壁的下半截都被染红，红色浓到发暗。光的颜色是纯正的深红，没有橙色，没有黄光。它的下缘被染成朱红，上部沉入黑暗，阴影投向岩顶。暗面也带红，不是死黑。背景留大片纯黑，但整幅画铺满整个画面，没有画框，没有边框，没有装裱，没有留白纸边。没有天空，没有地平线，没有文字。整幅画用石版画的方式绘制：细密排线，深墨轮廓，赭黄与烟灰只用在岩壁和器物上，画面的光全部是血红，红色是画面里最饱和的颜色。整幅画只用墨黑与血红两种色块，中间没有灰阶过渡；所有表面都是哑光的，没有高光，没有反光，没有金属亮斑；形体只靠硬边轮廓和排线分开，不靠明暗塑形。
```

新提示词方向：「一块刻满条文的批文石板靠在协议柜前，签发栏的位置有一个新鲜的手写签名，签名用的墨还湿着，石板边角压着半截断掉的旧章。」——「新鲜签名 + 断章」就是「越权」两个字的可画形态。
