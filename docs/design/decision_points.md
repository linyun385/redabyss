# T506 · 每回合决策点数量（4 能量 / 抽 5 张粗估）

> 模型：手牌=抽 5 张，按游戏稀有度权重 {普通6,精良3,稀有1}（特殊按精良处理）从「本角色池+通用池」抽；1000 回合模拟，seed=42。复算：`python data/audit/gen_t506.py`。

| 角色 | 手牌类别数 A | 可打张数 B | 资源决策数 C | 决策广度 D=A+C | 判定 |
|---|---|---|---|---|---|
| 下潜者 | 3.37 | 4.34 | 0.37 | 3.75 | 充足 |
| 震语者 | 3.45 | 4.49 | 0.70 | 4.14 | 充足 |
| 维护者 | 2.94 | 4.57 | 0.03 | 2.98 | 中等 |
| 疯先知 | 2.98 | 4.32 | 0.00 | 2.98 | 中等 |

### 解读

决策广度最低的角色是 **维护者**（D=2.98）——手牌里同时出现的用途类别最少。决策广度最高的是 **震语者**（D=4.14）。

注意：这个模型只算「手牌内的分支数」，不含跨回合规划（留牌、共振积攒路线选择）——后者对疯先知/震语者这类资源系角色的实际决策量贡献更大，模型里只体现为资源决策数 C。

### 模型细节（复算用）

1. 权重抽牌与 `web/index.html` 的 `weightedCards` 同款稀有度权重；special 稀有度权重按 3（=精良档）处理。
2. 类别判定 = `audit_common.effect_types`（伤害/格挡/资源/减益/增益，一卡多类）。
3. 可打张数 = 4 能量下按费用升序贪心可打出的张数（不算共振/凝视支付牌的额外打开能力——它们计入 C 而不是 B）。
4. D = A + C；阈值：<2.5 偏少，<3.2 中等，否则充足——阈值是粗估口径，不是实测结论。
