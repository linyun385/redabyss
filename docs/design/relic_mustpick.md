## 反面清单：带副作用的遗物（30 件，不会是必拿）

其中凝视正数（凝视是债）22 件；负数值（掉血/减益）若干。完整列表随逐件数据可查，典型：凝视+2 换收益的遗物在凝视经济里是「贷款」，不是白给。

## 判定算法（复算用）

1. 副作用 = `effect_code` 中存在 `gaze` 正值（凝视是债）或任何负数值。
2. 必拿候选 = 无副作用 ∧ trigger ∈ {combat_start, turn_start, run_start} ∧ 存在正数值非凝视动作。
3. `on_kill` 需要击杀（条件性），一律不算必拿。
4. 收益差 = 主动作数值 − 同(稀有度,动作)全部遗物数值中位数（含带副作用者，作市场价）。
5. 必拿入选线 = 收益差 ≥ +1，或该(稀有度,动作)组合 ≤2 件（稀缺位）；其余无副作用自动触发的归「白赚件」附录。
