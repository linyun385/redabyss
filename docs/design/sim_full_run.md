# H14 · 整局抽卡序列模拟（200 局）

> **假设**：① 四角色各 50 局；战斗承伤=simulate_fight（裸吃口径），精英 ×1.4 / boss ×1.6 粗乘数（声明：精英/boss 数值更大的近似）；
> ② 奖励=主脉加权三选一+贪心拿牌（同 H01）；事件按 T512 概率触发，金/血/牌用 RAW 实测均值；商店策略=血 <60%% 先回血（60 金）否则买卡（75 金）；
> ③ 逐场扣血=承伤 × 格挡减伤 0.25（**校准自 H11 的贪心格挡实测**，非裸吃——首版裸吃口径 100%% 死亡、记账 bug 各一次，均已修）；事件/商店回血回充；成型=任一脉 ≥5 张；散牌=活着但 max<5。
> **局限**：不模拟格挡决策（H11 证明贪心格挡能省大量血——本模型死亡率远高于真实）；不模拟升级/遗物加成/共振层反应/双世界；精英 boss 承伤乘数是粗估。

## 判断

1. **死亡率是裸吃口径的上界**——真实玩家有格挡（H11 证明初始卡组贪心格挡 L3 每场只掉 0.6-2.8 血），真实死亡率会显著低于本表；本表的价值在**相对结构**：死亡集中在哪一层、谁的死亡率高。
2. 散牌率=活着但 max 脉 <5 的占比——T400 关心的「散牌局」风险量化；注意本模型玩家策略是「无脑拿主脉」，真人的多样拿牌会让散牌率更高还是更低取决于目标定义。
3. 拿牌通道的成型率见 H04（单脉 5 张中位场数）——本篇是「全流程版」，把死亡/事件/商店都放进来了。
