## 三、合理厚度区间与判断

- **合理厚度**：4 能量 + 每回合抽 5 + 平均费 1.09 → 每回合消耗牌库 3.7 张、补 5 张。卡组在 **22~26 张**时，核心牌（~10 张）的上手率舒适；**30 张以上**核心牌稀释明显；**42 张**基本抽不到关键牌。
- **现在的获取速度：偏肥**。期望 +12~18 进牌 vs +1~3 删牌——**净增 10~16 张**，多数局终局卡组落在 28~34 的「偏肥区间」，删牌手段不足以对冲。
- **肥的后果**（对照现有池）：核心牌上手率下降 + 基准牌占比高（`least_picked_20.md` 里那批陪跑卡一直留在卡组）→ 手牌质量被稀释。
- **结构观察**（只报告）：删牌供给（商店 1~2 次 + 一张稀有卡）与进牌速度（+12~18）之间差一个数量级——如果设计意图是「卡组要管理」，删牌手段应该更多；如果意图是「卡组自然变肥、靠稀有度权重保持质量」，那现在的参数自洽。**哪个是意图，归设计者。**
