# 第五层 · 热泉裂带

## 你看见的

热是看得见的。这一层的空气自己会流动——从每一道地缝、每一个泉眼里往上顶，把硫雾顶成一根根半透明的柱子，柱子不散，笔直地上去，撞到洞顶才摊成一顶缓慢的黄云。红光从云的后面透上来，光在里面折了好几次，落到你身上时已经是暖红色的了。

管虫林从热泉通道的天花板垂下来，一片一片，触须全朝下开合。硫塔倒挂在更高的地方，塔尖往下滴的不是水。沸泥池在栈道两侧咕嘟着，泥面鼓起、塌下、再鼓起，每一次塌下的位置都和你上一脚踩的位置有关。这一层的地面不可信，可信的是栈道——栈道也是锈的，但至少是死的。

你在这里第一次觉得「下面」这个词有了温度。红光不再是从远处漏上来的，它是热的一部分：泉是它的锅，硫雾是它的呼吸，你从头到脚泡在它里面。

## 这一层为什么有这条规矩

热泉层的规矩是：热会记账。

每一回合，你在这层停留的时间都在扣钱——不是洞收的，是你自己的身体收的。走得越久，汗越多，账越厚。所以这里的一切都在催你：管虫的触须开合是催，沸泥的鼓泡是催，连硫雾柱升上去的速度都是催。这一层不打你，它只是让「待着」变成一件需要理由的事。

共振在这一层是清晰的。热把空气撑薄了，声音走得直，你的每一次共振都像敲在一面好鼓上。「震语清晰」——清晰的另一面是：你听见的东西里，有些是替你听见的。

## 你听见的声音

底噪是 `ambience.depth5`：水声换成了汽声。很密的嘶嘶声垫在最底下，上面飘着泉眼每隔一阵的一声「咕咚」，闷，圆，像很深的喉咙在咽东西。

管虫林开合有节奏，你心跳快了它就快——这不是错觉，但你宁可当它是错觉。打出代价沉重的牌，`card.play.cost` 的音在这层带一点「汽」的尾音。你的共振条第一次成了主角：`state.resonance` 的嗡在这里不再是提醒，是旋律，你甚至开始跟着它呼吸。

战斗里 `combat.kill` 的声音在这层最利——热的东西断得干脆。偶尔泉眼方向传来一声很轻的「啵」，蛋裂了：`special.egg`，那声音不属于任何敌人，它属于这层正在孵的东西。你最好别问是什么。

`special.boss_phase` 的低鸣在这里是从地缝里出来的，先从脚底麻上来，然后才听见。打完一切照旧：汽声、咕咚、管虫林的开合。热泉不纪念谁。
