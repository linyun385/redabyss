# 第八层 · 红渊核心

## 你看见的

最后一层的入口是一段隧道，走过去之后，脚下的岩层没有了。

核心是一个腔。不是洞——洞有底，这个没有。你的栈道悬在腔的中段，往下是红，往上是红，光是唯一的材质。这一层的一切都悬着：茧室垂在不知多高的地方，垂丝从穹顶一直漫到视线尽头；行像在上面走，步态和地面上的行走一模一样；空了的防护服在更高的地方晾着，广播早就哑了。

红光在这里不再是环境，是气候。它从所有方向来，强弱像呼吸，有天气——偶尔整腔的红会暗半息，再涨回来。你的影子在这一层死了：光从四面来，影子就散了，脚边只剩一小团模糊的暗。

这是全世界最亮的地方，也是唯一让你想念第一层那线暗红的地方。那线光还弱得像个错误；这里的光已经是事实本身。

## 这一层为什么有这条规矩

最深的规矩只有一条：脉是锁的。

你从地表带来的那些活法——借水、借热、借光——在这里全部失效。核心不外借。脉锁上的时候你手里只剩你自己：你的牌，你的零件，你一路攒下来的骨头。这一层把「下潜的代价」一次结清：越深，你越像你自己，也越少东西可借。

红光偶尔「消失」的那半息，是这一层在喘气。它在喘气的间隙里，把所有挂着的东西的重量还给你看一眼——看一眼就够了。

## 你听见的声音

底噪是 `ambience.depth8`：没有水，没有汽，没有电。是一种非常深的、连成一片的哼，低到你不确定它是声音还是你的血管在响。偶尔整腔的红暗下去，底噪跟着空半息，安静得你能听见自己的睫毛。

战斗在这里不需要开场音——`combat.start` 一响，你就知道这次是真的。牌音全被那片哼垫着，`card.play.attack` 出手即沉，`combat.hurt` 闷得像隔着一层水。凝视在这里不是背景了，`state.gaze` 的嗡几乎贴着耳膜，它是这一层和你说话的方式。

垂丝动了，没有声音。行像走过，没有声音。这一层的居民已经过了需要声音的阶段。

倒下的东西是唯一有声音的：`special.death` 的断电声之后，是丝断开的「簌」。结束了，`special.victory`——金属落定的那一声在红渊核心里传了很久很久，比你任何一次都久。然后红光涨回来，把一切都收走。

你往下看。红得看不见底。你终于明白第一层标牌为什么朝下——它们写给的是走到这里的人。
