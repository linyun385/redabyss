# 第四层 · 稳定空洞海

## 你看见的

下到最后一段竖井，脚下忽然没有石头了。

空洞海是一片悬在岩层之间的黑水，水面平得像结了蜡。红光在这一层终于成了主角：光柱从水下的裂缝里一根根立起来，粗细不一，在水面上折出第二层光。整个洞是亮的——但亮得很怪，因为没有太阳，所有光都从下面来，所有影子都挂在天花板上，摇摇地垂着，像一排排睡着的蝙蝠，是藤，是须，是别的什么。

鱼群贴着光柱转，银的，腹面被照透；垂光蕨的根从顶上垂到半人高。你站在旧矿道骨架的栈道上，锈成发黑的紫。你的影子在水里，你的倒影在天上——看久了分不清哪个是你。

这是全世界第一层让你想抬头而不是低头的层。想抬头是有道理的：这里的称重、点名、滤食，都在光柱里进行，而光柱的观众席在天花板上。

## 这一层为什么有这条规矩

这层的规矩写在光柱的秩序里：定期扫过。

红光在这里不是照明，是巡逻。每隔一阵，光柱齐齐地脉冲一次，扫过整个洞——水面上所有的东西被它数一遍，数到的东西亮一下。不是光要伤人，是光需要清点。你走进来那一刻就成了清点对象，脉冲扫到你的时候，你会看见自己身体是半透明的，里面的骨头是红的。

「稳定」是层名里最不安的词：一切都在正常运转，包括清点。你在这里学会的事情是：有些光照你不是为了让你看路，是为了让别的什么看清你。

## 你听见的声音

底噪是 `ambience.depth4`：水声回来了，但不是流——是涨。一种极慢的、往上的潮压，偶尔一个气泡从深处破上来，声音圆得吓人。

脉冲扫过来的时候没有专门的音效，你只会听见 `ambience.depth4` 里所有的水声同时停半拍，然后接着涨。那半拍就是规矩。

战斗在这里最吵。`combat.start` 一响，鱼群会先围过来——`enemy.hit` 的声音是湿的，打在它们身上像打在鼓了水的皮上。你出牌，`card.play.attack` 终于有了回声：空洞把每一声都送还给你，慢半拍。第一个大东西倒下的时候，`special.boss_phase` 那声低鸣会从水底传上来，水面起一层细纹。

共振条在涨的时候，`state.resonance` 的嗡在这里最像心跳。打完，`special.victory` 是一种干脆的金属落定，像栈道把你接住了。然后水声重新涨起来，好像什么都没清点过。
