# 第二层 · 外层冷洞

## 你看见的

下去的第一件事是发现呼出的气白了。冷洞的冷不是旷野那种冷，是洞的冷——空气从洞壁里渗出来，渗一层，冷一层。岩壁上凝着薄霜，霜的下面是活的：青色的菌斑贴着壁走，走得极慢，你盯住看的时候它没动，你转个身它就挪了一指宽。

这一层开始，天花板变成主角。洞顶垂下一排排冰须，须尖挂着水珠，水珠在落地前冻住，掉在地上变成一颗颗冰珠，铺了满地。踩上去咯咯响，响声在洞里滚很远——所以你在这里走路是有代价的，所有挂着的东西都听得见你。

头顶高处的洞缝里偶尔探出半截鳗，灰白的，探出来悬一会儿，又缩回去。它不咬你。它只是在清点。落物线上方每隔一阵掉点东西下来：碎石、旧工具、冻硬的手套。地上那条「线」特别干净，干净得像被人扫过。

红光在这一层还没有名字。岩缝里那线暗红偶尔从冰须的反光里闪一下，像是有什么在很深的下面翻身。

## 这一层为什么有这条规矩

冷洞的规矩是：每一回合，你的第一下都要多付一点。

不是洞在收钱，是手在变僵。指尖冻透的人在拧第一颗螺栓的时候都会慢半拍——这一层把「慢半拍」写成了规矩。它教你的事情很简单：进洞先搓手。把这个习惯带下去，越深的洞越暖，这个习惯就越像遗物。

冰须之所以悬在头顶不落，也是同一条规矩的另一面：这里的所有东西都在省着动。省着动，才活得过冷洞。

## 你听见的声音

底噪是 `ambience.depth2`：比上一层空，水声没了，换成一种很细的风声，风从冰须之间过，像有人在很远的地方吹一支没调的笛。

你的第一张牌在这个洞里会贵一点，按下的时候 `card.play.cost` 的音头比别层钝，像指甲敲在冻硬的皮上。防御在这里是好习惯，`combat.block` 的声音在这层格外清——冷，脆，余音短。

能量用空的时候，`state.energy_empty` 在冷洞里听起来像呵气。翻地图，`ui.page`。偶尔头顶传来一声极轻的「嗒」，那是水珠冻住落地——游戏里它没有专门的音效，它混在 `ambience.depth2` 的风声里，你听久了会发现，那不是风。

杀掉东西的声音 `combat.kill` 在冷洞里传得最远。响完之后，冰须会集体颤一下，把多余的回声抖掉，然后洞重新安静。
