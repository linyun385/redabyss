# 第一层 · 地表死寂区

## 你看见的

光从脚下来。这是全世界唯一一个光的方向不需要适应的地方——它太弱了，弱到只是岩缝里的一线暗红，像有人在地底深处划了一根很久没熄的火柴。

这一层的走廊曾经是矿道。矿道的天花板比别处低，低到伸手能够到。够到的地方都挂着东西：垂垢毯、盐柱、一串擦得很亮的工牌。它们挂得不紧，但也不打算掉下来。空气是干的，带着一点盐味和旧机器的油味——油味说明这里的机器最近还转过，虽然一台都不转了。

墙壁上每隔一段就有一块标牌，字都被盐蚀平了，只有编号还认得出。编号朝下。写字的人当时大概没想到，后来的人是从下往上看这些牌子的。

洞顶是这一层最忙的地方。白得发灰的菌垫沿着头顶的热管爬成一条线，稀稀拉拉的，像一根没串紧的项链。再往上，通风井的铁篦子锈死在井口，篦子眼里塞着多年的灰。偶尔有一根丝从缝里垂下来，很细，你看它的时候它不动，你不看它的时候它也不动。

## 这一层为什么有这条规矩

规矩写在每一块标牌的背面：这里没有光。

不是「禁止光」，是「没有」。矿灯照出去三步，第三步就是纯黑。地表死了几百年，能死的都死了，剩下的东西不靠光活——它们靠头顶热管的那点余温，靠水汽，靠你走进来时带下去的那一口气。这一层的规矩其实是提醒：你带来的光不是这里的常态，是例外。例外是要还的。

所以这里安静。死寂区不欢迎声音大的客人。

## 你听见的声音

底噪是 `ambience.depth1`：很远的水声，隔着一层岩壁，像有人在很深的地方洗手。

你按开第一扇门，`ui.click`。你在界面里翻检自己的装备，`ui.page`，纸一样的声音是这层唯一干净的动静。

第一场战斗开始前有一个很短的定音，`combat.start`，像合拢一个工具箱。你打出第一张攻击牌，`card.play.attack` 是金属刮过金属的声音——这一层的攻击音都发闷，因为回声被顶棚吸掉了。敌人打你，`combat.hurt` 是钝的；你挡下来，`combat.block` 是脆的。你把能量用光还想出牌，`state.energy_empty` 会替走廊笑话你一声。

最安静的时候是杀完东西之后。`combat.kill` 一响，菌垫那边的丝就收回去一根。然后一切回到 `ambience.depth1`，仿佛刚才只是你听错了。
