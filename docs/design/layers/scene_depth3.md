# 第三层 · 干旱空洞区

## 你看见的

这一层的空气是粉的。不是雾——是磨碎的岩粉悬浮在空气里，红光从地核方向斜着穿上来，穿过粉尘，把整个洞照成一种旧照片的颜色。光有角度：它不从窗来，不从灯来，它从地面来，把所有东西的影子打在天花板上。你第一次看见自己的影子悬在头顶，会本能地缩肩。

干是这层的主语。泥壳裂成龟背纹，裂缝里嵌着上一场水的痕迹。肺鱼壳一样的空壳散在地上，壳口朝着曾经有水的方向。顶棚开始出现真正像样的居民：蛇从矿脉里垂下半身，红须团悬在须上，离你头顶差一臂。它们不动的样子比动的样子更像这一层。

顶棚是这层最红的表面——因为光从下面照，顶棚接的是反光，永远是暖的。你在这里第一次意识到：洞顶上的东西，全都把腹部朝着你。

## 这一层为什么有这条规矩

干旱层的规矩是：水，贵。

不是这里没有水——是这里的水都被顶棚收着。蓄水顶悬在头顶，渗水囊挂在渗水线上，谁想喝水，得先跟顶上谈判。水脉的牌在这里贵那一份，贵出来的部分是运费：从顶到手的运费。这条规矩在教你抬头——这一层所有值钱的东西都在你头顶，包括你的命。

红光在这一层第一次「稳定下来」。它不再是一线暗红，是一整面从下面照上来的底光。稳定的意思是：从这层起，你再也不能假装它是错觉。

## 你听见的声音

底噪是 `ambience.depth3`：风声里有沙。沙粒打在岩壁上，密得像远处的雨，但永远下不下来。

在这里打出水脉的牌，`card.play.cost` 会先响一声，再响牌本身的音——那一声「先」就是运费。牌音里 `card.play.skill` 用得最多，这一层的战斗偏文：不是砍，是撬。

你开始听见自己的共振了。`state.resonance` 是一种从下颌骨传上来的嗡，每次都在你快忘了的时候提醒一下。红光稳定下来的时候没有音效——它是一种「突然不缺什么」的感觉，硬要说，是 `ambience.depth3` 里的沙声矮下去一截。

受伤的音 `combat.hurt` 在这层发干，没有回弹。敌人挨打的声音 `enemy.hit` 反而闷闷的，像打在晒裂的泥上。杀掉红须团的时候 `combat.kill` 会带一声很短的、往下坠的尾音——须是一截一截断的。

最响的一次是你抬头看蓄水顶的时候：什么声音都没有。干旱层里，安静本身就是最贵的东西。
