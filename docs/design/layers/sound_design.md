# 八层声音设计

> 2026-11-06 夜班 · 第二轮方向 5（换角度：第一轮 scene_depth1-8 写的是「会听见什么」的文学面，本轮是**声音规格**——每一层该挂哪些已有的 wav、怎么混、缺什么）。
> 权威依据：`docs/SFX_LIST.md`（T41 钩子清单，含每条的「不要什么」）、引擎音频系统（`RedAbyssSFX` / `RedAbyssAmbience` / `opts.gain` 单次音量、ambience 循环 + 进场 1.5s 渐入）。
> 现状缺口先记两条：①切层时旧 ambience 是**硬切**（`ambSrc.stop()`），没有淡出—— eight 层的渐变设计在现状下做不了，见第六节；②wav 对账已清：`web/sfx/` 实数 **27 个音频**（19 钩子 + 8 氛围，另有 1 个 README.txt 被 ls 误计入），与 `SFX_LIST` 的 19 钩子**完全一致**；不一致的只有代码注释「28 个（20 音效 + 8 氛围）」——注释多算 1，无实际缺文件。
> 本文件只写设计，不动代码。所有 gain/闪避建议是**定性方向**，具体数值归引擎侧。

## 通用原则（八层共用）

1. **ambience 是层的呼吸，不是背景音乐**：不设旋律、不设节拍器。八条 ambience 的差异主要在「颗粒密度」与「低频量」，切换时的 1.5s 渐入保留，**建议补淡出**（0.8s），让切层像「下了一段楼梯」而不是「换了频道」。
2. **战斗音永远压 ambience 一头**：`combat.*` 全量 gain，ambience 在战斗期间建议闪避到约七成——引擎当前没有闪避通道，属缺口（第六节）。
3. **每层一个「签名瞬间」**：该层独有的声音事件（对应层规则触发），全池只在这层出现，让玩家闭眼也能报层。
4. 「不要什么」沿用 SFX_LIST 的纪律：所有新增建议末尾都给一条反向约束。

## L1 · 地表死寂区（ambience.depth1：远处水声，隔一层岩壁）

| 时刻 | 音 | 处理 |
|---|---|---|
| 签到/工牌类 UI | `ui.click` / `ui.page` | 全量。这层的 ui 音是「地表还文明」的证据 |
| 战斗开始 | `combat.start` | gain 稍低（八层里最轻的一次开场）——地表的死寂配重锤会破功 |
| 走廊空转（无事发生数秒） | 无——保持 ambience | 静默本身是 L1 的签名瞬间：**全游戏唯一会「什么都没有」的层** |
| 缺口 | 岩缝滴水（event_d1_9 场景）无对应 wav | 建议：极简水滴单音，或不做——用 ambience 里的水声带过 |

「不要」：L1 不加任何低频轰鸣。地表的死寂区如果听起来「深」，方向就错了。

## L2 · 外层冷洞（ambience.depth2：极细的风，穿过冰须）

| 时刻 | 音 | 处理 |
|---|---|---|
| 回合首张牌加费 | `card.play.cost` | gain 加两成、音头压钝——「冻僵的手」的代价感 |
| 格挡 | `combat.block` | 本层 gain 最高：冷脆的盾音在冰须层会格外好听 |
| 敌人从顶缝出手 | `enemy.hit` | 干、短，去湿感（SFX_LIST 说 enemy.hit 带「一点湿」——本层建议牺牲它） |
| 签名瞬间 | 冰须坠地的「嗒」 | **缺口**：现池没有这个音。建议一个 50ms 级的高频短点，混进 ambience 循环本体而非独立 wav |
| 「不要」 | — | L2 的风声里不许有旋律感。风不是音乐。 |

## L3 · 干旱空洞区（ambience.depth3：风里有沙）

| 时刻 | 音 | 处理 |
|---|---|---|
| 水脉牌加费 | `card.play.cost` | 与 L2 同键不同色：L2 钝、L3 干——同一条 cost 音建议按层叠不同底噪 |
| 共振阈值 | `state.resonance` | 首次「值得听」的层：steady 模式回血时共振音放低半档，让「稳定」有听觉含义 |
| 玩家受击 | `combat.hurt` | 去湿、加沙——本层的伤害听起来是磨的 |
| 签名瞬间 | 蓄水顶的水悬着不落 | **缺口**：无「悬而未落」的水声。建议复用 depth1 的水声元素但 gain 压到两成 |
| 「不要」 | — | 沙声不能密成雨。干旱层最忌讳听出发霉。 |

## L4 · 稳定空洞海（ambience.depth4：缓慢上涌的潮压 + 气泡）

| 时刻 | 音 | 处理 |
|---|---|---|
| 脉冲清点（层规则） | 无现成——建议复用 `state.resonance` 的低频轰鸣、gain 减半、拉长 | 签名瞬间：所有水声同时停半拍（引擎侧需在脉冲帧做 ambience 闪避脉冲——缺口） |
| 鱼群称重（d4_02 出手） | `enemy.hit` | 湿感全开——这一层 enemy.hit 的「一点湿」是主菜 |
| 首个 Boss | `special.boss_phase` | 光蛭母的钟声从水底传来：gain 先低后高（两拍内推满） |
| 「不要」 | — | 潮压不许变成旋律或心跳。它是重量，不是情绪。 |

## L5 · 热泉裂带（ambience.depth5：汽声 + 泉眼咕咚）

| 时刻 | 音 | 处理 |
|---|---|---|
| 出带代价的牌 | `card.play.cost` | 加汽尾（与 cost 叠加的现有机制不变，建议本层 cost 的 gain 尾部拖长） |
| 共振 | `state.resonance` | 本层是共振主场（resonant 模式）：嗡声走低频直给，允许它「过门」——从状态音升级成这层的准签名 |
| 彩蛋 | `special.egg` | ~~本层的 special.egg 是叙事内事件~~ **更正（交叉检查）**：引擎里它是全局彩蛋触发音（7256 行 `checkEasterEggs`，T39），不专属 L5；保留在 L5 段落只是因为热泉生态最合适触发彩蛋，语义以 SFX_LIST 为准 |
| Boss | `special.boss_phase` | 从地缝来：先低频震脚，后钟声（与 L4 的「从水下」区分） |
| 「不要」 | — | 汽声不许盖过 ui 音。玩家读不了菜单比什么都糟。 |

## L6 · 辐射矿石区（ambience.depth6：持续电流嗡 + 计量器咔哒）

| 时刻 | 音 | 处理 |
|---|---|---|
| 凝视增长 | `state.gaze` | 本层 gaze 音密度天然高（辐射区凝视涨得快）——建议同帧多次触发时只响第一次，其余静默，避免「沙沙成灾」 |
| 玩家受击 | `combat.hurt` | 加「发酵感」：hurt 音的尾音带一丝低频残余（rad_tick 持续伤的听觉化——缺口：持续型伤害无独立钩子） |
| 敌人受击 | `enemy.hit` | 鳞鳄类给金属音、菌毯类给湿音——同一 code 无法分型，缺口；建议按敌人 traits 二选一 |
| 签名瞬间 | 计量器咔哒进 ambience | 已在 depth6 本体里（好设计，保持），战斗中建议把咔哒压到四成，避免与 state.gaze 打架 |
| 「不要」 | — | 电流嗡不许有节奏。辐射不是鼓机。 |

## L7 · 核心高热区（ambience.depth7：贴着水壶的热鸣）

| 时刻 | 音 | 处理 |
|---|---|---|
| 能量不足 | `state.energy_empty` | 本层主角音：音头削短，像被烫回去——locked 层规则（时间感异常）的听觉面 |
| 格挡 | `combat.block` | gain 降两成：热的挡挡不住热的，格挡音自己先「虚」 |
| 大牌 | `card.play.power` / `card.play.attack` | 被热鸣垫住一半——不另做音，靠 ambience 闪避缺失的现状反而合适（唯一受益于「没有闪避」的层，见第六节的悖论） |
| 签名瞬间 | 岩腔受热的「啪」 | **缺口**：极脆的高频爆点，随机间隔——建议做进 ambience 循环本体 |
| 「不要」 | — | 热鸣不许变歌声。核心高热区是物理的，不是神性的——神性在 L8。 |

## L8 · 红渊核心（ambience.depth8：连成一片的深哼，间或整腔空半息）

| 时刻 | 音 | 处理 |
|---|---|---|
| 一切 ui | `ui.click` / `ui.page` | gain 压到六成——UI 是地表的概念，这层连界面都应该小声 |
| 战斗 | `combat.*` 全家 | 闷、沉、慢——建议全局 gain 不变但 ambience 不闪避，让牌音陷在哼声里 |
| Boss 阶段 | `special.boss_phase` | 墟蛹阶段切换建议**去掉钟声**、只留哼声塌一格——最深的地方不用钟 |
| 胜利/死亡 | `special.victory` / `special.death` | victory 的金属落定在这里传「很久」：建议尾音拉长（若引擎支持 per-call 参数）；death 是全池最轻的一次 |
| 签名瞬间 | 红光暗半息 → ambience 整体空半息 | **缺口**：需要 ambience 支持「呼吸式闪避」（周期性 duck），当前循环做不到 |
| 「不要」 | — | 深哼里永远不要出现任何近似人声的成分。L8 的可怕在于它不是任何人。 |

## 六、缺口清单（按性价比排序，全部只提设计、不动代码）

| # | 缺口 | 影响 | 建议 |
|---|---|---|---|
| 1 | ambience 切层无淡出（硬切） | 八层渐变全部失效 | `RedAbyssAmbience` 里给旧源加 0.8s 淡出再 stop——改动最小、收益最大 |
| 2 | 战斗期 ambience 无闪避 | 战斗音与氛围互相糊 | master 之外加一条 ambience bus，战斗开始 duck 到七成 |
| 3 | 脉冲/层规则触发无独立音 | 各层「签名瞬间」立不起来 | 先做 L4（脉冲停拍）与 L6（rad_tick 残余）两个，验证手感再铺 |
| 4 | 敌人受击无分型 | L6 金属/湿两种质感无法共存 | 按 enemy id 前缀映射两套 gain/滤波预设，不新增 wav |
| 5 | 回收/商店无音效链 | 交易已出文案（shops 文档），听觉空白 | 最小集三个：上秤「嗒」、零件入账、价签转向 |
| 6 | 代码注释「28 个」与实数 27 差 1 | 对账口径 | 注释改一行即可（引擎侧顺手）；`__SFX_LOG` 对账仍建议做一次 |
