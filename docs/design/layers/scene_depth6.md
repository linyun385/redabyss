# 第六层 · 辐射矿石区

## 你看见的

这一层的红不用光描述。矿石自己红——晶簇从巷道的壁和顶上长出来，红的、暗红的、红得发黑的，每一簇都在缓慢地吐着自己的光。你手上的计量器一直在响，咔哒、咔哒，快慢取决于你站在哪，以及——你很快会发现——取决于你刚打过什么。

顶棚是金属的。真正的矿用钢梁架成的顶，梁上挂着锈，锈上挂着垢，垢里嵌着螺。鳞鳄倒吸在梁上爬，腹部的鳞缝漏红光，它爬过的地方计量器响成一片。菌毯封住更远的顶，红得均匀，像一块烧透的铁。这里的「顶棚」不再是可以仰头看看的东西，它是另一层地面——有居民、有道路、有治安。

这一层的生物全部没有眼睛。眼睛在剂量表面前是多余的器官，这里的居民很早就想通了这一点。

空气是干的，但有味道：一股金属被加热又放凉过很多次的味，从鼻子里进去，在嗓子那里停一下。

## 这一层为什么有这条规矩

辐射区的规矩是：这里的东西都在呼吸辐射。

红光到这里不是「照明」也不是「巡逻」，是食物链。菌毯吃它，鳄长它，锈靠它活。所以这一层的脉冲不是扫过——是失控。局部失控的时候，整个巷道的红会齐齐涨一格，居民们跟着涨一格。你在这层学会的事情最简单也最贵：别在它呼吸的时候站在它嘴边。

凝视从这里开始真正地攒。不是因为你看它，是因为它看你——计量器的每一声咔哒，都是被看的证据。

## 你听见的声音

底噪是 `ambience.depth6`：汽声没了，换成一种持续的、极低的电流嗡，像有什么在岩层里持续放电。中间夹着计量器的咔哒——那不是游戏给你的音效，它混在底噪里，快慢就是你离危险的距离。

战斗在这里开始变得脏。`combat.hurt` 的声音带一层「沙」，是辐射在伤口里发酵的声音。`enemy.hit` 打在鳞鳄身上是金属音，打在菌毯上是湿的——同一层里两套回声。你打出力量型的牌，`card.play.power` 的低频在这里走得最远，钢梁替你传。

`state.gaze` 第一次真正成为背景音：一种很轻的、从耳朵后面来的嗡。你停不下它，就像停不下计量器。

杀掉大东西的时候 `special.death` 不像死亡，像一台机器断电——先是所有声音矮下去，然后「嗒」一下。巷道重新只剩电流嗡和咔哒。在这里，安静反而是坏消息。
