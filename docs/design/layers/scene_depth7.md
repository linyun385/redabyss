# 第七层 · 核心高热区

## 你看见的

这一层没有巷道了。矿道到这里就断了，断口整齐得像按图纸断的——往下的路全是从岩层里烧出来的空腔，一个接一个，腔和腔之间只有短的、烧斜的连接段。你在里面走，其实是被一层层往下递。

热把光变成了实体。岩腔的每一面都在发光，不是反射——岩壁本身红到了白，白到了亮的边缘。你的影子在这里是唯一黑的东西，它贴在你脚下，小得可怜。天花板上挂的东西开始不像生物：旧光者的防护服四肢张开地悬着，光柱蛇蜥缠着熄灭的柱子不动，静默歌者倒挂在穹顶的最高处，嘴张着。它们都比你安静，比你耐热，比你早到很多年。

苔是这里最不对的东西。整面穹顶的苔是活的，垂到半墙，每一条都在极轻地颤。颤的节奏你在第四层听过——那是共振的节奏，但这回不是你的，是它们自己的。

## 这一层为什么有这条规矩

核心高热区的规矩是：手会烧。

不是修辞。你的手在这里握不住太多东西——牌发烫，能量在指尖存不住，容量被热吃掉一份。这条规矩教你放弃：这层的战斗不奖励囤积，奖励决断。你手里的东西随时会 fewer，所以每一张都要值得。

时间感在这里是坏的。腔和腔的连接段长短不一，走的人会觉得有些步子特别长。「时间感异常」写进规则时，是在告诉你：你对节奏的信心是地表带来的，到这层为止。

## 你听见的声音

底噪是 `ambience.depth7`：电流嗡没有了，换成一种持续的、很低的热鸣，像把耳朵贴在烧开的水壶上但听不见气泡。偶发的音只有两种：岩腔受热的「啪」，极脆，来自头顶；以及很远的一声金属呻吟，来自更深。

你的能量条开始骗你。用空的那一刻，`state.energy_empty` 的声音发短，像被烫了一下缩回去。防御在这里成了奢侈品——`combat.block` 的脆响在这层听着都不太可靠，你知道格挡是热的，热的挡不住热的。

打出每一张大牌，`card.play.power` / `card.play.attack` 的音都会被热鸣垫住一半，闷。敌人倒下，`combat.kill` 之后常有第二声：什么挂在上面的东西松了一截，坠了半臂，又被什么接住。

`special.boss_phase` 在这一层是全套里最沉的一声，它响的时候苔会停一拍。停的那一拍里，你能听见穹顶的苔在等你先动。

你从这里开始，不太想抬头了。
