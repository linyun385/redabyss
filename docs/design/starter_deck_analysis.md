> 数据源：`engine/core.js` buildStarterDeck + `web/index.html` startRun STARTER_EXTRA（见 `first_run_flow.md` §一）。
> 数字口径：模拟 5000 手（每手抽 5、4 能量贪心出牌，seed=7），脚本输出存 `data/audit/starter_analysis.txt`。复算命令在文末。

## 观察

1. **三张「基础牌」占 9/12**（疯先知除外）：下潜者/震语者/维护者的初始卡组 = 一击×5 + 缩起×4 + 三张签名牌。签名牌全是 **0 费润滑/资源位**（抽牌/力量/共振），没有一个攻击签名位——开局输出全靠无脉的一击（7 伤）。
2. **疯先知是唯一全 1 费、唯一双世界、唯一脉标签占 7/12 的初始卡组**——醒侧无脉 5 张（输出 5 伤很弱），梦侧热 5 张（9 伤/8 挡很强）。开局强度完全取决于睡不睡。
3. **脉分布与 T400 §2.2 擅长脉的对照**：下潜者初始带矿 2+光 1（擅长=光、矿 ✓ 方向对）；震语者带震 1+矿 1+热 1（擅长=震、热，矿是不擅长脉——**相石·封忆把不擅长脉塞进了初始**）；维护者带矿 2+光 1（擅长=矿、水——**水 0 张**，且光是不擅长脉）；疯先知带热 5+光 2（擅长=水、热——**水 0 张**，光是不擅长脉）。
4. **0 费签名牌=每回合多打一张**：0×2 的维护者/震语者平均出牌 4.4~4.6 张，疯先知全 1 费只有 4.0——**疯先知的初始卡组是唯一吃不满 4 能量的**（12 张全是 1 费，第 5 张牌永远打不出，除非抽到 0 费）。

## 一句判断（每角色）

- **下潜者 vs 味道（前期强势、简单直观、小构筑）**：**对得上**。基础牌干净、0 费抽牌教构筑、备用电源一费抽 3 给爆发回合——新手第一小时手感顺。差在：签名牌全是资源位没有攻击位，「前期强势」的强势感其实来自敌人弱，不是卡强。
- **震语者 vs 味道（高上限低下限、机制性+随机性）**：**差一口**。初始 12 张里没有任何随机性/高上限元素（封忆是确定性弃牌换力量）——「赌」的味道开局不存在，要等共振/凝视卡进卡组后才有。开局手感其实是最平庸的。
- **疯先知 vs 味道（高复杂机制、联动点多、步步为营）**：**方向对、容量差**。双世界在开局就教（醒/梦两套牌）——这是四角色里唯一开局就有「决策复杂度」的。差在：梦侧牌太强、醒侧牌太弱（9 伤 vs 5 伤），「选世界」在开局不是真选择——答案永远是睡。
- **维护者 vs 味道（犹豫、不断操作、数值怪）**：**错位**。初始卡组没有任何零件相关内容——「不断操作」的手感要等玩家自己发现 HUD 齿轮（T451 的引导缺口）。初始 12 张是最「乏味」的（双 0 费抽牌+基础牌），唯一特色是基因修复台的回 8。**维护者的味道完全不在初始卡组里，在战后系统里。**
