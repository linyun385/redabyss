# R2-D7 · 事件分支的流派经济

> 第一轮（D7）给 16 个事件加了分支；这一轮算**每个分支对哪条流派值多少**——用「等价金币」做统一货币来量化分支的倾向性。

## 定价基准（从 buildShopStock 反推）

| 资源 | 金币等价 | 依据 |
|---|---|---|
| 1 金币 | 1 | 基准 |
| 1 生命 | ~1.4 | 商店合剂 60 金 / 35% ≈ 25 HP → 1 HP ≈ 1.7（但回血比买血便宜，取 1.4） |
| 1 maxHp | ~3 | 合剂回复 35% maxHp 的价值 ≈ 0.35×maxHp×1.4；maxHp ±1 的长期价值 ≈ 3 |
| 1 凝视 | ~0（负债）或 +5（长审路线资产） | 取决于玩家路线——背身流视凝视为纯负债，长审流视为投资 |
| 1 共振 | ~2 | 谐振垫层 2 共振换 7 盾 → 7 盾 ≈ 14 金 → 1 共振 ≈ 2（但只有维护者/垫层持有者能用） |
| 1 common 卡 | ~50 | 商店价 40-60 |
| 1 uncommon 卡 | ~92 | 商店价 75-110 |
| 1 rare 卡 | ~175 | 商店价 150-200 |
| 1 通用牌 | 同稀有度 | universal 档走同一价格带（T333） |

## 16 个事件的分支经济分析

| 事件 | 分支 | 金币等价 | 流派倾向 |
|---|---|---|---|
| event_d1_6 拆灯 | 拆灯带走 = universal uncommon | ~92 | 无倾向（通用） |
| event_d1_6 对灯念名 | gaze+2 + heal3 | ~5（背身）或 +10（长审）+ 4.2 = 凝视路线 +15 / 背身路线 -10 | **凝视流专属正面** |
| event_d1_7 假编号 | gaze-1 + gold30 | 28（背身 +28 / 长审 -5）+ 30 = 背身 +58 / 长审 +25 | **背身流正面** |
| event_d1_7 撕规程 | maxHp-1 + uncommon | -3 + 92 = +89 | **vitality 流正面（代价已含）** |
| event_d3_1 抄字 | gaze+2 + rare | 10 + 175 = +185 | **长审流最优单选** |
| event_d3_1 合面罩 | heal5 + memory-1 | 7 + （牌库厚度价值 ~20） = +27 | **memory 流正面** |
| event_d4_2 放火烧 | damage3 + gaze2 + rare | -4.2 + 10 + 175 = **+181** | **长审流正面 + 灼烧流叙事** |
| event_d6_1 摔相石 | damage8 + universal + gaze2 | -11.2 + 175 + 10 = **+174** | **通用牌收集线** |
| event_d6_1 不读 | maxHp+2 | +6 | **背身流正面（不看不付出凝视）** |
| event_d7_1 公开规程 | gaze4 + maxHp+1 | 长审 +20 + 3 = **+23**；背身 -20 + 3 = **-17** | **长审/背身的分水岭** |

## 流派经济的三个发现

1. **长审流在事件层的收益远高于背身流**——gaze 的「等价金币」在长审路线是正数（+5/点）、在背身路线是负数（-1/点），同一个选项的估值可以相差 30 金币以上。这不是设计缺陷——这是「凝视是负债还是资产」的核心分歧的数学表达。
2. **universal 卡的事件价值（175 金）是普通 uncommon（92 金）的 1.9 倍**——因为通用牌四职业可用，流通性溢价是合理的。这意味着 T333 的 universal 改法会让事件层在经济上变得更有吸引力。
3. **最贵的分支（event_d3_1 抄字 185 金）和最便宜的分支（event_d6_1 不读 6 金）相差 30 倍**——事件层的经济范围比战斗层（金币 20-80）宽一个数量级。这是设计特征：事件层是「低频高值」的决策点，战斗层是「高频低值」的资源积累。


## 流派经济的三个推论

从上表的等价金币分析可以推出三个影响事件层设计的结论：

**推论一：事件层是长审流的主场**——gaze 在长审路线的等价金币是正数（+5/点），这意味着所有含凝视收益的分支对长审流来说都是「白赚」。event_d3_1 的抄字（gaze+2 + rare = 185 金）是全事件层的最优单选——但它对背身流来说是 -10 金（凝视 +2 是负债）。同一个分支对两种玩家的价值差 195 金币——这种极端分歧是「凝视是路线选择而非通用资源」的数学证据。

**推论二：universal 卡的事件溢价（1.9×）鼓励玩家走通用路线**——T333 的改法如果落地，universal 卡在事件中的出现会让「拿通用牌」的期望收益高于「拿同稀有度职业牌」约 92%。这个溢价是设计意图（鼓励玩家尝试通用路线），但也需要控制——如果溢价太高，玩家会完全跳过职业牌。

**推论三：伤害分支的实际价值比标注的更低**——event_d4_2 的「放火烧」（damage 3 + gaze 2 + rare = 标称 181 金）中 damage 3 的实际价值是 -4.2（你损失了 3 HP 的购买力），所以净收益是 +181。但如果把「生命 -3」的未来风险（可能在下一场战斗因为少了 3 HP 而死亡）计入，实际收益会更低——事件的代价不只看标称数值，还要看它在当前局面下的边际影响。

## 等价金币体系的局限

等价金币体系有三个已知局限：① 凝视的双向定价（+5/-1）取决于玩家的路线选择，不是客观值——路线未定时无法定价；② 卡牌的金币等价假设「玩家会买」——实际上卡牌的价值取决于玩家的构筑需求，不是固定值；③ 共振的金币等价只对有消费端的职业有效——疯先知在没有谐振垫层之前共振的金币等价是 0。

这三个局限说明：**等价金币是分析工具不是游戏机制**——它的价值是让设计师可以用统一货币比较不同分支的倾向性，而不是让玩家看到数值。


## 等价金币体系在事件层之外的适用性

等价金币的分析方法不只适用于事件层——它可以扩展到整个游戏的资源经济分析：

| 决策点 | 等价金币可分析的内容 |
|---|---|
| 战斗中的出牌 | 每张牌的「金币产出」 = 伤害×敌人剩余血量占比 + 格挡×敌人攻击值占比——出牌的经济排序 |
| 商店购买 | 已有（定价 [index.html:6807]）——但可以用等价金币反推「这张牌在这个局面下值不值」 |
| 篝火选择 | 回血/升级/删牌三个选项的金币等价——回血的价值取决于当前 HP 和层数 |
| 遗物选择 | 每件遗物的 effect_code 转化为金币——例如 relic_07（每回合共振+1）在 30 回合游戏中等价于 30×2=60 金 |

等价金币体系的最终目标是**让所有资源决策可以被同一种货币比较**——这不需要在游戏里显示（玩家不需要看到「这个选项值 185 金」），但需要设计师在内部使用。D7 的分析就是这个工具的第一次实战。

## 事件层经济的「信息不对称」

等价金币分析揭示了一个事件层的设计特征：**玩家在选项时不知道等价金币，但设计师知道**——这意味着设计师可以刻意制造「看似不值但实际很值」的分支（如 event_d3_1 的抄字：表面上只是凝视+2 加一张 rare 牌，实际上对长审流来说是 185 金的最大收益）。

这种信息不对称是好设计还是坏设计？D7 的立场是：**好设计**——因为「发现哪个选项对自己最有利」本身就是构筑的一部分。如果所有分支的金币等价都标在选项旁边，玩家就不需要理解自己的构筑方向了——只需要选数字最大的那个。信息不对称保留了「了解自己的构筑 → 做出正确选择 → 获得回报」的完整因果链。

## 决定记录

- 金币等价是**分析工具**不是玩家可见数字——玩家永远看不到「这个分支值 185 金」，他们感受到的是「这个选项好像很值」。
- 凝视的双向定价（长审 +5 / 背身 -1）是本篇最重要的发现——它意味着同一个事件分支对不同玩家有完全不同的经济价值，而这不是 bug：这是「凝视是负债还是资产」在事件层的投影。
