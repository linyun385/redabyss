# R2-D5 · 层与层之间的过渡设计

> 第一轮（D5）写的是「每层是什么」；这一轮写**层与层之间的缝隙**——玩家从 L(n) 走进 L(n+1) 的那一刻，什么变了、什么没变、怎么感知到。

## 过渡的三种信号

| 信号 | 来源 | 玩家感知 |
|---|---|---|
| 主题色跳变 | LAYER_THEME [index.html:6527] | 瞬间的视觉冲击（L3→L4 是全游戏色温最大跳变） |
| 层规则生效 | LAYERS [engine/core.js:17] | 第一次出牌时发现「多花了 1 费」或「这张牌没了」 |
| 共振资源变化 | beginTurn 的 res [index.html:5620] | 共振增长速率变快/变慢——微妙的节奏变化 |

## 七个过渡面

### L1→L2

L1 的 no_light 只影响光脉牌，L2 的 cold 影响所有牌的首费——过渡的信号不是「某种牌不能用了」而是「所有东西都贵了一点」。玩家从「有些牌不行」变成「所有牌都打折」——代价系统从选择性变成全局性。

**过渡建议**：过渡事件建议：进入 L2 的第一个节点前插一段文案「你把手电关了。下面的东西不需要光，它们靠冷感知。」——用叙事层替代规则说明。

### L2→L3

L3 是红光第一次稳定的层（steady 模式）——从 L2 的无光进入 L3 的微光，玩家的瞳孔（心理上）放大。water 牌开始 +1 费（dry），但共振开始 +3/回合（比 L2 的 +2 快 50%）。

**过渡建议**：过渡的核心不是「变难了」而是「变量变了」——L2 你在管能量，L3 你在管共振。资源类型的切换是层间的真正分界。

### L3→L4

L4 的 bright 模式给光脉牌 +2，同时整个空洞海在脉动（红光明灭）。这是光脉牌从 L1 被禁到 L4 被加成的 180 度反转——玩家如果在 L1-L3 攒了光脉牌，L4 是它们的 Revenge Tour。

**过渡建议**：过渡设计：L4 的第一个节点如果是 combat，出图时给一张光脉牌当奖励（weightedCards 的稀有度权重对 light 标签加权——需接线）。

### L4→L5

L5 的 heat_tick 开始磨血，但 resonant 模式的层反应是抽 2——红光从「背景」变成「对话者」。震语者在这一层获得叙事主场（听音记录 [docs/ECO_ENEMIES.md]）。

**过渡建议**：过渡的卡面信号：burn 系牌开始出现在奖励池——环境在替灼烧流做铺垫。

### L5→L6

L6 的 rad_tick + overload 是全游戏环境压力的峰值：每回合 1 伤 + 敌人 +3 攻 + 玩家手牌可能被射线打穿。L5→L6 的过渡是全游戏最陡的难度跳变。

**过渡建议**：过渡建议：L5 的最后一个节点给一张稀有牌（现有 weightedCards 已保证）+ 一次全额回复——让玩家带着满状态进 L6。

### L6→L7

L7 的 burn_hand 开始烧手牌（每回合随机一张）。rad_tick 停了但 burn_hand 接了——磨血从被动变成主动掠夺。过载模式的 +3 攻在 locked 模式变成 energy_penalty。

**过渡建议**：过渡的核心：**L6 惩罚你的血，L7 惩罚你的牌**——资源类型的切换（HP→手牌）比 HP→HP 的递增更有设计感。

### L7→L8

L8 的 void 模式锁脉+红光消失——一切基于脉的策略在最后一层失效。L7→L8 的过渡是全游戏最大的构筑范式转换：连携不再有意义，无脉牌（通用牌 + 少数无脉职业牌）成为唯一稳定的输出语言。

**过渡建议**：过渡设计：这是 T331 通用牌价值的终局证明——如果玩家手里有 2-3 张无脉通用牌，L8 不是难度墙而是收割场；如果没有，L8 是最难的层。

## 收束：过渡设计的统一原则

1. **层间过渡不是难度递增，是资源类型切换**——每一层问的是「你带了对的工具吗」而不是「你够强吗」。
2. **主题色跳变是免费过渡**——LAYER_THEME 的 8 个色阶已经做好了视觉层间区分，不需要额外过渡动画。
3. **过渡文案是唯一需要新增的**——7 个过渡面各一段叙事文本（10-20 字），放在进入新一层的第一个节点的 flavor 里。

## 决定记录

- 过渡建议中的「光脉加权」「满状态回复」需要引擎接线（weightedCards 分支 / 层转换事件），不在本包范围。
- L7→L8 的「构筑范式转换」是 T331 通用牌设计的终局验证——如果通用牌在 L8 没有特殊价值，整个设计需要重审。

## 层间过渡的七个「第一次」（玩家在每个过渡面会经历什么）

| 过渡面 | 玩家的第一次 | 触发机制 | 情感 |
|---|---|---|---|
| L1→L2 | 第一次被加价 | cold 层首张 +1 费（[index.html:5772]） | 「为什么贵了？」→ 冷洞文案解释 |
| L2→L3 | 第一次共振增速变化 | res 2→3（[engine/core.js:17] 的 res 字段） | 微妙——大部分玩家不会主动注意 |
| L3→L4 | 第一次光脉被加成 | bright 层 +2（[index.html:5820]） | 如果带了光脉牌：「终于有用了！」 |
| L4→L5 | 第一次被环境灼烧 | heat_tick 每 3 回合灼 2（[engine/core.js:274]） | 「环境在打我」→ 意识到层规则是双向的 |
| L5→L6 | 第一次被辐射抽血 | rad_tick 每回合 1 伤（[engine/core.js:279]） | 「每回合都在掉血」→ 意识到时间压力 |
| L6→L7 | 第一次被烧手牌 | burn_hand 每回合随机烧一张（[engine/core.js:284]） | 「它在偷我的牌」→ 比掉血更痛 |
| L7→L8 | 第一次脉锁死 | void 模式（[engine/core.js:36]） | 「连携不能用了」→ 构筑范式转换 |

七个「第一次」按层排列，构成了一条**从「代价选择」到「代价被迫」**的弧线：L2 的 +1 费是玩家可以预防的（不带水脉就行），L7 的烧手牌是完全不可控的（随机）——层间过渡的难度递增不是数值递增，是**可控性递减**。

## 过渡文案的七个草稿（叙事层的层间标记）

| 过渡面 | 文案 |
|---|---|
| L1→L2 | 你把手电关了。下面的东西不需要光。 |
| L2→L3 | 空气变干了。但你听见了——很远的地方有东西在亮。 |
| L3→L4 | 红光开始呼吸。这一层的每一面墙都在跟着它的节奏。 |
| L4→L5 | 这里太热了。热到石版上的刻痕都在冒烟。 |
| L5→L6 | 石头自己在发光。你不需要灯了。你害怕的也不是黑了。 |
| L6→L7 | 你的手牌在卷曲。红渊没收的不是牌，是你拿牌的手。 |
| L7→L8 | 红光消失了。不是因为到了最暗的地方——是因为你在光里面。 |

七段文案每段不超过 25 字，语气从「说明」渐变为「你」——前四段是旁白，后三段是对玩家说的。这个渐变与倒吊弧线（D5 第一轮的 L1 直立→L8 上下失效）同步：世界在倒转的同时，叙事的视角也在从旁观转向对峙。
