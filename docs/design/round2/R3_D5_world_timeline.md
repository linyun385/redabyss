# R3-D5 · 八层的世界观事件史

> 第二轮 D5 写了层间过渡的「现在」；这一轮写**每层的「过去」**——红渊的世界观时间线上，每一层发生过什么。

| 层 | 过去 |
|---|---|
| L1 | 地表死寂区曾是矿场的地面部分。告示牌还立着是因为没人来拆——不是因为有人守着。排班表的最后一行是空白的：当天的班次没有人签到。矿工们从这一天开始不再上来。 |
| L2 | 冷洞的钟乳石用了三百年长成现在的形状。矿工在钟乳石之间挂了工具——第一个倒挂物不是设计出来的，是「随手一挂」的结果。挂的人再也没回来取，但挂的位置成了后来者的惯例。 |
| L3 | 干旱空洞区的泉眼在矿场时代是水源。泉水干涸的那一年，矿工们在泉眼旁边刻了记号——不是纪念，是标记「这里曾经有水」。悬浮的粉尘是矿场爆破的残留物：它们被上升气流托住，三十年没落下来。 |
| L4 | 空洞海的菌幕是矿场废弃后长出来的。菌幕的生长速度是每年向下延伸约两米——它还没长到底，但已经在路上了。老浮标是矿工用来标记水下地形的，被菌幕缠住之后没人去解。 |
| L5 | 热泉裂带的盐晶在矿场时代就被采集——采盐是矿工的副业。盐晶共鸣腔的「会说话」是采盐工人最先发现的：他们在敲盐的时候听到了回声，回声里有些东西在回应。 |
| L6 | 辐射矿石区的矿脉在矿场时代就被标记为危险区——标记的方式是把入口焊死。但焊死的入口被从里面打开了：从里面打开意味着有什么东西从深处上来了，或者有什么人从深处下去了。 |
| L7 | 核心高热区的温度在矿场时代就足以让金属变形。旧光者残影是最后一批矿工的遗留——他们在高温中失去了形态，但他们的位置被热量保存了下来。burn_hand 的烧手牌不是这层的规则——是这层的温度在替规则执行。 |
| L8 | 红渊核心从来没有人到达过。墟蛹是唯一在记录中提到这个深度的存在——但它不是到达者，它是从更深处上来的东西在 L8 停下的痕迹。void 模式的「红光消失」不是因为没有红光——是因为你已经在红光的里面。 |

## 时间线的统一规则

八层的时间线遵循一条规则：**越深的层，人类的活动痕迹越少，非人的痕迹越多**。L1 的排班表是纯人类的，L8 的墟蛹是纯非人的——中间的 L2-L7 是人类痕迹逐渐被非人痕迹覆盖的过程。这个过程的方向只有一个：向下。

「倒吊」在这个时间线里也有位置：L2 的倒挂工具是人类的，L4 的倒挂菌幕是非人的，L7 的倒挂金属泪是「人类造的东西被热量改造成了非人形态」——倒吊形态从人工到非人的过渡就是「红渊接管」的过程。


## 时间线与 19 张新卡的对齐

19 张新卡的 flavor 里的时间指向：回声壁（「刻痕是谁留的已经没人知道」=矿场时代之前或期间）、守夜人的钟（「下一个班」=矿场时代的班次制度）、风险合同（「你签得太快」=当下）、散落的铅字（「报馆塌了以后」=城邦崩塌后）、活水引泉（「泉眼认得口渴的人」=持续性的自然现象）。全部 19 张的时间指向都在「矿场时代→废弃→红渊接管」的时间线内，没有出现时间穿越。

## 决定记录

- 时间线为新增世界观层（GLOSSARY/LAYERS/ECO_* 均无时间轴条目）——它与「倒吊+红光」的推演规则（D5 第一轮）互补：D5 写空间的倒转，本篇写时间的纵深。
- 「矿场时代」的设定来自现有 flavor 的暗示（event_d2_1 的「搬的人不在这里」、dive_0056 的「不保证返程」）——没有明确的年代但方向明确：矿场在前、废弃在后、红渊接管在废弃之后。

## 时间线与「倒吊」弧线的交叉

D5 第一轮的「倒吊弧线」（L1 直立→L8 上下失效）是空间维度的推演；本篇的时间线是历史维度的推演。两条弧线交叉产生了一个新的发现：

**倒吊形态的转变恰好对应了时间线的推进**。L2 的倒挂工具串是人类放的（矿场时代的惯例）——L4 的倒挂菌幕是红渊自己长出来的——L7 的倒挂金属泪是人类造的东西被红渊的热量改造的——L8 没有倒挂因为「上下」失效了。

也就是说：**从人类倒挂 → 红渊倒挂 → 人类的东西被红渊改造 → 没有方向**——这四步既是空间弧线也是时间弧线。越深的层，人类痕迹越少、红渊痕迹越多——倒吊形态是这个趋势的视觉表达。

## 时间线与 461 张图的关联

461 张已有图（web/assets/art/*.webp）是「现在」的红渊——它们是玩家看到的。时间线是「过去」的红渊——它只在文案和世界观文档中存在。两者的关联是：**过去解释了现在为什么是这样**——菌幕为什么垂到水面（因为长了三十年）、盐晶为什么挂在岩顶（因为矿工采盐时留下的切口在结晶）、排班表为什么空白（因为最后一天没人签到）。

这种「过去解释现在」的关系对美术的意义是：新画的图（D2 补牌 19 张、D4 新卡 19 张）应该在画面中留下「时间痕迹」——锈、裂、灰、旧、残——这些不是装饰，是时间线的视觉锚点。

## 时间线与卡面 flavor 的交叉验证

461 张已有卡的 flavor 里散落着时间线的碎片。把这些碎片按层归类可以重建一个粗略的红渊编年史：

L1 的 flavor 提到「管道凉了三十年」（enemy_d1_01）——说明矿场废弃至少三十年了。L2 的 flavor 提到「挂着铅笔」（trem_0062 的石碑）——工具挂在原地没人取，与 D5 第一轮的「倒挂工具串」呼应。L3 的 flavor 提到「矿场爆破的残留物」——爆破是矿场终结的方式之一。L4 的 flavor 提到「被菌幕缠住」（enemy_d4_01）——菌幕的生长速度是时间线的度量。L5 的 flavor 提到「前人留下的听音记录」（trem_0062）——前人是矿场时代的震语者。L6 的 flavor 提到「焊死的入口被从里面打开」（D6 层敌人系列）——「从里面」是时间线最重要的线索：有人在深处活着。L7 的 flavor 提到「失去形态」（D7 层敌人系列）——高温改写了形态也改写了时间感。L8 的 flavor 只有「墟蛹」——它不是时间的产物，它是时间之外的存在。

这八层的 flavor 碎片拼出的时间线是：矿场运营（有人）→ 某种灾难（人走了）→ 三十年的废弃（自然接管）→ 玩家到来（现在）。玩家的角色不是拯救者也不是探险者——是「第一个在废弃之后走完整条路的人」。

## 时间线与 D2 补牌的世界观校验

D2 的 19 张补牌设计卡如果在时间线上「穿越」了（比如在 L1 出现 L7 才该有的东西），它们的叙事一致性就破了。用本篇的时间线校验 19 张设计卡的 flavor：全部通过（没有一张引用了不属于它所在层的时间碎片）。但有两张卡的时间指向值得标注：D2 设计 12 的「清剿令（自请）」 flavor 里的「血指印」暗示这份文件不是第一次被签——这与 L1 的时间线（矿场废弃后无人管理）有张力（谁在管理协议的签发？）。这个张力可以在 D7 的事件分支里回收（一个 L7 或 L8 的事件揭示「清剿令一直在自动签发」）。

## 时间线的叙事功能（为什么它重要）

时间线不是世界观装饰——它有三个实际功能：

第一，**它解释了为什么敌人长这样**。L1 的嗜热古菌贴在余温上（因为矿场走了之后管道凉了但它们还在等）；L5 的热泉管虫在起手防御（因为热泉的节奏就是间歇的）；L8 的墟蛹是唯一在记录中提到这个深度的存在（因为它不是到达者，是从更深处上来的东西在 L8 停下的痕迹）。每一个敌人的形态和行为都可以用时间线来解释——这给了美术和设计一个统一的参照系。

第二，**它解释了为什么层规则是这样的**。L1 的 no_light 不是因为「没有灯」而是因为「地表的日光到这里已经失效了」——失效是物理事实不是设计选择。L5 的 heat_tick 不是因为「这层很热」而是因为「热泉的间歇性加热」——间歇是地质事实。层规则是世界观的物理后果，不是抽象的难度调节器。

第三，**它解释了为什么玩家的角色是独特的**。「第一个在废弃之后走完整条路的人」——这个定位在 T29 的目标通关率（8-18%）里得到了数值确认：大部分人走不完，但走完的人不是英雄，是幸存者。幸存者不需要拯救世界——他们只需要知道自己在哪个深度停下了，以及为什么。
