# T330 · 流派现状诊断：现在到底有没有流派？

> 方法：用 T320 已建立的机制签名口径（effect 顶层键 + special code），加上三个新维度——**命名家族**（同一词根的卡成套出现即设计意图的证据）、**专属数据字段**（如 `dream`）、**专属引擎系统**（如 memory 代价、协议协议）——把 267 张卡聚类，再逐簇判断「有意设计」还是「卡多了自然成堆」。
> 判断标准：**设计出来的流派** = 有专属命名家族、或专属字段、或专属引擎机制承接；**涌现的流派** = 只是同类基础动作堆到一定数量后的统计聚类，抽掉名字后没有内核。
> 一个关键的全池事实先放在这里：**267 张卡里双脉卡为 0 张**（`veins` 数组长度 ≥2 的卡逐张核对为零），脉只做单选标签；且没有任何卡的效果字段引用另一个脉——「A 脉给 B 脉充能」的结构现在不存在。

疯先知的流派设计全部押在「世界」这一个轴上；脉、共振、凝视、代价系统它一个都没接（T320 已证）。它的「流派」是**位置流**（你在哪边打），不是**机制流**（你打的是什么）。

## 判决

**现在有 16 个可辨识聚类，其中 7 个是设计出来的（有命名家族、专属字段或代价体系支撑），9 个是涌现的（纯数值堆叠）；另有 1 个「幽灵流派」（维护者协议流）在引擎里完整实现、卡池零张。**

四个结构性问题，直接指向 T331 要做什么：

1. **流派都长在职业身上，跨职业的只有「基础动作」**。震语者的凝视控制拿到下潜者手里就是 4 张 gaze_cost 孤岛——因为没有任何桥牌把别的职业接进这套体系。
2. **脉不是流派，是染色**。五脉在四个职业都覆盖，但脉的作用只有连携加成（+1/+2）和两层环境规则（no_light/dry）——「光脉流」不存在，存在的只是「带光脉标签的 64 张卡」。双脉卡 0 张意味着 A 脉接 B 脉的路在数据层就不存在。
3. **流派之间没有计数与奖励机制**。没有一张卡「统计你打了几张灼烧牌」「共振在 20 以上时如何如何」（共振阈值是引擎算的，卡池不知情）。流派是聚类，不是玩家可认领的身份。
4. **涌现流派占 56%**。9/16 的聚类没有内核，它们就是 T321 那 161 张换皮卡的另一个名字。
