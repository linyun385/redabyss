# J03 · 模拟结论置信度分级（A / B / C）

> 分级定义：**A 已修复验证**=结论所依赖的代码经过 bug 修复且重跑对账（J02）；**B 未验证但逻辑干净**=确定模型或独立逻辑（J02 复跑稳定，且不依赖被污染函数）；**C 存疑**=依赖被污染的中间量、或依赖未拍板的口径/强假设——**别用绝对值，只能看方向**。
> 给设计师的话：**A 级直接用；B 级可用（记得是估算）；C 级只看方向和相对排序，绝对数字别引用。**

## C 级 · 存疑（只看方向，别引绝对值）

| 结论 | 为什么存疑 |
|---|---|
| H14 死亡率绝对值（70%/125 局） | 三个粗估叠加：精英 ×1.4/boss ×1.6 乘数、格挡减伤 0.25 校准、无格挡决策——**相对结构可信（死亡峰 L6/L5/L8），绝对值不可信** |
| H14 疯先知 50/50 全死 | 模型无梦池——已判「模型局限极端化，不证明角色不可玩」 |
| H07 性价比绝对值 | 金→分锚（1 分≈0.44 金）是强假设；**排名可信，绝对「亏多少金」别引用** |
| H09 脉等级的绝对数值 | 生态映射表未拍板（T526 假设）——形状可信（峰值 1~2、活不过 3 层），换映射=换拐点 |
| H03 卡组 42.5 张 | 贪心策略上限——绝对值依赖「每场必拿」假设 |
| I01「副作用检查」推断 | 主脉权重挤压水的**方向**可信，挤压幅度未单独验证 |
| H06/H07 价值分的绝对定价 | 横向排序可靠；「分」对「金」的换算锚是设定的 |
| 全部 sim 对「真实玩家」的映射 | 无真人玩测数据——一切「玩家会怎样」都是模型推演 |

## 一句话使用指南

**数字引用三问**：① 这条在 A 级吗？② 引用的是相对结构还是绝对值？③ 它依赖的口径（映射表/减伤系数/金分换算）拍板了吗？——三问过后再写进设计决定。

## 复算

分级判定依据=_SIM_BUGFAMILY（污染面）+ _SIM_RECALC（对账）+ 各 sim 文档假设段；分级本身为人工判读，逐条带依据可对照。
