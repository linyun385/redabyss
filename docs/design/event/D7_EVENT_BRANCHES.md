## 决定记录

- 只扩 16 个代表事件而非全部 82 个：分支的质量密度优先于覆盖密度（每层 2 个示范，模板可复制到其余事件）。
- 3 个分支需要引擎/前端接线（combat_start_block / next_combat_draw / class 条件分支），接线点已标——不接线就不落这些分支（T333 改法一的原则）。
- 「让别人先潜」的失败分支是有意设计：事件层允许一个「世界不配合」的选项存在，这是红渊叙事的一部分。
