## 一、这套附属卡想让维护者玩成什么样

**维护者是一台会自己长大的机器。**

核心卡（0051–0057）已经写好了这个幻想的骨架：拆下来的是零件，长上去的是本体。附属卡的任务不是加新机制，是把三个已经存在的动作填满：

1. **赚**（支柱 A）：打牌、拆牌、打赢，都该有零件落袋。零件是跨战斗的钱——这一场省下的，下一场开场就带着。
2. **变厚**（支柱 B）：挡、反伤、再生、敏捷。维护者的防御不是「少挨打」，是「你打我的部分归我」。
3. **花**（支柱 C）：零件随时能换成任何东西——能量、牌、血、一记大拳。汇率分三档，单买贵、批发省。

**两档变强是整套设计的轴**：本场变厚（B 柱，便宜，死了就没了）vs 一局变厚（A 柱，2 零件/点永久力量，死也带不走——下一场还在）。玩家每回合都在回答同一个问题：这个零件，现在花，还是存着转正？

**不碰的东西**：召唤物（只有子代理一种，够了）、条件判定（引擎没有）、跨局存档（用户否了）。全列在 `06_needs.md` 第五节。
