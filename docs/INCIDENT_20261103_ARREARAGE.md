# 事故：备选图批量生成中断于「百炼账号欠费」

2026-11-03 11:54，`gen_versions.py` 全量跑完，返回「成功 535 / 失败 367」。
367 张失败看起来像提示词被拒，**实际是账号欠费**。

## 定性

原样重发一张失败素材（`cng_0028`），响应体是：

```json
{"code":"Arrearage","message":"Access denied, please make sure your account is in good standing. ... overdue-payment ..."}
```

百炼把「欠费」报成 **HTTP 400**，不是 402/403，也不是 429。
原脚本只记状态码、丢掉响应体，所以 367 条全被记成 `submit 400` —— 一个看起来像
「提示词不合规」的错误码。**差一步就去改提示词了。**

## 时间线

| 时刻 | 事件 |
|---|---|
| ~10:06 | 开跑，前 534 张全部成功（5.5–6 张/分） |
| 第 535 张（`cng_0028` v1） | 开始 400，此后 368 次提交只成功 1 次 |
| 11:54 | 跑完「902/902」，实际 535 成功 |

余额在被跑光之前，节奏完全正常 —— 所以这不是限流、不是并发、不是提示词。

## 已做的修复

`tools/gen_versions.py`：

1. 失败时把响应体里的 `code` 与 `message` 一并记进 `data/gen_failed.json`，
   不再只有裸状态码。
2. 新增 `_hard_fail()`：识别 `Arrearage / InvalidApiKey / Unauthorized / AccessDenied`
   与 `overdue-payment`，命中即置 `_abort`，**其余排队的任务立刻返回 skip**，
   主循环末尾打印「账号级硬失败，已提前停手」。
   今晚白烧了 368 次提交才停，以后是 1 次。
