# ENEMY_DESIGN — 敌人与 Boss 变体深化（T48）

> 新增 24 个：每层 +2 精英 + 1 Boss 变体（enemies/all.json，id `enemy_d<层>_<e1|e2|b1>`）。
> 意图只用引擎已支持的字段：attack(value/times/mirror/pierce/drain_discard)、defend、buff(value=攻击加成)、debuff(status: steal|gift)。
> 数值是「能打过但会掉血」的粗估（对标同层既有精英血量带），不做深度平衡。
> 登场方式备注：精英走地图精英节点、Boss 变体走 boss 节点的随机池（同层同 tier 随机）。**L1/2/3/6 的 Boss 变体当前地图没有 boss 节点——数据已就绪，等地图加节点后自动入场；L1 目前也没有精英节点。**

## D1 地表死寂区

- **气味**：空壳与干燥——敌人少而弱，打的不是生态，是「真空里还有东西在动」（证据：既有 L1 敌人意图以 attack 2–4 / defend 5 为主，伤害全池最低）。
- **盐壳拾荒者**（精英，30 血）：循环 攻4 → 防7 → 攻4 → 自强3。意图循环 4 回合一转；**转折点**：自强后攻 4 变攻 7（buff 叠加）。应对：自强回合攒爆发，循环窗固定。差异点：既有 L1 敌人没有 buff 行为，它第一次在 D1 引入「回合资源积累」。
- **孢子清道夫**（精英，28 血）：gift → 攻5 → 攻5 → 防5。它的 gift 给你抽 1 + 凝视 1——**玩家要主动选择要不要这份收益**。差异点：第一只在 D1 送凝视的敌人（D1 本层凝视真空，这条牌因此改变 LAYER_NOTE 的体感）。
- **Boss 变体「钟乳盐·塌落体」**（46 血）：循环 攻5 → 防8 → 攻5 → 攻9。**可预判杀招**：第 4 回合攻 9（固定循环，第 1 回合就能看到排程）。**可利用破绽**：第 2 回合纯防御不还手——蓄力/爆发牌打这个窗。转折点：血量 50% 以下进入塌落相（攻 6/防 9/攻 11），防御变厚、单发变重。
- 玩家应对：D1 卡浅，用最便宜的循环（缩起+一击）即可，重点是别在它防御回合浪费能量。

## D2 外层冷洞

- **气味**：慢、旧、历法——敌人的行为周期特别长（证据：既有噬骨菌群意图 6 手循环、休眠两栖类的存在）。
- **历虫**（精英，42 血）：防8 → 攻5 → 防8 → 攻9。**转折点**：第二个攻 9 比第一个高 80%——历虫的循环是「记两笔，讨一次债」。应对：在防 8 回合攒手牌，讨债回合前留格挡。
- **菌膜织者**（精英，40 血）：自强3 → 攻6 → 偷1 → 攻7。**转折点**：第 3 手偷牌——手里留着最不值钱的牌挨这一下。差异点：D2 第一只动玩家手牌的敌人。
- **Boss 变体「历壁的守读者」**（58 血）：攻6 → 防9 → 攻6 → 攻12。**杀招**：第 4 回合攻 12（可预判：循环固定，第一次见到就能背）。**破绽**：第 2、3 回合之间防御重复出现——两个输出窗固定在攻 6 之后的下一回合。转折点：50% 血换「重读相」攻 7/防 10/攻 14。

## D3 干旱空洞区

- **气味**：干、硬、钻——防御厚、攻击间隔规律（证据：钻孔贝以防御意图为主、硬矿石区敌人 HP 带 20–30）。
- **钻孔贝群**（精英，52 血）：防10 → 攻7 → 防10 → 攻10。差异点：双防御回合的纯防守循环，考验玩家「不打白过」的纪律。应对：穿甲没有就用防御回合抽牌/上 buff。
- **旱螈伏兵**（精英，48 血）：攻7 → 攻7 → 自强4 → 攻11。差异点：连击起手——前两手固定同值，第三手自强后第四手 11 是全层最重单发。
- **Boss 变体「旱脉的封口者」**（62 血）：攻8 → 防6 → 攻8 → 攻14。**杀招**：第 4 回合攻 14（D3 数值带里最重的一击）。**可利用破绽**：防御只在第 2 回合出现一次且只有 6——循环记熟后，第 2 回合是唯一的输出窗，其余回合全防御。

## D4 稳定空洞海

- **气味**：丰盛、光、巨影——敌人从「单只」变「环境的一部分」（证据：浮光水母/光藓蠕虫的非攻击型意图、穹顶之影的漂移设定）。
- **藻毯伏击者**（精英，60 血）：攻9 → 自强4 → 攻9 → 防8。差异点：自强嵌在两次攻击之间——拖得越久打得越疼，速攻才是解。
- **红腔鱼·巡游种**（精英，64 血）：攻7×2 → 防8 → 攻7×2 → 自强3。差异点：times:2 双段攻击首次出现在 D4 常规池；防御回合卡在双段之间。
- **Boss 变体「光蛭母·逆流」**（130 血，三段）：
  - 一段（66%+）：攻10 → 防10 → 攻8 → 偷1。偷手牌是压迫点。
  - 二段（33–66%）：自强5 → 攻12 → gift → 攻9。**可利用破绽**：gift 回合送你抽 1 + 凝视 1——收益窗口，但要付凝视的代价。
  - 三段（33% 以下）：**杀招**：攻 10×2 双段开场（进入三段的第一个回合就能从意图看到），随后攻 14 收尾。破绽：三段防御全无——所有防御回合消失，换成全攻。

## D5 热泉裂带

- **气味**：周期、节奏、硫——敌我都在「喷发-休眠」的拍子上（证据：热泉螈/硫塔菌的意图周期、喷息城邦设定）。
- **喷息守卫**（精英，62 血）：防7 → 攻11 → 防7 → 攻11。差异点：完美二拍循环，全池最「卡点」的敌人——踩错点吃 11。
- **硫沫赘生体**（精英，60 血）：攻6×2 → 自强4 → 攻6×2 → 攻9。差异点：双段×2 + 自强，D5 的「越拖越疼」教科书。
- **Boss 变体「震喉·空腔独奏」**（110 血）：攻9 → **弃牌吞音（drain_discard）** → 防8 → 攻12。**杀招**：第 4 回合攻 12，且第 2 回合会吃掉你弃牌堆的一张牌——弃牌堆的构成是可以被它读走的。**可利用破绽**：第 3 回合纯防御（8 点），是全循环唯一的蓄力窗。转折点：50% 血进入副歌相（吞音移到每循环第一手，攻 9/10/13）。

## D6 辐射矿石区

- **气味**：辐射、金属、骨灰坛——敌人不是生物链的一环，是环境病的症状（证据：辐射系敌人全员 buff/高攻低频）。
- **辐射休眠孢子群**（精英，72 血）：偷1 → 攻12 → 攻12 → 自强5。差异点：D6 第一只「先偷后打」的敌人——偷牌那手是对第 2、3 手的预告。
- **金属鳞鳄幼体**（精英，76 血）：攻13 → 防9 → 攻13。差异点：三手循环、无过渡——D6 敌人的攻击开始「不讲道理」（14 档单发进入常规池）。
- **Boss 变体「辐射金属鳞鳄王·蜕」**（150 血）：攻14 → 防10 → 攻14 → 自强6。**杀招**：攻 14 出现两次/循环（第 1、3 手，从意图直接可读）。**可利用破绽**：循环里没有穿透，格挡完全有效；自强 6 是双刃——它越打越疼，但节奏不变。转折点：40% 血「蜕皮相」弃防转攻（攻16/攻12/防12），防御移到循环尾。

## D7 核心高热区

- **气味**：烧、祭祀、锁死边缘——敌人和环境一起烧你（证据：层规则 burn_hand、穹顶之影 56 血但意图带 mirror/debuff 的复杂度）。
- **烧手的灰烬**（精英，88 血）：攻15 → 自强6 → 攻15 → 防10。差异点：攻 15 是 D7 常规池最重单发，且自强让它第二次攻 15 变 21——**必須在第一次攻 15 后处理掉它**。
- **震台祭司**（精英，84 血）：自强7 → 偷1 → 攻12 → 攻10。差异点：自强 7 全池最高——它的攻击增长速度是玩家削血速度的竞赛。
- **Boss 变体「穹顶之影·网颤」**（72 血）：攻12 → 攻8×2 → gift → 攻16。**杀招**：第 4 回合攻 16（单发全池最重）。**可利用破绽**：第 3 回合 gift（送牌+送凝视）——要不要这份收益是本循环的抉择点。转折点：50% 血后网收紧（攻14/攻10×2/攻18），gift 从循环里消失——抉择窗关闭。

## D8 红渊核心

- **气味**：循环、锁死、自动化——敌人的循环就是「程序」（证据：墟蛹的三段 phases、空壳旧光者的设定）。
- **循环的巡逻体**（精英，98 血）：攻16 → 防12 → 攻16 → 自强6。差异点：攻 16 双次/循环，防御 12 挡在中间——它的循环是既定程序，一格不差。
- **墟影残片·重奏**（精英，102 血）：攻10×2 → 防10 → 攻10×2 → 自强5。差异点：双段×2 出现两次/循环——总伤 40/循环，全池最高 DPS。
- **Boss 变体「墟蛹·未完成」**（200 血，两段）：
  - 一段（33%+）：攻12 → 防10 → 攻12 → 偷1。它在核对——偷牌那手是「读取」。
  - 二段（33% 以下）：**杀招**：攻 14 与攻 16 变为 **pierce（不可格挡）**，进二段的第一手就能从意图看到「从骨头里响起来」。**可利用破绽**：二段循环第 2 手仍是可格挡的攻 10，且第 3 手防御 12 是它唯一的喘息——穿透回合前把格挡牌换成爆发牌。
- 玩家应对：D8 的核心问题是「穿透让格挡失效一半」——爆发牌与回复牌的配比比纯防御构筑更重要。

## 边界声明

- 数值为粗估：对标同层既有精英血量带（L2 38–46、L3 58–68、L4 66–76、L5 58–66、L6 68–74、L7 52–58、L8 54–72）与 Boss 血量（120/96/56/68），「能打过但会掉血」的判断依据是同层卡组数值，未跑 sim 分布验证。
- 登场机制：同层同 tier 的池子是**随机抽取**——Boss 变体与原版 Boss 各约 50% 出现率（除 L1/2/3/6 变体因无 boss 节点暂不登场）。这会改变 Boss 战的重复体验，属本任务的设计意图。
- L1 目前没有精英节点与 boss 节点、L2/3/6 没有 boss 节点——这些敌人的登场需要地图数据配合（另开任务），数据已就绪。
- 意图字段全部来自引擎已实现通道（attack/defend/buff/debuff-steal/debuff-gift/mirror/pierce/drain_discard/times），未发明新字段；「traits」沿用空数组。
