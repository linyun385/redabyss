# EXPANSION_IDEAS — 值得扩展的方向（T45–T52 全程积累）

> 2026-10-30。这份清单不是愿望单——每一条都有本过程中的**证据**（哪个任务/哪份报告/哪组数字发现它），以及**落点**（改哪个文件）。
> 优先级排序依据：证据强度 × 改动量 × 与既有架构的契合度。标 ★ 的是我认为最值得先动的五条。

---

## 一、玩法机制（有提案、有落点）

### ★ 1. Boss 专属改则
- 依据：T45 调研（Balatro Boss Blind 是「逼玩家展示构筑另一面」的核心结构）；红渊现状 Boss 打的是本层规则的加强版敌人，没有 Boss 专属规则。
- 落点：4 个 Boss 各一条全局改则写入 `C.layerRuleExtra`，提示复用黯民协议横幅 UI（现成通道）。T45 评估为改动量/收益比第一。
- 依据文档：docs/RESEARCH_BORROW.md 四-1。

### ★ 2. 共振回应浮字反馈
- 依据：T49 经济模拟跑通后回头看战斗反馈——共振跨阈值只有闪红+一行日志，回应数值静默生效；「爽感不是算出来的，是看见自己算出来的」。
- 落点：`web/index.html` checkResonance 的前端回调，复用 T37 浮字队列（回血绿字/全体伤害逐敌数字）。零引擎改动。
- 依据文档：docs/RESEARCH_BORROW.md 四-4。

### 3. 状态牌（牌组内持续负担）
- 依据：T45 调研（StS 诅咒牌）+ T47 卡池诊断的代价牌生态缺口——现有代价牌全是「打出时付费」，没有「躺在牌组里就有害」的形态。
- 落点：新 status 卡类（不可打出、占抽牌位），负面事件塞入 → 商店删牌/营火听震移除，与既有删牌生态闭环。
- 依据文档：docs/RESEARCH_BORROW.md 一-2。

### 4. 献祭手牌（cost_type: discard）
- 依据：T45 调研（Monster Train Sacrifice）——代价落在「你已经投资的手牌」上，比扣血更可控。
- 落点：engine playCard 的 cost 分支 + 卡面「代价：弃 2 张手牌」。量级 2 张牌起步。
- 依据文档：docs/RESEARCH_BORROW.md 二-3。

### 5. 事件旗标（flag 记账）
- 依据：T45 调研（StS 事件后果持久化）+ T46 写 24 个事件时的直接感受——事件之间互不知晓，「分他一半水」的人再也没出现过。
- 落点：`run.flags` 集合 + events JSON 的 `set_flag`/`require_flag` 字段；先做 2–3 对互相引用的事件。
- 依据文档：docs/RESEARCH_BORROW.md 一-3。

### 6. 跨职业混牌事件
- 依据：T45 调研（Monster Train 双族群混组的小剂量变体）；T46 写层档案时「别的下潜者」类事件天然适合带一张他职业的卡。
- 落点：events JSON 的 card_reward 池扩展为跨职业小池，一局最多 1–2 张。
- 依据文档：docs/RESEARCH_BORROW.md 二-2。

### 7. 精英层轻改则
- 依据：T45 调研（LocalThunk 访谈明确说的方向）；T48 已给 Boss 层做了变体，精英层还是纯数值加强。
- 落点：D6/D7 精英各叠一条从本层 rule 衍生的轻改则（如辐射层精英「每 3 回合烧 1 张」），走 layer rule 同通道。
- 依据文档：docs/RESEARCH_BORROW.md 四-3。

## 二、内容扩充（空洞有数字、hook 已埋）

### ★ 8. 卡池四个空洞补牌
- 依据：T47 卡池诊断的数字空洞——diver 水脉 4/80（残差 −11.2 全池最大）、anmin 2 费 1 张、cangmin 3 费 0 张、tremor power 4/80。
- 落点：`cards/*.json` 对应职业（主题都现成：贸易局配给 / 协议工程大件 / 三神梦牌 / 历法石碑 power）。
- 依据文档：docs/CARD_AUDIT.md 结构问题 1/2/3/6/7。

### 9. 「0 费抽 1」家族换血
- 依据：T47——12 张完全同指纹的抽 1 卡，名义 260 张池的机制折叠。
- 落点：`cards/*.json` 至少 4 张改出复合效果（抽1+弃1 / 抽1+共振1 / 抽1+凝视−1）。
- 依据文档：docs/CARD_AUDIT.md 结构问题 5。

### 10. D4/D5 加商店节点
- 依据：T49 经济曲线断点 1——D4/D5/D7/D8 商店访问 500 局全 0，金币净堆积（diver D4→D5 中位 +141）。
- 落点：`layers/layers.json` rows（D4 或 D5 加 1 个 shop 节点）。风险：通关率预计 +1–2pp，需重跑 T14 曲线。
- 依据文档：docs/ECON_CURVE.md 断点 1。

### 11. Boss 后金币兑换遗物
- 依据：T49 断点 2——通关者 D8 层末金币中位 879，D7/D8 无店可花。
- 落点：`web/index.html` finishCombatFlow boss 分支加「150 金 → 随机 uncommon 遗物」兑换。风险低（只花死钱）。
- 依据文档：docs/ECON_CURVE.md 断点 2。

### 12. 彩蛋扩量到 12–16 个
- 依据：T45 调研（密教模拟器 Moment 组合的双份奖励结构）+ T39 已验证的触发框架（配对/同卡两次/特定层三类条件都是现成通道）。
- 落点：`EASTER_EGGS` 表 + docs/EASTER_EGGS.md。
- 依据文档：docs/RESEARCH_BORROW.md 三-3。

### 13. 敌人「合拢」格挡上限（最大的一颗平衡雷）
- 依据：T35/T49 两次实测——敌方格挡全额累积（玩家侧已改留一半），第 1 层杂兵战拖到 33 回合破不了防、玩家被过载耗死；T49 通关率 2.6–3.4% 低于 T14/T16 带宽，此为主要嫌疑之一。
- 落点：engine 敌人合拢的 block 累积加帽（如上限 = maxHp 的一半）或改临时格挡。**需要另开平衡任务**，配合 T14 式曲线重校。
- 依据文档：TASK_DONE T35/T49 notes、docs/DELIVERY.md 已知问题 1。

### 14. T14 式曲线重校
- 依据：T49 与 BALANCE.md 的真冲突——新内容（T46 事件、T48 敌人）后通关率 2.6/2.6/0.8/3.4 vs T14 的 6.0/5.0；黯民 0.8% 还含 sim 口径偏差。
- 落点：重跑 T14 流程（sim 多种子 + 敌人/卡池微调），先修 13 再校。
- 依据文档：docs/ECON_CURVE.md 对照节。

## 五、工程与质量

### 21. sim.js 黯民金币口径同步
- 依据：T49——sim 把黯民事件金币直接入 gold，网页折算零件；黯民 0.8% 通关率含此口径偏差。
- 落点：`tools/sim.js` 事件段加 anmin 折算（注意 econ_sim 的同步断言只锁 aiCombat，playRun 改动需手动同步）。
- 依据文档：docs/ECON_CURVE.md 建议 4。

### 22. 删牌经济的边际收益
- 依据：T49——tremor 卡组 D6 26 → D8 16（memory 代价牌持续删卡），删牌在深层的边际收益偏高。
- 落点：memory 牌删牌数下调或删牌价递增（T38 界定的平衡范围，另开任务）。
- 依据文档：docs/ECON_CURVE.md 曲线表 + 建议 5。

### 23. D1 层 --dim 的体感分级
- 依据：T52——--dim 修后最差 3.68（达标），但 D1 层（最亮背景）比 D4 层（最黑）体感更难读——WCAG 只给及格线。
- 落点：若要进一步，可按层深度给 --dim 两档值（applyLayerTheme 已是现成通道）。
- 依据文档：docs/A11Y_PERF.md 边界声明。

### 24. 短局流程的回归盲区
- 依据：T51/T52 的多次声明——静默段（黯星回响）与「伊格的痛苦」自 T21/T26 后未做完整回归，期间引擎与 UI 经历了 T35–T52 的全部改动。
- 落点：一次专项回归（不新增内容，纯验证两条短局还能完整跑通）。
- 依据文档：docs/DELIVERY.md 已知问题 5。
