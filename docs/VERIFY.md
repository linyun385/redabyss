## 四、质量抽查

**5 张卡的 flavor**：
- 聚能枪「填弹的时候它自己热了。这里没有火。」——不解释机制，现象自洽。
- 震语：听骨「岩壁在讲一件旧事。你听过这一段，结尾是别人的。」——有不对劲，不追问。
- 墟盐「你按规程尝了一点。规程没说不能咽，你也没咽。」——代价（被记下）藏在克制里。
- 震语：断脉「切断了。岩层安静下来。你的喉咙跟着哑了一瞬。」——效果与代价同象。
- 圣火武器（殉爆）「它想快点。你按住了它，又松开。」——和卡名、代价文案成一套。
- 无一条在复述规则文本。

**3 个敌人的出招表节奏**：
- 嗜热古菌（攻2/攻2/防3）：低速磨血，符合 D1 教学位。
- 震喉：镜像→蓄力→穿骨三段，每段换一种威胁方式，节奏成立。
- 光蛭母：抢牌/给牌/双抢——围绕「共用牌组」一个主题变奏，不散。

**3 个事件的选项差异**：
- 矿道口的碎石：金币+受伤 / 拿卡 / 走——三种收益曲线，无重复。
- 一池不流动的水：稳回血+凝视 / 深潜换稀有卡+掉血 / 走——风险梯度清晰。
- 静日里响起的震语：凝视+稀有卡 / 掉血+金币 / 不听——「听/找/捂」三种态度。
