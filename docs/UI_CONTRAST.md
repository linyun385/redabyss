## 3. 色条与地图图标同源

- 色条颜色 = **地图生态色板 ECO_C**（tools/check_palette.js 管理的那张表，L*≥55 已验证）：
  - 事件选项：按选项的**脉取向**取色（light→#998b53 地表金 / heat→#d06b6b 喷口红 / water→#68b291
    空海绿 / mineral→#85a567 辐林草绿 / tremor→#59b4b6 寒洞青 / 无脉→#84b2e4 枢网蓝），
    常量 `OPT_BAR` 定义在 web 模块（与 ECO_C 同表，`check_contrast.js` 断言 ⊆ ECO_C）。
  - 营火选项：按位轮换（#68b291 / #998b53 / #c46994，CSS nth-of-type，检查器断言 ∈ ECO_C）。
- 检查器把 OPT_BAR / 营火色条字面量与地图模块的 ECO_C 十六进制集合逐一比对——色值漂移会红。
