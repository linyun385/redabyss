## 三、人工复核步骤（#3 / #4 / #6）

1. **断网可玩（#6）**：把整个 `game/web/` 目录拷到 U 盘 → 拔网线（或禁用网卡）→ 双击 `web/index.html` → 确认开始界面卡面图案加载正常（assets 相对路径生效）、选职业进图、打一场战斗能出牌/结束回合。F12 Console 无红色网络错误即过。
2. **Chrome / Edge 实机（#4）**：同一断网环境下分别用 Chrome 与 Edge 打开，各玩一场战斗；F12 Console 无报错、出牌动画正常即过。
3. **内存 3 局（#3）**：F12 → Console，每局开始前执行 `performance.memory.usedJSHeapSize/1048576` 记数 → 打满一局（至少 6 回合+1 场完整战斗）→ 死亡/结算页再记一次，连打 3 局。判定：数值有涨有跌、3 局后不高于首局约 20% 即通过；若单调递增不回落，记下数值并回报。
