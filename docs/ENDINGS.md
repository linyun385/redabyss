# ENDINGS.md — 结局、多周目与解锁（T51）

> 判定函数：`RedAbyss.pickEnding(gaze, classId)`（engine，纯只读）；「回头」是结局页上的主动选择（web，不走引擎）。
> 解锁状态存 localStorage（单文件、无后端）。键名见文末。
> 截图：docs/endings/ending_watched / averted / walked / turned .png（均为控制台构造状态后实拍，1440×900）。

## 一、长审（被凝视吞噬的方向）

- **触发条件**：`到达第 8 层通关 && run.gaze >= 20`
- **演出**：结算页标题「红渊核心 · 长审」。正文：它把你从头到尾又数了一遍，这一次数得很慢……数完了。它没有放开你，也没有收回你。你就站在那里，被看成了它的一部分。末行按职业不同（下潜者：「合同第三页的空白处，有人替你签了收。」）。统计区显示凝视 25（长审：它把你从头到尾数完了）。
- **它回答了什么**：红渊不是容器，是注视本身——你走到核心，是为了被完整地看一遍。
- 来源：T16 实现，本任务未改动判定；正文为引擎 `ENDINGS.watched`。

## 二、背身（沉底未遂的方向）

- **触发条件**：`到达第 8 层通关 && run.gaze <= 5`
- **演出**：标题「红渊核心 · 背身」。正文：谐振器没有声音……红光在你身后亮了很久，像有人在门口留了一盏灯。你没有回头。回头的人要留下来解释。
- **它回答了什么**：红渊允许沉默通过——不被看全的人，也不必交代。
- 来源：T16 实现，未改动。

## 三、同行（沉底的方向）

- **触发条件**：`到达第 8 层通关 && 5 < run.gaze < 20`
- **演出**：标题「红渊核心 · 同行」。正文：你的骨头跟着它转了很久……下面没有更深的层了。你还是往下迈了一步。
- **它回答了什么**：你和它互相带着走完了全程——分不清是谁在下潜。
- 来源：T16 实现，未改动。

## 四、回头（主动放弃；T51 新增）

- **触发条件**：任意通关结算页上**点击「回头」按钮**（玩家主动选择，与凝视值无关）。
- **演出**：标题「红渊核心 · 回头」，正文按职业四选一（下潜者：它让你走。走的人不带东西——你把带下来的都留下了……），无统计区（放弃了一切），只有「重新开始」。
- **为什么改**：任务书第三方向「回头：主动放弃下潜」需要一个玩家动作来成立——被动判定的「背身」已经是沉默通过，「回头」必须是选择，所以做成结算页按钮而非凝视分支。
- **它回答了什么**：红渊放走的不是幸存者，是它不再需要的东西——或者，是它第一次学会放手的东西（两种读法都对）。

## 五、多周目（二周目变体）

- **解锁条件**：任意一局**通关任意结局**（含回头）→ `localStorage['redabyss_cleared'] = '1'`。
- **它改变什么**：此后每局开局牌组自带一张 **「死亡合同（增补条款）」**（diver 池实卡：0 费、代价扣 3 血、抽 2 张）——签过一次的人，第二次签得更熟练。主线牌组 16 → 17 张。
- **验证步骤**（本次实测）：① 控制台 `localStorage.clear()`；② 构造通关（gaze=10 + showVictory）；③ `localStorage['redabyss_cleared']` === '1'；④ `startRun('diver')` → `run.deck` 中出现 uid `ng0` 的「死亡合同（增补条款）」，牌组 17 张。
- 备注：回响短局（静默段）不注入二周目牌——它是另一套规则。

## 六、localStorage 键名

| 键 | 值 | 写入时机 |
|---|---|---|
| `redabyss_cleared` | `'1'` | 首次通关任意结局时 |
| `redabyss_endings` | JSON 数组，如 `["watched","averted","walked","turned"]` | 每次通关（去重追加） |
| `redabyss_hint_*` | `'1'` | T40 新手提示（每条一次） |
| `redabyss_death_*` | `'1'` | T40 死因提示（每种一次） |
