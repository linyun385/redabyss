## 一、真实样本（分析用，禁止照抄）

### 状态卡 · 病

> 我生了一种病。我的血液有恙，筋骨不适。我会死去。不过若得了我们愉悦者的圣血，我或许能延命无虞。

> 疾病来向我索命了。要是我能活下来，我一定会品尝我们愉悦者的鲜血，而且会迫不及待那样做。

> 我缩成一团，脸色苍白。疲倦噎住我的喉咙。我必须确定我没有白白死掉，而是为了实现某种目的。

> 愉悦者的鲜血温暖了我。它让我的双颊绽放红花，将美酒倾倒入我的心脏；它以赤杯教给轰雷之皮的节拍拨动我的琴弦。我决定了，我要再活久一点。

### 状态卡 · 转化

> 我进食了一小瓶鲜血，躺下，闭眼。明天，我会变得更强壮。

> 我现在好多了——还不止——我现在豪奢丰盛。我眼睛的巩膜，我手腕的血管涌动着玉液琼浆。当谢肉祭来临，我会成为压轴大菜。

### 进阶卡 · 蜕变

> 悼歌诗人已教导我要铭记，在我最后一部分蜕变的时候。我将带着这番教诲穿过王皮之门。

> 骨头总被留到最后。等我学会它们的转变之法，我便已准备就绪。

> 现在日已东升，阴影为之驱散，是时候记起了；我会如我所学，用我的骨骼记起。我可说已准备就绪。

## 二、从样本里拆出来的 12 条特征

这是**真正的规则**，比 `DESIGN.md` §10 更准确。

| # | 特征 | 说明 |
|---|---|---|
| 1 | **第一人称「我」** | 不是"你"。角色在叙述自己的状态。**这条我之前写错了** |
| 2 | **半文半白** | 白话打底，混文言词：有恙 / 筋骨不适 / 若得了 / 为之驱散 / 是时候了 / 可说 / 已备 |
| 3 | **术语零解释** | 愉悦者、赤杯、轰雷之皮、悼歌诗人、王皮之门、具名者——全都不解释，读不懂是正常的 |
| 4 | **句号短促** | 一句话说完就断。"我会死去。" 三个字也是完整一段 |
| 5 | **分号串联长句** | 情绪浓度高时反而变长：`它让…；它以…。` |
| 6 | **破折号插入** | `我现在好多了——还不止——我现在豪奢丰盛。` 用来递进或打断 |
| 7 | **身体部位具体化** | 不说"我变强"，说"我眼睛的巩膜，我手腕的血管" |
| 8 | **不写"感到"** | 全篇没有"我感到恐惧/喜悦"，全是生理反应与动作 |
| 9 | **仪式感的自我宣告** | `我决定了，我要再活久一点。` `我可说已准备就绪。` |
| 10 | **时间词带古意** | 日已东升 / 明天 / 是时候了 / 三夜 |
| 11 | **比喻只用一次** | `疲倦噎住我的喉咙` 一个比喻就够，不堆砌 |
| 12 | **没有感叹号** | 一次都没有 |

## 三、我原来的示范 vs 按真实风格的改写

### 卡牌 flavor

**原（第二人称，现代语感，不够）**
```
外套内侧还有上一任主人的编号。你没擦掉它。
```

**改（第一人称 + 半文半白）**
```
外套内侧还留着上一任的编号。我没有擦掉它。
```

**再改（更像密教）**
```
外套内侧留着一串编号。上一任主人的。我没有擦。
```

### 真实样本对照学到的节奏

```
✅ 我生了一种病。我的血液有恙，筋骨不适。我会死去。
   └ 三句，越来越短，越来越重。最后一句四个字收尾。
   这是密教模拟器最核心的节奏：一次比一次低。

❌ 我的身体出现了不适，血液检查结果异常，我想我快要死了，不知道还能撑多久。
   └ 一句到底，堆叠形容，语气慌。完全不是这个味道。
```

## 四、红渊化示例（可以直接用的调子，原创）

用红渊的术语，按上面的节奏写。**这 20 条是给你对齐语感的参照，不是让你抄。**

### 下潜者

```
编号还是新的。我用指甲刮过一遍，没刮干净。

我签的时候没看第三条。第三条写着：不保证返程。

轨道上的人按了按钮。他们看不见我，也不需要看见。

我的手套内侧是干的。这里没有干的东西。

它一共说了四个音节。前三个我听懂了。第四个不在任何语言里。

我把头盔摘了。这里的空气够我活三次呼吸。
```

### 震语者

```
我把额头贴上岩壁。它在说一件很久以前的事，语速很慢。

今天不该说话。我闭上嘴，世界反而清楚了一些。

我切断了它。岩层安静下来，像被我按住喉咙的东西。

我忘了母亲的声音，只记得那是一个很高的音。

它记住了我的掌心。我也记住了它记住了我。

我数到第七下才敢动。数到第七下的时候，它已经不在了。
```

### 敌人

```
它在啃一具比它大四百倍的东西。已经啃了很久。

它不追。它只是比我慢，而且不打算停。

红光从它鳞片的缝里漏出来。它在发光，但它不是光源。

它的意思是：这里只有我能站。
```

### 事件

```
矿道口堆着别人搬开的碎石。还有人比我更早到这。石头是新的。

门开着。门是往里面开的。

红光从下面来，影子朝下。
```

## 五、三条最容易犯的错

1. **写成第二人称"你"** —— 除非是 UI 提示（"点击卡牌"），否则一律第一人称
2. **太白话，没有文言味** —— 加一点就行：把"没有"换成"未曾/没有"，把"然后"换成"于是"，偶尔用"之/其/已"
3. **解释术语** —— 绝对不能写"相石（一种能记录记忆的矿物）"。读不懂才对

## 六、自检方法

写完之后问自己三句话：

1. 这段话如果**没有上下文**，单看能读懂吗？→ 能读懂说明太直白了
2. 里面有没有一句**四个字以内**的短句？→ 没有就加一句
3. 有没有**解释任何名词**？→ 有就删掉

三个都过了，才算合格。
