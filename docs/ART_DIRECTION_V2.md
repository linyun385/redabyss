# 美术方向 v2：具象优先（2026-10-31 用户判定后重写）

> 起因：用户指出两个硬问题
> 1. **多种对象共用同一张素材**，而这些对象彼此完全不同 → 必须「一对象一图」
> 2. **过于抽象**：密教模拟器抽象归抽象，但**怪物要有怪物的样子、工具要像工具、事件要有对应场面**；
>    BOSS / 结局可以抽象，那是特色。

## 一、三档抽象度（按对象类别定，不许越档）

| 档位 | 适用 | 画法 | 判定标准（自检） |
|---|---|---|---|
| **A 具象**（默认）| 普通敌人、卡牌里的工具/物件、事件场面、精英怪 | 「旧博物志铜版图」：米白纸 + 墨线 + 密集排线 + 一处朱红；**能一眼认出是什么东西/在发生什么** | 给没玩过的人看 3 秒，能说出"这是一只XX / 一个人在XX" |
| **B 半抽象** | 抽象概念的卡（条款、协议、记忆、协议类）| 仍要有**具体承载物**（纸页、印章、锁、绳、容器），不是纯符号 | 能指出"这是纸/这是印" |
| **C 抽象**（限定）| BOSS、结局、遗物徽记 | 允许纯符号、几何、徽记 | 只允许这三类用 |

**铁律**：A 档图像里**必须出现可辨认的主体**（生物要有身体结构/姿态/器官；物件要有材质与用途；事件要有动作或痕迹）。禁止"几条线 + 一个圆点"这类符号充当怪物。

## 一之二、复用规则（用户 2026-10-31 20:0x 明确）

> 复用**本身可以**，但类别之间不能混，命名差别大的同类别对象也最好不要共用。

| # | 规则 | 判定 |
|---|---|---|
| R1 | **跨类别绝对禁止**：怪物 / 卡牌工具 / 事件 三个池子互不共用任何一张图 | 一个图 id 只属于一个类别 |
| R2 | 同类内允许复用，但**每张图服务对象 ≤ 3 个** | `data/art_families.json` 里每个成员的计数 |
| R3 | 被共享的对象必须同属一个**形态族**（同目 / 同材质 / 同功能） | 名字并排放一起，外人能看出"是同一类东西" |
| R4 | **命名/形态差异大的必须拆族** | 例：`古菌` vs `跳蛛` 不同族；`冷洞食腐鳗` vs `冷洞跳蛛` 不同族；`例检条款` vs `齿轮扳手` 不同族 |
| R5 | 族由数据文件定义，代码按 `对象 id → 族 → 图` 查表，**不再用哈希** | `data/art_families.json` + 改 `cardArtId()` / 敌人查表 |
| R6 | 兜底只在**同类别内**回落（没有怪的兜底图，不许拿事件的图顶上） | 生成时查不到族就报错，不静默 |

**复用示例（允许）**：`冷洞食腐鳗` 与 `深渊鳗` 共用一张"鳗形生物"图，且该图只服务这 2 只。
**复用示例（禁止）**：`休眠两栖类` 与 `例检条款` 共用（跨类别）；`古菌` 与 `跳蛛` 共用（形态差异大）。

## 二、底材与配色

| 类别 | 底 | 线条 | 强调色 |
|---|---|---|---|
| 普通/精英敌人 | 米白纸 | 墨黑细线 + 排线 | 一处朱红（眼睛/伤口/发光处）|
| 卡牌（工具/物件）| 米白纸 | 同上 | 一处朱红 |
| 事件 | 米白纸 | 同上，可加淡墨块 | 一处朱红 |
| BOSS / 结局 | 黑底或深色 | 白/灰线 | 朱红或金 |
| 遗物 | 保持现有 SVG 几何徽记（不必生图）| — | — |

> 统一纸底还有一个好处：现在卡牌里贴黑底方图 = "贴纸感"，换纸底线稿会跟卡面融在一起。

## 三、提示词模板（对象优先，风格在最后）

**教训（T44 踩过）**：风格前缀放最前会把"画什么"吃掉。**先写对象与动作，最后挂风格。**

```
怪物：<它是什么> + <身体特征：腿/鳃/甲/触手/大小> + <姿态与动作> + <环境痕迹> + STYLE
工具：<什么物件> + <材质与磨损> + <用途留下的痕迹> + <摆放方式> + STYLE
事件：<场景里有什么人/物> + <它处于什么状态> + <关键细节（面罩里的字/地上的痕）> + <环境> + STYLE
BOSS/结局：<象征主体> + <构图> + <光> + STYLE_DARK
```

`STYLE`（A/B 档固定后缀）：
```
ink line drawing on aged off-white paper, dense fine hatching, plate from an old naturalist
volume, single small red accent, no border
```
`STYLE_DARK`（C 档）：
```
dark scene with one glowing area, muted palette with a single hot red accent, grainy print
texture, no border
```
负面词（全档通用）：
```
text, letters, glyphs, caption, watermark, border, frame, photograph, 3d render,
color photo, bright saturated colors, gradient, glow, extra limbs, deformed
```

## 四、一对象一图（命名与规则）

| 类别 | 图 id | 路径 | 数量 |
|---|---|---|---|
| 敌人 | `foe_<enemyId>` | `web/assets/art/foe_<enemyId>.webp` | 145 |
| 卡牌 | `face_<cardId>` | `web/assets/art/face_<cardId>.webp` | 266 |
| 事件 | `evt_<eventId>` | `web/assets/art/evt_<eventId>.webp` | 102 |
| 职业 | `class_<classId>` | 现有 4 张（重出成 A 档语言）| 4 |
| 结局 | `end_<endingId>` | 现有 3 张（C 档，保留）| 3 |
| 遗物 | 不出图 | 沿用 SVG 徽记 | 0 |

代码侧要改 `cardArtId()` / 敌人查表：从"生态哈希"改成"直接用对象 id"（查不到时回落到当前符号）。

## 五、分批与预算

| 批次 | 内容 | 数量 | 预估（50–90 秒/张）|
|---|---|---|---|
| 1 | 全部敌人 | 145 | 2–3.5 小时 |
| 2 | 事件场面 | 102 | 1.5–2.5 小时 |
| 3 | 卡牌（按职业分批）| 266 | 4–6.5 小时 |

每批出完都要：**闸门复跑（相似度）+ 随机抽 10 张人工过目 + 更新映射表**，过了再进下一批。
