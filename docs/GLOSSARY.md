# GLOSSARY.md — 术语与命名规范（T64 产出，后续写作任务的唯一参照）

> 词源：`glossary.json`（红渊.md 权威）+ 游戏既有文案 + T54–T63 新增概念。**所有命名从这里取，不要发明新专有名词**；新增词先补进本表再用。
> 写法总规则（与 `docs/STYLE_SAMPLES.md` 配套）：①术语零解释——正文里不写「相石（一种…）」；②数值走 UI——正文禁止「你获得/失去 + 数字」；③敌人/现象用「它」，玩家动作用「你」，状态类文案用「我」（三条例外并行，沿现有池惯例）；④一句话说完就断，无感叹号。

## 6. 命名规则

1. **敌人**：三式——「意象+部位」（空服的壳/晒裂的软管/历壁的蛀痕）、「行为者」（守夜者/补写者/执汤者/收藏家/看守/看火者）、「系列前缀」（墟-：墟蟹/墟蛹/墟腔；硫-：硫塔菌/硫雾囊菌；震-：震鳞蜥/震鳞鲤）。同前缀=同源生物，不算重名。
2. **卡牌家族**：装备类用「词干（括注）」——聚能枪（双管/过热/超载/三管）、曜元（缓释/空腹/高浓）、震频器（校准/并联/微型）、硬矿钻（重型/手持）；括注 ≤2 字。震语者仪式牌用「震语：××」。
3. **事件**：四字以内名词短语优先（气闸的对答/值班交接/签到处/呼吸口）。
4. **遗物**：器物名可带出处前缀（渊光重工·工作灯 / 红渊贸易局·水牌 / 涌喉·水契残页）。
5. **升级后缀**：·新 / ·改 / ·Ⅱ（禁用 +1 / 完全体）。

## 7. 禁用词（现代词汇，正文禁出）

系统、数据、能量饮料、状态、buff/debuff、属性、面板、玩家、刷新、重开、教程、任务、奖励池、经验值、等级。（UI 操作提示除外——按钮/焦点提示不受此限。）

**语域例外（逐条裁决制）**：黯民与殖民者的文案语域本来就是官僚科技腔（协议/编号/回传/评估/清单），这些词在这两个语域内是**拟真**而非出戏——已裁决保留的实例：anm_0041「系统将优先保运行」（黯民协议语域）、anm_0018「评估员只需要看清等级」（黯民评估员语域）、dive_0008「冗余数据」（殖民者回传语域）。禁用的判定标准是**叙述层**出戏（叙述者嘴里冒出现代词），不是角色嘴里有科技词。新增此类用词需在本节登记。

## 8. 近似名判定基准（text_lint.js 规则说明）

同名 → 冲突；同词干+括注/·/：或共有前缀 ≥2 字（且较短名 ≥3 字）→ **家族命名**（设计使然，报告单列）；其余 lev ≤2（4 字名）/≤1（≤3 字名）→ 真近似，需人工裁决。当前全池 8 对真近似全部判定为系列命名（墟- / 硫- / 静日 / 影语-墟语 / 红腔鱼变体 / 光蛭母-浮光水母），保留不改。
