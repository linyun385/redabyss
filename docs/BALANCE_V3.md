# BALANCE_V3 — 只修明显坏掉的卡（T38）

> 数据来源：`node tools/sim.js --class <X> --runs 300`（seed0=12345，简单 AI）。
> 使用率 = 该卡被 AI 打出过的局占比；Δ胜率 = 打出该卡的局的胜率 − 总通关率（单位 pp）。
> **测量偏差声明**：模拟 AI 不主动堆凝视（凝视≈0），苍民 AI 每场开局自动入梦（醒侧牌整场打不出）。
> 这两类卡的模拟使用率天然失真，判废时以「人工构筑下是否可用」为准，不全按数字来。

总通关率基线：下潜者 7.3% / 震语者 6.7% / 黯民 3.0% / 苍民 6.7%（改后 7.3 / 8.0 / 3.0 / 6.7，通关率不作为本任务验收标准）。

## 已知但不修（给用户决策）

1. **凝视门槛家族**（镇爆弹 5.7%/辐射弹 9.0%/氧气再生器（满压）9.3% 等，Δ≈−7pp）：依赖人工堆凝视，模拟失真。若日后要调，建议整体调门槛系数，不是单卡逐个动。
2. **苍民醒侧牌群**：同上，建模问题（AI 永远入梦）。要真实数据需先给模拟 AI 补"按血量/清醒度决策是否入梦"。
3. **黯民模拟通关率 3.0%**：模拟器只装基础遗物池（RAW.relics），黯民专属遗物/零件经济不在模拟内，数字系统性偏低，不代表真人体验。
4. **静底·深阅**：低使用率 + 正相关，好设计，别动。
5. 使用率上限整体偏低（正常卡 12–36%）：这是"打出过该卡的局占比"口径 + AI 每场只打 12 张牌上限所致，属统计口径现象，不是卡坏。
