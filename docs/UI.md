## 6. 未达标项与建议（按性价比排序）

1. **带目标牌的键盘目标选择**（验收 #17 缺口）：`pending` 态下给敌人加 Tab 循环焦点或数字键选目标（敌人 ≤5 个，`1-5` 在 pending 态转发给敌人），改动集中在战斗键盘处理器一处。
2. **升级后效果预览**（验收 #5 缺口）：`openCardDetail` 里对 `card.upgrade && !card.upgraded` 已有分支，把 `card.upgrade.effect` 的差量渲染成一行「升级后：…」即可。
3. **`Tab` 键位冲突说明或补绑**：T28 要求 Tab 切牌堆/日志，T74.1 已把 Tab 给了总图。若维持现状，应在帮助页（`#help-overlay`）把键位表写成实际行为；若要兼容两者，可在面板开时 Tab 轮转面板焦点。
4. **治疗色 `#7da06f` 与不可用色的语义登记**：治疗 hex 与任务书不同且无注释来源；不可用无专用色。建议在 `:root` 增补 `--heal`/`--disabled` 变量并加注释，纳入 `check_contrast.js` 管理。
5. **悬停 300ms 详情**：现方案（点击打开右侧常驻区）是用户拍板形态，建议保持，但在帮助页注明「点击卡牌看详情」，避免按旧预期找悬停。
