# T31 新手引导

## 目标
让一个**没读过设定**的人，5 分钟内知道三件事：
1. 我在干什么（往下走）
2. 我该点什么（出牌）
3. 我为什么输了（共振/凝视/代价）

**不做**教程关，不弹大段文字。

## 一、开场 30 秒
第一次进入游戏，在职业选择界面下方加 3 行说明：

```
你在往红渊的核心走。
每下一层，它就更注意你一些。
红渊的凝视越高，你越强，也越危险。
```

就三行。不要更多。

## 二、前 3 场战斗（D1-D2）
用**非侵入式提示**：只在玩家第一次遇到某个概念时，在对应位置浮一行小字，3 秒后消失。

必须覆盖：
| 时机 | 提示内容 |
|---|---|
| 第一次抽牌 | `每回合抽 5 张。用完的会进弃牌堆。` |
| 第一次能量不足 | `能量不够。结束回合会恢复。` |
| 第一次共振跨 10 | `共振到阈值了。小心，它也在注意你。` |
| 第一次用带代价的牌 | `这张牌要你付代价。代价是永久的。` |
| 第一次凝视 +1 | `红渊记住了你一点。` |
| 第一次敌人显示意图 | `敌人下一步要做什么，都写在它头上。` |

**每条只出现一次**，用 `localStorage` 记录。

## 三、第一次死亡
死亡结算界面下方，根据死因显示一条不同的提示：
- 被打死（没格挡）：`格挡在回合结束会清空。`
- 被共振过载烧死：`共振过 30 就危险了。找牌压一压。`
- 被代价耗死：`带代价的牌很强。但它们要的是真的东西。`
- 被凝视放大伤害：`凝视每 10 点，敌人伤害 +10%。`

## 四、一个"设定速查"
右上角加一个 `?` 按钮，点开是**一页纸**的设定摘要：
- 五脉是什么
- 共振是什么
- 凝视是什么
- 代价是什么

用最少的字，最多 200 字。文风照 `STYLE_SAMPLES.md`。

## 五、不许做的
- 不许弹模态框挡住操作
- 不许强制教程
- 不许写"点击这里开始游戏"这种话
- 提示文案必须符合密教文风，不能写"提示：你的能量不足了"

## 自检
```powershell
node tools\check_web.js
```
手工：
1. 清 `localStorage`，重开一局，6 条提示都只出现一次
2. 不点 `?` 也能玩完整局
3. 死一次，看到对应的那句提示
