# T13 文风第二轮（这是质量关卡）

## 前置
T1/T2 的卡牌、T3 的敌人、T9 的事件都已成型。

## 问题
第一轮的 flavor 是按规则写的，能过检查，但还不够。目标是**让读过密教模拟器的人认出这种文风**。

## 产出
重写三个文件里的全部 flavor / body / result_text：
- `cards/diver.json`（60 条 flavor）
- `cards/tremor.json`（60 条）
- `enemies/all.json`（36+ 条）
- `events/all.json`（24 条 body + 72 条 result_text）

## 这一轮的标准（比第一轮更严）

### 1. 用具体的名词代替感受
```
❌ 你感到畏惧。
✅ 你的手在抖。你把它按在岩壁上，岩石是凉的。
```

### 2. 不解释因果，只给现象
密教模拟器的文本从不告诉你"为什么"，它只告诉你"是什么"。
```
❌ 因为共振之底在记录你，所以你的记忆变少了。
✅ 你想不起的母亲的声音，只剩一个音节的形状。
```

### 3. 每句话都要有一个"不对劲"的地方
```
✅ 他的手套是干的。这里没有干的东西。
✅ 门开着。门是在往里面开。
✅ 红光从下面来，但影子朝下。
```

### 4. 句长控制在 8–25 字，允许一句成段
三个字以下的句子是合法的。
```
✅ 你听见了。
✅ 你没有回应。
```

### 5. 禁用（硬性）
- 感叹号
- "你感到""你觉得""仿佛"
- "非常""极其""十分"
- 任何解释设定的话
- "这是……""这意味着……"
- 形容词堆叠

## 方法
不要一次全改。按这个顺序，**改一批跑一次检查**：
1. 先挑 10 条最像 AI 写的（有"感到""仿佛""仿佛在诉说着"这类），重写
2. 再挑 10 条最短最平的（比如只有"它很危险。"），重写
3. 剩下的按段落过一遍

每改 20 条，跑一次 `node tools/pack_check.js cards` 确认没弄坏 JSON。

## 一个自测方法
把改完的 flavor 连起来读。如果读起来像"设定说明"，就是没改好。如果读起来像"一个人在黑暗里记的笔记"，就对了。

## 自检
```powershell
node tools\pack_check.js all
```
必须全过（禁用词检查会挡住低级错误）。

## 完成
追加写 `TASK_DONE.md`，notes 里写：
- 重写了多少条
- 举 2 条改前 / 改后的对比
