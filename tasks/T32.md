# T32 音效架构（只留钩子，不生成音频）

## 重要
**不许生成音频文件**，不许找素材，不许用在线资源。
这一项只做**架构和清单**，音频由用户以后自己把关。

## 一、做一个音效接口

```js
// web/index.html 里
function playSfx(code, opts) {
  // 现在什么都不做，只记录
  if (window.__SFX_LOG) window.__SFX_LOG.push(code);
}
```

要求：
- 所有需要音效的地方**都调用它**，参数是语义化的 code
- code 命名规范：`card.play.attack`、`enemy.hit`、`ui.click` 这种
- 音量/静音开关的入口先留好（不实现）

## 二、列出完整音效清单

`docs/audio/SFX_LIST.md`，按类别组织：

```markdown
## 卡牌
| code | 触发 | 描述（给以后做音效的人看） |
|---|---|---|
| card.play.attack | 打出攻击牌 | 短促，有金属质感，不要尖锐 |
| card.play.skill | 打出技能牌 | 更闷，像布料或水 |
| card.play.power | 打出能力牌 | 低频，有余响 |
| card.play.cost | 打出带代价的牌 | 叠加一层"东西被拿走"的声音 |
```

类别至少覆盖：
- 卡牌（4 种）
- 战斗（命中、格挡、暴击、死亡）
- 状态（共振阈值、凝视增加、能量耗尽）
- 界面（点击、切换、展开）
- 特殊（Boss 阶段切换、世界切换、通关、死亡）

**每个 code 要有一句"不要什么"**，因为做音效时最怕方向错。

## 三、静音与设置入口
- 在右上角加一个齿轮，点开有：静音开关、音量条（灰掉不可用）、音效清单入口
- 状态写进 `localStorage`

## 四、自检
1. `window.__SFX_LOG` 能收集到所有 code
2. 玩一局，日志里出现的 code 都在 `SFX_LIST.md` 里
3. 没出现"未定义"的 code
