# T51 结局、多周目与死后记忆点（叙事 + 小改代码）

## 目标
T39 做了死亡结算的记忆点，但**通关之后没有去处**。补三结局 + 一个多周目解锁。

## 产出 1：docs/ENDINGS.md
三个结局，每个写：
- **触发条件**（具体的状态量：层数 / 凝视 / 共鸣 / 持有遗物 / 是否进过沉默层，写成可判定的表达式）
- **演出**（玩家看到什么：文字 + 界面变化，不超过一屏）
- **它回答了什么**（红渊是什么 / 你在里面成了什么）
- 文风按 `docs/art/STYLE_SAMPLES.md`（不给解释，只给现象）

三个方向（可改，但要说明为什么改）：
1. **沉底**：一路下潜到底，见到「它」
2. **被凝视吞噬**：凝视满溢，人变成渊的一部分
3. **回头**：主动放弃下潜（代价是失去已获得的一切）

## 产出 2：多周目
通关任一结局后解锁一个变体（写清解锁条件与它改变什么，例如：开局自带一张诅咒牌 / 某层替换为沉默层）

## 产出 3：代码（小改）
- `web/index.html`：结局判定 + 结局页渲染；若需要，`engine/core.js` 加一个纯判定函数（只读状态，不改机制）
- 结局与解锁状态用 localStorage 存（单文件、不用后端），键名写进文档

## 验收

- 解锁逻辑可复现：清空 localStorage → 触发结局 → 刷新 → 变体出现
- 三检查器全绿；10 张手牌不出整页滚动条
