# T36 图标系统 + 卡牌模板（本轮核心）

## 目标
不是画图，是**搭模板**——把"以后要填素材的位置"全部预留出来，并且用符号先把位置占住，让界面现在就能看出信息层级。

## 一、HUD 图标化

用户原话：「血量不是在上面写个血量而是一个红心后面跟着数据」。

用 **Unicode + CSS 着色**，不要用图片（单文件自包含，不能引资源）。

| 含义 | 符号 | 颜色 |
|---|---|---|
| 生命 | ♥ | `#8b2a20` |
| 格挡 | ⬢ | `#5a7fa0` |
| 能量 | ✦ | `#a8834a` |
| 共鸣 | ∿ | `#b05a1a` |
| 凝视 | ◉ | `#8b1a1a` |
| 金币 | ◈ | `#c9a35a` |
| 零件 | ⚙ | `#8a8a8a` |
| 清醒度 | ☾ | `#7a8fb0` |

要求：
- 文字标签（"生命""格挡"）**保留但弱化**（更小的字号、更暗的颜色），符号在前
- 悬停时有 `title` 说明
- **符号和数字之间留固定间距**，不要贴在一起

## 二、卡牌改长方形

现在是 118×118 正方形（战斗）/ 210×210（奖励），都不像卡。

改成接近真实卡牌比例（约 0.71）：

```css
.card { width: 150px; height: 210px; display: flex; flex-direction: column; }
```

结构改成四段：

```html
<div class="card">
  <div class="cost">1</div>
  <div class="ctype">攻</div>
  <div class="art">              <!-- 图案区：现在放占位符号 -->
    <span class="art-ph">◈</span>
  </div>
  <div class="cname">光导透镜</div>
  <div class="ctext">格挡 6 · 共振锁定</div>
  <div class="cflavor">我看它的时候它也在看我。</div>
</div>
```

### 图案区规则（**这是给未来素材留的接口**）
```css
.card .art {
  height: 78px; flex: 0 0 auto;
  background: #1a1214 center/cover no-repeat;
  border-bottom: 1px solid #4a2a2c;
  display: flex; align-items: center; justify-content: center;
  position: relative; overflow: hidden;
}
/* 未来填充：给 .art 加 style="background-image:url(art/xxx.webp)" 即可 */
.card .art-ph { font-size: 30px; color: #3a2224; }  /* 无图时的占位符号 */
```

**过渡方案**：现在每张卡按脉给不同的占位符号
```
光 ◉   水 ≋   热 ✹   震 ⌇   矿 ◈   无脉 ·
```
符号颜色用各脉对应的暗色。

有 `art.image` 字段的卡（暂时都没有）就显示图，没有就显示符号。

### 其他元素
- 费用：左上角圆形，保持
- 类型（攻/技/势）：右上角小字
- 卡名：13–14px
- 效果文本：11–12px
- flavor：10px，颜色更暗，最多 2 行，超出省略

## 三、职业立绘占位

职业选择界面的四张卡，每张顶部加一个 100px 高的图案区：

```html
<div class="class-card">
  <div class="portrait"><span>◉</span></div>   <!-- 未来 background-image -->
  <h2>下潜者</h2>
  ...
</div>
```

占位符号：
```
下潜者 ◈   震语者 ⌇   疯先知 ☾   维护者 ⚙
```

## 四、敌人立绘占位

敌人卡片里也加图案区（60px 高），占位用该敌人的层级符号：
```
普通 ·    精英 ◆    Boss ✦
```

## 五、验收

```powershell
node tools\check_web.js
node tools\pack_check.js all
```

浏览器实测：
1. HUD 显示成 `♥ 80/80  ⬢ 0  ✦ 3/3  ∿ 1  ◉ 0  ◈ 0` 这种形式
2. 战斗手牌是竖版长方形，每张有图案区（显示脉符号）
3. 卡牌奖励界面也是长方形，且**不超出屏幕**
4. 职业选择四张卡都有图案区
5. 敌人卡有图案区
6. **在一张卡上手写 `style="background-image:url(...)"` 能覆盖占位符号**——证明接口是通的

## 五之二、`check_web.js` 的硬冲突（必读）

`tools/check_web.js` 第 7 条会把下面两样判 **FAIL**：

- 任何 `<img` 标签
- CSS 里出现 `background-image:url(`

所以：

- **CSS 里不许写 `background-image:url(...)`**。图案区只写背景色 + 占位符号；填充接口在注释里说明即可。
- 第 6 条那个验证，**测完必须把 inline style 删干净**再跑 `node tools/check_web.js`，最后交上去的文件里不能留。

## 注意

- 手牌变大后，**确认日志区仍然可压缩**（T35 修的 flex 不能被破坏）
- 手牌超过 5 张时的换行/缩小行为要正常
- 不要动 `engine/core.js`
