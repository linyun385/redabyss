# T44 材质风格 × 层深度色的协调适配（最后一棒）

> 2026-10-29 22:55 用户定：**密教风整体改造放到最后做，但不放弃层深度换色，两者要对照着组合协调**。
> 所以本任务的产出**不是**一个"换皮结果"，而是 **3 个候选方案 + 可比证据 + 一个可切换开关**，由用户拍板。

## 前提（读之前先读）

1. `docs/art/STYLE_ART.md` —— 密教风美术规范（木刻版画、棕褐 + 暗红、色板 `#d9cfbe / #6b5334 / #2b2118 / #8b2a20 / #a8834a`）
2. `docs/HANDOFF_D2.md` 第 5 条 —— 已定的层深度色（D1 蓝灰 `#39434e` → D4 黑 `#0d1013` → D8 红 `#64101a`），**这套色不许废掉**

目标是把两者**组合**，不是二选一。

## 第一步：实现三个候选方案（可随时切换）

| 方案 | 做法 | 一句话 |
|---|---|---|
| **A 全纸底** | 背景整体换老化纸 `#d9cfbe` 系，主线棕墨，暗部用深褐 | 整页像一页手稿 |
| **B 暗底贴纸** | 背景保深色 + 层色不变，卡牌 / 面板 / 日志改成纸底 | 暗处摊开的一页纸 |
| **C 层色 + 纸纹** | 层色保留，叠低透明度纸纹与暗角，卡牌纸底 | 暗底上压了一层旧纸 |

实现约束：

- 只改 **CSS 变量层 + 必要覆盖样式**。建议引入：`--paper` `--ink` `--ink-dim` `--layer-tint` `--grain-opacity` `--card-paper`
- **不许动 `engine/core.js`，不许改卡牌/敌人/遗物数据，不许改 DOM 结构**
- 三方案用根元素上一个 class 切换，例如 `<html data-theme="A|B|C|off">`，**默认 `off` = 现状**
- 不许引外部字体、外部图片、网络资源（单文件自包含是硬约束）

4. **白 → 暗 → 红三段递进**仍在：D1 最亮、D4 最暗、D8 最红
