# T37 战斗顺滑 + 点击反馈

## 一、动画时序（定死这些数字）

| 动作 | 时长 | 说明 |
|---|---|---|
| 卡牌飞出 | 180–240ms | 不要超过 250ms，会拖沓 |
| 伤害数字上浮 | 400ms 后消失 | |
| 敌人意图切换 | 200ms 淡入 | |
| 敌人受击闪烁 | 120ms | |
| 敌人死亡 | 400ms 变灰 + 淡出 | |
| 回合切换提示 | 600ms | |
| 层深度主题切换 | 400ms 渐变 | 现在是无过渡跳变，改成 fade |

**除世界切换和 Boss 阶段以外，任何动画不超过 500ms。**

## 二、动作队列（关键）

现在连续快速出 3 张牌时，动画会互相覆盖、伤害数字叠在一起。

实现一个简单队列：
```js
const animQueue = [];
function enqueueAnim(fn) { animQueue.push(fn); pumpAnim(); }
```
规则：
- 动画依次播放，**但输入不等待动画**
- 连续出牌时，后一张牌的动画排在后面，不打断前一张
- 伤害数字错开垂直位置（-0 / -20 / -40 px），避免重叠

## 三、必须补齐的反馈

逐条对照，缺一个补一个：

| 操作 | 反馈 |
|---|---|
| 出牌 | 卡飞出（不是瞬间消失） |
| 造成伤害 | 敌人闪红 + 数字上浮 |
| 获得格挡 | 盾形符号脉冲 |
| 共振跨阈值 | 屏幕四边闪红一次 |
| 凝视 +1 | HUD 数字跳动 |
| 卡牌不可用 | 轻微抖动 + 浮字说明原因 |
| 敌人死亡 | 变灰淡出 |
| 牌堆为空洗回 | 抽牌堆数字重置动画 |

## 四、可点元素要"看得出来能点"

用户原话：「玩家点击的东西要足够显眼」。

- 地图可走节点：加**外层光晕**（`box-shadow` 呼吸动画，2s 循环）
- 卡牌可出：hover 时上浮 4px + 边框变亮
- 卡牌不可出：`opacity: .35` + 光标 `not-allowed`（已有，确认生效）
- 选项按钮：hover 时左边框亮起

## 五、性能保护

- 用 `requestAnimationFrame`，不要堆 `setTimeout`
- 如果一帧耗时 > 50ms，自动降级（关掉光晕和上浮，只留颜色变化）

## 六、验收

```powershell
node tools\check_web.js
```

浏览器实测：
1. 连续快速点 3 张牌，动画依次播完，没有叠加错乱
2. 伤害数字不重叠
3. 切换层级时背景是渐变的，不是瞬间跳
4. 地图上可走的节点在发光，一眼能分辨
5. 卡牌不可用时点它会有提示（不是完全没反应）
