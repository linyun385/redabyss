# T28 UI 打磨

## 一句原则
界面不该让玩家问「这是什么」，应该让他问「我该选哪个」。

## 一、信息层级（先定这个，再谈好看）

每个界面最多三级：
1. **一眼看到**：生命、能量、敌人意图
2. **需要时看到**：格挡、共振、凝视、遗物
3. **主动查看**：牌堆、弃牌堆、卡牌详情、日志

现在的问题可能是三级信息混在一起。**把第三级全部收进可展开面板。**

## 二、具体改造项

### 1. 卡牌详情
- 悬停 300ms 才显示大图（避免扫过一堆牌时疯狂弹窗）
- 详情里必须显示：完整效果、代价、脉、升级后效果

### 2. 数字对齐
- 所有数字用等宽字体
- 血条上的数字不能随动画抖动

### 3. 对比度
- 正文 `#d8cfc9` on `#0a0506` → 对比度约 12:1 ✓
- **检查所有次要文字**（提示、说明），低于 4.5:1 的提亮

### 4. 状态颜色语义（全局统一）
```
伤害      #d94a4a
治疗      #6b9f6b
格挡      #5a7fa0
共振      #b05a1a
凝视      #8b1a1a
不可用    #4a4442
```
任何界面不许用别的颜色表达这些含义。

### 5. 键盘操作
- `1-9`：打出手牌第 N 张
- `空格`：结束回合
- `Tab`：切换牌堆/日志面板
- `Esc`：关闭面板

### 6. 小屏兼容
- 1280×720 下所有元素可见，不需要横向滚动
- 手牌超过 7 张时自动缩小
