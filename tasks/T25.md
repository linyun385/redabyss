# T25 苍民 DLC 接入

## 前置
T23 数据、T24 引擎。

## 产出
`web/index.html` 支持第四个职业 + 苍垣层 + 双世界 UI。

## 要做的事

### 1. 职业选择变四个
下潜者 / 震语者 / 黯民 / **苍民**

### 2. 双世界 UI（这是重点）
必须让玩家**一眼看出自己在哪个世界**：

| 元素 | 醒着（wake） | 梦中（dream） |
|---|---|---|
| 背景色 | 冷灰蓝 | 暗红 |
| 边框 | 细线 | 脉动红光 |
| 生命条标签 | 身体 | 梦境 |
| 手牌边框 | 素色 | 带光晕 |

切世时要有明显的过渡（0.3–0.5 秒的闪烁或渐隐），不要瞬间跳。

### 3. 清醒度 HUD
显示 `清醒度 N/10`，低于 3 时闪烁警告。

### 4. 不可用的牌
世界不匹配的牌显示为**半透明 + 不可点**，点击提示对应文案（不是"不可用"这种系统话）。

### 5. 苍垣层
按 T22 的判断接入。逻辑上要自洽（苍民是梦到红渊，入口要能解释）。

### 6. 数据内联
保持单文件自包含。

## 自检
```powershell
node tools\check_web.js
node tools\pack_check.js all
node tools\test_engine.js
```

手工确认：
1. 选苍民能开
2. 能切世界，切世有过渡
3. 梦境里打不出清醒牌
4. 梦里"死"了会醒，游戏继续
5. 清醒度耗尽强制醒
