### T402 · 重复效果标记

**产出**：在 T401 的表格上补「与谁重复」列，并在文末加一节「重复清单」。

跑 `python tools/dup_check.py`，把它的输出对照 T401 表填进去。

分两档标：

| 档 | 定义 |
|---|---|
| **完全撞** | effect JSON 除了数值外完全一致 |
| **近似撞** | 效果键集合相同，主数值差 ≤2，target/hits 相同 |

**文末单独列一节**：
- 完全撞的每一组，列出全部 id + 名字
- 近似撞的每组，列出 id + 差异点（哪个数值差多少）

**注意**：`dup_check.py` 当前报「完整撞 4 次 / 近似撞 21 次」。你跑出来的数字如果不一样，**写清楚为什么**（可能是脚本版本不同），不许悄悄改数。

### T403 · 效果类型分布

**产出**：附在 T401 表尾的统计表。

对**每条脉 × 每个角色**做交叉统计：多少张伤害牌、多少张格挡牌、多少张抽牌/资源牌、多少张增益/减益牌。

判型规则（按 effect 的键判定，一张卡可归多类）：
- 有 `damage` 或 `hits` → 伤害
- 有 `block` → 格挡
- 有 `draw` 或 `energy` 或 `discard` → 资源
- 有 `special` 且 code 属于 burn/poison/weak/frail → 减益
- 有 `special` 且 code 属于 strength/dexterity/regenerate/thorns → 增益

表格式：行 = 脉，列 = 角色，格子里写「伤害x / 格挡y / 资源z / 减益a / 增益b」。

**再加一节**：每条脉在四角色里的**总量**，一眼看出哪条脉在哪缺。

**产出**：`docs/design/vein_audit_matrix.md` 里单独一节「跨角色同脉同效果」。
