# T11 商店与营火（两个新节点）

## 前置
T10 已完成（岔路地图）。

## 产出
两种新节点类型：`shop` 和 `campfire`。

## 一、营火（campfire）

**功能**：三选一
1. **静日**：回复 30% 最大生命
2. **修整装备**：升级一张卡牌（见 T12；若 T12 未完成，则改为"获得 1 个随机遗物"）
3. **听震**：移除一张牌（永久，从牌组删掉）

三者**只能选一个**。

**叙事**：每次进入营火，text 从池子里抽一句，不要每次都一样。
参考素材：渊民的「静日」「禁声日」，下潜者的「换氧气罐」。

```json
"campfire_texts": [
  "你把头盔摘了。这里的空气够你活三次呼吸。",
  "火是你自己生的，很小心，很小。红蕨在远处看着。",
  "你听见岩层在动。它一直动，只是你平时听不见。"
]
```

## 二、商店（shop）

**功能**：用金币买东西，4–6 个货位

货位类型与价格：
| 类型 | 价格 |
|---|---|
| 普通卡 | 40–60 |
| 罕见卡 | 75–110 |
| 稀有卡 | 150–200 |
| 遗物（普通） | 120–160 |
| 遗物（稀有） | 250–320 |
| 删牌服务 | 75（一次，用完即无） |
| 回血（25%） | 60 |

**规则**：
- 金币从哪来：战斗掉落（已有）、事件
- 商店里买不起的东西**变灰**
- 可以什么都不买直接走

**叙事**：商店是殖民者的地方，要冷、要交易感。
```json
"shop_texts": [
  "玻璃柜里摆着别人的东西。有些编号还没刮干净。",
  "掌柜没抬头。他只是把价签转了个方向。"
]
```
