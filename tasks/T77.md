# T77 开局牌库审计（太强太无脑的牌不进初始牌库）

## 用户原话（2026-10-31 19:30）
> 「某些太强太无脑的牌至少不要开局放进牌库中」

## 问题
四职业初始牌库里混着高强度/无决策的牌（0 费抽牌、无代价全体伤害等），开局就能滚雪球，压掉前期的紧张感。

## 做法
### 1. 先做「强度分」脚本 `tools/card_power.js`
对每张牌算一个可解释的分数：
```
power = (伤害 + 格挡×0.8 + 抽牌×3 + 能量×4 + 全体伤害×1.6 + 附加效果估值)
        / max(1, 费用)            // 0 费按 0.5 计，避免爆炸
```
- 连锁/条件效果给固定估值表（写在脚本头注释，可调）
- 输出每张牌的 power，并按现有卡池算 **P75 / P90 分位**

### 2. 审计规则（硬）
| 规则 | 内容 |
|---|---|
| R1 | 初始牌库的任何一张牌 **power ≤ 当前卡池 P75** |
| R2 | 「无脑牌」黑名单不进初始牌库：0 费且抽 ≥2、无代价全体伤害 ≥10、无限连组件（打出后抽回自身） |
| R3 | 初始牌库必须包含 ≥1 张防御/应对牌（不能全攻） |
| R4 | 每职业初始牌库 **10–12 张**，且至少 3 种不同机制（不许全是打击类） |
| R5 | 被移出的牌**不删除**，改名进「奖励池/商店」，并在文档里列出 |

### 3. 输出
- `tools/card_power.json`：每张牌 power + 分位
- `docs/DECK_AUDIT.md`：四职业初始牌库前后对照表（移出哪些、为什么、去了哪里）
- 若移出后某职业胜率掉 >5pp，允许从奖励池挑回 1 张低 power 牌补位（要有数据支撑）
