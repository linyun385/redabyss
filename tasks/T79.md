# T79 素材「形态族」划分与逐族提示词清单

## 目标
按 **ART_DIRECTION_V2** 的复用规则，把三类对象各分成「形态族」，每族一张图、族内成员 ≤3，并给每族写一条**对象优先**的提示词。

## 先读（2026-11-01 用户要求：先重读世界观，再设计提示词语言）
**必须按顺序读，读完在 TASK_DONE 里写一句「我从哪份文档取到了什么」**：
1. `docs/GLOSSARY.md` —— 专有名词的唯一写法
2. `docs/LAYERS.md` + `layers/layers.json` —— 八层环境规则
3. `docs/ECO_ENEMIES.md` / `docs/ECO_EVENTS.md` / `docs/ECO_RELIC_CARD.md` —— 每个生态的气味
4. `docs/ENEMY_DESIGN.md` / `docs/ENDINGS.md` —— 既有设定，不许矛盾
5. `docs/art/ART_PROMPT_SPEC.md` —— **提示词语言规范 v1（写提示词就照它）**
6. `docs/art/ART_DIRECTION_V2.md` —— 三档抽象度 + 复用规则 R1–R6
7. 对象自身的 `flavor` / `body` / `intent_pattern` —— 每条 prompt 的语义锚点

> **为什么先读**：2026-11-01 的第一版样张被用户判「太素、太现实」——
> 画出来就是地球上的青蛙。缺的不是画技，是**红渊化的形态语言**。
> 所以每条 prompt 必须带 **1–2 个异化标记**（A 材料替代 / C 工艺寄生 / B 器官错位，见规范 §二）。

## 产出 1：data/art_families.json
```json
{
  "foe":   {"foe_family_amphibian": {"name": "两栖类", "members": ["enemy_d2_04", "enemy_d2_07"], "prompt": "...", "style": "A"}},
  "card":  {"card_family_checklist": {"name": "检查单类", "members": ["anm_0004", "anm_0011"], "prompt": "...", "style": "A"}},
  "event": {"evt_event_d3_1": {"name": "遇难者遗体", "members": ["event_d3_1"], "prompt": "...", "style": "A"}}
}
```
硬要求：
- **跨类别不复用**：一个 id 只出现在一个类别里
- 每族 **members ≤ 3**，且成员必须形态相似（R3/R4）
- **事件族 = 一事件一族**（事件都是独立场面，不做复用）
- 每个对象都必须被某个族覆盖：`foe` 覆盖 145 只、`card` 覆盖 266 张、`event` 覆盖 102 个；缺一个就报错
- 族 id 命名：`foe_family_<英文短名>` / `card_family_<英文短名>` / `evt_<eventId>`

## 产出 2：tools/check_families.js
- 断言：覆盖率 100%、跨类别 0 冲突、成员 ≤3、族内成员至少共享 1 个"形态关键词"
- 输出统计：三类各自的族数、复用率（成员数/族数）、被"最多共用"的前 10 族

## 产出 3：提示词质量要求
每条 prompt 必须按模板顺序写：**对象是什么 → 身体/材质特征 → 姿态或痕迹 → 环境 → STYLE**。
- 禁止只写 `a symbol of X`、`abstract embodiment`、`minimal emblem`
- 每条 prompt 里**至少 3 个可画的具体名词/形容词**（腿/鳃/甲/锈/裂/血/绳/纸/印…）
- BOSS/结局保持 C 档（可抽象），不进本任务的族表
