# T69 批量补齐剩余素材（68 条）

## 现状
`art/` 目前只有 **11 张**（5 张生态卡面 + 4 张职业立绘 + 2 张结局），而 `tools/art_manifest.json` 有 **79 条**。
T66 只做了「样张送审」，所以剩下的 **68 条没生成**——本任务把它补齐。

## 做法
用已交付的 `tools/gen_art_batch.py` 跑 manifest 里缺的那些条目：

```powershell
cd C:\Users\Administrator\Desktop\杂七杂八\红渊\game
$env:HF_ENDPOINT='https://hf-mirror.com'
python tools\gen_art_batch.py            # 默认跳过已存在的，断点续跑
```

## 硬要求
1. **尺寸**：卡面/敌人用 **640×936**，职业立绘 640×960，结局 640×936。
   （832×1216 在 8GB 显存上会溢到共享内存，单张要 8–10 分钟，别用。）
2. **单张体积**：≤ 30 KB（webp，quality 78–82）。超了就降 quality 或尺寸，不许超。
3. **失败处理**：每张失败重试 1 次，仍失败写 `tools/art_failed.json` 继续跑下一个；最后报告失败清单，不许静默跳过。
4. 跑完**必须复跑闸门**：`python tools\art_similarity.py`，命中（汉明距离 ≤6）的图**弃用并换 seed 重出**，直到 0 命中。
5. 生成过程会占 GPU 数十分钟：**不要同时跑 sim / 训练**等吃显存的任务。

## 验收
- `art/` 下 webp 数量 = manifest 条目数（79），或明确列出未完成项与原因
- `tools/art_run.json` 记录每张耗时，总耗时写进报告
- 闸门 0 命中
- 三检查器全绿（本任务不动 `web/`）
