# T50 素材降级方案：纯 CSS / SVG 的卡面质感（绕开 ComfyUI）

> **2026-10-30 拍板：默认主题已改为 C**（见 `docs/THEME_DECISION.md`）。
> 本任务**以 C 为准**做质感；B 只需不破相；A 已作废，不用管。
> 也就是说：暗底 + 纸纹 + 卡面用纸 = 现在的默认观感，你要在这个基础上加东西，不是重来。

## 背景
ComfyUI 环境今晚起不来（py3.13 与这版 ComfyUI 的自定义算子冲突），T42 停在探测阶段。
但卡面现在只有占位符号，太素。**不依赖任何生图**也能先做出质感。

## 目标
用**纯 CSS / 内联 SVG**给以下三处做质感，全部单文件自包含（`check_web.js` 不许红）：
1. 卡牌图案区底纹：按脉不同（光/水/热/震/矿/无），用 CSS 渐变 + 重复线性/径向渐变造出「手工印刷的网点/纹理」
2. 敌人卡：剪影级图形（SVG path，几何象征物：眼、门、刀、杯、蛇），按层级（普通/精英/Boss）换构图
3. 遗物：小图形徽记（≤30 个，SVG，几何化），替换现在的纯文字

## 硬约束
- **禁止** `<img>`、`background-image:url(...)`、外部字体、网络资源（`check_web.js` 会判 FAIL）
- 不允许用「模糊/滤镜把字压暗」来凑质感
- 与 T44 的 B / C 主题兼容：主题切换后质感仍在（变量走 `--paper` / `--ink` 系）
- 性能：新增 DOM 节点不超过 200，首屏不许出现明显卡顿（用 `performance.now()` 记首次交互耗时，写入报告）

## 产出
- 代码：`web/index.html`（只加 CSS 与 SVG，不动引擎与数据）
- 截图：`docs/artstyle/SVG_cards_off.png`、`SVG_cards_B.png`、`SVG_cards_C.png`、`SVG_enemy.png`、`SVG_relics.png`（1440×900）
- 报告：`docs/art/ART_FALLBACK.md` 写清每个图形用了什么画法、在哪几个类名下、以后接入真图时怎么替换
