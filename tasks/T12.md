# T12 卡牌升级系统

## 前置
T4 或 T11 已有营火节点。

## 产出
卡牌可以在营火升级，升级后效果变化。

## 数据
每张卡已有 `upgrade` 字段（可能为空）。要做的：

1. **给全部 120 张卡补上 `upgrade`**（两职业各 60）
2. 升级不是简单加数值，要有**质变感**

```json
"upgrade": {
  "name_suffix": "·刻",
  "effect": { "damage": 4 },
  "cost_type": "none",
  "flavor_add": "你把它重新磨过一次。它记得你的手。"
}
```

要求：
- 攻击牌升级：伤害 +30~50% **或** 加一条效果
- 技能牌升级：格挡 +30~50% **或** 降费
- 能力牌升级：强化持续时间/触发次数
- **带代价的牌升级时，代价可以减轻或加重**（自己判断哪个更好玩）

## 命名
升级后的显示名 = 原名 + 后缀。后缀从这套里选（不要全用同一个）：
`·刻`、`·改`、`·残`、`·Ⅱ`、`·旧`、`·新`、`·固`

## 引擎
`engine/core.js` 加一个 `upgradeCard(card)` 函数：
- 返回一个新的卡对象（不修改原对象）
- 合并 `effect` 数值
- 打上 `upgraded: true`

**不许改坏现有行为**：改完跑 `node tools/test_engine.js` 全绿。

## 前端
- 营火选「修整装备」时，打开牌组，选一张可升级的卡
- 已升级的卡在卡面显示一个小标记（比如名字后缀 + 金色边框）
- 手牌区要能看出哪张是升级过的
