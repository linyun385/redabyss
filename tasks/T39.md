# T39 趣味性：build 多样性 + 彩蛋

## 一、三条可通关的 build（每职业）

不是"三条都能赢"，是"三条**打法完全不同**"。

写进 `docs/BUILDS.md`：

```markdown
## 下潜者 · 供能流
核心卡（≤8 张）：xxx、xxx
打法：把遗物堆到 6 个以上，靠共振过载反杀
爽点：你明明快死了，但下一回合整个屏幕在闪
和哪条流冲突：和"零遗物"流互斥
```

要求：
- 每条 build 核心卡 ≤ 8 张
- 任意两条之间**至少有一张卡是互斥的**
- 四条职业各写三条

## 二、卡牌组合彩蛋（8 个）

两张特定卡在同一场战斗都打出过 → 触发额外效果 + 一行特殊文案。

要求：
- **不写在卡面上**（让玩家自己发现）
- 触发时有明显的视觉提示（一句话 + 屏幕微闪）
- 记录在 `docs/EASTER_EGGS.md`

设计方向（自己发挥）：
- 同脉连打到第 5 张
- 某张代价牌 + 某张治疗牌一起用
- 在特定层用特定卡
- 同一张卡打出两次

## 三、死亡结算要有"记忆点"

现在死亡结算只是数字。要加一条**这一局最值得说的事**：

从这些里选最极端的一条显示：
- 拆了最多零件的那次
- 凝视最高的时刻
- 单回合最大伤害
- 走得最远的层
- 用了最多带代价的牌

格式：一句话，不是数据罗列。
```
你在第 5 层拆了 7 台机械。它们记得你的编号。
```

## 四、通关结算显示关键选择
- 拿了哪些稀有卡
- 走了哪条岔路
- 最终凝视值代表什么

## 五、不要做的

- 不加"看广告复活"
- 不为趣味牺牲可读性
