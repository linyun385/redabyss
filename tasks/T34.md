# T34 布局修复与机制说明（用户实测反馈）

## 背景
用户实际玩了两局，提了 5 个问题。这些是**体验阻断级**的问题，优先级高于一切新内容。

## 问题一：日志撑爆页面，点不到「结束回合」🔴

**现象**：回合数增加后，战斗日志不断累积，页面整体被撑高，出现页面级滚动条，底部的「结束回合」按钮被挤出屏幕，点不到。

**根因**：flex 子项默认 `min-height: auto`，日志内容会把父容器撑开，`overflow-y: auto` 失效。

**修复**：
```css
/* 战斗界面容器必须能被压缩 */
#screen-combat {
  flex: 1; display: flex; flex-direction: column;
  min-height: 0;              /* ← 关键 */
}
/* 日志区：只在这里滚动，绝不撑开父级 */
#log-wrap {
  flex: 1 1 0;                /* 用 0 而不是 auto */
  min-height: 60px;
  overflow-y: auto;
}
/* 手牌区固定不压缩 */
#hand-area { flex: 0 0 auto; }
```

**验收**：打完 10 个回合，日志堆到几百行，「结束回合」仍然在视口内，页面**没有**滚动条（`document.documentElement.scrollHeight === innerHeight`）。

## 问题二：HUD 横向撑破 🔴

**现象**：遗物变多后，顶部那排（生命/格挡/能量/共鸣/凝视/金币/遗物）横向超出屏幕。

**根因**：`#hud` 有 `white-space: nowrap`，但没有溢出处理。

**修复**：
```css
#hud {
  flex-wrap: nowrap;
  overflow: hidden;                    /* 不撑破 */
  white-space: nowrap;
}
/* 遗物太多时收缩并显示 ... */
#hud .relics { flex-shrink: 1; min-width: 0; overflow: hidden; text-overflow: ellipsis; }
```
或者更简单：遗物超过 4 个时折叠成「遗物 ×N」，悬停展开。

## 问题三：HUD 应该常驻所有界面 🟡

**现象**：只有战斗界面有 HUD。但路上（地图、事件、商店、营火）也会扣血、得金币、加凝视，玩家看不到。

**修复**：把 HUD 提到 `#app` 层级，所有界面都显示。数据来源统一走 `run` 对象。

**验收**：在地图上触发一个扣血事件，回到地图后立刻能看到血量变化。

## 问题四：三个界面尺寸不一致 🟡

**现象**：开场（职业选择）、路程（地图）、战斗，三个界面的宽度/留白/居中方式都不一样，切换时画面会跳。

**修复**：
```css
.screen {
  flex: 1; min-height: 0;
  width: 100%; max-width: 1280px;
  margin: 0 auto;
  padding: 0 24px;
  box-sizing: border-box;
  display: flex; flex-direction: column;
}
```
三个界面用**同一套**容器规则。

**验收**：在三个界面之间来回切换，左右边距、标题位置不跳动。

## 问题五：keep_block 遗物让格挡无限累积 🔴

**现象**：用户拿到 `keep_block` 遗物后，格挡一路累积到 44，变成"第二条命"，机制失去意义。

**根因**：
```js
let keepBlock = false;
(C.run.relics||[]).forEach(r => { if (r.mod && r.mod.keep_block) keepBlock = true; });
if (!keepBlock) C.block = 0;
```
`keep_block` = 永不清零 = 无限累积。

**修复方案（选一个并说明理由）**：
- A. 改成**回合结束保留一半**（`C.block = Math.floor(C.block / 2)`）
- B. 改成**保留固定上限**（比如最多保留 15 点）
- C. 改成**只在特定条件保留**（比如"本回合没受伤害时保留"）

推荐 A，理由：保留一半有策略价值（鼓励叠甲），但不会有滚雪球。

同时把这个遗物的 `effect_text` 改准确。

## 问题六：核心机制没有说明 🟡

**用户原话**：「格挡、共振、凝视机制具体是怎么样的，坦白说我最开始以为格挡是一回合内的"血"，后来发现似乎不是，但格挡数加上去后好像又是这样了」

他在实际玩了两局之后仍然不理解格挡，说明**说明不够**。

**要做的**：
1. 在 HUD 上，格挡数字后面加一个极小的标记（比如 `🛡 44 ↓`），悬停显示「回合结束会消失」
2. 战斗界面右下角加一个 `?` 按钮，点开是**一页纸**的机制速查：

```
生命    归零就结束
格挡    敌人回合帮你挡伤害。你的回合结束后会消失（除非有特别的东西留着它）
能量    每回合回满，出牌消耗
共鸣    每回合自动上涨。到 10/20/30 各触发一次这个层级的事。超过 30 会反噬
凝视    每 10 点，敌人伤害 +10%。有些牌要够高才能打
```

**文风**：按 `docs/art/STYLE_SAMPLES.md`，不要写成说明书。上文的"除非有特别的东西留着它"就是调子。

3. 第一次获得 `keep_block` 类遗物时，浮一行提示：「你的格挡不会再消失了。」
