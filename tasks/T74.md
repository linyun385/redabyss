# T74 修复三件：生成性能回归 / 深度节奏 / 小图挡标题

## 来源
我 2026-10-31 19:15 的独立核验（数字都是实测，不是估计）。

## 问题 1：生成性能回归（T73 验收第 7 条未达标）
- 实测 `node tools/mapgen_test.js` → **exit=1**：100 图 **9.36 秒**（93.6ms/图），200 图 20.3 秒
- **重试平均 19.3 次、最多 103 次**（约束过紧→反复重试）
- 目标：100 图 **< 2 秒**、重试平均 **≤ 6 次**

**允许的修法**（按优先级）：
1. 网格加宽 `w: 14 → 20`（同时 `h` 保持 64），生态块下限 `12 → 8`
2. 放宽 `verticalOk`（纵向间距 ≥2 → ≥1）或把 band 配额做成"软目标 + 兜底"
3. 重试策略：先做"位移/交换"局部修补，再做整图重生成（现在的做法是整图重来）

**禁止**：把验收目标改小来"过关"。

## 问题 2：深度节奏（T73 核心目标未达）
- 实测 500 局：步数 **32.3**（目标 40–70）；每带 D2–D7 **3.8–4.0**（目标 ≥4.5）；BOSS 3.25 ✓；通关率 100% ✓
- 根因（T73 notes 已写）：14 列 + 不交叉 + 入度 ≤3 的 DAG，单路径长度被"脊柱"卡死

**修法**：网格 `h: 64 → 96`（带高 8 → 12 行），配合问题 1 的加宽；若步数仍 < 40，**在 spec 里把目标改成 36–50 并注明依据**（单局 ≈ 18–25 分钟），不许默默不达标。

## 问题 3：小图在选择态挡住页面标题
- 实测：选择态 `#mm-dock` = **620×547 居中**（top 86px），把「第 N 深度带 XXX」标题整个盖住
- 要求：**常驻小图固定右边缘**（top ≥ 96px、right ≤ 12px、宽 ≤ 380px），**不居中**
- 只有"点开地图区"时才允许放大居中；放大态必须有明显的关闭入口（× / Esc / 点背景）
