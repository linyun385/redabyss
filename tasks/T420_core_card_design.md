## 2. 工具怎么用

打开 `http://127.0.0.1:8771`（卡牌工作台），流程：

1. 点「新建」，选职业 → id 自动分配（维护者 `anm_`、疯先知 `cng_`、下潜者 `dive_`、震语者 `trem_`）
2. 填名字、类型、费用、稀有度、属性脉
3. **勾上「核心卡」** ← 这一步别忘，勾了才有 `★` 标记和保底保护
4. 「这张牌做什么」：用大白话写效果
5. 「想让玩家怎么玩」：一句话，写设计意图
6. 「保存到草稿」

**卡的 id 会自动分配，别手改**（上次手改撞了 id，覆盖掉一张卡）。

### 稀有度怎么选

| 稀有度 | 奖励权重 | 什么时候用 |
|---|---|---|
| 普通 common | 6 | **核心卡不要用这个**，太容易出，失去分量 |
| 精良 uncommon | 3 | **大多数核心卡用这个** |
| 稀有 rare | 1 | 只给极少数「一张定江山」的核心卡 |

核心卡的出现靠**保底计时器**保证（连续 3 次奖励没出核心卡就强制塞一张），不靠稀有度堆。

### 费用

**现在是 4 能量，不是 3。** 3 费卡 + 1 费辅助可以同回合打出，所以 3 费核心卡是可行的，别怕。

## 5. 写卡顺序：先 4 张验证

**第一批：维护者 × 矿（4 张）**

为什么选这个组合：

- 矿是阶段 0 定的验证脉
- 维护者有零件机制，能验证「零件当配料、脉当主料」这条原则
- 矿的累积特性最容易看出「战斗太短/太长」的问题

**4 张的定位建议**（只是方向，你可以完全推翻）：

| # | 定位 | 大致长什么样 |
|---|---|---|
| 1 | **成长主卡** | 每回合没花掉的格挡不消失，存着；零件负责把它变成别的东西 |
| 2 | **格挡 → 零件** | 把现有格挡拆成零件，零件再组装成更大的东西 |
| 3 | **爆发** | 一次性清空攒的格挡，换成伤害。这就是「某回合做到很强效果」 |
| 4 | **不擅长脉的样例** | 维护者 × 光 各 1 张，用来验证「不擅长脉的核心卡长什么样」 |

写完这 4 张开一局，重点看：**零件进度看得见吗？攒到什么程度算够？**

## 6. 每张卡写完后自检四问

**问 1：遮住脉名和角色名，只看效果，能猜出是哪条脉吗？**
猜不出 → 只是换了个标签，重写。

**问 2：这张卡换到别的角色手里还能用吗？**
- 能用 → 它更像通用池的卡，不该占核心卡名额
- 不能用 → 对，核心卡**允许**依赖角色机制（这点和通用池的判据相反）

**问 3：同脉的另一张核心卡，能和它叠出一个更好的组合吗？**
- 能 → 它们不是两条路，是同一张卡的两个版本，退回重写
- 不能 → 才是真路线

**问 4：「想让玩家怎么玩」那句话，玩家实际玩出来是不是这个感觉？**
不一致 → 要么改卡，要么改这句话。两个必须对上。

## 7. 我审的时候看什么

| 层 | 查什么 |
|---|---|
| 单卡 | 费用 vs 效果（对同角色同脉的通用卡）；有没有依赖引擎外的东西；文本有没有歧义 |
| 组合 | 核心卡 × 核心卡 会不会无限循环；核心卡 × 通用卡 有没有「一变二」的过强组合 |
| 结构 | 同脉几张是不是三条不同的路（就是上面的自检问 3） |
| 意图 | 「想让玩家怎么玩」和实际效果对不对得上 |

**我不审**：数值合不合理（那是玩测出来的）、卡名好不好听（那是你的）。

## 8. 常见错误（预判你会踩的）

| 错误 | 长什么样 | 怎么避 |
|---|---|---|
| **写成通用卡** | 「造成 8 伤害，抽 1 张」—— 谁都能用 | 核心卡必须和角色机制咬合，否则它不配叫核心 |
| **零件盖住脉** | 「本回合每装一个零件，造成 5 伤害」—— 玩家看到的是零件，不是脉 | 卡名和效果主体落在脉上，零件只在中间做转化 |
| **同脉几张抢同一位置** | 三张矿核心卡全是「格挡越攒越厚」 | 用自检问 3 |
| **按 3 能量写数值** | 3 费卡写得很猛，因为以前 3 费=整回合 | 现在是 4 能量 |
| **忘了「一波打不死人」** | 下潜者的卡写成一波斩杀 | 下潜者的味道是**前期强、能持续压**，不是一波结束 |

## 9. 写完 4 张之后

停下，开一局实测。记录三件事：

1. 零件进度看得见吗（不看数字也能感觉到差几个吗）
2. 攒到什么程度算「够了」—— 玩家自己知道吗
3. 一场战斗里，这套东西实际用出来几次

这三个答完，再决定剩下 28 张怎么写。
