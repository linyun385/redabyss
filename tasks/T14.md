# T14 数值平衡

## 前置
T7（卡池扩充）、T8（Boss 多阶段）、T12（升级）都完成。

## 产出
1. 调整 `enemies/all.json` 的血量与伤害
2. 调整 `cards/*.json` 里明显过强/过弱的卡
3. 写一份 `docs/BALANCE.md` 说明当前数值的设计意图

## 先量化，再动手
写一个模拟脚本 `tools/sim.js`：

```
node tools/sim.js --class diver --runs 200
```
对局逻辑：
- 按层顺序走
- 每场战斗用简单 AI 自动出牌（能出的牌就出，优先攻击）
- 跑 200 局，统计：
  - 到达各层的比例
  - 总体通关率
  - 平均死亡层
  - 每层平均剩余血量

**这个脚本要自己写，不算改坏引擎**（只 import core.js，不改它）。

## 目标数值
| 指标 | 目标 |
|---|---|
| 通关率（新手 AI） | 5–15% |
| 平均死亡层 | 第 4–6 层 |
| 前 3 层通过率 | > 70%（不能劝退） |
| D5 之后通过率 | < 40%（要有压力） |

如果 AI 通关率 > 30%，说明太简单；< 3%，说明太难。

## 调整原则
1. **先调敌人，后调卡牌**。敌人是节奏，卡牌是能力
2. 一次只改一个变量，改完重跑 200 局
3. 记录每一步：`docs/BALANCE.md` 里写「第 N 次调整：把 D5 敌人伤害 9→7，通关率 4%→9%」

## 已知的坑
- 凝视系统会放大后期难度，如果 D7 敌人伤害本来就高，叠加凝视会瞬间杀玩家
- 共振过载（>= 30）在深层每回合额外伤害很痛，注意别让玩家必须一直压共振
- 卡池越大，抽到关键牌的概率越低——60 张牌组时要注意抽牌类卡牌的重要性
