# T40 新手引导

## 目标
一个没读过设定的人，5 分钟内知道：
1. 我在往下走
2. 我该点什么
3. 我怎么输的

**不做教程关，不弹模态框。**

## 一、开场三行字
职业选择界面下方加三行：

```
你在往红渊的核心走。
每下一层，它就更注意你一些。
红渊的凝视越高，你越强，也越危险。
```

**文风按 `docs/STYLE_SAMPLES.md` 重写**，上面只是内容提纲。

## 二、前 3 场战斗的 6 条一次性提示

只在第一次遇到时浮一行小字，3 秒消失，用 `localStorage` 记录。

| 时机 | 内容（要重写措辞） |
|---|---|
| 第一次抽牌 | 每回合抽 5 张，用完的进弃牌堆 |
| 第一次能量不足 | 能量不够。结束回合会恢复 |
| 第一次共振跨 10 | 共振到阈值了。它也在注意你 |
| 第一次用带代价的牌 | 这张牌要你付代价。代价是永久的 |
| 第一次凝视 +1 | 红渊记住了你一点 |
| 第一次看到敌人意图 | 敌人下一步做什么，写在它头上 |

**每条只出现一次。**

## 三、第一次死亡的提示（按死因）
- 没格挡被打死 → `格挡在回合结束只留一半。`
- 共振过载烧死 → `共振过 30 就危险了。`
- 代价耗死 → `带代价的牌很强。它们要的是真的东西。`
- 凝视放大伤害 → `凝视每 10 点，敌人伤害 +10%。`
