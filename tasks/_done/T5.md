# T5 战斗界面（单场可玩）

## 产出
`web/index.html` —— **一个自包含的 HTML 文件**，双击浏览器打开就能玩一场完整战斗。

## 这一步只做战斗，不做整局流程
进游戏 → 选职业 → 直接进入 D4 稳定空洞海的一场战斗 → 打完显示胜负。
**不要**做 8 层推进、卡牌奖励、事件，那些是 T6 的事。

## 硬性技术要求

| # | 要求 |
|---|---|
| 1 | **单文件自包含**。不许 `fetch`、不许引外部 js/css/图片/字体 |
| 2 | 把 `engine/core.js` 的内容**原样内联**进 `<script>` 标签 |
| 3 | 把 `cards/*.json`、`enemies/all.json`、`relics/all.json`、`layers/layers.json` 的内容内联成 JS 常量 |
| 4 | 打开后 console **零报错** |
| 5 | 不依赖网络。断网也能玩 |
| 6 | 视觉全部用 CSS + Unicode 字符。**不许生成或引用任何图片** |

## 直接复用引擎，不要重写规则
`engine/core.js` 已经实现了全部规则：抽牌、出牌、共振、凝视、五脉连携、代价、层规则、敌人意图、胜负判定。

**你的工作是画界面和接事件，不是重新写规则。** 调用它就行：

```js
// 建局
const run = RedAbyss.newRun('diver', { seed: 42 });
run.depth = 4;  // 直接进第 4 层

// 开战（从内联的敌人数据里挑 1-2 个 D4 的普通敌人）
const C = RedAbyss.startCombat(run, [enemyDef]);

// 出牌：handIndex 是手牌序号，targetIdx 是敌人序号
const r = RedAbyss.playCard(C, 0, 0);
if (!r.ok) toast(r.msg);          // 失败要告诉玩家原因

// 结束回合
RedAbyss.endTurn(C);

// 读状态渲染
C.energy, C.hand, C.drawPile.length, C.discardPile.length,
C.block, C.resonance, C.turn, C.over, C.result,
run.hp, run.maxHp, run.gaze,
C.enemies[0].name / .hp / .maxHp / .block / .intent / .dead
```

`C.log` 是战斗日志数组（字符串），把它渲染出来，这是本作的叙事载体。

## 界面必须显示

**顶部 HUD**
```
生命 62/80   格挡 5   能量 2/3   共鸣 18   红渊的凝视 3   第 4 层 稳定空洞海
```

**敌人区**
- 名字、血条（数字要有）
- **意图必须可见**：攻击显示 `⚔ 8`，防御显示 `🛡 6`，增益显示 `▲`，减益显示 `▼`
- 死了的敌人变灰

**手牌区**
- 每张牌显示：名称、费用（左上角圆形）、脉（用汉字小标签：光/水/热/震/矿）
- 带代价的牌**边框换成暗红**，并在悬浮时显示 `cost_text`
- 能量不够 / 凝视不够的牌**变暗不可点**
- 点击出牌；如果卡牌需要选目标（`effect.target === "single"`），先选牌再点敌人

**底部**
- 结束回合按钮
- 抽牌堆 / 弃牌堆 的数字，点击可展开查看

**日志区**
- `C.log` 逐行渲染，最新的在下面，自动滚到底

## 视觉基调
```css
背景: #0a0506（近黑）
主红光: #8b1a1a
亮红光: #d94a4a
文字: #d8cfc9
次要文字: #7a6f6a
字体: ui-monospace, Consolas, monospace
```
不要圆角太大（≤4px），不要渐变发光那种手游感。要**冷淡、粗糙、像终端**。

## 交互细节（这些决定好不好玩）
1. 敌人意图变化时，短暂高亮一下
2. 出牌后敌人掉血要有数字浮动
3. 共振达到 10/20/30 时，屏幕边框闪一下红
4. 凝视每 +1，HUD 上那个数字闪一下
5. 卡牌不能出时，**必须告诉玩家为什么**（能量不足 / 凝视不足 / 共振不足 / 锁死）
