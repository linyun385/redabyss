## 一、遗物 20 个

### 稀有度
common 8 / uncommon 7 / rare 4 / boss 1

### 命名来源
`glossary.items.relic_seeds` 里已经给了 16 个种子，从里面选，不够的从 `minerals` / `yong_min_objects` 补：
磨损的相石、断裂的震髓、半块墟盐、光苔矿碎核、上一任的矿牌、被咬坏的氧气表、圣火残留、地文历残页、静日触杖、共振抑制仪残件、光导透镜碎片、旧光者的门牌、望渊台的观测记录、第一降的船票、净化者的灰、转化者的手记

### 格式
```json
{
  "id": "relic_01",
  "name": "上一任的矿牌",
  "rarity": "common",
  "veins": ["mineral"],
  "effect_text": "每场战斗开始时，抽 1 张牌。",
  "effect_code": [{ "trigger": "combat_start", "action": "draw", "value": 1 }],
  "flavor": "牌号还看得清。名字被人用指甲抠掉了。"
}
```

### effect_code 只准用这些

| trigger | action | value 含义 |
|---|---|---|
| `combat_start` | `draw` | 抽几张 |
| `combat_start` | `block` | 初始格挡 |
| `combat_start` | `gaze` | 凝视变化（可负） |
| `turn_start` | `heal` | 每回合回血 |
| `turn_start` | `draw` | 每回合多抽 |
| `turn_start` | `resonance` | 每回合额外共振 |
| `run_start` | `maxhp` | 最大生命变化 |
| `on_kill` | `heal` | 击杀回血 |
| `on_play` | `draw` | 打出卡后抽牌 |

### 平衡
- common：小效果，无条件
- uncommon：中等效果，可能有小代价（`veins` 限定某脉时更强）
- rare：强力，带代价或条件
- boss：唯一一件，改变玩法（例如"你的凝视不再增加敌人伤害，但每层开始凝视 +3"）

## 二、事件 12 个

### 分布
D2–D7 每层 2 个候选（共 12 个），实际进入时随机抽 1 个。

### 格式
```json
{
  "id": "event_d3_1",
  "layer": 3,
  "title": "一处干涸的泉眼",
  "body": "水脉的痕迹还在岩壁上。它退下去的时候，把什么留下了。",
  "options": [
    {
      "text": "尝一口残留的水。",
      "veins": ["water"],
      "result": { "heal": 12, "gaze": 1 },
      "result_text": "很苦。舌头麻了很久。但血在回暖。"
    },
    {
      "text": "把手贴上去，听。",
      "veins": ["tremor"],
      "result": { "card_reward": "uncommon" },
      "result_text": "岩层还在说话。只是没有人应它。"
    },
    {
      "text": "走开。",
      "veins": [],
      "result": {},
      "result_text": "你没有回头。"
    }
  ]
}
```

### 硬性规则
1. **必须正好 3 个选项**
2. 三个选项的 `veins` **至少覆盖 2 个不同的脉**（验收脚本会查）
3. **至少一个选项是"什么都不做"**（veins 为空，result 为空）
4. 每个选项必须有 `result_text`
5. `result` 里只准用这些键：`heal` / `damage` / `gaze` / `gold` / `card_reward` / `relic` / `maxhp`
6. `card_reward` 的值只能是 `common` / `uncommon` / `rare`

### 事件题材（12 个各写一个，不要重复）
参考这些意象，每个事件必须**具体到一个场景**，不要写抽象的"你遇到一个选择"：
矿道口新搬开的碎石 / 穿防护服的遗体 / 还在转的旧光者自动门 / 渊民的埋骨布 / 被烧过又长回来的红蕨 / 震台上的旧刻痕 / 一池不流动的水 / 别人的营地 / 反应堆城的废弃管道 / 会自己开关的矿灯 / 一块有字的相石 / 静日里突然响起的震语

### 文风
事件文本是**整个游戏最重要的文风展示区**。参照 `DESIGN.md` §10.2 第三组。

```
✅ body: 矿道口堆着别人搬开的碎石。还有人比你更早到这。石头是新的。
❌ body: 你发现了一处废弃矿道。请选择你的行动。
```

## 三、层定义 `layers/layers.json`

```json
{
  "layers": [
    { "id": 1, "name": "地表死寂区", "nodes": ["combat", "combat"] },
    { "id": 2, "name": "外层冷洞",     "nodes": ["combat", "event", "elite"] },
    { "id": 3, "name": "干旱空洞区",   "nodes": ["combat", "event", "elite"] },
    { "id": 4, "name": "稳定空洞海",   "nodes": ["combat", "event", "boss"] },
    { "id": 5, "name": "热泉裂带",     "nodes": ["combat", "event", "boss"] },
    { "id": 6, "name": "辐射矿石区",   "nodes": ["combat", "event", "elite"] },
    { "id": 7, "name": "核心高热区",   "nodes": ["combat", "event", "boss"] },
    { "id": 8, "name": "红渊核心",     "nodes": ["boss"] }
  ]

```

**节点总数必须是 21**（2+3+3+3+3+3+3+1）。
节点类型只能是 `combat` / `elite` / `event` / `boss`。
`name` 必须与 `DESIGN.md` §4 的表一致。
