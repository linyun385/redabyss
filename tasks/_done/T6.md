# T6 完整流程接线（8 层贯通）

## 前置
T5 已完成：`web/index.html` 能打单场战斗。

## 产出
仍然只有 `web/index.html` 一个文件，但要接上完整流程。

## 要做的事（按顺序实现）

### 1. 开局
选职业界面 → 点「下潜者」或「震语者」→ `RedAbyss.newRun(classId)`

### 2. 层推进
按 `layers/layers.json` 的节点表推进。每层有若干节点，逐个走完才进下一层。

节点类型处理：

| type | 处理 |
|---|---|
| `combat` | 从该层 `tier === 'normal'` 的敌人里随机抽 1–2 个开战 |
| `elite` | 从该层 `tier === 'elite'` 的敌人里抽 1 个开战 |
| `boss` | 从该层 `tier === 'boss'` 的敌人里抽 1 个开战 |
| `event` | 从该层 `layer` 匹配的事件里随机抽 1 个，展示选项 |

### 3. 战斗胜利后
- `combat`：卡牌三选一（从该职业卡池抽 3 张，按稀有度加权：common 60% / uncommon 30% / rare 10%），也可跳过
- `elite`：卡牌三选一 **+ 遗物三选一**
- `boss`：遗物三选一 + 金币

奖励界面要能「跳过」（除了 boss 遗物）。

### 4. 事件节点
展示 `title` + `body` + 3 个选项。
- 如果选项有 `requires.vein_min`，当前牌组该脉卡数不足则**该选项变灰不可点**
- 点击后显示 `result_text`，应用 `result`：
  - `heal` → 回血
  - `damage` → 扣血
  - `gaze` → 凝视变化
  - `gold` → 金币
  - `maxhp` → 最大生命变化
  - `card_reward` → 给一张该稀有度的卡（三选一）
  - `relic` → 给一个遗物

### 5. 遗物生效
遗物在 `run.relics` 里。引擎已处理 `combat_start`，其他 trigger 你需要在合适时机处理：
- `turn_start` → 每回合开始
- `on_kill` → 敌人死亡时
- `run_start` → 开局时（改 maxHp）

**遗物效果必须在 HUD 上可见**：显示已获得的遗物图标（用 Unicode），悬浮显示 `effect_text`。

### 6. 结算
- 死亡 → 显示：到达第几层、打了多少场、凝视值、击杀数 → 「重新开始」
- 通关 D8 → 显示结局文本 + 同样的统计 → 「重新开始」

### 7. 结局文本（通关时显示，必须自己写）
要求：**不超过 120 字**，第二人称，不写"恭喜通关"。
写"你到了那里，你看见了什么，然后呢"。
参考基调（不要照抄）：
> 谐振器还在转。没有声音，但你的骨头在跟着它转。
> 你不确定自己还剩下多少是"你"。
> 红光很暖。你决定再待一会儿。
