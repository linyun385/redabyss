## 要实现的机制

### 1. 双世界状态
```js
C.world = 'wake' | 'dream'   // 当前在哪个世界
C.wakeHp / C.wakeMaxHp       // 醒着的身体
C.dreamHp / C.dreamMaxHp     // 梦中的身体
C.clarity                     // 清醒度，进入梦境消耗
```

规则：
- 进入梦境：消耗 `clarity`（比如 10 点），切换牌堆
- 梦境中死亡 → **不会真死**，但 `wakeHp` 扣一半，强制醒来
- 清醒度耗尽 → 强制醒来，本场战斗不能再进
- 醒来：恢复少量 `wakeHp`

### 2. 双牌堆
- `deckWake` / `deckDream`
- 切世时手牌全部弃掉，从对应牌堆抽
- 共鸣/凝视/零件等跨世界保留

### 3. 卡牌过滤
打牌时校验：`card.dream === (C.world === 'dream')`
不匹配的牌**不能打**（显示"这不是梦里的东西"或对称文案）

### 4. 预兆（可选，做一个）
- 每回合开始抽 1 张预兆，进入 `C.omens`
- 预兆在 3 回合后触发（好或坏）
- 最多同时存在 3 张
