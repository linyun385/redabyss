# T245 写 artctl.py

## 实测问题
今晚要反复做的是同一批操作（质检 → 判不合格 → 改提示词 → 重画 → 再质检），现在全靠一次性小脚本，每换一次人就重写一遍。

## 目标
把这一条流程固化成一个可复用脚本。把 build_families / _make_jobs / wanx_gen / art_sync 串成一个入口，只做编排。

## 做法（按优先级）
1. 先读现有的同名或同类脚本，能复用就不重写
2. 命令行参数要给 --help，输出路径一律落在 `data/` 下
3. 写完自己先跑一次，把真实输出贴进 TASK_DONE 的 check 行

## 禁止
只读原始素材，不许改 `web/assets/art/`。不许复制别人的逻辑再改名字。

## 验收
| # | 指标 | 门槛 |
|---|---|---|
| 1 | 能跑通 | `python tools/<名字> --help` 有输出 |
| 2 | 有真实产物 | 对应输出文件存在且非空 |
| 3 | 有 docstring | 文件头说明用途、参数、产出 |
