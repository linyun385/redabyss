## intent_pattern（出招表，必须有设计感）

每个敌人的 `intent_pattern` 是循环出招，**至少 2 项，最多 5 项**。

好的出招表有节奏：`攻 → 攻 → 防御`（三回合一轮）
差的出招表是 `攻 → 攻 → 攻`（没有变化，玩家没有决策）

**精英和 Boss 必须至少有一个"蓄力"设计**——连续两回合 buff，然后一次重击。
例如：
```json
"intent_pattern": [
  { "type": "buff", "value": 4 },
  { "type": "attack", "value": 18 },
  { "type": "defend", "value": 12 }
]
```

## 字段格式
```json
{
  "id": "enemy_d2_01",
  "name": "冷洞食腐鳗",
  "layer": 2,
  "tier": "normal",
  "hp": "16-24",
  "intent_pattern": [
    { "type": "attack", "value": 5 },
    { "type": "attack", "value": 5 },
    { "type": "defend", "value": 4 }
  ],
  "traits": [],
  "flavor": "它不追你。它只是比你慢，而且不打算停。"
}
```

`hp` 必须是 `"16-24"` 这样的字符串，或单个数字。
`tier` 只能是 `normal` / `elite` / `boss`。
`layer` 是数字 1–8。

## flavor 写法
敌人 flavor 一句话，写它**在做什么**，不写它"有多强"。

```
✅ 它在啃一具比它大四百倍的东西。已经啃了很久。
✅ 它不追你。它只是比你慢，而且不打算停。
✅ 红光从它鳞片的缝里漏出来。它在发光，但它不是光源。

❌ 这是一种强大的敌人，攻击力很高。
❌ 光蛭母是第四层的 BOSS。
```
