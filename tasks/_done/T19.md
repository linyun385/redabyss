## 要实现的机制（按 T17 定的）

### 1. 回收（Salvage）
- 敌人被击杀时，不掉金币，掉**零件**（`C.parts`）
- 零件有两个用途（在战斗内实现）：
  - **改造**：选一张手牌，永久 +N 效果（本局有效）
  - **拆解**：花 3 零件换 1 个随机遗物（战斗结束后结算）
- 每次拆解，**当前战斗剩余敌人攻击 +1**（威胁等级上调）

### 2. 协议（Protocol）
- 协议卡打出后，本场战斗规则改变，不可撤销
- 至少实现 3 种协议：
  - `封锁`：双方每回合少抽 1 张
  - `清剿`：所有攻击 +3，但玩家每回合受 2 点伤害
  - `静默`：所有敌人不再获得 buff，但玩家也不能抽牌

### 3. 职业数据
- `newRun('anmin')` 要能工作
- 初始生命、能量按 T17 定

## 数据结构
```json
// 卡牌上加
"anmin_mark": { "kind": "salvage|protocol", "value": 3, "protocol": "lockdown" }

// 战斗状态加
C.parts = 0
C.activeProtocol = null
C.threatLevel = 0
```
