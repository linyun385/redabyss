# T8 巨怪机制深化（四个 Boss 多阶段）

## 前置
T3 已完成（敌人 36 个），T6 已完成（完整流程能跑）。

## 问题
现在四个 Boss 只有一个循环出招表，打到死都一样。巨怪是这个世界最重的东西，不能这么平。

## 产出
1. 改 `engine/core.js`：支持 Boss 的**阶段性意图切换**
2. 改 `enemies/all.json`：四个 Boss 加阶段数据
3. 前端显示阶段变化

## 引擎改动（谨慎，只加不破）
在敌人对象上加 `phase` 概念：

```json
"phases": [
  { "hp_above": 0.66, "intent_pattern": [...第一段...] },
  { "hp_above": 0.33, "intent_pattern": [...第二段...] },
  { "hp_above": 0.0,  "intent_pattern": [...第三段...] }
]
```

引擎规则：
- 每回合开始前检查 `hp / maxHp` 落在哪个区间，切换 `intent_pattern`
- 切换时输出一条 log（这是叙事点）
- 没有 `phases` 的敌人保持原行为（**向后兼容**）

**不许改坏现有测试**：改完必须 `node tools/test_engine.js` 全绿。

## 四个巨怪的三段设计

参考 `红渊.md` 第六部分的形态描述，每段要对应一个"它变得更不像活物"的过程。

### D4 光蛭母（120 血）
- 一段（100–66%）：吸收——抽你的牌、削弱
- 二段（66–33%）：光照——每回合给你充能但加凝视
- 三段（33–0%）：集体共振——**你的手牌每回合被部分夺走**

### D5 震喉（150 血）
- 一段：复制你的振动模式——模仿你打出的上一张牌
- 二段：广播——把你的牌序公开，敌人知道你要干什么
- 三段：共鸣——持续低频伤害，无法靠格挡挡

### D7 穹顶之影（180 血）
- 一段：漂移——不主动攻击，只让废墟"流动"（环境伤害）
- 二段：记录——每次你出牌，它加一层"记录"，满了爆发
- 三段：旧光者最后状态——自动化重启，敌人变多

### D8 墟蛹（260 血）
- 一段：计算——不断 buff，看你打
- 二段：编织——把你的弃牌堆变成敌人
- 三段：释放新旧光者——一个拥有你牌组部分卡牌的敌人

（"变成敌人"和"模仿你的牌"这两条如果实现不了，改成等效效果，在 `TASK_DONE.md` 里说明改成了什么。）
