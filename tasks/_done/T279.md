## 实测问题
82 个事件、8 层的节点表，事件是不是每张都挂上了、有没有孤立事件，从没核过。

## 目标
把「事件清单」和「节点表」做双向核对：事件→节点、节点→事件。

## 做法（按优先级）
1. 读 `events/all.json` 与 `layers/layers.json`
2. 逐个事件查它是否在某层节点里被引用
3. 再反过来查每个事件节点引用的 id 是否真的存在
4. 产出两张表：孤立事件（有事件无节点）、断链节点（有节点无事件）
