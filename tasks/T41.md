# T41 音效架构（只留钩子，不生成音频）

## 绝对禁止
**不许生成、下载、嵌入任何音频文件。** 也不许找素材。
音效由用户以后自己把关。

## 一、接口

```js
function playSfx(code, opts) {
  if (window.__SFX_LOG) window.__SFX_LOG.push(code);
  // 未来在这里接 Web Audio
}
```

要求：
- 所有需要音效的地方**都调用它**，参数是语义化 code
- code 命名：`card.play.attack` / `enemy.hit` / `ui.click`
- 静音开关入口先留好（不实现）

## 二、清单 `docs/audio/SFX_LIST.md`

按类别，每个 code 要有**一句"不要什么"**：

```markdown
| code | 触发 | 描述 | 不要什么 |
|---|---|---|---|
| card.play.attack | 打出攻击牌 | 短促，有金属感 | 不要尖锐刺耳 |
| card.play.cost | 打出带代价的牌 | 叠加一层"东西被拿走" | 不要血腥 |
| resonance.cross | 共振跨阈值 | 低频轰鸣 | 不要爆炸 |
| gaze.up | 凝视 +1 | 极短的沙沙声 | 不要刺耳 |
```

类别至少覆盖：
- 卡牌（attack/skill/power/cost）
- 战斗（hit/block/kill/defeat）
- 状态（resonance/gaze/energy_empty）
- 界面（click/open/close）
- 特殊（boss_phase/world_switch/victory/death）
