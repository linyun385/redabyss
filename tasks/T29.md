# T29 卡牌平衡（数据驱动）

## 前置
四个职业都在（下潜者/震语者/黯民/苍民），`tools/sim.js` 应该已有（T14 建的）。

## 一、先把模拟器做扎实

`tools/sim.js` 要能：
```powershell
node tools/sim.js --class diver --runs 500
node tools/sim.js --class tremor --runs 500
node tools/sim.js --class anmin --runs 500
node tools/sim.js --class cangmin --runs 500
```

输出：
- 通关率
- 平均死亡层
- 每层存活率
- **每张卡的使用率**（打出的次数 / 抽到的次数）
- **每张卡的胜率相关性**（带这张卡时胜率 vs 不带）

AI 出牌策略不用很聪明：能出就出，优先攻击，血低优先防御。**关键是可复现**（固定 seed）。

## 二、找出三类问题卡

### 1. 废卡（使用率 < 10%）
玩家抽到也不打。原因可能是：费用太高、效果太弱、有更好的选择。
**处理**：加强，或者降费，或者改成有独特用途。

### 2. 超模卡（使用率 > 70% 且胜率相关性显著正）
抽到必打，无脑强。
**处理**：加代价、降数值、或改成条件触发。

### 3. 陷阱卡（使用率低但带它胜率高）
这是**好设计**——难用但强。**保留**，别改。

## 三、目标数值

| 职业 | 目标通关率 |
|---|---|
| 下潜者 | 8–18% |
| 震语者 | 8–18% |
| 黯民 | 5–15%（高风险职业，可以更低） |
| 苍民 | 8–18% |

平均死亡层：**4–6 层**。

## 四、调整方法
1. 一次只改**一个职业的一个流派**
2. 每次改完重跑 500 局
3. 记录到 `docs/BALANCE_V2.md`：

```
第 3 轮 | 震语者 · 纯删牌流 | 把「断念」费用 2→1
        结果：通关率 6.2% → 9.1%，使用率 22% → 41%
```

## 五、不要做的事
- 不要为了数字好看把所有卡改成一个模子
- 不要动 flavor
- 不要改敌人（那是 T14 的事）
- **不要追求 50% 通关率**，这是 roguelike，失败是设计的一部分
