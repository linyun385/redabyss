# T20 黯民 DLC 接入

## 前置
T18 数据、T19 引擎都完成。

## 产出
`web/index.html` 支持第三个职业 + 黯星层。

## 要做的事

### 1. 职业选择
开局界面从"两选一"变成"三选一"：
- 下潜者
- 震语者
- **黯民**（显示名从 T17 取，比如「维护者」）

每个职业显示一句对应的气质描述。

### 2. 黯星层接入
按 T17 的判断接进层结构：
- 如果 T17 定为**第 9 层**：放在 D8 之后，通关 D8 才能进
- 如果 T17 定为**支线**：在 D6 或 D7 加一个岔路入口

无论哪种，都要在地图上**看得出区别**（用不同的颜色/符号）。

### 3. 回收 UI
- 战斗界面显示 `零件: N` HUD
- 击杀敌人时飘出「+1 零件」
- 点零件区能打开"改造/拆解"面板
- 拆解确认时提示「威胁等级会上升」

### 4. 协议 UI
- 打出协议卡后，屏幕顶部显示当前协议名
- 协议生效期间，相关数值用不同颜色标出

### 5. 数据内联
新数据全部内联进 `web/index.html`，保持**单文件自包含**。

## 自检

```powershell
node tools\check_web.js
node tools\pack_check.js all
node tools\test_engine.js
```

再手工确认：

3. 零件能获取、能改造、能拆解
4. 威胁等级上升后敌人伤害确实变高
5. 协议能打出且生效
