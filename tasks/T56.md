## 前提
T55 已交付 `tools/mapgen.js`（确定性生成 + validate）。本任务把它的产出**渲染进游戏**。

## 目标
实现用户要的两张图：
- **小图**：常驻，显示玩家位置 + 已访问 + 周边（1 格邻接）+ 深度线
- **总图**：点开看全区域（已访问高亮、未访问打雾）

## 产出
1. `web/index.html` 内新增地图渲染模块（SVG，内联，无外部资源）：
   - `renderMiniMap(region, state)` → 右下角常驻小图（建议 200×260 以内，不遮手牌/按钮）
   - `renderFullMap(region, state)` → 点「总图」打开的全屏层（可关，Esc/点背景/×）
2. 可见性**在数据层裁剪**：渲染前先把不可见节点/边过滤掉（不许只靠 CSS 隐藏）
3. 交互：小图/总图里点击**当前可达**节点 → 触发对应事件（本任务可先只 `toast('进入：'+type)`，玩法接入留给 T57/T58）
4. 与既有界面共存：现在的「4 行节点」地图**保留**，用一个开关 `?map=gen` 启用新地图；默认可先保持旧地图（见 T54 的待确认问题）
