## 产出
`cards/tremor.json` —— 一个 JSON 数组，40 个卡牌对象。

## 硬性配额（验收脚本逐条查）

| 项 | 要求 |
|---|---|
| 总数 | 40 |
| `class` | 全部为 `"tremor"` |
| `rarity` | common 16 / uncommon 14 / rare 8 / special 2 |
| 脉分布 | 震 14 / 热 10 / 光 6 / 水 5 / 矿 3 / 无脉 2 |
| 费用分布 | 0 费 5 张、1 费 20 张、2 费 12 张、3 费 3 张 |

| 需要凝视 | ≥ 4 张（`effect.gaze_cost` > 0） |
| 需要共振 | ≥ 4 张（`effect.resonance_cost` > 0） |

## 命名来源

- `glossary.items.yong_min_objects`：震器、地文历残页、震台石碑、光导石、静日触杖、埋骨布、历法刻盘、五脉符、震语铃、记忆封瓶
- `glossary.terms.divination`：观红、听震、尝水、触温、辨矿
- `glossary.terms.yong_min_ritual`：静日、埋骨礼、禁声日、回归墟骨
- `glossary.places.yong_min_cities`：震台、涌喉、喷息、三震、静底

**震语类卡牌统一用这个格式**：`震语：<两个字的动作>`
例如：`震语：听骨`、`震语：压息`、`震语：回响`、`震语：断脉`

## 这个职业的调性
本地人。什么都知道，什么都不能说。靠记忆和躯体换力量。
他的强牌是"烧掉自己的记忆"，他的代价比下潜者**更狠**——因为他是自愿的。

**这个职业必须有明确的"删牌"主题**：至少 5 张卡带 `memory` 代价。
删牌在这个职业里不是惩罚，是**瘦身**——牌越少，关键牌越容易抽到。

## 文风
比下潜者更慢、更静、更有仪式感。允许出现渊民词汇，但**不准解释**。

### 正例
```
name: 震语：听骨
flavor: 你把额头贴上岩壁。它在说一件很久以前的事，语速很慢。

name: 静日
flavor: 今天不该说话。你把嘴闭上，世界反而清楚了一些。

name: 震语：断脉
cost_type: memory
cost_text: 你忘了母亲的声音。
flavor: 你切断了它。岩层安静下来，像被你按住喉咙的东西。

name: 相石·初刻
cost_type: mark
flavor: 它记住了你的掌心。你也记住了它记住了你。
```

### 反例（直接判失败）
```
❌ flavor: 对敌人造成 8 点伤害
❌ 解释名词："相石（一种能记录记忆的矿物）"
❌ 感叹号
```

## 与 T1 的差异（必须做到）
同一个 id 命名空间，但**两套牌不许有同名卡**。下潜者的牌是器械，震语者的牌是行为与物。
如果发现想写一张"防御"牌，下潜者叫「折叠」，震语者叫「禁声」。
