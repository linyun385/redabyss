## Y1 · 数据一致性：cards/anmin.json ↔ web/index.html 的 RAW

**要做的**：确认两份数据完全一致。

- `cards/anmin.json` 有 N 张
- `web/index.html` 里 `const RAW = {...}` 的 `anmin` 键有 M 张
- N 是否等于 M？每张卡的 `id` 集合是否完全相同？每张卡的内容是否逐字节相同？

**方法**：写脚本 `tools/hy4_raw_vs_json.js`，解析 RAW（注意它是一整行 JSON，
用大括号深度扫描，参考 `tools/_sync_cards.js` 的写法），跟 `cards/anmin.json` 对比。

**输出**：`docs/design/_HY4_Y1_sync.md`，给出：条数、差异清单（如果有）、脚本路径。

**验收**：脚本能跑，结论明确。

## Y2 · 零件经济核算

**要做的**：算这 6 张核心卡在一场典型战斗里的零件收支。

按这个假想场景算（每场战斗 3～5 回合）：

```
第 1 回合：打 0051 机械增生（0 费）→ 本回合再打 3 张牌 → +3 零件
第 2 回合：打 0056 重铸（1 零件 → 抽 1 + 1 能量）→ 再重铸 → -2 零件
第 3 回合：打 0057 更新换代（弃 3 张手牌）→ +3 零件
第 4 回合：打 0054 武器试验（-3 零件，+1 永久力量）
```

**要算的**：
1. 每回合结束时的零件结余
2. 一场打完净增/净减多少零件
3. 如果每场都这么打，打 8 场后 `run.parts` 是多少、`run.strength` 是多少
4. **指出这个循环里最危险的一步是哪一步**（会让零件或力量失控的那步）

**输出**：`docs/design/_HY4_Y2_parts_economy.md`，必须有一张逐回合的表。

**验收**：数字能对上，每一步都写清加减了什么。

## Y3 · 新 special code 的使用率审计

**要做的**：统计这 8 个新 code 在卡池里被用了多少次。

```
mech_grow / perm_strength / energy_gain / energy_on_enemy_attack
enemy_defend_draw / discard_hand / parts_from_discard / random_effect
```

- 每个 code 出现在几张卡里？分别是谁？
- 有没有 code 写了但**一次都没用上**？
- 有没有卡用了**不在白名单里**的 code？（扫全部 219 张，不只黯民）

**方法**：写脚本 `tools/hy4_special_codes.js`，从 RAW 里扫所有 `special[].code`，
输出「code → 使用次数 → 卡 id 列表」，并跟白名单对比。

**输出**：`docs/design/_HY4_Y3_codes.md` + 脚本。

**验收**：能列出所有用过的 code，白名单外的要单独标红（在文档里标「⚠️」）。

## Y4 · 卡面描述映射完整性

**要做的**：`web/index.html` 里有个函数 `cardDesc(card)`，
它有一个 code → 中文名的映射表。检查：**白名单里每个 code 在映射表里都有中文**。

- 缺了哪个？缺的会在卡面上**什么都不显示**（玩家看不到效果）
- 有没有映射表里有、但白名单没有的 code（死代码）？

**方法**：不用跑浏览器。读 `web/index.html` 里 `cardDesc` 的源码（grep `function cardDesc`），
把映射表抽出来，跟白名单比对。

**输出**：`docs/design/_HY4_Y4_carddesc.md`，给两张表：缺映射的 / 死映射的。

**验收**：两个表都要有具体 code 名，不能只写「没有缺失」。

## Y7 · 回归：确认改动没弄坏别的职业

**要做的**：这次改了 `applyCardEffect`（伤害/格挡公式）、`playCard`（扣费）、
`enemyAct`（敌人行动）、`beginTurn`（能量/弃牌）—— 都是**公共路径**。

请逐条确认这些老行为没变：

1. 普通攻击牌：`伤害 = effect.damage + 连携加成 + buffs.strength`（没有 `runStrengthCarry` 时结果应和以前一样）
2. 格挡牌：`格挡 = effect.block + 连携加成 + buffs.dexterity`
3. 有 `anmin_mark` 的协议卡：还能正常激活
4. 敌人 `defend` 意图：不加 `enemyDefendDraw` 时行为不变
5. 回合开始：能量仍等于 `energyMax + energyBonus`（`nextTurnBonusEnergy` 为 0 时）

**方法**：读 `web/index.html` 相关函数，**逐行**对比逻辑。不要跑起来看，读代码。
如果项目里有 `git`，可以 `git diff` 看改了什么（**先确认 git 是否初始化过**，没有就别折腾）。

**输出**：`docs/design/_HY4_Y7_regression.md`，五条逐条给「一致 / 不一致 / 无法判断」+ 依据。

**验收**：五条都要有结论，「无法判断」要写清为什么。
