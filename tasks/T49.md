# T49 经济与进度曲线（全数字，跑模拟）

## 目标
把「金币 / 遗物 / 商店价格 / 层深度」这条经济链用模拟跑出曲线，找出断点。
不做手感讨论，只给数字与结论。

## 产出 1：tools/econ_sim.js
- 复用 `tools/sim.js` 的对局逻辑（不要另写一套战斗），加：金币收支、遗物获取时机、商店访问与消费、卡组规模
- 跑 **500 局 × 4 职业**，输出 `tools/econ_curve.json`：每层的 金币中位数/分位数、遗物数、卡组规模、商店可买项比例
- 支持 `--runs N --class diver --out path`

## 产出 2：docs/ECON_CURVE.md
- 曲线表（8 层 × 四职业）
- **断点**：哪一层开始「钱没处花」或「想买买不起」，各给数字证据
- 建议：最多 5 条，每条必须落到具体文件/字段（商店价格表 / 事件金币 / 遗物价格），并标注「改动风险」
- 与平衡文档 `docs/BALANCE.md` 的既有结论对照：一致的写一致，冲突的写冲突（不要悄悄改结论）

## 硬约束
- **不改游戏数据**，只产出脚本 + 报告（改数据另开任务）
- 模拟必须可复现：固定种子，报告里写明种子与命令

## 验收
- `node tools/econ_sim.js --runs 500` 一次跑通（≤5 分钟），产出 JSON
- 报告里每个数字都能在该 JSON 找到
- `node tools/pack_check.js all`、`test_engine.js`、`check_web.js` 全绿
