## 产出 1：docs/mapgen/MAPGEN_DESIGN.md
必须包含下面全部小节：

### 1. 数据模型（用 JSON 伪结构写清字段与含义）
- `Region`：`w/h`、`cells[]`、`ecoOf(cell)`、`weight[cell]`
- `Eco`：生态枚举（6–8 种，与既有「脉/层」体系挂钩，不要把现有设定推翻——列出对应关系）
- `Node`：`id/type/x/y/band/eco/binding`，`type ∈ combat|elite|random|shop|event|boss|finalBoss`
- `Edge`：`from/to/len/angle`（angle 用度，向下为 0±）
- `Band`：深度线（由 y 反算：`band = f(y)`，公式写死）

### 2. 生成流程（五步，每步写清输入输出与失败条件）
1. **生态生长**：多源生长 / 噪声 + 聚合约束；参数含 生态数、聚合度 κ、最小块面积、允许的连通分量数
2. **事件格布点**：在每个深度带内按配额撒点，**同类型最小间距**（分散要求）用蓝噪声 / 泊松盘
3. **连线**：从起点向下的有向无环图；每节点出边 1–3 条；长度 1..k 格；角度集合固定（如 ±35/±60/±85/0）；**y 必须单调向下**；**禁止交叉边**
4. **深度线与 BOSS**：按 y 分配带；带间连接节点强制为 `boss`；最底带唯一 `finalBoss`
5. **内容绑定**：`binding[eco][band] → {enemyPool, elitePool, bossPool, eventPool, shopTier}`（只给结构与默认值，实际表在 T58）

### 3. 不变量（invariants，写成可断言的条件）
- 每带节点数 ≥ 配额；每带至少 1 条入边 1 条出边（末带除外）
- 无环；y 严格单调（防回头）
- 最底带恰好 1 个 `finalBoss`，且从起点可达
- 同带同类型节点之间最短路径 / 曼哈顿距离 ≥ D（默认 2 格）
- **100% 可达**：给定起点，所有非 finalBoss 节点都能被某条路径到达（DFS 验证）
- 生成失败重试上限 20 次，超限报错并打印原因（不许静默返回半成品）

### 4. 可见性规则
- `visible = visited ∪ neighbors(visited, depth=1)`（用户要求「周边」）
- 未可见节点**下发到前端时就被裁掉**（不是靠 CSS 隐藏）——防止玩家从 DOM 里偷看

### 5. 死路救援规则
- dead-end 判定：无未访问出边且非 finalBoss
- 救援：从「未访问节点」里挑最近的可达入口（优先同带、再按曼哈顿距离）
- 代价二选一、随机：`penalty`（扣血/扣金币，比例写死）或 `ambush`（触发一场随机战斗）
- 救援**不消耗回合数、不重置迷雾**

### 6. 参数表
一张表列出所有可调参数、默认值、取值范围、影响。**默认值必须能跑出可玩的地图**（20 次生成全部通过不变量）。

### 7. 伪代码
`generate(seed, params) → Region` 的完整伪代码，含重试与校验。
