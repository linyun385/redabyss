## 硬性配额（验收脚本逐条查）

| 项 | 要求 |
|---|---|
| 总数 | 40 |
| `class` | 全部为 `"diver"` |
| `rarity` | common 16 / uncommon 14 / rare 8 / special 2 |

## 命名来源
下潜者是殖民者，名字只用这几类：

- `glossary.items.colonist_gear`：密封装甲、聚能枪、震髓探测器、共振抑制仪、光导透镜、深地车、轨道炮、聚变鱼雷、硬矿钻、辐射弹、震频器、圣火武器
- `glossary.items.minerals`：相石、震髓、墟盐、光苔矿
- `glossary.factions.organization`：抗共振司、红渊研究院、反走私局、红渊贸易局
- `glossary.factions.companies`：星髓矿业、渊光重工、深红资源集团、黑曜采掘、北荒矿业

允许组合：`星髓矿业·深地车`、`抗共振司·抑制规程`、`光导透镜（残）`

## 这个职业的调性
工业、器械、冷硬、签字进场的外来者。他不知道这里是什么，靠仪器和常识活着。
他的强牌是"用装备换命"，他的代价是"装备在吃掉他"。

## 文风（最容易做错的地方）
核心三条：
1. **flavor 不写机制**。不写"造成 10 点伤害"，因为那是 UI 的事
2. 第二人称或无人称，短句，**不用感叹号**
3. 每条 flavor 要让人想往下问一句"然后呢"

### 正例
```
name: 密封装甲
flavor: 外套内侧还有上一任主人的编号。你没擦掉它。

name: 光导透镜（残）
cost_type: vitality
cost_text: 你的手开始透光。
flavor: 你看它的时候它也在看你。这不算对视，你没有能给它的眼睛。

name: 轨道炮支援
energy: 3
effect: { damage: 24, target: "single" }
flavor: 上面的人按了按钮。他们看不见你，也不需要看见。
```

### 反例（会直接判失败）
```
❌ flavor: 造成 12 点伤害并有概率使敌人虚弱
❌ flavor: 恭喜获得强力卡牌！
❌ flavor: 这张卡非常强大，但代价也很高
```

## 代价牌的写法
`cost_type` 只能是：`memory` / `vitality` / `mark` / `lock`

| 类型 | 叙事 |
|---|---|
| memory | 读数据读到自己的记忆被读走 |
| vitality | 被红光同化，身体越来越透明 |
| mark | 用了相石，被共振之底记下 |
| lock | 用了某个不可再用的东西 |

代价牌强度应是同类卡的 1.6–2.0 倍。
