# INBOX · 外部追加任务的入口

> 这是给 GLM 的**备用任务投递箱**。规则写死在 `tasks/QUEUE_20261105.md` 规则 5b。

## 怎么用

**每做完一个任务、记完账之后**，回来翻一次这个目录：

1. 列出 `tasks/INBOX/*.md`（**不含** `DONE/` 子目录）
2. 有文件 → 取**编号最小的那个**，通读，把它当新任务做
3. 做完 → 追加 `TASK_DONE.md` → 把该文件**移动**到 `tasks/INBOX/DONE/`
4. 然后回去做原队列的下一个任务
5. 没有文件 → 继续原队列

## 目录里现在有什么

| 文件 | 内容 | 什么时候读 |
|---|---|---|
| `01_batch.md` | T500–T514，15 个任务 | 最先读 |
| `02_batch.md` | T520–T534，15 个任务 | 01 做完之后 |
| `03_fallback.md` | 兜底方向（无编号，自己写任务书） | 02 做完之后 |

## 硬规则

- **不许跳过 01 直接做 02**，按编号来
- **不许把任务改简单**。规格里写了什么就做什么
- **不许改 `web/` `cards/*.json` `engine/`** —— 和主队列同一条红线
- **做完必须把文件移到 `DONE/`**，否则会重复做
- 任务本身看不懂、数据查不到 → 写「未确认：<原因>」跳过，继续下一个
