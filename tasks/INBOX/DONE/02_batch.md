| # | 任务 | 产出 | 要什么 |
|---|---|---|---|
| T520 | **每张卡"如果重设计"的建议** | `docs/design/redesign_notes.md` | 219 张逐张写一句：如果重做这张牌，会改哪里。**只提建议，不许说"删"**。按「改数值 / 改机制 / 改定位 / 不用改」四类标 |
| T521 | **四角色开局 5 分钟体验脚本** | `docs/design/first_5min.md` | 给四个角色各写一段（叙事口吻）：「选了他之后头五分钟会发生什么」。要能读出这个角色**手感上的差别** |
| T522 | **敌人意图可预测性** | `docs/design/intent_predictability.md` | 每只敌人的意图是不是有规律（循环/随机/条件触发）。玩家能不能提前算出来。分三档：完全可算 / 大致能猜 / 完全随机 |
| T523 | **卡池里最没人拿的 20 张** | `docs/design/least_picked_20.md` | 用**逻辑推断**（不是数据）：哪些卡在有更好选择时一定被跳过。给出推理：因为 X 卡更便宜 / 更通用 / 更强。**不许说删** |
| T524 | **事件风险收益比表** | `docs/design/event_rr.md` | 每个事件的每个选项：期望收益 vs 期望损失。做成表。找出**收益远低于风险**的选项（玩家不会选）和**零风险高收益**的（玩家必选） |
| T525 | **遗物强度分级** | `docs/design/relic_tier.md` | 按「拿到就变强多少」把遗物分成 S/A/B/C 四档。分级标准要写清楚（可量化最好）。重点是找出**C 档里没人要的** |
| T526 | **脉象等级成长曲线建议** | `docs/design/vein_curve.md` | 按 T400 定的规则（进生态 +1、离开 2 事件块 -1、上限 5），推演：一局里玩家大概能到几级、维持几级。给一张逐层推演表 |
| T527 | **恢复机制检查** | `docs/design/healing_check.md` | 游戏里所有回血手段列出来（卡、遗物、事件、商店）。算出：一局大概能恢复多少血、相对上限是多少。判断**够不够** |
| T528 | **每层"死法"清单** | `docs/design/death_causes.md` | 每一层玩家最可能怎么死（被哪个敌人、什么打法、什么情况下）。结合敌人数据推演。找出**最容易死的那一层** |
| T529 | **卡组厚度分析** | `docs/design/deck_size.md` | 初始卡组多少张、一局大概能拿到多少张、删牌手段有多少。算出**成型卡组的合理厚度区间**，判断现在的获取速度会肥还是瘦 |
| T530 | **升级覆盖率** | `docs/design/upgrade_coverage.md` | 219 张里有多少张有 `upgrade` 字段。按角色/稀有度分。找出**没升级的牌**是不是集中在某类 |
| T531 | **敌人攻击频率** | `docs/design/attack_rate.md` | 每只敌人平均几回合攻击一次、每次多少伤害。算出**每回合期望承伤**。按层给表 |
| T532 | **资源曲线** | `docs/design/resource_curve.md` | 金币 / 零件 / 凝视 / 共振 四种资源：一局各能拿多少、花在哪、收支平衡吗。做成逐层表 |
| T533 | **游戏时长估算** | `docs/design/playtime_estimate.md` | 按层数 × 每层节点数 × 每场战斗回合数 × 每回合思考时间，粗估一局多久。分「熟练玩家 / 新手」两档 |
| T534 | **新手会犯的 10 个错误** | `docs/design/newbie_mistakes.md` | 推演新玩家最容易犯的十个错（比如「看到代价牌不敢拿」「不知道点 HUD 上的零件」）。每条写：为什么容易犯 + 在哪一步能提示 |
