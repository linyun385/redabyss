## 任务 A（最高优先）· 卡池结构画像 —— 用户正在设计核心卡

**背景**：用户今晚在做「核心卡设计」。他不知道现有 209 张卡在结构上占了哪些位置、空着哪些位置。
你的产出要能回答一句话：**「我要设计一张核心卡，哪个生态位是空的、值得占？」**

**输入**：`cards/*.json`（5 个职业文件，共 209 张）

**产出**：`docs/design/ui/07_card_pool_shape.md`

### A1. 四维交叉表

费用 × 稀有度 × 类型 × 职业。费用用 0/1/2/3（超出就写实际值），稀有度用 JSON 里的字段，
类型用 atk/skill/power（或 JSON 里的实际值），职业用 diver/tremor/anmin/cangmin/shared。

输出一张表，每格填**张数**。空格写 `·` 不要写 0。

### A2. 薄位与过密位

- **薄位**：张数 ≤ 1 的格
- **过密位**：张数 ≥ 8 的格

各列一张表，每格给 1–2 个卡名当例子。

### A3. 效果类型分布

统计所有卡用到的 effect 键（`damage` / `block` / `draw` / `energy` / `buff` / `debuff` /
`status` / `scry` / …），每个键：出现次数、被多少张卡用、平均数值。
标出**只用了一次的键**——那可能是废弃字段或者还没铺开的新机制。

### A4. 结论（这段最重要）

回答三个问题，每个都要有数字支撑：

1. 现在最空的三个生态位是哪三个？
2 **「核心卡」（高费、独特机制、每个职业 1–2 张那种）该占哪个位置最不容易跟现有卡撞车？**
3. 如果要做一张「改变玩法」的卡，现有效果键里有没有能实现它的？还是必须加新键？

**注意**：A4 是判断，允许给建议。但每条建议后面必须跟一句「依据：A1/A2/A3 里的哪个数字」。

## 任务 C（第三优先）· 音效触点时序表

**背景**：游戏里现在有 **19 个音效 + 8 层氛围**（`web/sfx/*.wav`），
播放器已经接好（`window.RedAbyssSFX` / `RedAbyssAmbience`）。
但**不知道「什么时候该响」**——现有的 `playSfx()` 调用点很少，大部分事件是哑的。

**输入**：
- `web/index.html`（找所有 `playSfx(` 调用点）
- `web/sfx/` 目录（实际有哪些 wav）
- `docs/SFX_LIST.md`（定义清单 + 末尾有实现记录）

**产出**：`docs/design/ui/09_sfx_touchpoints.md`

### C1. 三方对照表

| 音效 code | 有 wav 文件？ | SFX_LIST 里定义了？ | 游戏里有人调 `playSfx` 吗？ | 调用点行号 |
|---|---|---|---|---|

分出三类：
- **孤儿音**：有文件、有定义、游戏里没人调 → 做了没用上
- **哑事件**：游戏里有明确的事件点、但没有对应音效
- **正常**：三方都对得上

### C2. 哑事件清单（这段最有价值）

按 `SFX_LIST.md` 的定义，找出所有「按设计该有声音、但代码里没调 `playSfx`」的时刻。
例如：`combat.start` 定义了「进入战斗」，但 `startCombat()` 里有没有调？

每条给：事件名 + 所在函数 + 行号 + 该响哪个 code + 现在有没有。

### C3. 氛围层

`setLayerAmbience(depth)` 被调用的条件是什么（在哪个函数里、什么时机）？
8 层氛围对不对得上 8 个深度？

**注意**：C 只做「缺什么」的清单，**不要设计音效**（音效已经做完了）。
