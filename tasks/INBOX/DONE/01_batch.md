# INBOX 01 · T500–T514（第二批，做完全部移到 DONE/）

> 前置：先读 `tasks/T400_vein_system_master.md` §2.1（五脉味道）和 §2.2（角色定义）。
> 全部产出写到 `docs/design/`。不许改代码和数据文件。

| # | 任务 | 产出 | 要什么 |
|---|---|---|---|
| T500 | **每张卡的设计意图反推** | `docs/design/card_intent_reverse.md` | 219 张逐张写一句「这张牌当初大概想解决什么问题」。不是复述效果，是**猜设计意图**。同一角色的放在一起，看意图有没有重复 |
| T501 | **敌人 ↔ 卡牌对应** | `docs/design/enemy_card_map.md` | 每只敌人是拿来「考」什么牌的（多段攻击考格挡、高血量考爆发、不给喘息考抽牌）。写出每只敌人主要在惩罚哪种打法 |
| T502 | **每层主题一致性** | `docs/design/layer_theme.md` | 每层的敌人 / 事件 / 名字 / 文本是不是在讲同一件事。找出**主题跳脱**的层（比如名字很文静但敌人很暴烈） |
| T503 | **三种特殊机制的使用分布** | `docs/design/special_mech_dist.md` | `lock` / `mark`(凝视) / `resonance`(共振) 三种机制各被多少张卡用到、分布在哪些角色、平均数值多少。找出**只被一张卡用到**的机制 |
| T504 | **稀有度分布合理性** | `docs/design/rarity_dist.md` | 每个角色 common/uncommon/rare 各多少张。判断稀有度是不是在「按强度分」——找出**低稀有度但明显强**、**高稀有度但很平庸**的卡 |
| T505 | **事件结果的信息量** | `docs/design/event_info.md` | 每个事件的每个选项，玩家**选之前**能不能看出大概会发生什么。分三档：明示 / 暗示 / 完全随机。统计三档比例 |
| T506 | **每回合决策点数量** | `docs/design/decision_points.md` | 按 4 能量、抽 5 张粗估：玩家每回合要在几张牌之间做选择、有多少个「有意义的」选择。找出**选择太少的角色** |
| T507 | **第一局前 3 层完整推演** | `docs/design/first_run_flow.md` | 从开局到第 3 层结束，玩家会依次遇到：几个战斗、几个事件、有没有商店、拿到多少资源。写成一条时间线，标出玩家大概在哪一步会卡住 |
| T508 | **卡面描述可读性分级** | `docs/design/card_readability.md` | 219 张的 `cardDesc` 输出按字数分档（<20 / 20–40 / >40 字）。最长的 15 张逐张分析：是不是**长到玩家不想读** |
| T509 | **遗物里的"必拿"** | `docs/design/relic_mustpick.md` | 找出拿了就明显变强的遗物（无条件增益、无副作用）。判断方法写清楚：和同稀有度的比，收益差多少 |
| T510 | **敌人里的"必躲"** | `docs/design/enemy_avoid.md` | 找出性价比极差的敌人（血厚攻击高、收益低）。玩家会想避开的那种。判断依据写清楚 |
| T511 | **卡池三维分布** | `docs/design/pool_3d.md` | 费用 × 类型 × 稀有度 的交叉表（3×2×3 = 18 格）。每格几张。找出**空格和只有 1 张的格** |
| T512 | **每层事件密度** | `docs/design/event_density.md` | 每层有几个事件、几个战斗、几个商店。算出比例。判断玩家**多久才能遇到一次事件** |
| T513 | **卡牌之间的自然组合** | `docs/design/natural_combos.md` | 不靠核心卡，纯靠现有牌能凑出的组合（A 给灼烧 + B 消耗灼烧翻倍这种）。列出至少 15 组，每组写：需要哪两张、强度如何、容易凑吗 |
| T514 | **游戏内数字全清单** | `docs/design/all_numbers.md` | 游戏里所有关键数字的清单：几层、多少张卡、多少敌人、多少遗物、多少事件、初始血量、初始能量、抽牌数、手牌上限、商店价格区间。**每项都要写数据来源文件** |
