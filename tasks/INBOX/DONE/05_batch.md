# INBOX 05 · H01–H15（第五批：蒙特卡洛模拟，做完全部移到 DONE/）

> 前四批都是**静态分析**（读文件、列表、归类、合并）。这一批换成**动态验证**：写脚本、跑模拟、看数据。
> 允许写 Python 脚本，但**只能写到** `tools/sim/` 和 `data/sim/`。**不许改** `web/` `engine/` `cards/*.json` `DESIGN.md`。
>
> ★ **最要紧的边界声明**：你写的模拟器**不是真引擎**。它是按文档假设搭的近似模型，
> 结论必须标「估算」而不是「实测」。每份报告开头都要写清：假设了什么、近似了什么、哪些地方一定不准。
>
> ★ 如果某个模拟做不出来（数据不够、规则不清楚），**写「做不了：<具体原因>」直接跳过**，不要硬凑一个假模型。

## 任务表

| # | 任务 | 产出 | 要什么 |
|---|---|---|---|
| H01 | **抽卡加权蒙特卡洛** | `docs/design/sim_reward.md` + `tools/sim/sim_reward.py` | 按 T400 §2.3 的公式（稀有度 6/3/1 × 脉权重 1+min(持有,6)×0.25 × 擅长1.3 + 三选一硬保证），模拟 1000 次「打 20 场奖励」。统计：主脉出现率、各脉出现次数、核心卡保底触发次数。**验证目标是否落在 45~65%**。跑不到就把实际值报出来，不许调参数凑数 |
| H02 | **战斗回合数模拟** | `docs/design/sim_combat.md` + 脚本 | 用 T440 的敌人数值 + 4 能量 / 平均费 1.09 / DPS ≈15 的假设，算每层战斗平均几回合、玩家的血够撑几回合。按层给表 |
| H03 | **一局资源流模拟** | `docs/design/sim_economy.md` + 脚本 | 模拟一局（8 层？按实际层数），统计：拿到多少张牌、多少金币、多少零件、多少遗物、遇到几个事件。按 1000 局取分布（中位数 + 10%/90% 分位） |
| H04 | **卡组成型速度** | `docs/design/sim_build_speed.md` + 脚本 | 模拟「想组矿脉体系」，看第几场战斗能凑到 5 张矿牌。按各脉各跑一次（5 条脉 × 4 角色太贵就先跑 5 条脉不限角色） |
| H05 | **数值敏感度** | `docs/design/sim_sensitivity.md` + 脚本 | 敌人血量 ±10% / ±20% 时，战斗回合数和玩家承伤怎么变。找出**哪个参数最敏感**（改动它影响最大） |
| H06 | **事件期望收益** | `docs/design/sim_event_value.md` + 脚本 | 用 T441 的事件数据，算每个选项的期望价值（金币/零件/卡牌/血量统一折算成一个「价值分」）。找出期望为负的选项 |
| H07 | **遗物长期收益** | `docs/design/sim_relic_value.md` + 脚本 | 每件遗物在一局 20 场里的累计收益估算。和商店价格对比，看**性价比** |
| H08 | **常见组合期望伤害** | `docs/design/sim_combo_damage.md` + 脚本 | 挑 20 组常见两卡组合（用 T513 的清单），算单回合期望伤害。找出**效率最高和最低**的 |
| H09 | **脉象等级成长模拟** | `docs/design/sim_vein_level.md` + 脚本 | 按 T526 的规则（进生态 +1、离开 2 事件块 -1、上限 5），模拟一局玩家各脉能到几级、维持多久 |
| H10 | **决策负担量化** | `docs/design/sim_decision_load.md` + 脚本 | 每回合手牌数 × 可打出的组合数 = 决策点。算出每回合平均要比较几个选择，按角色分 |
| H11 | **初始卡组生存推演** | `docs/design/sim_starter_survival.md` + 脚本 | 四个角色的初始卡组分别打第 1~3 层，能撑几回合、第几层开始吃力 |
| H12 | **模拟器工具化** | `tools/sim/README.md` + 统一入口 | 把前 11 个脚本的共同部分抽成一个库：读数据、抽卡、算战斗、算经济。写清怎么改参数重跑。**以后改了数值只要重跑一次** |
| H13 | **反推数值调整建议** | `docs/design/sim_tuning_suggestions.md` | 用 H01–H11 的结果，列出现在**最该调的三个数值**，每个给：现状 / 建议值 / 依据（哪份模拟的哪个数字）/ 风险。**只建议，不改** |
| H14 | **整局抽卡序列模拟** | `docs/design/sim_full_run.md` + 脚本 | 模拟 200 局完整游戏：每局记录拿了哪些牌、结局（成型/散牌/死）。统计**成型率和散牌率**。这是 T400 说的「散牌局」风险的实际量化 |
| H15 | **模拟总报告** | `docs/design/_SIM_REPORT.md` | 把 H01–H14 的结论汇总成一页：哪些假设被验证、哪些被推翻、哪些做不了。开头写清所有模拟的共同局限 |

## 几条硬规矩

| # | 规矩 |
|---|---|
| 1 | 脚本必须**能重跑**，不能写死结果。参数放在文件顶部 |
| 2 | 随机模拟要**固定种子**，结果可复现 |
| 3 | 每份报告必须写「假设」和「局限」两段 |
| 4 | 数字不许拍脑袋。算不出来就写「做不了」 |
| 5 | 跑得慢的（>10 秒）就把结果落盘，别每次都重算 |
