## 设定事实（不许改）
```
苍垣：游父（气态巨行星）的岩质卫星，距游父 180 万公里，周期 21 天
潮汐锁定：一面永远朝向游父（朝向面），一面永远背向（背向面）
三重光源：昴宿（红矮星，50 天周期）+ 游父反射红渊红光 + 红渊直射
三神体系：巨神（游父）、光父（昴宿）、火母（红渊／伊格）
三国：游父王国（朝向面）、火母部落联盟（背向面）、三神城邦联盟（晨昏带）
神秘学四支：影语者（穹顶之影）、震喉使（震喉）、光导者（光蛭母）、墟语者（墟蛹）
夜游率：十分之一（**所有文明里最高**），夜游者在主流社会被恐惧、隔离、秘密利用
极少数疯先知能触及 L3，听到旧光者的模式
约 1300 年前红渊被抛出 → 光照骤降到十分之一 → 红藻死亡 → 人口从数百万跌到数万
→ 共振之底在苍垣的投射减弱 → 夜游停止 → 梦游者失去力量 → 神秘学死亡 → 第二次黑暗时代
历史事件：猎巫运动、地下学院、历法之争
```

## 这一卷要写什么

### 一、苍垣的世界
- 天空：巨大的暗红色游父圆盘（朝向面）／永恒的昴宿星光（背向面）
- 生态：赤道浅海沿岸的岩洞，渔猎采集
- 人口：数万（巅峰数百万）
- **关键意象**：他们在黑暗里等一颗不会再亮起来的小点

### 二、夜游到底经历了什么
这是这一卷的**情绪核心**：
- 红渊在的时候：十分之一的人每夜都能去红渊，那是他们的**常识**
- 红渊走了：夜游停了，梦游者失去了力量
- 现在的苍民：**记得祖先会飞，但自己不会了**

猎巫运动的真正原因不是迷信，是**嫉妒**——那些还能偶尔做梦的人，被清醒的人仇恨。

地下学院保存的是**夜游的操作手册**，但没有人能执行了。

### 三、玩法规格

> **机制：夜游（Dreamwalk）—— 双世界**
> 苍民玩家有两个身体：
> - **醒着的身体**（在苍垣）：生命低、牌弱，但**不会真的死**（醒来就没事）
> - **梦中的身体**（在红渊）：生命高、牌强，但死了会**反噬**到醒着的身体
>
> 每次进入梦境消耗「清醒度」，清醒度用完必须醒一次。
> 两个世界各有自己的牌堆（清醒牌 / 梦牌），切世时手牌清空。

这个机制让苍民和另两个职业完全不同：
- 下潜者：一次下潜，线性推进
- 震语者：一次旅程，靠记忆
- **苍民：一次梦游，随时可以醒**

再给一个可选机制（做一个就行）：**预兆（Omen）**——每回合抽 1 张"预兆"，预兆不占手牌，但会在 3 回合后变成事件（好或坏）。

## 文风
苍民的语气是**失去神迹的信徒**：
- 他们用宗教语言说日常事
- 他们对红渊有乡愁（叫它"伊格"或"火母"）
- 例：`火母走了三百年。母亲说她会回来，母亲也走了。`

**不许**写成"原始部落的野蛮人"。他们是**文明倒退者**，不是未开化者。
