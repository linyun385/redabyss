# T280 素材三方对账

## 实测问题
素材有三处真相：`data/art_catalog.json`（清单）、`web/assets/art/`（磁盘）、`web/index.html`（引擎实际引用的 id）。没人核过三者是否一致。

## 目标
四方对账，找出「清单有磁盘无」「磁盘有清单无」「引擎引用了不存在的 id」。

## 做法（按优先级）
1. 用脚本抽出三处的 id 集合（引擎那边 grep 图片路径）
2. 求差集，四类各列一表
3. 再统计每个 id 的文件大小，找出 0 字节或过小的可疑文件

## 禁止
不许删任何文件。

## 验收
| # | 指标 | 门槛 |
|---|---|---|
| 1 | 四类差集 | 都有数量且为 0 或列全 |
| 2 | 可疑小文件 | 阈值自己定并说明 |
| 3 | 脚本一起交 | `tools/_art_reconcile.py` |

## 交付
`docs/art/ART_RECONCILE.md` + `tools/_art_reconcile.py`
