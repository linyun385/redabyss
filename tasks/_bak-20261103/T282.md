# T282 全 docs 漂移扫描

## 实测问题
`docs/` 有 60 多份文档，里面大量写着「当前 320KB」「88 个敌人」「生图 422 秒/张」这类数字，早就过期了。新人读了会被误导。

## 目标
扫出文档里所有可核验的数字与路径，与当前实际值比对，产出漂移清单。

## 做法（按优先级）
1. 写脚本抽取 docs 里的数字陈述（带单位的）与文件路径引用
2. 逐个核：路径是否存在、数字是否与当前数据一致
3. 按「已过期 / 路径失效 / 无法核验」三类列表，每个给出当前真值

## 禁止
不许直接改文档（改文档是另一件事）。不要试图全量精读，用正则抽。

## 验收
| # | 指标 | 门槛 |
|---|---|---|
| 1 | 覆盖 | `docs/*.md` 全部扫过 |
| 2 | 三类清单 | 每条带当前真值 |
| 3 | 脚本一起交 | `tools/_doc_drift.py` |

## 交付
`docs/DOC_DRIFT.md` + `tools/_doc_drift.py`
