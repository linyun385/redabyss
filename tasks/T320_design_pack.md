**产出**：`docs/design/T320_MECHANISMS.md`

## 二、T321 冗余诊断（这一篇最重要）

**产出**：`docs/design/T321_REDUNDANCY.md`

找出「**换了名字的同一张牌**」。

必须给出三类清单，每类都要具体 id：

### A. 效果完全重复

两张卡效果字段一模一样（或只差数值），只是名字和正文不同。
→ 列成对：`dive_00XX` ↔ `dive_00YY`，说明差在哪（只有伤害值不同？还是真的一样？）

### B. 功能重复（效果不同但打出来感觉一样）

比如都是「造成伤害 + 抽一张」，只是费用不同。
→ 判断标准：**如果玩家在两局里互换这两张牌，会发现打法没变**。按这个标准找。

### C. 升级版没有质变

`upgrade` 字段只加了数值、没改机制的卡。列出**所有**只加数值的升级。
（这类卡升级前后玩法一样，是"假升级"）

最后给一个结论：**266 张卡里，实际有多少张是不可替代的？** 给数字。

## 三、T322 单调性诊断与方向建议

**产出**：`docs/design/T322_MONOTONY.md`

### 第一部分：诊断

不要重复 T320 的数字，而是要回答 **「为什么单调」**。可能的答案不止一个：

- 是不是**缺少交互类型**？（现在只有「我打它」「我挡」「我抽」—— 没有"改变敌人的意图""窃取敌人的行动""改变牌的归属""延迟生效"这类）
- 是不是**状态效果太薄**？（22 种机制里，状态只有 strength/dexterity/weak/frail/poison/burn/thorns 七种，且用量都不大）
- 是不是**资源只有两种**（能量、共振）？
- 是不是**每张卡的决策都是"打不打"，没有"什么时候打"**（延迟、蓄力、反制）

**每条判断都要能指到具体的卡或机制。**

### 第二部分：方向建议

给出 **5 到 8 个**可行的新机制方向。每个方向必须写明：

| 项 | 要求 |
|---|---|
| 机制名 | 中文，符合世界观（地底、倒吊、红光、矿工） |
| 一句话规则 | 能用一句话说清，玩家看一遍就懂 |
| 它解决上面哪条诊断 | 对应第一部分的具体问题 |
| 该加在哪个职业 | 哪个职业最需要，为什么 |
| 与现有机制怎么互动 | 至少说清新机制跟「共振」或「凝视」怎么咬合 |
| 落地形态 | 说清它对应 effect 里的什么结构（能写成 json 最好） |
| 风险 | 这个机制最容易出的问题（数值失控？理解成本高？跟某张卡冲突？） |

**不许给"加强 xx 属性"这种建议** —— 那不算新机制。

## 四、T323 规则说明书（从代码提取，不是抄文档）

**产出**：`docs/design/T323_RULES.md`

`docs/` 里有 `BALANCE.md`、`FEEL.md`、`ENDINGS.md` 一堆文档，但**文档可能过时**。
这一篇要的是**代码里实际生效的规则**。

必须覆盖（每条都要给 `[文件:行号]`）：

1. **一局的结构**：地图怎么生成、8 层怎么走、什么条件进下一层
2. **战斗流程**：回合怎么开始、能量怎么给、牌怎么抽、手牌上限、弃牌、洗牌
3. **能量与费用**：卡的费用是怎么算的（有没有动态费用）
4. **共振是什么**：怎么涨、怎么花、跨阈值会发生什么
5. **凝视是什么**：怎么涨、有什么后果、跟结局的关系
6. **脉（veins）系统**：脉是什么、连击怎么算、有什么加成
7. **代价类型**：`cost_type` 有几种（vitality / none / …），各自什么后果
8. **升级**：卡怎么升级、升级改什么
9. **遗物怎么触发**：`effect_code` 里的 trigger 有哪几种
10. **战斗结束与结算**

写法：**先给一张总表（规则 → 代码位置），再逐条展开**。看不懂的代码写「没看懂」，不许猜。
