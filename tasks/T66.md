# T66 素材生产管线与样张（生图，不含全量接入）

## 前置事实（2026-10-30 实测，别重复踩）
- **ComfyUI 不可用**：`D:\ComfyUI` 是 10-29 master，新依赖 `comfy-kitchen` 在 torch 2.6 上崩（torch.fx 不认 `list[int]`）。**不要试图修它**。
- 可用管线：`tools/gen_art_diffusers.py`（diffusers + 盘上 SDXL 单文件）
  - 768×1152 / 20 步 ≈ **60 秒/张**（关 attention slicing）；832×1216/25 步会爆到 9.8GB 显存，慢到 10 分钟/张
  - 必须设 `HF_ENDPOINT=https://hf-mirror.com`（直连 HF 超时）
- 风格 LoRA：`D:\ai_lora\out\cultsim_sdxl_v1.safetensors`（本地训练，**不入项目、不发布**）。强度控制有 bug（`--lora-scale` 未生效），本任务**先不用 LoRA**也可以用。
- 风格结论见 `docs/REF_CULTIST_CLASSIFY.md`（**重要：不是木刻**）
  - 玩法卡语言 C：米白纸面 + 扁平小插画 + 硬边 + 1–3 色
  - 象征卡语言 B：黑底 + 单一高饱和色符号 + 颗粒噪点
  - 塔罗语言 A：黑框 + 罗马数字 + 暗色绘景（只给结局/神祇用）

## 目标
产出**能过闸门**的样张与批量管线；本任务**不接进游戏数据**（接入留给 T67）。

## 产出 1：tools/art_manifest.json（素材清单）
按 T60 口径 B 的生态枚举，列出要生成的东西：
- 卡面图案：每生态 6 张（共 8 生态 = 48 张），命名 `eco/<eco>/<三位序号>_<英文短名>.webp`
- 敌人图形：每生态 3 张（共 24），语言 B
- 职业立绘：4 张，语言 C
- 结局插画：3 张，语言 A（黑框 + 数字位）
每条含：`out / eco / lang(B|C|A) / prompt / negative / size / seed`

## 产出 2：tools/gen_art_batch.py
- 读清单，逐张调 diffusers 管线；**断点续跑**（已存在的跳过）
- 失败重试 1 次，仍失败记录到 `tools/art_failed.json` 并继续
- 记录每张耗时与显存峰值到 `tools/art_run.json`

## 产出 3：tools/art_similarity.py（版权闸门）
- 把生成的图与用户提供的 25 张密教参考图（只读、不复制进项目）做感知哈希（dHash/pHash）比对
- 输出相似度排名；**阈值写死**（建议汉明距离 ≤ 6 视为过近 → 弃用并重新生成，换 seed）
- 报告里写清阈值依据与命中数

## 产出 4：docs/ART_PROMPTS_V2.md
- 按语言 B/C/A 各给一套**可复制**的 prompt 模板（前缀/对象/后缀/负面），并写 3 条反面例子（会画崩的写法）
- 记录 T44 那个坑：风格前缀放最前会把内容带跑，对象要写在前面

## 验收
- 先出**样张 10 张**（B×4、C×4、A×2），交给用户看
- 相似度闸门跑通，命中数写进报告
- 耗时与显存数字落盘（`art_run.json`）
- 三检查器全绿（本任务不动 web/）
