# T68 素材接线体检（catalog↔文件↔web 三方对账）

## 实测问题
461 张图分三处登记：`data/art_catalog.json`（生成侧目录 461 id）、`web/assets/art/`（成品文件 607 个 webp）、`web/index.html` 的 ART 表/引用（79 个运行时 id）。三方从未做过一致性对账，断链会让游戏里出现空卡面（T67 只做了加载失败回落，没做接线体检）；另有一批历史命名遗留文件（card_zh* 系列、anm_0011.old）从未盘点。

## 目标
三方全量对账，断链清单落盘；断链率归零，或给出逐条修复清单。

## 做法
1. 写 `tools/_audit_art_links.py`：python 脚本对账
   `data/art_catalog.json` 的 id ↔ `web/assets/art/<id>.webp` ↔ `web/index.html` 中该 id 的引用（ART 表 key / 正文任意字面出现）。
   - 三方各建集合，输出「缺失（登记无文件）/ 多余（文件无登记）/ 断链」三类清单
   - 引用判定从宽：id 字符串出现在 ART 表段或正文任意位置即算引用，宁可宽判不误报；判定口径写进报告
   - 目录 id 重复、ART 表值路径错位也一并核查
2. 不许改 `web/` 与 `art/`：发现断链只记录不修。
3. 产出报告 `docs/ART_LINK_AUDIT.md`（数量、断链清单、判定口径、结论），脚本可重跑刷新。

## 禁止
- 不许改 `web/assets/art/` 里的成品图；不许删任何文件
- 要改任何现有文件先在旁边留 `.bak`（本任务理想情况下零改动）
