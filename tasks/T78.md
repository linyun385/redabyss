# T78 开始界面重构（只给卡面 → 点开详情 → 确认开局）

## 用户原话（2026-10-31 19:30）
> 「这个开始界面这里，人物可以设计成只有卡面，点开后会有详情（左卡面右详情这种）然后你要点确认才可以开始」

## 现状
开始页四张职业卡**卡面 + 大段描述 + 数值**全铺开，一屏信息过载；点一下就直接开局，没有确认。

## 改成两步
### 第一步：只显示卡面
- 四张**纯卡面**（立绘图 + 职业名 3–4 字），**不显示**描述、生命、偏重、专属
- 卡面统一比例（建议 3:4），悬停轻微上浮 + 边框亮起
- 顶部保留标题与一句引导（沿用现有文案）

### 第二步：点开详情（模态）
- **左卡面（大）+ 右详情**（两栏，1280×720 下左 40% / 右 60%）
- 右栏内容固定顺序：职业名 → 一句话身份 → 初始生命 / 偏重脉 / 专属 → 核心机制 2–3 条 → 「以此身份下潜」按钮
- 关闭：× / Esc / 点遮罩 → 回到卡面选择（不丢失选择）
- **必须点「以此身份下潜」才真正开局**；在卡面页点一下只是打开详情

### 可访问性
- 卡面与按钮可键盘操作（Tab 聚焦、Enter 确认、Esc 关闭）
- 卡面 `<img>`/背景图走 `assets/class/<id>.webp`（相对路径，不许内联）
