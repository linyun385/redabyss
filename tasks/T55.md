# T55 地图生成器原型（纯算法 + 可视化调试，先不接游戏）

## 已确认前提（2026-10-30 18:35）
- 生成器只产 band 与 crossBand 标记，**不产 boss 节点**（boss 由运行时替换产生）。
- 不变量按整张大图的 8 个深度带校验。


## 先读
`docs/MAPGEN_DESIGN.md`（T54 产出）、`tools/mapgen_spec.json`。

## 目标
把设计实现成**不依赖 DOM、可 node 直接跑**的生成器，并用一个调试页把它画出来。
**本任务不接游戏**（不改 `web/index.html`），先在离线环境把地图生成正确。

## 产出 1：tools/mapgen.js（纯 JS，无 DOM 依赖）
- 导出 `generate(seed, params) → Region`，与设计文档的数据模型一致
- 确定性：**同一 seed + 同参数 → 完全相同的 Region**（自己实现 PRNG，如 mulberry32，不许用 Math.random）
- 生成后自动 `validate(region) → {ok, errors[]}`，实现 T54 的全部不变量
- 失败则按设计重试（上限 20 次），仍失败抛错并附原因

## 产出 2：tools/mapgen_test.js（命令行断言）
- 跑 200 个 seed，逐个 validate，输出通过率与失败原因分布
- 额外统计并打印：平均节点数、每带节点数、分叉度分布、平均边长、最长最短路径、`finalBoss` 唯一性
- **要求 200/200 通过**才算完成；不允许「大部分通过」就交

## 产出 3：tools/mapgen_debug.html（可视化）
- 读 `mapgen.js`，用 SVG 画：生态色块（底）、深度线、节点（按 type 形状/颜色区分）、连线（带角度）
- 控件：seed 输入、节点数、生态聚合度滑块、「重新生成」按钮、雾层开关
- 显示校验结果（绿/红）与统计数字
- 单文件、无外部资源（本地直接 open 即可；不要求进游戏）

## 硬约束
- 不许用 `Math.random`（要可复现）
- 不许改 `web/`、`engine/`、数据文件
- 生成 100 张图 < 2 秒（node 上测，写进报告）

## 验收
- `node tools/mapgen_test.js` → 200/200 通过，打印统计
- 浏览器打开 `tools/mapgen_debug.html`：换 seed 出不同图；同一 seed 刷新出同一张图
- 100 张图耗时数字写进报告
