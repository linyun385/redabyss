# T21 黯民 DLC 验收

## 目标
黯民 DLC 整体验收，写 `docs/dlc/DLC_ANMIN_VERIFY.md`。

## 步骤

### 1. 三个检查器
```powershell
node tools\pack_check.js all
node tools\test_engine.js
node tools\check_web.js
```

### 2. 内容量核对
| 项 | 要求 |
|---|---|
| 卡牌 | ≥ 50 张，三条流派各 ≥ 12 张 |
| 敌人 | ≥ 16 个 |
| 遗物 | ≥ 15 个 |
| 事件 | ≥ 10 个 |
| 协议 | 3 种，各有明显副作用 |
| 设定文档 | ≥ 4000 字 |

### 3. 三局实测（黯民）
| 局 | 侧重 | 记录 |
|---|---|---|
| 1 | 只用改造，不拆解 | 到达层数 |
| 2 | 大量拆解（堆威胁等级） | 到达层数 + 是否被反噬 |
| 3 | 每场都用协议 | 哪条协议最强 |

### 4. 横向对比（重要）
黯民和另外两个职业比，**是不是真的不一样**？写清楚：
- 三职业的核心决策点分别是什么
- 黯民有没有变成"换皮的震语者"
- 如果像，问题出在哪

### 5. 文风抽查
抽 5 张黯民卡牌 + 3 个事件，问：
- 有没有"官僚/工程术语描述恐怖"的味道？
- 有没有和另外两个职业重复的句式？
