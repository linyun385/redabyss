# 红渊：下潜

一个卡牌构筑游戏。你在往一颗星球的核心走。

## 怎么玩

双击 `web/index.html`。不需要联网，不需要安装。

选一个职业，往下走。八层。地图每层是岔路：战斗拿卡，精英拿遗物，商店花金币，营火回血或升级，事件赌运气。走到第八层的核心，或者死在半路——死在这里是常事。

## 操作

- **鼠标**：点手牌出牌（要选目标的牌会提示你点敌人），点「结束回合」换敌人行动；地图上点发光的节点前进。右下角 `?` 随时能看一页机制速查。
- **键盘**：数字键 1–9 出对应手牌，Enter 或 E 结束回合，W 入梦（仅疯先知），Esc 关闭弹窗；地图上方向键移动、Enter 前进。
- 右上角「文- / 文+」调字号，「素」切低饱和显示（减轻红光刺激）。
- **材质主题**（可选）：控制台执行 `document.documentElement.dataset.theme = 'B'`（或 `'C'`）切换密教纸面风；`'off'` 或删除该值恢复默认。三种候选的指标与截图见 `docs/ART_STYLE_MATRIX.md`。

## 四个职业

- **下潜者**——殖民者。签了死亡合同下来的，靠仪器和常识活着。
- **震语者**——渊民。震台城邦的记忆者学徒。什么都知道，但什么都不能说。
- **疯先知**——苍民。一千三百年来第一批重新梦见伊格的人。城里人叫你疯先知，你没有纠正。
- **维护者**——黯民。登记在册的维护者，和按时来的机械互为彼此唯一的供应商。

## 它是怎么来的

地表之下有一颗星球，它的名字没人记得了，去的人都只叫它红渊。

红渊不是空的。它在往下渗，渗进岩层、矿脉、水和人的睡梦里。上面的人拿它没办法，就签合同——一层一层往下递人，去看清楚它到底是什么。合同第三条写着：不保证返程。

你签的是同一份。区别只是，这次往下走的是你。

红渊会看着你。你走得越深，它看得越清楚。被它看着的东西会变强，也会变得不像自己。到了核心，它怎么对待你，取决于你这一路上被它看了多少。
